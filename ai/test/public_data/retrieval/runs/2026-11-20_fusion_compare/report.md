# 채널 결합 방식 비교 (개발용)

라벨 `labels_llm_v7`, 명세 `query_spec_v2`. 외부 API 호출 0. 채널 후보(dense·BM25 상위 100), 가중치 0.5/0.5, 조건 필터, 채점은 고정하고 결합 방식만 바꿨다. `rrf60`가 파일럿 1 hybrid를 58/58 재현.

**개발용 결과다.** 같은 58문항으로 설정을 고르므로, 운영에 반영하기 전에 별도 질문으로 확인해야 한다.

- `rrf20`, `rrf5`: RRF k를 줄인 것(각 채널 상위를 더 강하게 우대). `interleave`: 두 채널 순위를 번갈아 합침. `protect3+rrf60`: 각 채널 상위 3개를 먼저 두고 나머지는 RRF k 60.

| 방식 | 2점 MRR@5 | nDCG@5(등급) | 2점 R@10 | P@10(1점 이상) | judged@10 | 미판정@10 합 |

| rrf60 | 0.559 | 0.609 | 0.769 | 0.528 | 0.962 | 0 |
| rrf20 | 0.602 | 0.643 | 0.795 | 0.536 | 0.964 | 0 |

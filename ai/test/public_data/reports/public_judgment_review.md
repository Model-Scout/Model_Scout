## 현재 상태

- 58개 질의 × 12개 후보 = 696행을 검토했다. 2점 103행 / 1점 221행 / 0점 346행 / ? 26행.

- 판정 근거는 워크시트에 저장된 카드 정보다. 외부 페이지·실제 API 응답·현재 갱신 상태를 전수 검증한 결과가 아니다.

## 판정 시 적용한 경계 기준

- 주제어만 같은 통계·시설 목록은 정답으로 삼지 않는다. 예: 주차장 정기권 판매량, 어린이집 보육통계, 화장실 수, 층간소음 원인 집계.
- 실시간은 API라는 이유만으로 인정하지 않는다. 정적 마스터·과거 이용량·시간표·최종확정 파일은 실제 현재값과 다르다.
- API가 명시적으로 금지된 p025·p051, 파일이 필수인 p052, 파일 업로드가 명시적으로 금지된 p055는 반대 방식만 제공하면 0 wrong_delivery다. p024의 API 선호에 파일 대안은 기존 README의 부분 답안 규칙대로 1로 표시했다.
- p026은 일반 상업 이용뿐 아니라 공공누리 제1유형만 요구한다. 제한없음은 비상업 라이선스라는 뜻이 아니지만, 제1유형 표기 요구와는 다르므로 0 license와 구체적인 설명을 남겼다. 라이선스 공란은 ?로 남겼다.
- p053·p054의 일반 상업 조건에서는 제한없음 또는 제1유형 표기를 근거로 판정하고 라이선스 공란은 ?로 남겼다.
- 지역명이 없는 카드의 전국 표시는 믿지 않고 실제 설명의 경기도·수원·대구 등 범위를 확인했다. 지역 사본 개수만으로 전체 전국을 덮는다고 가정하지 않았다.
- 여러 항목이 필요한 서비스 아이디어는 한 후보가 일부만 주면 1점이다. 후보 여러 개를 합쳐 쓰는 경우의 항목 coverage는 현재 평가기가 별도로 측정하지 않는다.

## 다음 활용 순서

1. CSV에서 ?와 1점을 우선 필터링해 원문·사용 목적을 사람이 재확인한다. 수정 사항은 먼저 CSV에 반영한다.
2. ai 디렉터리에서 `python test/public_data/judging.py import`로 평가용 라벨을 다시 생성한다.
3. 임베딩·인덱스가 준비된 환경에서 `python 22_eval_recommendations.py --public --unjudged-out test/public_data/reports/unjudged.jsonl`로 평가한다. 이번 작업에서는 추천 성능 평가는 실행하지 않았다.
4. `python test/public_data/judging.py extend test/public_data/reports/unjudged.jsonl`로 새 미판정 후보만 추가해 2차 판정한다.
5. P@10·nDCG@10만 보지 말고 judged@10, raw/condensed 차이, must_exclude 위반을 함께 확인한다.

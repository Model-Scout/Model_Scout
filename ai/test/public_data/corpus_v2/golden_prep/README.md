## 자동 검사와 제안 규칙

필수 조건을 먼저 판단하고, 그다음에 주제를 본다.

| 조건 | 충족 | 부분 | 불충족 | 미확인 |
|---|---|---|---|---|
| 지역 (요청 지역 있음) | 제목에 그 지역 | 전국 데이터 | 제목에 다른 지역 | 추정(기관 소재지 등)으로만 일치하거나 다름, 범위 미확인 |
| 상업 이용 | 상업 가능 | – | 비상업(2·4유형·비영리) | 조건부·라이선스 미확인 |
| 공공누리 1유형만 (p026) | 문구가 1유형 | – | 그 밖의 모든 문구 ("제한 없음", 제3자 권리 포함, 다른 유형) | 문구 없음 |
| API 필수 | API 있음 | – | 파일만 | 제공 방식 미확인 |
| 파일 필수 | 파일 있음 | – | API만 | 제공 방식 미확인 |
| 실시간 | – | – | – | 항상 미확인. 포털 갱신 주기 표기는 근거로 쓰지 않고, 현재값 단서 필드만 근거로 적는다 |
| 자치구·언어·기간·공간 단위 (새 질의) | 표시가 요청과 같음 | – | 표시가 다름 | 표시 없음. 서울 전체판이나 한국어판으로 단정하지 않음 |

**지역을 말하지 않은 질문**에는 조건 검사를 하지 않는다. 데이터 범위는 `region_scope`("목적 판단")로만 붙인다. 이 값은 점수를 올리거나 내리지 않고, 판정자가 질문 목적에 비춰 정한다.

제안 순서는 이렇다.

1. 불충족이 있으면 `0 후보 (사유)`
2. 요구 항목 단어가 하나도 없으면 `0 off_topic 또는 보류`
3. 미확인이 하나라도 있으면 `보류 (확인 필요: …)`. 필드 목록이 없는 카드에서 요구 항목 단어가 일부만 보여도 보류로 둔다. 카드가 짧은 것일 뿐 빠졌다는 근거가 아니기 때문이다
4. 부분 조건이 있거나, 필드 목록으로 빠진 요구 항목이 확인되면 `1 후보 (부분 적합)`
5. 나머지는 `2 후보`

정보가 부족하면 1점을 제안하지 않는다. 주제 판단은 단어 일치일 뿐이라 의미 판정을 대신하지 않는다.

## 검색 방식 두 가지

두 방식은 같은 질문 임베딩과 같은 골든 필터를 쓴다. 차이는 키워드·개념뿐이다. 질의별로 실제로 넘긴 값은 `prelim_summary.json`의 `search_settings.per_query`에 있다.

| | question_only | pool_terms |
|---|---|---|
| 질의 벡터 | 원문 질문 임베딩 | 원문 질문 임베딩 |
| `commercial_only` | 골든 `conditions.commercial` | 골든 `conditions.commercial` |
| `roles` | `["service"]` | `["service"]` |
| 개념·키워드 | 없음 | 라벨 `dataset_terms`(= `pool_terms`) + `conditions.region` |
| 랭커에 넘기지 않는 조건 | delivery, realtime, p026 1유형 | 같음 |

**`pool_terms`가 평가 입력으로 들어가는 경로**

1. `build_public_pool.py`는 `pool_terms`로 판정할 후보 12개를 고른다. 이 파일은 "점수에는 쓰지 않는다"고 적어 두었다.
2. `judging.py`의 `to_label`이 질의의 `pool_terms`를 라벨의 `dataset_terms`로 복사한다.
3. `22_eval_recommendations._public_top`이 여기에 지역 조건을 더해 키워드와 개념으로 넘긴다.

판정 후보를 고른 단어가 평가 순위에도 들어가는 순환이다. 서비스(`17_recommend_graph.py`)는 LLM 계획이 만든 단어와 다시 쓴 문장을 쓰므로, 이 단어를 받지 않는다.

### 표본 판정 (24행, judge `claude-pilot`)

출처와 조건 종류별로 고르게 뽑았다. 출처는 보류·우선순위 높음·새 후보, 조건은 1유형·제공 방식·실시간·상업·지역·목적 판단이다. 판정용 근거만 보고 판정한 뒤 자동 검사와 대조했다.

- **기준 검사** (`review_batch.py validate`): 위반 0, 확인 필요 0
- **판정 분포**: 2점 1, 1점 12, 0점 9, `?` 2
- **일관성**: 비슷한 경우에 같은 판단을 했다.

| 경우 | 판정 |
|---|---|
| 질문 목적이 넓은데 한 지역·한 시장 데이터 (p019, p021, p031, p050, p053, p054 경기) | 모두 1점, 빠진 범위를 `note`에 적음 |

| 다른 지역 (p032) | 0 `wrong_region` |

| p026 "제한 없음" | 0 `license` |
| 실시간 질의 | 제목·필드·설명으로 결정. "월별 평균"은 0점, 설명에 실시간 경락이 있으면 실시간으로 봄 |

## 제안 질의 14개

- **선택 편향:** v2에 해당 판이 있다는 걸 알고 고른 질의라 v1 대비 v2에 유리하다. 기존 58개와 섞지 말고 따로 보고한다. v1에서도 별도 데이터였던 l2·l3·l4·y2를 대조군으로 쓴다.
- 지금 질의 형식에는 자치구·언어·기간·공간 단위 칸이 없어서 `conditions_extension`에 제안만 했다. 0점 사유(`wrong_language`, `wrong_period`, `wrong_spatial_unit`)도 함께 정해야 한다.

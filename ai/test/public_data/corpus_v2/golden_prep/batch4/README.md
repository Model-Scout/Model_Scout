>
> | | 이 폴더의 v5 초안 | 팀원 기준 라벨 v5 |
> |---|---|---|
> | 파일 | `batch4/labels_llm_v5.jsonl` (sha256 `201712dd…`) | `batch3/labels_llm_v5.jsonl` (sha256 `c1708cd4…`) |

> 두 판정 사이에 겹치는 쌍은 없다. 이 폴더의 판정을 팀 v5에 합치는 작업은 골든셋을 정리할 때 별도로 한다.

- **만든 시점과 기준:**
  - 2026-11-13에 v2 `documents_id f2fd56aad2b61b41`(내용은 `37026bd2`와 같음)로 v1·v2를 검색해, 양쪽 상위 10에서 v4 라벨에 없던 후보 179쌍을 모았다.
  - 그중 보류 5쌍을 뺀 174쌍을 판정했다.
  - 후보는 최신 고정본 `data_version 04239c20eb394c12`의 검색 결과가 아니다.
- **판정:**
  - 카드(v2 보완본 기준 사실과 자동 검사)만 보고 한 LLM 1차 판정(`llm_first_pass`)이다. 공식 페이지는 열지 않았다.
  - 분포: 2점 4, 1점 44, 0점 123, 보류 3. 검사기 위반 0, 경고 0
- **보류:** p023 `15142031`(정류장 좌표 여부), p041 Kaggle 유튜브 2건(조회수·댓글 항목 여부)
- **폴더 이름:** 처음 만들 때는 `batch3`였으나, 팀원이 같은 이름으로 batch3을 만들어 `batch4`로 옮겼다. 내용은 같고, `labels_llm_v5.meta.json`의 경로만 batch4로 고쳤다.
- **최신 고정본과의 차이:** 이후 정제 보완(엑셀 형식 구분, 서울 공식 설명, 표준데이터 기관, 삭제 5건 제외)으로 카드 내용이 바뀐 데이터가 있다. 이 판정을 기준 라벨에 합치기 전에, 형식·설명이 판정 근거였던 쌍은 다시 확인해야 한다.

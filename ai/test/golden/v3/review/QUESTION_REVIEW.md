# 골든셋 v3 질문 검수표

질문 품질은 기계가 완전히 판정할 수 없다. 아래 여덟 항목을 질문마다 확인하고 문제가 있으면 `queries.py` 에서 질문을 고친 뒤 `build_drafts.py` 를 다시 돌린다. '기계 힌트'는 확인이 필요한 신호일 뿐 판정이 아니다.

점검 항목: 1) 실제로 물을 법함 · 2) 필터 나열 아님 · 3) 목적 이해됨 · 4) 숨은 조건 없음 · 5) 극단적이지 않음 · 6) 불필요한 모델명 없음 · 7) 표현 스타일 적절 · 8) 문형 반복 아님

자동으로 이미 확인된 것: 숨은 조건(모든 조건에 질문 속 근거 표현 존재), abstention 극단성, 유형별 10개.

# 공공임대주택 단지정보 조회 서비스

한국토지주택공사에서 관리하는 공공임대주택의 단지 정보를 제공하는 API 입니다. 광역시도 코드와 시군구 코드 등의 요청 파라미터를 통해 단지 정보를 조회할 수 있습니다. 자세한 활용 방법 및 요청/응답 메세지 예제는 OPEN API 활용 가이드를, 광역시도 코드 및 시군구 코드에 해당하는 지역명은 요청 파라미터 코드를 참고해주시길 바랍니다. 본 API는 인증키 오류를 개선하여 '국토교통부_마이홈포털 공공임대주택 단지정보 조회 서비스'로 제공 중에 있으므로 참고해주시길 바랍니다.

제공기관: 한국토지주택공사
분류: 국토관리

# 한국국제협력단_파견지 통합 정보_20220321

KOICA의 해외봉사단 파견지와 관련된 정보를 통합적으로 제공하는 API입니다. 파견국가별 활동지 위치, 주요 사업, 협력기관, 생활 환경 등 파견과 관련된 정보를 종합 제공하며, 사전 파견 준비, 체류 중 지원 체계 수립, 지역 리스크 평가 등에 활용됩니다. 해당 API는 인증키(serviceKey), 페이지 번호(pageNo), 한 페이지 결과 수(numOfRows) 등 기본적인 요청변수를 사용하며 한글 국가명, ISO 2자리코드, 파견기관명 등의 필터 파라미터를 추가로 설정할 수 있습니다. 출력결과에는 국가명, 파견기관명, 파견기관 주소, 자살 사망률, 깨끗한 음용수 사용 비율, 결핵 10만명 당 발병률, 고용률, 실업률 등의 항목이 포함되며, 각 항목에 대한 데이터는 XML 형식과 JSON 형식으로 반환됩니다.

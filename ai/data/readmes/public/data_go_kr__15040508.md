# 부산 마을버스 운행 현황 정보 서비스

부산시 16개 구군에서 운행중인 마을버스 운행 현황 데이터를 개방합니다. 마을버스는 일반적으로 도시 내 주요 교통 노선이 닿지 않는 주거 지역이나 외곽 지역을 연결해주는 소형 대중교통 수단입니다. 주로 짧은 거리를 운행하며, 주민들의 일상생활에 밀접하게 연결된 교통수단으로 사용되고 있습니다. 짧은 노선, 소형, 저렴한 요금, 지역기반 운영등의 특징을 가지고 있습니다. 개방되는 데이터는 노선번호, 업체명, 기점, 경유, 종점 정보와 버스회사 전화번호, 운행차량수, 운행거리, 첫차/막차 시간, 배차간격과 대상별 버스요금(카드/현금) 데이터가 포함되어 있습니다.

제공기관: 부산광역시
분류: 교통물류
키워드: 골목, 노선, 운행, 구석, 좁은길, 소형
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-05-28
이용허락: 이용허락범위 제한 없음

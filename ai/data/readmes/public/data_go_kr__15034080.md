# 해수욕장 수질 정보 서비스

여름 휴가철 많은 관광객이 찾아와 휴가를 즐기는 부산의 대표 관광휴양지인 광안리, 다대포, 송도, 송정, 일광, 임랑, 해운대 등 7개 해수욕장의 해수를 채취하여 수질 검사한 데이터를 개방합니다. 광안리 5, 다대포 3, 송도 3, 송정 5, 일광 3, 임랑 3, 해운대 5개 지점에서 해수를 채취하여 해수욕장 개장전, 개장중, 폐장 후 등의 수질 측정 데이터를 개방합니다. 개방된 데이터는 측정연월일, 측정횟수, 측정지점, 장구균 측정값, 대장균 측정값, 수질평가 자료 등의 데이터가 포함되어 있습니니다. 검사 결과 장구균, 대장균의 검출량에 따라 적합/부적합 여부를 판정하여 해수욕장 이용에 참고자료로 사용할 수 있습니다.

제공기관: 부산광역시
분류: 환경기상
키워드: 오염, 관광, 휴가, 대장균, 측정, 표본
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-05-21
이용허락: 이용허락범위 제한 없음

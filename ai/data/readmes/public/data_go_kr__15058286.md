# 환경관리 인허가 대상등록 신청 현황

이 데이터는 경기도 북부지역에서 환경오염물질 배출시설에 대한 방지시설의 설계 및 시공을 수행하는 환경전문공사업체의 등록 현황을 제공합니다. 주요 항목은 사업장명, 업종구분명, 대표자명, 전화번호, 소재지 주소, 관할기관명, 대기·수질·악취·소음·실내공기 등 분야별 등록 여부, 위경도 좌표 등으로 구성되어 있으며, 환경설비 시공업체의 지역 분포 및 기술영역 분석에 활용할 수 있습니다. 해당 데이터는 현재 중복된 데이터로 인해 갱신이 중단되었으며, 최신 현황은 별도로 제공되는 ‘환경 전문공사업체 현황’ 데이터셋을 참조해야 합니다. 데이터는 Open API 형식으로 제공되며, 대기환경개선, 수질개선 정책 수립, 환경관리대상 사업장 현황 파악 등 환경행정 및 정책 연구에 활용될 수 있습니다.

제공기관: 경기도
분류: 환경기상
키워드: 환경전문공사업, 오염물질방지시설, 대기오염, 수질오염, 사업장정보, 업종구분, 등록현황, 공공데이터
형식: api

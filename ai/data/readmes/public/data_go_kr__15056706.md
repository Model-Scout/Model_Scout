# 서울특별시 One-PMIS 주간작업내용

해당 데이터는 서울특별시 One-PMIS의 주간보고에 등록된 작업내용 OpenAPI입니다. 데이터의 원본 시스템은 서울특별시 도시기반시설본부 One-PMIS시스템입니다. 요청인자 : 인증키, 요청파일타입, 서비스명, 요청시작위치, 요청종료위치, 사업코드 출력값 : 총 데이터 건수(정상조회 시 출력됨), 요청결과 코드, 요청결과 메시지, 순번, 사업코드, 사업명, 당기정보 기간, 당기정보 내용, 차기정보 기간, 차기정보 내용 ※ 바로가기 링크 클릭 시 서울 열린데이터광장 개방 데이터로 이동합니다.

제공기관: 서울특별시
분류: 국토관리
키워드: 건설, 시설, 공사, 주간작업, 주간보고
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-07-07
이용허락: 제3자 권리 포함 : 저작권 표시, 공공저작물 : 출처표시 (제 1유형)

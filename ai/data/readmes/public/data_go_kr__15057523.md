# 시행일 법령 본문 조회

법제처에서 제공하는 시행일 기준 법령 본문 조회 서비스 데이터입니다. 특정 시행일에 효력이 발생한 법령의 본문 내용을 조문 단위로 상세히 제공합니다. 본문 항목에는 조문번호, 조문제목, 조문내용, 개정·폐지 이력, 법령코드, 시행일자 정보 등이 포함되어 있습니다. 법령코드, 시행일자, 조문번호 등의 파라미터를 통해 원하는 시점의 법령 본문을 조회할 수 있도록 구성되어 있습니다. 응답에는 총 결과 수, 페이지 정보 및 개별 조문 상세 링크가 포함되어 있어 원하는 범위의 본문을 체계적으로 확인할 수 있습니다. 이 데이터를 활용하면 특정 시점 법령 상태 분석, 법제도 정합성 점검, 법률 시스템 데이터 구축 등에 유용합니다. 또한 모바일 애플리케이션이나 웹서비스에서 시행일 기준 법령 제공 기능 구현 및 조문별 검색 기능 강화 등을 위한 핵심 자료로 적합합니다.

분류: 공공행정

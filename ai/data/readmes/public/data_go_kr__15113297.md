# 중소벤처기업부_사업공고

중소벤처기업부 사업공고 데이터는 중소벤처기업부가 게시하는 사업공고 목록과 관련 정보를 조회할 수 있는 서비스입니다. 주요 제공 항목은 사업공고 제목, 작성자, 첨부파일 등이며, REST 방식의 오픈 API를 통해 XML 형식으로 데이터를 제공합니다. 이를 활용해 관심 있는 사업공고를 찾아보고, 첨부자료를 통해 사업의 세부 내용과 참여에 필요한 사항을 확인할 수 있습니다. 또한 사업공고 정보를 외부 웹사이트나 애플리케이션에 연계하여 기업 대상 사업 안내 서비스를 구축하거나, 공고 자료 수집과 지원사업 동향 파악을 위한 기초자료로 활용할 수 있습니다.

제공기관: 중소벤처기업부
분류: 산업고용
키워드: 중소벤처기업부, 사업공고, 지원사업, 공고목록, 오픈API, 사업공고조회
형식: xml
선정 기준: 중앙·광역 기관 파일데이터

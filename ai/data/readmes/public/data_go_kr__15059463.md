# 생활 폐기물 처리시설  집계 현황

이 데이터는 경기도 내 생활 폐기물 재활용시설에 대한 집계 현황을 제공합니다. 주요 정보에는 시설의 설치년도, 운영방식(공공/민간 등), 선별방식(기계/수작업 등), 처리용량, 반입량, 재활용품목 수, 그리고 위치 정보(도로명/지번주소, 위도·경도) 등이 포함됩니다. 이 데이터는 자원순환정책 수립, 폐기물 관리 인프라 분석, 시설 증설 필요성 평가, 환경정책 효과 측정, 지역 간 폐기물 처리능력 비교 등에 활용할 수 있습니다. 특히 전년도 반입량 대비 처리 용량 분석을 통해 지역별 과부하 여부 판단이나 효율성 개선 전략 수립에도 유용합니다.

제공기관: 경기도
분류: 환경기상
키워드: 음식물, 건설폐기물, 폐지, 폐기물처리시설, 재활용시설, 선별방식, 선별용량, 생활폐기물
형식: api
선정 기준: 운영 자동승인 OpenAPI

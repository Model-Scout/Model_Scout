# 신호등 현황 서비스

대한민국 부산광역시 16개 구군의 신호등 현황에 대한 데이터를 제공하고 있습니다. 1. 교통안전시설물 신호등이란? 신호등은 교차로나 횡단보도 등에서 차량과 보행자의 통행을 안전하게 조절하기 위해 설치된 전자기기입니다. 교통 흐름을 원활하게 하고, 사고 예방 및 교통 법규 준수를 유도하는 중요한 시설물입니다. 2. 신호등 현황 공공데이터 주요 항목 설치 위치: GPS 좌표, 도로명 주소, 행정구역 정보 신호등 종류: 차량 신호등, 보행자 신호등, 자전거 신호등, 복합 신호등 등 설치 방식: 지상형, 천장형, 벽부형 등 설치 일자 및 제조사 정보 제어 방식: 고정시간 제어, 적응형 신호 제어 등 상태 정보: 정상 작동, 고장, 유지보수 필요 여부 부가 정보: 신호등에 부착된 CCTV, 교통 센서, 음성 안내기 등의 부속 장치 정보 3. 데이터 활용 목적 교통신호 체계 개선 및 최적화 연구 교통사고 예방 및 안전 강화 대책 수립 스마트 시티 및 ITS(지능형 교통 시스템) 구축 기반 자료 시민 대상 교통정보 제공 및 교통 시설 현황 안내 4. 데이터 제공처 및 접근 방법 공공데이터 포털(data.go.kr) 및 지방자치단체 교통관리부서에서 제공 파일 형식: CSV, JSON, XML 등 다양한 형태로 제공 API 연동을 통해 실시간 신호등 상태 모니터링 가능

제공기관: 부산광역시
분류: 교통물류
키워드: 교통, 안전, 신호등위치, 신호등종류, 신호등용도
형식: api
선정 기준: 운영 자동승인 OpenAPI

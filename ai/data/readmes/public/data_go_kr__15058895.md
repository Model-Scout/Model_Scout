# 지식재산처_KIPRISPlus_기계번역용 국문초록_REST API_20220216

1. 개요 기계번역의 정확성 향상을 위해 재가공한 한국특허국문초록 정보를 제공합니다. 한국 특허정보를 영문으로 가공한 한국특허영문초록(KPA)와 유사하게 해외데이터 교류 및 서비스를 위한 재가공 번역초록을 API(REST방식)와 대용량(BULK)으로 제공합니다. 2. 세부 정보 내용 국문초록 : 출원번호, 등록번호, 공개번호 정보를 조회하여, 국문초록 정보를 XML 형태로 제공합니다. 출원번호, 등록번호, 공개번호, 발명의명칭, 번역문요약내용 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

제공기관: 지식재산처
분류: 과학기술
키워드: 기계번역, 출원번호, 등록번호, 발명의명칭, 번역문요약내용
형식: api
선정 기준: 운영 자동승인 OpenAPI

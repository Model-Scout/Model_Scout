# 외교부_연설문_20250210

외교부 연설문 조회를 위한 API 입니다. 제목을 검색하여 외교부 연설문 데이터를 조회합니다. 제목, 내용,첨부 파일 링크, 연설자 직함, 일자 등이 결과값으로 표시됩니다. ※ [참고사항] '내용(contents)' 항목에서 외교부 홈페이지에 게시되는 html 원문을 그대로 (태그 포함)하여 조회 됩니다. 외교부 홈페이지(mofa.go.kr) 접속 > 뉴스·공지>연설·기고·인터뷰> 연설 게시판의 데이터를 조회 가능하며, 장관, 1,2차관, 국립외교원장, 간부 등의 연설문을 나누어서 볼 수 있고, 기간 별, 검색 등이 가능합니다.

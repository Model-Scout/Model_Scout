# 명품민물고기생산업체 현황

이 데이터는 경기도 내 명품수산물(G Fish) 생산업체에 대한 정보를 제공하며, 양식장명, 양식품종명, 소유자명, 소재지주소, 위도·경도 등의 항목으로 구성됩니다. G Fish 인증은 경기도가 도내 양식장 265개소를 대상으로 신청을 받아 중금속, 항생물질, 금지약품에 대한 식품의약품안전처 기준에 따른 안전성 검사를 통해 인증 업체를 선정하고, 도지사 인증서를 부여하는 제도입니다. 해당 데이터는 지역 수산물의 품질 관리, 안전한 식품 공급망 구축, 수산업 활성화 정책 수립 등에 활용될 수 있습니다. ※ G Fish(지피쉬) : 경기도에서 인증한 명품 수산물 브랜드로, 철저한 안전성 검사와 품질 기준을 충족한 수산물에 부여됩니다.

제공기관: 경기도
분류: 농축수산
키워드: 명품수산물, 양식장현황, G Fish, 수산물안전성, 양식품종, 도지사인증, 경기도수산업
형식: api

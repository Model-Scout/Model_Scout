# 해양환경공단_해양환경측정망CTD 관측서비스_20200304

이 데이터는 해양환경공단이 운영하는 해양환경측정망을 기반으로 CTD(Conductivity·Temperature·Depth) 장비를 활용하여 수행한 관측 정보를 제공하는 공공데이터 API 서비스이다. CTD 장비를 통해 수심별 전기전도도, 수온, 깊이 정보를 측정하며, 이를 바탕으로 염분, 수질 구조, 수층 안정도 등 주요 해양환경 특성을 정밀하게 분석할 수 있도록 수직 프로파일 자료를 제공한다. 또한 조사정점의 코드, 위치, 관측일시 등 기본 공간·시간 정보를 함께 제시하여 특정 해역의 수층 변화와 환경 특성을 종합적으로 파악할 수 있도록 지원한다. 아울러 연속적 수심 자료와 배경 환경요소를 포함한 표준화된 데이터 구조를 제공함으로써 해양 생태환경 연구, 수질 변화 감시, 정책 의사결정 등 다양한 활용 목적에 적합하도록 구성된 서비스이다.

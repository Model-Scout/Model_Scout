# 한국수력원자력(주)_원전건설 공정률 현황_20260324

위 api는 한국수력원자력(주)_원전건설 공정률 현황 API 입니다. 한국수력원자력(주)에서 현재 건설중인 원자력발전소 신한울1,2호기 및 신고리5,6호기 실적공정률 현황조회 자료입니다.

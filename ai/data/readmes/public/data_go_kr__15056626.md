# 후계농업인 집계 현황

이 데이터는 경기도 내 후계농업인의 연도별 선정 인원수를 집계한 자료로, 지역 농업을 이끌 차세대 인력의 규모를 보여주는 중요한 통계입니다. 후계농업인은 농업 경영을 계승하거나 새롭게 진입하는 인력입니다. 이 데이터는 특정 시기의 선정 인원 변동을 살펴봄으로써 정책적 지원의 효과와 한계를 가늠할 수 있으며, 지역 농업 경쟁력 강화와 인력 구조 개선의 방향성을 검토하는 데 기초자료가 됩니다. 또한 연도별 추이를 분석하면 농업 인력 공급이 안정적인지, 정책적 투입이 일관되게 유지되고 있는지 확인할 수 있어 농업·농촌 분야의 중장기 전략 수립에도 활용할 수 있습니다.

제공기관: 경기도
분류: 농축수산
키워드: 영농계승, 농업통계, 지역농업, 농업인력, 농촌인구, 농업정책
형식: api
선정 기준: 운영 자동승인 OpenAPI

# 인천교통공사_역별일별 이용인원현황

인천교통공사에서 운영 중인 도시철도 인천1호선, 인천2호선, 7호선 인천·부천구간의 2025년 7월 1일부터 2026년 6월 30일까지 역별 일별 이용이원 현황자료입니다. 해당 데이터는 호선, 통행일자, 역명, 구분, 이용인원(명), 승차인원(명), 하차인원(명) 항목으로 구성되어있습니다. 제공하는 자료에는 인천1호선 계양역에서 송도달빛축제공원역까지 30개역, 인천2호선 검단오류역에서 운연역까지 27개역, 7호선 인천·부천구간 까치울역에서 석남역까지 11개역의 정보를 포함하고 있습니다. 단, 2025년 6월 28일에 개통한 인천1호선 연장 3개역(검단호수공원역, 신검단중앙역, 아라역) 정보는 포함되지 않았습니다.

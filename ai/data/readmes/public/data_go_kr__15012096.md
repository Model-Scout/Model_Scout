# 해양경찰청_해양오염사고발생 및 폐기물수거현황

연간 해양오염 사고발생 현황과 해상에 유출된 오염물질의 유출량 및 방제조치로 발생된 폐기물, 오염물질이 묻은 폐기물 수거량과 오염물질의 회수량 등을 표출한 데이터 입니다. ※ 해양오염사고 : 바다에 오염물질(기름, 유해화학물질, 폐기물 등)이 유출되어 해양환경을 훼손되거나 훼손우려가 있는 해양오염사고 폐기물 수거량 : 오염물질이 묻은 폐기물 및 방제작업으로 발생된 폐흡착재 회수량을 나타나며, 단위는 "톤" 사용 폐유 수거량 : 해상에 유출된 오염물질을 기계적 방식 등으로 회수량을 나타나며, 단위는 "KL" 사용

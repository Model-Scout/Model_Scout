# 장비이용자서비스

공동활용서비스가 가능한 전국의 연구시설 장비 정보를 수집하고 예약서비스를 제공하여 연구자 편익 증대 및 R&D 효율화에 기여하기 위하여 생성된 API입니다. 제공 API(주요 응답항목) - 국가연구시설장비정보연계(모델, 주시설장비, 구축과제, 기관, 설치장소, 우편번호, 심의정보, 정보유효성, 시설장비) - 예약활용정보연계(예약서비스 목록, 예약서비스 상세, 예약서비스, 우편번호, 예약정보 신청등록, 예약희망시간 중복확인, 예약확정시간 중복확인, 예약정보 확정등록, 예약정보 승인/취소/완료/결제, 예약정보 수정)

제공기관: 과학기술정보통신부
분류: 과학기술
키워드: 기계, 기타 기계, 달리 분류되지 않는 기계, 연구시설장비정보, 연구장비, 장비예약, 공동활용
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-07-31
이용허락: 이용허락범위 제한 없음

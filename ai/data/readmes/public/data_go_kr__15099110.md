# 한국수자원공사_수문 운영 정보_20150106

ㅁ 개 요 : K-water에서 관리중인 댐 및 보의 수문정보 ㅁ 제공항목 : 댐수위[EL.m], 강우량[mm], 유입량[㎥/sec], 총방류량[㎥/sec], 저수량[백만㎥/sec], 저수율[%] * 댐수위[EL.m] : 저수지 수위를 의미 * 강우량[mm] : 일정한 기간 동안 내린 비의 양으로, 넓은 의미로 눈, 싸락눈, 우박, 이슬 및 서리의 양도 포함 * 유입량[㎥/sec] : 단위 시간당 댐 수위 변화에 따른 저수량의 차이와 단위 시간의 평균방류량을 이용하여 계산 * 방류량[㎥/sec] : 저수지 등 수체로부터 외부로 유출되는 양 * 저수량[㎥/sec] : 수위를 이용해 계산된 값 * 저수율[%] : 계획홍수위 기준(용수댐의 경우 상시만수위 기준) 저수용량(총저수용량)에 대한 현재 저수량의 비율 ㅁ 제공지점 : 61개소(다목적댐 21, 용수전용댐 14, 낙동강하굿둑, 홍수조절용댐 3, 조정지 6, 보 16) ㅁ 보유기간 : 2006년 1월 ~ 현재 * 지점별로 보유기간 상이함 ㅁ 제공주기 : 10분별, 시간별, 일별 ㅁ 제공형식 : 파일(XLS, CSV), 오픈API(XML, JSON) * 전국의 모든댐 수위정보는 공공데이터포털 환경부-한강홍수통제소의 '표준수문DB'를 참고하시기 바랍니다. 변경전 : 수문현황정보(http://opendata.kwater.or.kr/openapi-data/service/pubd/dam/sluicePresentCondition/) 변경후 : 수문 운영 정보(http://apis.data.go.kr/B500001/dam/sluicePresentCondition/) 추후 기본정보 수정 예정

# 치매 상담센터 현황

이 데이터는 경기도 내 치매안심센터의 운영 현황을 수록하고 있으며, 각 센터의 시군별 위치, 지역구분, 상담센터 전화번호, 운영방법(직영 등), 주소, 위도·경도 좌표 등의 정보를 포함하고 있습니다. 치매안심센터는 고령화 사회에 대응하는 핵심 지역보건 서비스 기관으로, 본 데이터는 지역별 인프라 분포와 상담 접근성을 분석하는 데 활용될 수 있습니다. 또한 이 자료는 고령층 돌봄체계 구축, 지역사회 통합돌봄 모델 설계, 보건의료자원 배치, 치매 예방 및 치료 접근성 개선, 공공보건 정책 수립 등에 유용한 기초 자료로 사용될 수 있습니다.

제공기관: 경기도
분류: 사회복지
키워드: 치매안심, 공공보건, 노인돌봄, 지역보건, 치매상담, 고령화
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-09-17

# 조달청_공사원가_표준시장단가

○ 시설공사 원가계산에 사용하는 자료를 목록화하고, 개방형 설계내역서 자료 호환 양식인 공사원가호환규정을 수립하여, 공사원가계산을 웹에서 처리할 수 있는 시스템을 개발 ○ 조달청 공사원가통합관리시스템(https://npccs.g2b.go.kr)에서 제공하는 표준공사코드의 세부항목을 제공하는 서비스 ○ 공사원가 산정업무의 효율성과 가격의 객관성을 확보하기 위해 ‘표준공사코드’ 체계를 운영 중 ○ 시설자재, 노무비, 기계경비, 세부공종 등에 대해 수요기관이 공사내역 작성 시 활용할 수 있도록 표준공사코드를 제공 ○ 표준시장단가의 최신발표일자, 세부공종코드, 품명, 규격, 단위, 재료비, 노무비, 경비, 합계 , 적용단가 조회

제공기관: 조달청
분류: 공공행정
키워드: 단가, 공사사, 표준, 건축, 정보통신, 원가, 나라장터, 전기
형식: csv
선정 기준: 중앙·광역 기관 파일데이터

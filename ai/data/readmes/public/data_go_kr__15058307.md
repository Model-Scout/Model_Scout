# 자립형일자리 코드 정보

한국노인인력개발원에서 운영하는 노인일자리 업무시스템의 코드 정보 중 자립형 노인일자리 사업 관련 행정구역 코드 목록을 조회하는 OpenAPI 서비스이며, 데이터 항목은 행정구역코드, 대분류코드, 중분류코드, 소분류코드, 행정구역명 등으로 구성되어 있습니다. 요청변수 입력을 통해 설정한 조건의 데이터를 조회할 수 있으며, 조회된 데이터는 자립형 노인일자리 사업과 관련된 한국노인인력개발원의 타 OpenAPI 및 오퍼레이션에서 요청변수로써 원하는 데이터의 조회에 사용될 수 있습니다.

제공기관: 한국노인인력개발원
분류: 산업고용
키워드: 노인일자리 업무시스템 지역 코드, 자립형 노인일자리 사업 행정구역 코드, 광역자치단체 및 기초자치단체 행정코드
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2024-08-24
이용허락: 이용허락범위 제한 없음

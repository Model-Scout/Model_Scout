# 비디오물감상실업 현황

이 데이터는 다수의 시청실 및 다수의 비디오물 시청기자재를 갖추고 비디오물을 공중의 시청을 제공하는 경기도 내 비디오물 감상실업 현황입니다.각 사업장의 인허가일자, 폐업일자, 영업상태(예: ‘영업중’, ‘폐업 등’), 위치정보 등을 포함합니다. 도로명주소, 시군명, 지역구분 등을 통해 사업장의 공간적 분포를 파악하는데 활용할 수 있습니다. 해당 데이터는 영상 콘텐츠 소비 공간에 대한 실태 조사, 폐업율 추이, 유흥업소 관련 정책 모니터링, 청소년 접근성 관리, 상업지역 내 콘텐츠 업종 분포 분석 등에 유용합니다.

제공기관: 경기도
분류: 문화관광
키워드: 영상물, 비디오감상, 상업시설, 영상산업, 영상콘텐츠, 디비디
형식: api
선정 기준: 운영 자동승인 OpenAPI

# 입학전형 유형별 선발 결과 현황

이 데이터는 대학 및 전문대학의 입학전형 유형별 선발 결과를 기록한 자료로, 수시·정시·추가 모집 단위에서의 모집 인원과 실제 등록 인원, 등록률을 비교할 수 있도록 구성되어 있습니다. 주요 정보에는 기준년도, 학교종류명, 설립구분, 학교명, 정원구분, 전형유형명, 전형대분류·중분류·소분류, 모집 인원과 등록 인원, 최종 등록률이 포함됩니다. 이를 통해 대학별·전형유형별 선발 구조와 등록 성과를 파악할 수 있으며, 특정 전형의 경쟁력이나 충원 안정성을 확인할 수 있습니다. 이 데이터는 대학 입학 정책 분석, 전형별 지원자 선호도 연구, 교육 수급의 지역 간 불균형 검토, 입학제도 개선 논의 등에 활용할 수 있는 기초 자료입니다.

제공기관: 경기도
분류: 교육
키워드: 입학전형, 대학입학, 수시모집, 정시모집, 추가모집, 등록률
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-09-17
이용허락: 이용허락범위 제한 없음

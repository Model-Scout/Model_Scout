# 한국토지주택공사_하남교산 토지이용계획표

한국토지주택공사에서 개발 조성중인 하남교산 지구 토지이용계획표로 전체 토지이용계획의 면적, 구성비 및 주택건설용지, 단독주택, 공동주택등 부분별 면적, 구성비 정보 제공합니다. 토지이용계획표는 특정 토지의 이용 목적과 규제 사항을 한눈에 확인할 수 있도록 표 형태로 정리한 정보입니다. 면적의 단위는 미터제곱으로 총 면적은 6,465,595 입니다. 공원녹지 공원 1,452,127 (23%), 공동주택 아파트 1,140,790 (18.1%), 도로 1,013,335 (16%), 도시지원시설 자족시설 682,073 (10.8%) 입니다.

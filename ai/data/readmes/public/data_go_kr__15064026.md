# 국토교통부 국토지리정보원_api활용예제

NGTN(OpenAPI)의 활용 예제 정보와 시나리오별 실행 방식 등을 담은 데이터로, 각 API 기능에 대한 실습 예제 및 사용 맥락(지도 제어, 객체 등록 등)을 포함한 시나리오 기반 API 설명 자료입니다. 1. 형식: CSV 2. 내용 요약 ■ appex_sn: 활용 예제 고유 식별 번호 ■ appex_nm: 예제 제목 (예: 사용자 객체등록, 지도 이벤트 등) ■ appex_dc: 예제 설명 및 사용 목적 (예: 마우스 드래그로 지도 확대/축소, 객체 속성 변경 등) ■ indict_at: 화면 표출 여부 (Y/N) ■ appex_se: API 유형 구분 (예: 3D, 2D 등) ■ appex_type: 예제 유형 (대부분 ‘senario’로 실제 시나리오 기반 사용 예시) ■ regist_date / updt_date: 예제 등록일 및 수정일 ■ register_id / updusr_id: 등록자 및 수정자 ID 3. 활용 예제 ■ 공공기관 또는 민간개발자가 3D 지도 제어, 사용자 객체 처리, 사용자 레이어 생성 등의 고급 기능을 실제로 테스트하거나 시스템에 적용할 때 참고 자료로 활용 ■ 공간정보 교육기관, 개발자 교육에서 OpenAPI 활용 방법을 학습하는 실습 콘텐츠로 구성해 학습 효과 증대 ■ 신규 API 설계 또는 UI 구성 시 기존 사용 시나리오 기반으로 기능 흐름과 인터랙션을 이해하고 사용자 중심 기능을 설계하는 데 활용 가능

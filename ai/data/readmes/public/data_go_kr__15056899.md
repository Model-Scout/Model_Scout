# 서울시 교통량 이력 정보

해당 데이터는 서울시 교통량 이력 정보 OpenAPI 데이터입니다. 데이터의 원본시스템은 서울시 교통정보 시스템(https://topis.seoul.go.kr)입니다. 요청인자 : 인증키, 요청파일타입, 서비스명, 요청시작위치, 요청종료위치, 지점번호, 년월일, 시간 출력값 : 총 데이터 건수(정상조회 시 출력됨), 요청결과 코드, 요청결과 메시지, 지점번호, 년월일, 시간, 유입유출 구분, 차로번호, 교통량 ※ 바로가기 링크 클릭 시 서울 열린데이터광장 개방 데이터로 이동합니다. 열린데이터광장에서 제공하는 오픈API를 사용하기 위해서는 먼저 인증키를 발급받으셔야 합니다.

제공기관: 서울특별시
분류: 교통물류
키워드: 교통량, 교통사고, 시간별, 교통량 이력, 교통상황
형식: api
선정 기준: 운영 자동승인 OpenAPI

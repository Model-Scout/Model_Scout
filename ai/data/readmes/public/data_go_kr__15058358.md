# 서울특별시 건설알림이 공사사진

해당 데이터는 서울시 건설알림이 공사사진 OpenAPI입니다. 서울특별시 건설알림이에서 제공하는 서울시(본청,사업소,자치구,투자출연기관) 공공발주 사업의 공사사진 자료이며, 원본시스템은 서울특별시 도시기반시설본부의 건설정보관리시스템(One-PMIS)입니다. 요청인자 : 인증키, 요청파일타입, 서비스명, 요청시작위치, 요청종료위치, 사업코드 출력값 : 총 데이터 건수, 요청결과 코드, 요청결과 메시지, 순번, 사업코드, 사업명, 사진순번, 사진URL, 사진명, 촬영일자 ※ 바로가기 클릭 시 열린데이터광장의 개방 데이터로 이동합니다.

제공기관: 서울특별시
분류: 국토관리
키워드: 건설알림이, 공사사진, 공사, 건설, 시공
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-07-04
이용허락: 제3자 권리 포함 : 저작권 표시, 공공저작물 : 출처표시 (제 1유형)

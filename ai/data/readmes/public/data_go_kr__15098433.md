# 한국국제협력단_코로나19 지원 실적_20220121

KOICA가 코로나19 대응을 위해 실시한 ODA 개발협력사업 지원 실적을 제공하는 API입니다. 마스크, 진단키트, 백신 장비 지원, 방역 인프라 구축, 보건인력 훈련 등 위기 대응 중심의 사업 내용을 포함하며, 국가별 긴급지원 규모, 분야별 집중도 등을 비교 분석할 수 있습니다. 해당 API는 인증키(serviceKey), 페이지 번호(pageNo), 한 페이지 결과 수(numOfRows) 등 기본적인 요청변수를 사용하며 한글 국가명, ISO 2자리코드 등의 필터 파라미터를 추가로 설정할 수 있습니다. 출력결과에는 국가명, ISO 2자리코드, 계획 금액, 집행 금액, 수혜자 수 등의 항목이 포함되며, 각 항목에 대한 데이터는 XML 형식과 JSON 형식으로 반환됩니다.

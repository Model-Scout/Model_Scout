# 커리어넷 대학학과정보

이 오픈 API는 교육부와 한국직업능력연구원이 운영하는 커리어넷(CareerNet)을 통해 제공되는 대학 학과 정보 서비스입니다. 초·중·고등학생의 진로 및 진학 지도에 필요한 다양한 학과 정보를 포함하고 있으며, 학과명, 학과분류, 전공계열 등의 상세 정보를 XML 형식으로 제공합니다. 이 API를 활용하면 진로 상담 시스템, 교육 콘텐츠 개발, 진로 교육 연구 등에 활용할 수 있습니다. 데이터는 무료로 제공되며, 활용을 위해서는 인증키 발급이 필요합니다. API는 링크 형태로 제공되며, 자세한 내용은 커리어넷 공식 웹사이트(http://www.career.go.kr/cnet/front/openapi/openApiMajorCenter.do)를 통해 확인할 수 있습니다. (제공데이터) 초.중.고생의 진로와 진학지도에 필요한 진로상담, 직업정보, 대학학과정보, 학교정보, 진로교육자료 제공

제공기관: 교육부
분류: 교육
키워드: 커리어넷, 진로상담, 직업정보, 대학학과정보, 진로교육자료, 학교정보, 진로진학지도, 초중고생
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-05-27
이용허락: 제3자 권리 포함 : 저작권 표시, 공공저작물 : 출처표시 (제 1유형)

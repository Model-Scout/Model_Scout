# 한국산업단지공단_팩토리온_업종관리

해당 공공데이터는 산업단지 내 입주기업의 현황을 체계적으로 관리하기 위한 행정 기반자료로, "21년 7월말 기준으로 집계된 공장설립온라인지원시스템(factoryon)에 등록된 공장들의 기본정보(회사명 등), 공장 규모, 공장 관리번호를 기반으로 업종정보(업종코드, 대표업종, 입주형태, 원자재 등)를 집계한 데이터입니다. 데이터 건수가 많아 일반적인 엑셀, 메모장 등에서는 전체 내용이 표출되지 않을 수 있으므로, 전용 데이터 분석 소프트웨어(R, Python, SPSS, Stata 등)를 활용하여 분석하시기 바랍니다.

제공기관: 한국산업단지공단
분류: 공공행정
키워드: 공장_업종코드, 공장_대표업종, 공장_입주형태, 원자재, 입주기업
형식: xlsx
선정 기준: 중앙·광역 기관 파일데이터
수정일: 2026-09-17

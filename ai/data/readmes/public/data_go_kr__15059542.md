# 모바일 법령 목록 조회

법제처가 제공하는 모바일 법령 목록 조회 데이터는 모바일 환경에서 활용할 수 있도록 구성된 법령의 기본 정보를 제공합니다. 해당 데이터는 법령명, 법령ID, 법령구분, 공포번호, 공포일자, 시행일자, 소관부처명, 연번, 제개정구분 등 주요 항목으로 구성됩니다. 사용자는 법령명, 공포번호, 소관부처, 페이지 번호 및 조회 건수 등의 조건을 입력하여 원하는 법령 정보를 맞춤형으로 조회할 수 있습니다. 모바일 인터페이스에 적합한 경량 구조로 설계되어 있어 법령 정보의 신속한 접근과 활용이 가능하며 법령의 최신 시행일과 공포일, 법령 상태 등 핵심 사항을 빠르게 확인할 수 있어 법령 관리, 행정 참고 및 모바일 기반의 법제 서비스에 유용합니다.

제공기관: 법제처
분류: 공공행정
키워드: 앱법률시행령, 법령구분, 소관부처, 시행일자, 공포일자, 공포번호, 법령명, 연번
형식: api
선정 기준: 운영 자동승인 OpenAPI

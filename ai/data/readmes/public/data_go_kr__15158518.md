# 한국국제협력단_ODA연구정보조회_20161213

KOICA에서 발간한 ODA 관련 연구보고서, 이슈리포트, 정책자료 등의 간행물 정보를 조회할 수 있는 ODA 연구 정보 API입니다. 최근 발간된 자료를 자동으로 조회할 수 있으며, 제목과 요약설명, 원문 링크 등을 통해 연구 동향 및 정책 방향을 쉽게 파악할 수 있습니다. 특히 최신 150일 이내 발행한 발간물 조회가 가능하여 시의성 있는 정보 수집에 적합합니다. 해당 API는 인증키(serviceKey), 페이지 번호(pageNo), 페이지당 데이터 개수(numOfRows) 등 기본적인 요청변수를 사용하며, 출력결과는 결과메시지, 한 페이지 결과 수, 전체 결과 수, 제목, 설명, 링크 등의 항목을 포함합니다. 또한 각 항목은 XML 형식으로 반환됩니다.

제공기관: 한국국제협력단
분류: 통일외교안보
키워드: KOICA, ODA, 개발협력사업, 연구보고서, 이슈리포트, 간행물, 정책자료
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2026-09-28
이용허락: 이용허락범위 제한 없음

# 법령 체계도 본문 조회

본 데이터는 법령의 조문 구조를 체계적으로 나타낸 법령 체계도 본문 정보를 제공합니다. 법률, 대통령령, 총리령, 부령 등 다양한 법령 유형에 대해 각 조문이 포함된 장, 절, 관, 조, 항, 호 등 계층적 구성 정보를 제공합니다. 데이터는 법령 ID, 조문 번호, 조문명, 계층 위치, 부모 항목 ID 등의 항목으로 구성되어 있으며, 법령 간 또는 내부 조항 간의 체계적인 연결 관계를 명확히 파악할 수 있도록 지원합니다. 이를 통해 법령의 전체적인 구조와 조문 간 관계를 직관적으로 이해할 수 있으며, 법령 해석 및 체계 분석에 필요한 기반 정보를 제공합니다. 법령을 체계적으로 정리하거나 법률 서비스를 설계하는 데 활용이 가능합니다.

제공기관: 법제처
분류: 공공행정
키워드: 체계도신구법3단비교, 조문구조, 법률계층, 조항연결, 항목분류, 법령구성, 구조정보, 체계연결
형식: api
선정 기준: 운영 자동승인 OpenAPI

# 보건복지부_10대 암 발생률

보건복지부의 10대 암 발생률 통계자료로 2016년~2022년까지 유형명, 발생건수, 조발생률, 연령표준화발생률의 데이터를 제공합니다. <데이터 이용 시 참고사항> * 유형명 : 조사 대상 암종류의 명칭(이름)을 의미 * 발생건수 : 10대 암 발생자(암 환자) 수를 의미 * 조발생률：해당 관찰기간 동안 특정 인구집단에서 새롭게 발생한 암 환자 수로, 일반적으로 인구 100,000명 당 발생하는 암 환자 수 * 연령표준화발생률：각 연령군에 해당하는 표준인구의 비율을 가중치로 한 가중평균발생률, 표준인구는 2020년 주민등록연앙인구를 사용

분류: 보건의료
키워드: 10대_암, 발생률, 데이터, 조발생, 연령표준발생

# 휴게음식점(떡카페) 현황

이 데이터는 경기도 내에서 운영 중인 '떡카페' 형태의 휴게음식점에 대한 인허가 현황을 제공합니다. 떡카페는 주로 전통차와 떡, 떡케이크, 디저트류 등을 제공하는 소규모 음식업소로, 한국 전통식문화를 현대적으로 재해석한 형태의 외식 공간입니다. 주요 항목으로는 사업장명, 인허가일자, 영업상태, 폐업일자, 소재지 주소, 위생업종 및 업태명, 급수시설 구분, 종사자 수, 영업장 주변 환경, 위치 정보(WGS84 위도/경도 좌표계) 등이 포함되어 있으며, XML 또는 JSON 형식의 Open API를 통해 이용 가능합니다. 이 데이터는 지역별 떡카페 분포 분석, 전통 식문화 확산 연구, 창업 입지 전략, 위생관리 정책 수립 등의 목적에 활용될 수 있습니다.

제공기관: 경기도
분류: 식품건강
키워드: 휴게음식점, 떡카페, 전통디저트, 인허가현황, 위생업소, 다과류, 전통차, 떡류판매
형식: api
선정 기준: 운영 자동승인 OpenAPI

# 예금보험공사_ 채권발행 현황_상환기금채권

1. 데이터 개요 -예보채상환기금은 ’97년 외환위기 당시 금융구조조정 과정에서 발생한 채무를 상환하기 위해서 설치하였습니다. - 동 기금의 재원 마련을 위해 상환기금채권을 발행하였고, 기발행한 채권의 만기도래 금액 중 금융회사가 납부하는 특별기여금, 회수 자금 등으로 충당하지 못하는 부족 자금 조달을 위해 차환 발행한 상환기금채권 현황 정보를 제공하고 있습니다. -채권의 종류 및 채권번호, 기금, 발행일, 만기일, 발행액, 이자율, 잔액 등의 정보를 제공하고 있습니다. 2. 데이터 단위 (원) : 발행액, 잔액 (%) : 이자율

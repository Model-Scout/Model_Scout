# 국토교통부_농지정보도(WMS/WFS)_20240601

농지정보 OGC(Open Geospatial Consortium) 표준 API는 공간 데이터의 공유와 상호운용성을 위해 개발된 국제 표준으로, 웹 기반에서 지도, 피처, 래스터 등 다양한 지리정보를 효율적으로 제공·활용할 수 있게 합니다. 최신 OGC API는 RESTful 구조를 채택해 개발 편의성과 확장성을 높였으며, WMS, WFS 등 기존 표준을 현대적으로 계승합니다

제공기관: 국토교통부
분류: 농축수산
키워드: 농지정보, 농지, 지도
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-07-11
이용허락: 제3자 권리 포함 : 저작권 표시, 공공저작물 : 출처표시 (제 1유형)

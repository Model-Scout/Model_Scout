# 휴게음식점(전통찻집) 현황

이 데이터는 경기도 내 전통차를 중심으로 운영되는 전통찻집 형태의 휴게음식점에 대한 현황 자료로, 31개 시군의 인허가 데이터를 기반으로 구성되어 있습니다. 주요 항목에는 시군명, 사업장명, 인허가일자, 영업상태, 폐업일자, 소재지 정보(주소, 면적, 위도/경도), 위생업종 및 업태, 종사자 수(남녀), 다중이용업소 여부, 시설규모 등이 포함됩니다. 본 데이터는 전통문화 기반 식음료 업소 현황 분석, 위생관리 및 정책 수립, 관광객을 위한 전통문화 체험시설 정보 제공 등에 활용될 수 있으며, XML 또는 JSON 형식의 Open API로 제공됩니다.

제공기관: 경기도
분류: 식품건강
키워드: 전통찻집, 휴게음식점, 전통차, 인허가현황, 위생업소, 다중이용업소, 식품안전, 문화공간
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-06-24
이용허락: 이용허락범위 제한 없음

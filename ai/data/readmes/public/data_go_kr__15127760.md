# 국가데이터처_KOSIS 통계목록 조회 서비스_20231231

국가데이터처가 운영하는 KOSIS(국가통계포털)에서 보유하고 있는 방대한 국가 승인 통계의 계층 구조와 디렉터리 정보를 체계적으로 탐색할 수 있도록 지원하는 오픈 API 서비스입니다. 이 서비스는 사용자가 수많은 통계 테이블 중에서 원하는 데이터를 신속하고 정확하게 찾아갈 수 있도록 돕는 일종의 '나침반' 역할을 합니다. 본 API 통해 사용자는 경제, 사회, 인구, 환경 등 각 기관 및 분야별로 분류된 통계 목록의 트리(Tree) 구조, 통계 명칭, 통계표 ID, 작성 기관 정보 등을 호출할 수 있습니다. 수많은 통계 데이터의 연동 위치와 식별자를 계층별로 명확하게 파악할 수 있기 때문에, 방대한 KOSIS 시스템 내에서 데이터 수집 범위를 정의하고 검색 경로를 최적화하는 데 필수적인 선행 서비스입니다.

제공기관: 국가데이터처
분류: 공공행정
키워드: 국가통계, KOSIS, 통계목록, 통계명, 통계작성기관
형식: api

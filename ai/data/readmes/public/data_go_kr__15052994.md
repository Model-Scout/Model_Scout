# 공무원연금공단_직급별 보수월액 추이 현황

공무원연금공단에서 관리하는 공무원 직급별 보수월액 추이 현황을 집계한 데이터이며, 보수월액을 취급하였던 1982년부터 2009년까지의 데이터가 있습니다. 2009년 공무원연금법 개정(2010년 시행)에 따라, 연금 산정 기준이 "보수월액"에서 "기준소득월액"으로 변경되어, 이전 체계를 반영하는 자료로 1회성 데이터로 제공합니다. 해당 자료는 과거 연금산정 체계 분석, 직급 간 보상수준 비교, 인사·보수 정책의 변화 평가, 연금재정 추계 모델의 입력값 설정 등에 활용할 수 있으며, 직급별 장기 재직자 분석 및 제도 개선연구에도 유용한 기초 자료입니다. 직급 : 관리관(1급), 이사관(2급), 부이사관(3급), 서기관(4급), 사무관(5급), 주사(6급), 주사보(7급), 서기(8급), 서기보(9급)

제공기관: 공무원연금공단
분류: 사회복지
키워드: 직급, 보수월액, 추이, 공무원연금통계, 현황
형식: csv

# 경기도 토산어종 방류내역 현황

이 데이터는 경기도 내 토산어종 방류 내역 현황을 제공합니다. 데이터에는 시군명, 어종명, 방류건수(천마리 또는 만립 단위) 등의 정보가 포함되어 있으며, 경기도 해양수산자원연구소에서 관리합니다. 토산어종 방류사업은 지역 생태계 보전, 수산자원 회복, 어족자원 다양성 유지 및 어업 기반 활성화를 목적으로 시행됩니다. 이 데이터를 활용하여 지역별 어종 분포, 방류 규모, 수산자원 관리 현황을 파악할 수 있으며, 어족 복원 연구, 수산자원 정책 수립, 수생태계 보호 및 지속가능한 어업자원 관리 등에도 활용됩니다. 데이터 활용 시 집계년도, 방류 단위 등의 세부 사항을 함께 고려하는 것이 필요합니다.

분류: 환경기상

형식: api

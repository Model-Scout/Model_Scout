# 경상남도 의령군 민박/펜션업소 API

본 데이터는 경상남도 의령군 민박/펜션업소 정보를 제공하며, 업소명, 업종명, 소재지도로명주소, 연락처, 객실수, 부대시설 등의 정보를 제공하는 민박/펜션업소 목록 조회 서비스와 고유번호를 통해 민박/펜션의 고유번호, 사진번호, 사진원본명, 사진저장명, 사진URL를 조회하는 서비스로 구성되어 있습니다. 자료는 지역 숙박업 현황 파악, 농어촌 관광 활성화, 방문객 편의 증진에 활용됩니다. 위치 데이터는 지도 서비스와 연계해 시각화할 수 있어 관광 안내 자료 제작에도 유용합니다. 본 데이터는 공공데이터포털에서 누구나 활용할 수 있도록 공개되어 있습니다.

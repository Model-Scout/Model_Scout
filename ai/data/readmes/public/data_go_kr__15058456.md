# 대규모 재난발생시 인명피해 현황

이 데이터는 경기도 내에서 발생한 대규모 재난의 인명피해 현황을 기록한 자료입니다. 주요 항목은 집계년도, 시군명, 재난유형명, 재난발생일시, 재난규모구분명, 사망자 수, 중상자 수, 경상자 수, 비고사항, 재난장소 주소(도로명·지번), 우편번호, WGS84 좌표(위도·경도) 등으로 구성됩니다. 해당 자료는 대형 화재, 붕괴, 추락 등 다양한 재난 유형에 따른 피해 양상을 파악할 수 있도록 하며, 재난 안전 정책 수립, 지역별 위험도 평가, 재난 대응 계획 수립, 피해 저감 대책 마련 등에 활용될 수 있습니다. 다만, 본 자료는 수집 시점의 신고 및 집계 데이터를 기반으로 하므로 실제 피해 규모와 차이가 있을 수 있습니다.

제공기관: 경기도
분류: 재난안전
키워드: 재난, 인명피해, 재난유형, 재난장소, 사망자, 부상자, 위치정보
형식: api
선정 기준: 운영 자동승인 OpenAPI

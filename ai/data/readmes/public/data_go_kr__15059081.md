# 우편접수용 우편번호조회

검색조건에 의해 우편접수용 도로명주소 및 지번주소 상세검색 리스트 조회 시 스페이스로 구분된 검색어의 세부조건이 일치하지 않을 경우 범위검색 결과 정보를 제공하는 OPEN API 서비스 입니다. ㅇ 출력하는 항목(사용자가 응답 받게 되는 데이터 ) : 주소상세목록(우편번호, 주소, 범위)

제공기관: 과학기술정보통신부 우정사업본부
분류: 교통물류
키워드: 경제/경영, 마케팅, 물류/유통
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2021-08-17
이용허락: 이용허락범위 제한 없음

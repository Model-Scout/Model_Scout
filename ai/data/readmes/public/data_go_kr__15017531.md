# 사회복무요원 제복사이즈 조회

사회복무요원 제복신청시 측정된 년생별 상의, 하의 신발 크기 정보를 제공(API제공) - 사회복무요원에게 통일된 제복을 지급하여 근무시간 중에 착용하도록 하여, 사회복무요원의 품위와 위상을 제고하고자 함. - 사회복무요원에게 지급하는 제복의 종류는 하복(셔츠 근무복, 티셔츠 근무복), 추동복(셔츠 근무복, 티셔츠 근무복), 점퍼, 벨트, 모자, 단화를 지급하고 있음. - 사회복무요원이 제복을 신청(신체 치수 입력)하고, 제복 신청을 받은 지방병무청장이 명단과 제복신청 자료를 복무기관의 장에게 송부하고 있음.

제공기관: 병무청
분류: 통일외교안보
키워드: 제복, 모자, 근무복, 점퍼, 벨트, 단화, 명찰, 티셔츠
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-09-09
이용허락: 이용허락범위 제한 없음

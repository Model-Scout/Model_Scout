# 한국국제협력단_SDG 분야별 성과지표

동 데이터는 한국국제협력단(KOICA)이 유엔의 지속가능발전목표(SDGs) 17개 분야와 연결된 각 사업의 성과지표 목록을 정리한 자료입니다. 지속가능발전목표(Sustainable Development Goals, SDGs)는 전세계의 빈곤 문제를 해결하고 지속가능발전을 실현하기 위해 2016년부터 2030년까지 유엔과 국제사회가 달성해야 할 목표이며, 제공된 성과지표는 각 분야별로 사업 수행 시 어떤 결과를 달성했는지를 정의합니다. 또한 지표는 분야별 전략목표(goal) 및 프로그램(program) 단위로 체계적으로 구성되어 있어 개발협력 사업이 어떤 논리적 흐름과 구조를 갖추고 있는지 파악하는 데 도움이 됩니다.

# 해양수산부_수산물 수출입품목분류코드_20160629

이 데이터는 해양수산부에서 수산물 수입 또는 수출시 활용되는 분류코드 정보를 제공하기 위해 수집한 데이터입니다. 전체 데이터 조회 또는 특정 품목명, 품목코드 값을 파라미터로 데이터를 조회할 수 있으며, 본 데이터의 주요 내용은 수출입품목 코드, 품목명(국문, 영문), 대/중/소/세분류 코드 및 HSK(국제 무역 표준분류코드) 코드 등 정보로 구성되어 있습니다. 본 데이터는 수산물 관련 무역 업무 처리, 수산물 품목 통계 분석, 품목별 수출입 동향 파악, 수산물 분류체계 기준 수립 등과 같은 분야에 활용될 수 있습니다.

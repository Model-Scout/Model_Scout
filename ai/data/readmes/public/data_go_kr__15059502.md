# 일반음식점(뷔페식) 현황

이 데이터는 경기도 내 다양한 음식을 고정된 장소에 배열해 손님이 자유롭게 선택할 수 있도록 제공하는 뷔페식 일반음식점의 인허가 및 영업현황 정보를 담고 있습니다. 항목에는 사업장명, 인허가일자, 폐업일자, 영업상태, 위생업종명, 위생업태명, 급수시설구분, 종업원 수, 다중이용업소 여부, 소재지 주소정보(WGS84 위도·경도 포함), 총시설규모 등이 포함됩니다. 해당 데이터는 고기뷔페, 한식뷔페, 호텔뷔페 등 다양한 유형의 뷔페 운영 실태 분석, 지역 상권 활성화 계획 수립, 위생관리 강화 등의 목적에 활용될 수 있으며, 경기도 31개 시군 전체를 대상으로 수집되어 Open API를 통해 실시간 연계도 가능합니다.

제공기관: 경기도
분류: 식품건강
키워드: 뷔페식음식점, 일반음식점, 위생업종, 인허가정보, 다중이용업소, 소재지정보, 종업원수, 급수시설구분
형식: api
선정 기준: 운영 자동승인 OpenAPI

# 보건진료소 현황

이 데이터는 경기도 내 의료취약지역에 위치한 보건진료소의 현황을 제공합니다. 보건진료소는 농어촌 등 의료 접근성이 낮은 지역 주민들에게 기본적인 보건의료 서비스를 제공하기 위해 운영되는 시설입니다. 항목에는 사업장명, 진료과목, 병상수, 의료인 수, 인허가일자, 입원실 수, 위치정보 등이 포함됩니다. 해당 데이터는 보건의료 인프라의 지역별 분포 파악, 의료 접근성 향상 정책 수립, 공공보건서비스 강화 등의 목적으로 활용될 수 있습니다. ※ 본 데이터는 2018년 9월 6일자로 갱신이 중단되었습니다.

형식: api

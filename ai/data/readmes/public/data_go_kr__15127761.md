# 국가데이터처_KOSIS 통계설명 조회 서비스_20231231

국가데이터처가 관리하는 KOSIS(국가통계포털)의 방대한 통계 데이터를 사용자가 더욱 정확하게 이해하고 올바르게 해석할 수 있도록 지원하는 오픈 API 서비스입니다. 통계 수치 자체를 제공하는 기존 서비스와 달리, 해당 통계가 도출된 배경과 맥락을 설명하는 메타데이터를 중심으로 구성되어 있습니다. 본 API는 각 통계 조사의 정의 및 개념, 조사 목적, 조사 대상 및 주기, 통계 작성 방법(산식), 주요 용어 해설 등 통계 데이터를 활용하기 전에 반드시 확인해야 할 필수적인 정보를 체계적으로 제공합니다. 데이터 사용자들은 수치 이면의 정확한 기준을 파악함으로써, 발생할 수 있는 데이터 오독이나 왜곡을 방지하고 분석의 신뢰도를 대폭 높일 수 있습니다.

분류: 공공행정

형식: api
선정 기준: 국가중점데이터 OpenAPI

# 위생용품제조업(기타) 현황

이 데이터는 ‘기타 위생용품제조업’에 속하는 사업장의 인허가 및 영업 현황을 정리한 자료입니다. 주요 항목에는 시군명, 사업장명, 인허가일자, 영업상태명(운영중·폐업 등), 폐업일자, 다중이용업소 여부, 위생업종명, 위생업태명, 소재지 도로명주소 및 지번주소, 우편번호, WGS84 좌표(위도·경도)가 포함되어 있습니다. 이 데이터는 지역별 위생용품 제조업 분포 현황을 파악하고, 운영 중인 업체와 폐업 업체의 변화를 분석하는 데 유용합니다. 또한, 위생산업 정책 수립, 안전 관리 강화, 중소기업 지원 정책, 지역 제조업 환경 분석 등에 활용될 수 있습니다.

제공기관: 경기도
분류: 보건의료
키워드: 위생용품, 사업장, 다중이용업소, 제조업, 위생업, 청결
형식: api
선정 기준: 운영 자동승인 OpenAPI

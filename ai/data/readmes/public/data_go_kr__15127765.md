# 국가데이터처_KOSIS 지표명별 설명자료 조회 서비스_20231231

국가데이터처에서 운영하는 KOSIS(국가통계포털)에서 제공하는 다양한 통계 지표에 대한 상세 설명 자료를 조회할 수 있는 서비스입니다. KOSIS 100대 지표를 포함하여 인구, 가구, 고용, 노동, 경기, 물가, 가계 등 국내 주요 통계 지표는 물론, 북한 및 국제(G20) 통계 지표까지 폭넓게 제공합니다. 사용자는 지표명을 통해 해당 지표의 개념, 산정 방법, 출처 등 상세 정보를 JSON 또는 XML 형태로 받아볼 수 있습니다. 이를 통해 통계 데이터의 이해도를 높이고 다양한 데이터 분석 및 서비스 개발에 활용할 수 있습니다

제공기관: 국가데이터처
분류: 공공행정
키워드: 국가통계, KOSIS, 통계지표, 통계설명자료, 지표산정방법
형식: api
선정 기준: 운영 자동승인 OpenAPI

# 한국수력원자력(주)_자체 재생설비 발전 현황_20260319

“자체 재생설비 발전현황” API는 한국수력원자력㈜이 제공하는 공공데이터 서비스입니다. 이 API는 한국수력원자력 자체 재생설비 발전기별 일일 판매량 및 기상정보를 XML 형식으로 제공합니다. 요청 시 서비스키(ServiceKey)를 통해 발전기코드, 발전기명, 발전원(resourceType), 설비용량, 지역, 기온, 습도 등의 상세 정보를 조회할 수 있습니다. 매일 오전 5시 전일 데이터를 갱신합니다. 개발계정은 10,000회 호출이 가능하며, 운영계정은 활용사례 등록으로 트래픽 증가가 가능합니다.

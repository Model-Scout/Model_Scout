# 지식재산처_KIPRISPlus_공모전 아이디어_REST API_20220216

1. 개요 13개 중앙부처 및 지방자치단체의 공모전 수상작, 공개작의 관련 정보를 제공합니다. 공모전을 통해 출품된 제안들 중 중복된 제안들을 가려내기 위하여 국가DB사업으로 구축한 아이디어DB를 API(REST방식) 및 대용량(BULK)으로 제공합니다. 2. 세부 정보 내용 ① 아이디어DB: 수상정보, 공모전명, 공모년도, 한국디자인분류 등의 정보를 XML 형태로 제공합니다. 아이디어명칭, 공모전명, 공모년도, 수상정보, 기술분류, 국제특허분류, 한국디자인분류, 국제디자인분류, 공개방법, 공개일자, 주최기관, 주관기관, 연계출원번호, 아이디어 내용 등 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

제공기관: 지식재산처
분류: 과학기술
키워드: 공모전 수상작, 공모전 공개작, 아이디어DB, 공모전명, 기술 분류
형식: api
선정 기준: 운영 자동승인 OpenAPI

# 과학기술정보통신부_주요정책_20201216

과학기술정보통신부에서 제공하는 주요정책 정보 조회 API 서비스입니다. 국가 과학기술 정책의 체계적인 분류와 관리를 통해 정책 추진 현황을 투명하게 공개하고, 정책 수립부터 실행까지의 전 과정을 국민과 연구자들이 쉽게 파악할 수 있도록 지원합니다. 이 API는 REST 방식의 GET 메서드를 통해 주요정책을 조회할 수 있으며, 공공데이터포털 인증키(serviceKey)를 통한 보안 인증을 적용합니다. 특히 10개의 정책 분야(연구개발정책, 미래인재정책, 정보통신정책, 네트워크정책, 전파정책, 과학기술정책, 과학기술투자, 성과평가제도, 국제협력, 기타)로 체계적으로 분류하여 제공하며, policyType 파라미터를 통해 원하는 정책 분야만 선택적으로 조회할 수 있습니다. 응답 데이터는 XML과 JSON 형식을 모두 지원하며, 정책 제목, 상세페이지 URL, 담당부서명, 담당자 정보, 연락처, 게시일과 함께 정책 계획서, 시행계획, 로드맵 등의 첨부파일을 포함합니다. 데이터는 매일 1회 갱신되어 최신 정책 동향을 실시간으로 확인할 수 있습니다. 이 API는 정책 연구자, 과학기술 정책 분석가, 정부 정책 모니터링 시스템 개발자, 학술 연구기관, 언론사 정책팀 등이 활용할 수 있으며, 특히 과학기술 분야의 정책 변화와 발전 방향을 체계적으로 추적하고 분석하는 데 유용합니다. 표준화된 정책 분류 체계를 통해 정책 간 연계성을 파악하고, 중장기 정책 추진 현황을 종합적으로 이해할 수 있어 효과적인 정책 연구와 의사결정을 지원합니다.

# 병원평가정보(질병-당뇨병) 현황

이 데이터는 경기도 내 의료기관 중 당뇨병 환자의 치료 및 관리가 우수한 의원을 대상으로 건강보험심사평가원이 수행한 병원평가 정보를 제공합니다. 당뇨병은 대표적인 만성질환으로, 정기적 관리와 적절한 치료가 중요하며, 본 평가는 각 의료기관의 진료 실적, 치료 적정성, 환자관리 체계 등 여러 지표를 기반으로 수행됩니다. 공개 항목은 시군명(SIGUN_NM), 시군코드(SIGUN_CD), 기관명(INST_NM), 평가내역(DIV_NM), 평가등급(GRAD), 도로명 및 지번 주소, 우편번호, 위도 및 경도 좌표 등입니다. 해당 데이터는 평가 결과가 양호한 기관만 선별하여 공개되며, 이를 통해 지역 주민이 당뇨병 치료에 적합한 의료기관을 선택할 수 있도록 지원합니다. 특히 의료기관별 진료 수준을 정량적으로 비교할 수 있어 환자 중심의 의료 선택권 확대에 기여하며, 보건정책 수립, 공공의료 질 향상, 만성질환 집중관리 사업 등에 효과적으로 활용될 수 있습니다. 데이터는 Open API 형태로 제공되어 다른 시스템과의 연계가 용이하며, 평가기준의 객관성과 반복성이 확보된 공신력 있는 자료로 다양한 의료 및 보건 행정 분야에서 실무적 활용이 가능합니다.

제공기관: 경기도
분류: 보건의료
키워드: 병원평가, 당뇨병, 질병관리, 의료기관등급, 보건정보, 치료평가, 건강보험심사평가원, 의원정보
형식: api
선정 기준: 운영 자동승인 OpenAPI

# 장례시설 현황 서비스

부산시내에서 운영중인 장례시설의 개방 데이터입니다. 개방된 데이터는 강서구 1, 중구 1, 연제구 1, 북구 2, 기장군 2, 남구 2, 수영구 3, 동구 3, 해운대구 3, 영도구 3, 서구 3, 사상구 4, 금정구 5, 부산진구 6, 동래구 6, 사하구 8 등 부산16개 구군의 장례시설 53 시설에 대한 정보가 포함되어 있습니다. 장례시설의 명칭, 공설/사설 구분, 주소, 전화번호, 최초 운영일, 부지면적, 연면적, 빈소수, 안치 능력, 안치료 사용가격, 염습료, 빈소임대료 등의 정보를 제공하고 있습니다. 장례시설 이용시 개방된 데이터를 참고하여 결정할 수 있습니다. *기준일 2025.5.19 현재

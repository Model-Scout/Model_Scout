# 한국산업단지공단_공장등록현황통계_시도별 업종별 현황

공장등록현황통계의 시도별 업종별 현황 csv 파일로, 한국의 17개 시도에 대한 업종현황을 데이터 기준일자로 제공하고 있습니다. 업종코드의 경우 통계청에서 고시하고 있는 한국표준산업분류코드(5자리)를 기준으로 작성하였으며, 현재 10차 기준으로 제공하고 있습니다. 17시도의 경우 광역시도에 대한 기준으로 서울, 인천, 경기, 강원, 충북, 충남, 대전, 전남, 전북, 광주, 경북, 대구, 경남, 부산, 울산, 제주, 세종 등으로 구분되어 있습니다. 해당 데이터는 공장설립온라인지원시스템(www.factoryon.go.kr)의 민원 데이터를 토대로 작성하였습니다.

제공기관: 한국산업단지공단
분류: 공공행정
키워드: 공장등록현황, 시도별업종, 공장통계, 업종, 공장업종
형식: csv
선정 기준: 중앙·광역 기관 파일데이터

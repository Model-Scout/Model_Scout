# 상수도 보급 집계 현황

이 데이터는 경기도 내 시군별 상수도 보급 현황을 연도별로 집계한 자료로, 총인구수 대비 급수인구수와 상수도 보급률, 광역 및 지방상수도 시설용량 정보를 포함합니다. 데이터 항목에는 시군명, 시군코드, 총인구수, 급수인구수, 보급률(%) 외에도 광역·지방·타시도 상수도 시설의 일일 처리용량이 포함되어 있으며, 수자원 인프라의 효율성 분석, 지역 간 상수도 보급격차 평가, 환경정책 수립 등에 활용될 수 있습니다. API는 인증키 기반으로 제공되며 XML 또는 JSON 형식으로 접근 가능하며, 시군명 또는 코드 기반 조건 검색이 가능합니다. -급수인구수: 상수도를 통해 정수된 물을 공급받는 인구 수를 의미합니다. -보급률: 해당 지역의 총인구수 대비 상수도 급수 인구 비율을 나타내는 지표입니다. -광역시설용량: 여러 시군에 걸쳐 운영되는 대규모 정수시설의 하루 처리 용량을 의미하며, 단위는 ㎥/일입니다. -지방시설용량: 단일 시군 내에 위치한 상수도 정수시설의 하루 처리 용량입니다. -타시도시설용량: 경기도 외 다른 시도에 위치한 정수시설을 통해 공급받는 수돗물의 하루 처리 용량을 말합니다.

제공기관: 경기도
분류: 환경기상
키워드: 상수도, 급수인구, 보급률, 상하수도, 수도통계, 시군정보, 시설용량, 수자원관리
형식: api
선정 기준: 운영 자동승인 OpenAPI

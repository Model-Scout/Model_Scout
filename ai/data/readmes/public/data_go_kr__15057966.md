# CCTV 기반 도로날씨정보 조회서비스

CCTV 지점별 도로날씨정보 조회와 표준노드링크별 도로날씨정보 조회를 제공하는 서비스 기상청의 CCTV 기반 도로날씨정보 조회서비스는 전국 주요 도로에 설치된 도로 기상관측 장비(RWIS) 및 CCTV 영상을 활용해 도로 위의 기상·노면 상태를 실시간으로 제공하는 서비스입니다. 이는 기상청이 운영하는 ‘도로기상정보시스템(Road Weather Information System, RWIS)’의 한 부분으로, 국민들이 교통안전 및 운전계획을 세울 때 참고할 수 있도록 구축되었습니다.

제공기관: 기상청
분류: 과학기술
키워드: CCTV 지점별 도로날씨, 표준노드링크별 도로날씨, 도로기상정보, 기온, 강수
형식: api
선정 기준: 국가중점데이터 OpenAPI
수정일: 2025-09-16
이용허락: 제3자 권리 포함 : 저작권 표시, 공공저작물 : 출처표시 (제 1유형)

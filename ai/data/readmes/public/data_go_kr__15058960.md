# 서울특별시 One-PMIS 부실벌점

해당 데이터는 서울특별시 One-PMIS의 이력관리에 등록된 부실벌점 자료입니다. 데이터의 원본 시스템은 서울특별시 도시기반시설본부 건설정보관리시스템 One-PMIS입니다. 요청인자 : 인증키, 요청파일타입, 서비스명, 요청시작위치(데이터 행 시작번호), 요청종료위치(데이터 행 끝번) 출력값 : 총 데이터 건수(정상 조회 시 출력됨), 요청결과 코드, 요청결과 메시지, 순번, 사업코드, 사업명, 점검일자, 점검종류, 벌점번호, 벌점, 벌점부과 ※ 바로가기 클릭 시 서울 열린데이터광장 개방 데이터로 이동합니다.

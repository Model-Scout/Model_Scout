# 금융위원회_REPO거래정보_20200424

REPO거래정보는 환매조건부채권거래(REPO)의 거래 현황과 잔고 정보를 제공하는 데이터입니다. 데이터는 다음 3가지 오퍼레이션으로 구성되어 있습니다. ① 건별거래 정보 조회 : 기준일자, 거래유형코드 등을 기준으로 거래일자, 매입자·매도자 구분, 거래금액, 거래금리 등을 조회하는 기능 ② 매입증권별 잔고금액 조회 : 기준일자와 증권종류코드를 기준으로 채권유형, 발행기관, 잔고금액, 평가금액 등을 확인하는 기능 ③ 통화별 잔고금액 조회 : 기준일자와 통화코드를 기준으로 통화구분, 보유잔고금액, 평가금액 등의 통화별 현황을 제공하는 기능 * REPO 거래란? : 환매조건부매매로 금융기관이 특정 자산을 일정 기간 후에 원금과 이자를 지급하고 다시 매입하기로 약정하는 거래 ※ 데이터 갱신주기는 일 1회입니다. ※ 금융위원회의 모든 API는 데이터 보유기관으로부터 데이터를 연계받아 수집 후 개방하고 있습니다. 금융위원회에서 제공하는 모든 서비스는 실시간이 아니며, 데이터 갱신은 기준일자로부터 영업일 하루 뒤 오후 1시 이후에 업데이트됩니다. 예를 들어, 금요일 데이터는 차주 월요일에 제공됩니다. (월요일이 공휴일인 경우, 다음 영업일에 제공됩니다) ※ 자주 묻는 질문(FAQ)은 https://www.fsc.go.kr/in060501 에서 확인하실 수 있습니다. ** 유의사항 본 개방데이터는 공공누리 2유형임을 참고하시기 바랍니다. 이용허락범위 제2유형 : 출처표시 + 상업적 이용금지 해당 데이터를 상업적으로 활용하고자 하는 이용자는 데이터 원천 소유자인 한국예탁결제원과 사용 목적과 범위에 따른 정보이용계약이 필요합니다. 정보이용계약 또는 해당 정보에 관하여 궁금한 점이 있으시면 한국예탁결제원 증권정보부(연락처: portal@ksd.or.kr)로 이메일 문의 주시기 바랍니다.

# 국가자격 계열별 학과 정보 데이터

“국가자격 계열별 학과 정보 데이터” API는 한국산업인력공단에서 제공하는 공공데이터 API로, 국가전문자격의 계열 코드에 따라 관련 학과 코드 및 명칭 정보를 XML 형식으로 제공합니다. 이 API는 자격증 정보 시스템, 진로 설계 서비스, 학과 추천 플랫폼 등에서 계열별로 연계 가능한 학과 정보를 효율적으로 조회하고 활용할 수 있도록 지원합니다. 교육기관, 진로상담사, 공공기관 등에서 자격 계열별 연계 학과 데이터를 기반으로 한 분석, 안내, 정보 제공 등에 널리 활용될 수 있으며, 공공데이터포털에서 인증키를 발급받아 이용할 수 있습니다.

제공기관: 한국산업인력공단
분류: 공공행정
키워드: 국가자격, 계열별, 학과, 큐넷, 정보
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2026-09-10
이용허락: 이용허락범위 제한 없음

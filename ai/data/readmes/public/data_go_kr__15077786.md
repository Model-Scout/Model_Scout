# 서울특별시_공공자전거 따릉이 대여소 운영현황(시간대별)

해당 데이터는 서울시 공공자전거 대여 이력 OpenAPI 데이터입니다. 데이터의 원본시스템은 서울자전거 홈페이지(https://www.bikeseoul.com)입니다. 최근 7일이내의 대여소 및 시간별 자전거 대여가능 건수, 거치율, 대여소 위치정보를 제공합니다. 호출시 시스템 부하로 한번에 최대 1,000건를 초과할수 없습니다. - 시스템 구조상 대여시간이 '시간'단위로밖에 표시되지 않는 점 유의 바랍니다. - 최근 7일 이내만 확인 가능합니다. ※ 바로가기 링크 클릭 시 서울 열린데이터광장 개방 데이터로 이동합니다.

제공기관: 서울특별시
분류: 공공행정
키워드: 자전거, 따릉이, 공공자전거, 대여, 이력
형식: xml
선정 기준: 중앙·광역 기관 파일데이터

# 문화체육관광부 국립중앙도서관_OAK(OPEN ACCESS KOREA) 학술정보_20220721

Open Access(오픈액세스)란? 오픈액세스는 "학술정보에 대한 자유로운 접근과 이용" 이라는 개념으로 인터넷을 통해 누구나 어디서든지 각종 연구성과물들을 출판과 동시에 자유롭게 공유 할 수 있도록 하는 국제적 운동입니다. 국립중앙도서관은 국내 기관리포지터리에서 수집된 학술정보를 OAK 국가리포지터리를 통해 제공하고 있습니다. 공공데이터 포털의 OAK 국가리포지터리 API를 통해 데이터를 활용할 수 있으며, OAK 국가리포지터리(oak.go.kr) 누리집을 통해서도 리포지터리에서 수집된 콘텐츠를 직접 검색 가능합니다. 또한 OAK 국가리포지터리에서 오픈액세스 학술지의 XML 원문 구축자료를 text 형태로 이용하실 수 있습니다. 이 외 국내 학술지저적권안내시스템(KJCI: Korea Journal Copyright Information) 을 통해 국내 학술지의 오픈액세스 관련 정책을 확인하실 수 있습니다.

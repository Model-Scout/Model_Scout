# 시‧도별 등록장애인 집계현황(장애등급별)

이 데이터는 전국 시도별 등록장애인의 장애등급별 현황을 제공하며, 장애인 인구 분포와 복지 수요 파악에 활용됩니다. 보건복지부와 경기도청 장애인복지과가 공동 제공하며, 매년 12월 말 기준의 자료로 시도별 장애인 수를 등급별로 집계합니다. 장애등급은 1급에서 6급까지로, 숫자가 작을수록 장애 정도가 심함을 의미합니다. 최근에는 등급제에서 ‘심한 장애’와 ‘심하지 않은 장애’로 단순화된 분류도 함께 제공합니다. 데이터는 정책 수립, 예산 배분, 지역별 복지 서비스 설계 등에 근거 자료로 활용되며, 특히 장애인복지법 개정 전·후 변화 분석에 중요합니다.

제공기관: 경기도
분류: 사회복지
키워드: 장애인수, 장애급수, 장애인인구, 등록장애인, 장애등급, 장애정도, 누림센터, 장애유형별
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-09-25
이용허락: 이용허락범위 제한 없음

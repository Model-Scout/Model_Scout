# 행정안전부_행정안전부_실시간 지도제공정보 조회(검색API)

1. API 서비스 개요 - 웹 기반의 지도 및 검색UI 제공 - DB 구축 및 현행화 부담 없음 - 실시간 주소 검색 가능 - 신청 및 승인 필요 - 1 시스템 1 승인키 부여 2. 지도제공 소개 - 웹 기반으로 실시간 지도(벡터 데이터로 구성된 타일맵 형식) 서비스를 제공합니다. - 우측 컨트롤러를 통해 초기화, 지도 확대/축소, 거리/면적 측정, 각종 레이어(기초구역, 행정구역, 민원행정기관) 기능을 제공합니다 3. 입력 파라미터 정보 신청 시 부여받은 승인키,도로명주소 검색결과 출력유형(1 : 도로명, 2 : 도로명+지번),검색결과 페이지당 출력할 결과 Row 수,지도 출력유형(1 : 위치/도로명주소 표기(작은영역 권장), 2 : 위치/주소 상세정보(작은영역 권장), 3 : 위치/주소 상세정보/검색결과(큰영역 권장), 4 : 위치/주소 상세정보/검색결과 (큰영역 권장)),주소검색(1 : 좌표정보, 2 : 도로명주소 코드정보, 3: 검색어),좌표정보(GRS80) - X좌표,좌표정보(GRS80) - Y좌표,도로명주소 코드정보 - 행정구역코드,도로명주소 코드정보 - 도로명코드,도로명주소 코드정보 - 지하여부,도로명주소 코드정보 - 건물본번,도로명주소 코드정보 - 건물부번,검색어

제공기관: 행정안전부
분류: 과학기술
키워드: 주소, 도로명주소, 지도제공(검색API), 주소위치검색, 지도검색
형식: json+xml
선정 기준: 중앙·광역 기관 파일데이터

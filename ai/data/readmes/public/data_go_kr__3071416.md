# 법무부_수용자처우 관련 통계

1. 수용자의 편지 수발신 현황(일반편지, 특수우편물, 전자편지) 및 수용자 접견, 보관금품, 진료 등에 대한 연단위 통계데이터 제공 2. 교정시설내 수용자 생활과 관련한 데이터 확인 가능 3. 수용자의 편지 수발신 현황, 접견현황, 보관금품 현황, 진료 현황을 통해 교정관계 수용자 처우에 대한 현황을 제공 4. 수용자 처우의 향상은 교정교화 및 건전한 사회복귀를 하는데 중요한 통계 자료로 활용 가능 5. 수용자 처우 관련 주요 통계 자료는 법무부 홈페이지 및 교정본부 홈페이지에 게시된 교정통계연보로도 확인 가능

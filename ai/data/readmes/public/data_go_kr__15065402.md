# 보건복지부_진료정보교류 참여 의료기관 현황

보건복지부에서 2024년 4월 말 기준으로 진료 정보를 교류하는 의료기관의 우편번호, 주소, 등록일자 등을 제공하고 있습니다. <데이터 이용 시 참고사항> 1. 진료정보교류 : 환자의 진료 시 의료인이 생성한 진료기록을 의료인 간에 전자적인 방식으로 교류문서를 상호 교환하는 방식 2. 진료정보교류 사업 : 의료의 연속성을 보장하기 위해 개인정보 제공에 동의한 국민(환자)에 대하여 본인의 진료기록을 원하는 의료기관에 전자적 방식으로 안전하게 송수신하여, 의사가 환자 진료에 참조할 수 있도록 교류하는 서비스

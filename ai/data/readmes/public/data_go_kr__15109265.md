# 국토교통부_데이터 시각 분석서비스_20221207

검색어, 데이터 등록일을 이용하여 국토교통부 데이터 통합채널의 정책으로 활용할 수 있는 유즈케이스를 기반으로 한 시각분석정보의 데이터 제목, 카테고리, 키워드, 제공기관, 원본등록일, 제공페이지 URL을 조회할 수 있는 국토교통부 데이터 시각분석정보 서비스 입니다. 공공데이터의 제공기관, 제공범위, 활용가능 분야 등을 안내하고 공공데이터를 활용한 창업과 사업화 방법에 대한 자문 등 공공데이터 개방(공공부문)과 이용 활성화(민간부문) 전반을 지원하기 위하여 제공하는 데이터 입니다.

제공기관: 국토교통부
분류: 국토관리
키워드: 데이터분석, 시각화, 규제지역, 유즈케이스, 시각분석
형식: api

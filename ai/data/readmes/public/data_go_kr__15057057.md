# 휴게음식점(백화점) 현황

이 데이터는 경기도 내 백화점에 입점한 휴게음식점의 인허가 현황 정보를 제공합니다. 해당 음식점은 아이스크림류, 패스트푸드점, 분식점 형태로 음식류를 조리 및 판매하는 업소로, 시군명, 사업장명, 인허가일자, 영업상태명, 폐업일자, 소재지 주소, 급수시설 구분, 위생업종명 및 위생업태명, 종사자수, 다중이용업소 여부, 위치정보(WGS84 위경도 좌표계) 등 다양한 항목으로 구성되어 있습니다. 이 데이터는 대형 쇼핑시설 내 외식 공간의 유통현황 분석, 소비 패턴 조사, 식품안전 모니터링, 외식창업 입지분석 등에 유용하게 활용될 수 있습니다. 데이터는 Open API 형식으로 XML 또는 JSON으로 제공됩니다.

제공기관: 경기도
분류: 식품건강
키워드: 휴게음식점, 백화점, 인허가현황, 위생업소, 쇼핑시설, 푸드코트, 패스트푸드, 분식점
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-06-24

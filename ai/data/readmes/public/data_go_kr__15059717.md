# 한국국제협력단_ODA 실적보고 로데이터

한국국제협력단이 OECD DAC(개발원조위원회)에 보고한 ODA 사업정보 로데이터로, 사업명, 사업분야, 지역명, 사업실시기관, 해당 SDGs 지표 등을 제공합니다. * 코드 칼럼 설명 - [채널코드]: [사업실시기관]에 명시된 데이터 값의 코드를 기재한 코드 칼럼입니다. - [원조유형코드]: [원조유형]에 명시된 데이터 값의 코드를 기재한 코드 칼럼입니다. - [지속가능개발목표(SDGs)]: OECD CRS CODE list 파일 내 SDGs focus 시트(코드북) 참조 - [기술협력],[프로그램원조],[프로젝트원조코드],[혼합신용]: 관련 사업의 칼럼 속성 해당 여부를 표시한 칼럼입니다. (해당 시 = 1, 해당하지 않을 시 = 0) - [통화]: 통화코드를 나타내는 칼럼으로 해당 데이터 값(302)은 USD를 뜻합니다. * 공란으로 남겨진 데이터 값의 경우, 사업에 해당되지 않아 미집계된것입니다.

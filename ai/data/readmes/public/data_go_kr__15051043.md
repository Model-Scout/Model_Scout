# 건강보험심사평가원_요양기관개폐업정보조회서비스_20161213

기준년월에 개폐업 또는 휴업한 병원과 약국의 요양기관명, 개폐업휴업구분, 전화번호, 주소 등을 조회하는 서비스 - 요양기호는 1:1로 매칭한 암호화된 요양기호로 제공하고 있으며, 별도의 복호화 방법 또는 요양기호는 제공하고 있지 않습니다. - 지역코드 등 API 활용을 위한 코드는 보건의료빅데이터개방시스템(opendata.hira.or.kr) > 서비스 소개 > 용어설명 > 코드조회를 참고하여 주시기 바랍니다. ※ 폐업정보는 기준년월 관계없이 최근 1년간 데이터를 제공합니다. ※ 개업정보는 기준년월 기준으로 개업한 데이터를 제공하고 있으며, 폐업정보가 적재시점으로부터 최근 1년 내에 이루어진 경우에는 동시 조회됩니다.

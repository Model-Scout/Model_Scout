# 외교부_국가(지역)별 정치현황

외교부 홈페이지에 공개 중인 각 국가별 약황 정보 중 일반정보를 CSV 형식으로 제공합니다. 데이터에는 한글 국가명, 영문 국가명, 국가코드(ISO 2자리), 정부형태, 국가형태, 의회구성, 주요정당, 대외정책, 주요인사 등을 포함하고 있습니다. 이러한 데이터는 해외 진출 기업이나 공공기관이 해당 국가와의 교류·협력 전략을 세우는 데 필요한 기본 정치 정보를 제공하며, 국제정세 분석과 외교정책 수립에도 중요한 참고자료로 활용됩니다. (데이터 업데이트 주기: 12개월, 실시간 정보는 동명의 API 참고)

제공기관: 외교부
분류: 통일외교안보
키워드: 국가_지역정보, 국가_영해, 정치, 약황_정보, 의회_구성, 전당_현황
형식: csv
선정 기준: 중앙·광역 기관 파일데이터
수정일: 2026-07-15
이용허락: 이용허락범위 제한 없음

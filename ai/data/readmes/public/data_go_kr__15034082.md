# 비브리오균 조사 정보 서비스

보건환경연구원에서 하절기 세균성 감염질환 원인 분석을 위해 6개 지역의 위치에서 조사한 비브리오균 조사 정보 데이터입니다. 개방된 데이터는 측정연월, 측정위치, 조사회차, 비브리오 콜레라균, 비브리오 패혈증균, 장염 비브리오균 의 데이터를 포함하고 있습니다. 측정위치는 기장군A지점, 사하구A지점, 수영구A지점, 중구A지점, 중구B지점, 서구A지점 6곳입니다. 측정위치별로 2009년부터 2023년까지의 측정자료입니다. 3종의 세균에 대해서 검출/불검출 여부를 보여줍니다. 수산물을 구매 소비하는 소비자 입장에서 세균 검출여부를 통해 안전한 식생활을 할 수 있습니다.

제공기관: 부산광역시
분류: 보건의료
키워드: 감염, 세균, 질병, 콜레라, 패혈증, 장염
형식: api
선정 기준: 운영 자동승인 OpenAPI

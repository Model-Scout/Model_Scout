# 한국토지주택공사 비축토지 현황

LH에서 보유하고 있는 수급조절용 토지 및 기업의 부채상환용으로 매입한 토지 목록의 상세 정보(사업지구, 소재지, 면적 등)를 제공합니다. 21년도까지의 자료이며 지구별로 살펴볼 때 제주지역본부 46 지구, 부산울산지역본부 44 지구, 대전충남지역본부 28 지구입니다. 한국토지주택공사는 5,072,705 미터제곱의 토지를 비축하고 있으며 이중 81.1%가 제주지역본부의 비축토지이며, 4.5%가 광주전남지역본부의 토지입니다. 지목으로는 목 부분이 가장 많으며 전체 토지의 65.5%를 차지하고 있습니다.

# 국토안전관리원_콘크리트 압축강도 시험

국토안전관리원에서 제공하는 여러 시설물을 대상으로 콘크리트 압축강도 시험을 수행한 결과 데이터 입니다. 모두 1종 시설물에 해당하며, 각 시설물은 교량, 댐, 상하수도, 터널, 하천, 항만으로 6개로 분류되어 있습니다. 설계기준강도, 코어강도, 측정횟수, 측정치, 반발경도, 재령일수, 재령보정계수외 여러 항목이 있으며 결과 데이터를 제공드립니다. 타격각도의 단위는(˚)입니다. 빈 값의 사유 : 데이터 미집계(시험결과에 따라 데이터가 집계되지 않은 항목도 존재), 정보제공을 위해 데이터가 없는 항목 제공

제공기관: 국토안전관리원
분류: 재난안전
키워드: 시설물, 콘크리트, 압축강도, 터널, 압축, 1종_시설물, 교량, 상하수도
형식: csv
선정 기준: 중앙·광역 기관 파일데이터

# 사회복지법인 행정 처분결과 현황

이 데이터는 경기도 내 사회복지법인에 대한 행정처분 결과 현황을 제공하며, 최근 5년간의 처분이력을 포함합니다. 데이터 항목에는 법인명, 소재지 주소(도로명/지번/우편번호), 시군명 및 코드, 위반내용, 처분결과, 데이터 기준일자 등이 포함되어 있습니다. 이를 통해 각 법인의 위반 유형과 행정적 조치 사항을 확인할 수 있으며, 비영리 법인의 법적 준수 여부 모니터링, 사회복지 정책 수립, 법인 운영 신뢰성 확보 등에 활용될 수 있습니다. API는 XML 및 JSON 포맷으로 제공되며 인증키를 활용하여 시군별 검색이 가능합니다. 데이터는 사회복지사업법 제51조 및 시행령 제24조의2를 기반으로 수집됩니다.

제공기관: 경기도
분류: 사회복지
키워드: 사회복지법인, 행정처분, 위반사항, 법인정보, 비영리조직, 처분결과, 복지정책, 법인허가
형식: api
선정 기준: 운영 자동승인 OpenAPI

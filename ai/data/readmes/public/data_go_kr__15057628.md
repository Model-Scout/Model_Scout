# 지식재산처_KIPRISPlus_디자인맵 형태분류_REST API_20220308

1. 개요 디자인을 물품의 유형, 구성 요소와 같은 특징적인 형태에 따라 분류한 형태검색 DB 정보를 제공합니다. 각 물품의 유형과 구성요소 같은 특징적인 형태에 따라 분류가 되어 있어 조사디자인의 세부적인 형태요소와 가장 근접한 형태를 검색하여 효율적으로 디자인 검색이 가능한 DB를 API(REST방식) 및 대용량(BULK)으로 제공합니다. 2. 세부 정보 내용 ① 디자인맵: 출원번호, 디자인일련번호, 출원국가 등의 정보를 XML 형태로 제공합니다. ② 특성분류정보: 물품명, 레벨, 특성코드 등의 정보를 XML 형태로 제공합니다. 물품코드, 형태분류코드, 물품유형(분류), 물품의 명칭(출원), 폼심벌(세부형태분류코드 취합) ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

제공기관: 지식재산처
분류: 과학기술
키워드: 물품코드, 형태분류코드, 폼심벌, 디자인맵, 특성분류정보
형식: api
선정 기준: 운영 자동승인 OpenAPI

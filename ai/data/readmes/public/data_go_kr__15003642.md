# 보건복지부_한방외래진료 이용율

보건복지부에서 2017년,2020년,2022년,2024년 한방외래진료 이용율 현황에 대한 정보를 성별(남성비율, 여성비율), 병원유형별(한방병원 비율, 한의원비율), 연령별(30대이하비율, 40대비율, 50대비율, 60대이상비율)로 분류하여 제공하고 있습니다. <데이터 이용 시 참고사항> 1. 해당 데이터는 보건복지부에서 게시하는 한방의료이용실태조사 보고서 내 유의미한 데이터를 발췌하였기에 해당 보고서 내용에 따라 연도별 구분 내용이 상이할 수 있음 2. 통계수치는 해당 년도의 전년도 4월부터 당해 년도 3월까지 건강보험 심사결정 기준 환자 수(건강보험심사평가원)를 기준으로 모수추정한 결과임 (단, 2017년 자료는 2016년 건강보험, 의료급여 대상자 기준 실환자 수(건강보험심사평가원)로 모수추정하였으며, 2020년 자료는 2019년9월~2020년8월까지 건강보험 심사결정 기준 환자수(건강보험심사평가원)로 모수 추정하였음) 3. 통계 데이터 조사 대상 기간 : 전년도 9월1일부터 당해 년도 8월 31일 4. 통계자료는 단위 미만을 반올림하였으므로 합계의 숫자와 각 항목별 삽계의 숫자는 일치하지 않을 수도 있음

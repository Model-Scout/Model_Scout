# 소각처리시설 일일대기질 현황 서비스

미세먼지, 초미세 먼지, 황사 등 대기질이 오염되어 실외 활동에 제약이 많아지고 있어서 환경공단에서 운영중인 소각시설에서 소각시 발생하는 대기오염물질 발생 정보를 제공하고 있습니다. 개방된 데이터에는 사업소코드, 사업소명, 연, 월, 일, CO(일산화탄소), 먼지, HCL(염화수소), NOX(질소산화물), SOX(황산화물), 일별 소각처리량 등의 정보를 제공하고 있습니다. 명지사업소1호기, 명지사업소2호기, 해운대사업소2호기 3곳의 소각시설에서 발생하는 대기오염물질의 정보를 2025년 발생한 78건의 자료를 제공하고 있습니다 *기준일 2025.5.19 현재

제공기관: 부산광역시
분류: 환경기상
키워드: 오염, 대기, 공해, 먼지, 질소산화물, 황산화물
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-05-21
이용허락: 이용허락범위 제한 없음

# 국가학술정보 Open-API 검색 서비스

국가학술정보 융합데이터 공유서비스의 검색 서비스를 외부에 공개하여 다양한 분석 서비스 및 어플리케이션을 개발할 수 있도록 외부 개발자 및 사용자들과 API으로 공유하는 서비스. 대한민국 연구자 정보, 주제어 정보, 학술정보 융합데이터 상세보기, 다양한 검색 필터 기준 학술정보 통합검색 결과 등을 제공함.

제공기관: 국회 국회도서관
분류: 공공행정
키워드: 국가학술정보, 융합데이터, 검색서비스
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2019-11-13
이용허락: 이용허락범위 제한 없음

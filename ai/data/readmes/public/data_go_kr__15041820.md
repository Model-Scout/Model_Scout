# 수시분양 결과 조회

국립식량과학원에서 개발되는 품종에 대해 도농업기술원, 농업관련 학교, 기관 및 농민에게 제공하는 분양 실적에 대한 정보임 - 제공 항목(작물수시보급내역조회) : 분양년도(lttotYear), 분양일자(lttotDate), 작물구분(cropsSpchcknNm), 품종명(spciesNm), 분양구분(lttotSpchckn), 요청수량(reqstQyKg), 분양수량(lttotQyKg), 유무상구분(grtsSpchckn), 분양부서(lttotDept), 요청기관(reqstInstt), 분양목적(lttotPurpose), 판매대금(sleAmount), 지역/도(do), 지역/시군(si), ATIS 품종 ID (atisSpciesId)

제공기관: 농촌진흥청 국립식량과학원
분류: 농축수산
키워드: 품종, 분양, 수시, 작물, 농업
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2026-08-27
이용허락: 이용허락범위 제한 없음

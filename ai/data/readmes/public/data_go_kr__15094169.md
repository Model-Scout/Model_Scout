# 한국도로교통공단_부문별 어린이 교통사고 통계

- 시도 시군구별 12세 이하 어린이 교통사고(2018) (사고건수,사망자수, 부상자수, 중상, 경상, 부상신고) * 부상자수 : 중상자수 + 경상자수 + 부상신고자수 ** "사망" 이란 교통사고 발생시로부터 30일이내에 사망한 경우 (99년까지는 72시간 이내) ** "중상" 이란 교통사고로 인하여 3주 이상의 치료를 요하는 부상을 입은 경우 ** "경상" 이란 교통사고로 인하여 5일 이상 3주 미만의 치료를 요하는 부상을 입은 경우 ** "부상신고" 란 교통사고로 인하여 5일 미만의 치료를 요하는 부상을 입은 경우 - 경찰에서 조사, 처리한 교통사고에 대한 통계 정보로 인적 피해가 있는 사고만 집계 됨 - 교통사고분석시스템(http://taas.koroad.or.kr)의 데이터를 바탕으로 함

# 부산 오늘의 수질 정보 조회

부산시 정수장별 상수도수질정보 및 수질통계 자료를 개방합니다. 개방하는 데이터에는 부산의 생활용수 및 공업용수 생산량 현황, 오늘의 수질(공업용수), 오늘의 원수 수질, 오늘의 정수수질, 오늘의 정수 상세 정보 등이 포함되어 있습니다. 생산량은 범어사, 덕산, 공업, 명장, 화명 생산량과 생산량 합계를 제공하고, 공업용수 오늘의 수질은 전기전도도, pH, 탁도, 알칼리도, 염소이온, 경도, 등의 검사항목이 있고, 원수 수질과 정수수질은 pH, 탁도, 암모니아성질소, 총유기탄소 등이 범어사, 화명, 덕산, 명장의 검사결과를 제공합니다.

제공기관: 부산광역시
분류: 환경기상
키워드: 생활용수, 공업용수, 원수수질, 정수수질, 생산량, 검사, 시험항목
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-08-28
이용허락: 이용허락범위 제한 없음

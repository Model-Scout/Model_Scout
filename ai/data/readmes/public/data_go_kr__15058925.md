# 보행어린이사고다발지역정보서비스

12세이하 보행어린이 교통사고에 대한 사고다발지역 정보 - 대상사고 : 1년간 발생한 12세 이하 보행어린이가 다치거나 사망한 교통사고 - 다발지역 선정 조건 : 반경 200m 내 대상사고 3건 이상 발생지점(사망사고 포함 시 2건 이상) - WMS 형태의 API 정보는 교통사고정보개방시스템(https://opendata.koroad.or.kr/api/sample.do)을 통해 확인하실 수 있습니다. * 해당자료는 교통사고분석시스템(https://taas.koroad.or.kr) 데이터를 기반으로 함

제공기관: 한국도로교통공단
분류: 재난안전
키워드: 교통사고 다발지역, 보행어린이사고, 교통안전, 교통사고, 사고다발지역
형식: api
선정 기준: 국가중점데이터 OpenAPI

# Diverse User Prompts v2

250,000 synthetic first-turn user prompts across 217 topics, 64 writing styles, 8 lengths, 12 complexity types (talk mode), 11 task specification levels (task mode), and 16 languages with a 60% English bias.

Every prompt is answerable and self-contained. Prompts are split into **talk** (discussion, advice, troubleshooting) and **task** (produce an artifact — write, translate, summarize, code, rewrite) modes, each with mode-appropriate difficulty axes.

Full axes and sampling code available in [axes_v2.py](axes_v2.py)

## Schema

JSONL, one object per line

| Field | Type | Description |
|-------|------|-------------|
| `topic` | string | Domain category. 217 values, each tagged as talk-only, task-only, or both |
| `mode` | string | `"talk"` (discussion/advice) or `"task"` (produce an artifact) |
| `style` | string | How the person writes. 64 values including 4 intellectual peer registers |
| `length` | string | Target word count bucket. 8 values, from "3-8 words" to "500+" |
| `complexity` | string \| null | Problem structure (talk mode only). 12 values. Null for task mode |
| `task_spec_level` | string \| null | Specification density (task mode only). 11 values incl. rewrite variants. Null for talk mode |
| `language` | string | One of 16 languages, weighted 60% English |
| `prompt` | string | The generated user prompt text |

## Axes

Prompts are generated by sampling from six independent axes, with mode-appropriate branching:

**Topic** (217): Each tagged `talk`, `task`, or `both`. Covers software engineering, household repair, cooking, creative writing tasks, science, personal life, NSFW, casual conversation, meta/adversarial, niche hobbies, health, philosophy, data extraction tasks.

**Mode** (2): `talk` for discussion/advice, `task` for artifact production. "Both" topics resolve 40/60 toward task at sample time.

**Style** (64): Writing voice and social posture. Ranges from "gen alpha brainrot slang" to "formal academic" to "building-toward-something — a chain of reasoning that accelerates as it goes." Includes 4 intellectual peer registers (bag-of-notes, here's-my-framework, mid-stream-thinking, building-toward-something) restricted to 80+ word lengths, and a shared-joke shorthand register restricted to sub-80 word lengths. 24 verbose styles excluded from the 2 shortest lengths.

**Length** (8): From "extremely terse — 3-8 words" to "an essay — 500+ words."

**Complexity** (12, talk only): Problem structure — straightforward, has a gotcha, XY problem, works on my machine, overconstrained, missing context, time pressure, already tried everything, scale problem, legacy constraints, conflicting information, multiple interacting issues.

**Task spec level** (11, task only): Specification density — from "bare minimum" through "full spec doc." Includes rewrite variants (bare minimum rewrite, detailed rewrite) that require source material in the prompt, plus structural challenges (conflicting constraints, reference-based, iterative revision, underspecified on purpose). 5 verbose spec levels excluded from short lengths.

**Language** (16): Weighted 60% English. Spanish, French, German, Portuguese, Japanese, Korean, Chinese, Hindi, Arabic, Russian, Turkish, Polish, Italian, Dutch, Indonesian. Non-English prompts are culturally adapted, not translated — a Hindi parenting prompt references joint families, a Korean cooking prompt uses gochujang.

## Filtering

Nonsensical combinations are excluded via scalpel blacklists:

- Verbose styles/specs × short lengths (can't write a spec doc in 5 words)
- Peer registers × short lengths (need 80+ words to establish the register)
- Shared-joke shorthand × long lengths (these are inherently terse)
- Casual conversation topics × structural complexity types (no "XY problem" in small talk)
- ESL style × non-English languages
- 4 anglosphere-niche topics restricted to English only
- Proofreading × verbose task specs (nobody writes a spec doc for proofreading)

## Generation

Each prompt is a single API call to Gemma 4 31B (`google/gemma-4-31b-it` via OpenRouter), 128 calls in parallel. The model receives the sampled spec and returns raw prompt text. Metadata is attached by the script, not the model.

The system prompt tells the model to write answerable first-turn prompts with specific situational details, inhabiting (not performing) the specified style. Short prompts must still be identifiably on-topic. NSFW topics use a permissive system prompt addition.

```bash
python generate.py --n 250000 --workers 128 --output prompts_v2.jsonl
python generate.py --resume prompts_v2.jsonl  # resume interrupted run
```

**Kink / reddit / XY problem** (talk, english):
> Title: Help with "Safe Word" automation/logging apps? (Need a way to track "aftercare" metrics)
>
> Hey everyone, long time lurker, first time posting here. I'm in a long-term D/s relationship and we've been trying to get more "scientific" about our scenes...

**Arabic chemistry / conflicting constraints** (task, arabic):
> أرجو من سيادتكم تزويدنا بتقرير مفصل حول استقرار المادة الكيميائية (X-42) عند درجة حرارة 100 مئوية، مع ضرورة الحفاظ على المادة في حالتها السائلة تماماً طوال فترة الاختبار. يرجى مراعاة أن هذه المادة تغلي وتتحول إلى غاز عند درجة حرارة 75 مئوية.

**Birdwatching / casual / scale problem** (talk, english, 6 words):
> too many birds to log manually

**Chinese keyboard nostalgia / scale problem** (talk, chinese):
> 记得十年前我刚接触机械键盘的时候，那时候觉得只要买个量产的青轴键盘，敲起代码来就有种在写剧本的仪式感。后来慢慢痴迷上了客制化 [...]

**Regex / here's-my-framework / full spec doc** (task, english):
> I've developed a "Capture-Entropy Scale" for regex maintenance: 1 is a literal string, 5 is a nested recursive pattern that breaks on a single newline. I'm auditing a legacy log-parser that's currently a level 5 nightmare. Can you rewrite the provided pattern to a level 2 by decomposing it into a named-group dictionary?

**Economics / building-toward-something** (talk, english):
> So I've been thinking about why my local coffee shop raised prices by 50 cents last month, and at first, I just thought it was inflation, right? But then I noticed the place across the street didn't change their prices at all, which makes me wonder if it's not just about the cost of beans but more about the specific demand for that one shop's atmosphere [...]

## Use cases

- Fine-tuning: pair with responses from your target model for SFT datasets
- Evaluation: test how models handle diverse styles, complexity types, languages, and task specifications
- Robustness: stress-test against misspelled, slang-heavy, multilingual, or NSFW inputs
- Classification: train on the labeled style/topic/complexity/mode metadata
- Intellectual engagement: the peer-register styles (bag-of-notes, building-toward-something) test whether models can engage with user thinking rather than just answer questions

## Known limitations

- **Single-turn only.** Every prompt is a first message. Multi-turn conversations, follow-ups, and iterative refinement across turns are not represented.
- **No multimodal context.** No images, screenshots, audio, or file attachments. Real users frequently paste screenshots of errors, photos of broken things, or upload documents.
- **Synthetic substance in peer registers.** The intellectual peer styles (bag-of-notes, here's-my-framework, building-toward-something) produce coherent but not brilliant content. The register is captured; the quality of the underlying thinking is "B+" not "A+". For evaluating genuine intellectual engagement, curated real prompts are better.
- **Rewrite prompts contain synthetic source material.** The rewrite task-spec variants generate fake source text to be rewritten. This is functional but less realistic than prompts containing real artifacts.
- **Cultural adaptation is unvalidated.** Non-English prompts are generated by Gemma with no native-speaker review. Quality likely varies by language — high-resource languages (Spanish, French, German, Japanese) are probably better than lower-resource ones.

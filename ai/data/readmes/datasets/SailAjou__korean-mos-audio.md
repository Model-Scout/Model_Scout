# 한국어 합성 음성 평가 자료

신규 모델: CLID-TTS (5epoch, step 1735), Qwen3-SFT-VD-CLID (5epoch, step 1735), VoxCPM2, Gemini 3.1 Flash TTS, Qwen3-TTS VoiceDesign (Base-init). 각 897개, 신규 WAV 총 4,485개. 기존 평가 기록을 재생할 수 있도록 이전 음성 패키지도 보존합니다.

모델 가중치, 참여자 정보, 평가 응답, 비밀번호 및 API 토큰은 포함하지 않습니다. 모델별 평가 항목은 MOS 관리자 화면에서 선택합니다.

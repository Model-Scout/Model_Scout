## Reproduce This Run

Use the command below to regenerate a dataset with the same publish-time configuration.

```bash
uv run main.py generate \
+  --repo-id "junyeong-nero/synthetic-ocr-images-ko-50k" \
+  --lang ko \
+  --size 50000 \
+  --markdown-renderer playwright \
+  --style-profile balanced \
+  --similar-char-ratio 0.08 \
+  --novelty-window 80 \
+  --novelty-threshold 0.95 \
+  --novelty-max-attempts 4 \
+  --formula-source-mode mixed \
+  --formula-dataset-weight 0.45 \
+  --formula-random-weight 0.3 \
+  --formula-synthetic-weight 0.25 \
+  --train-ratio 0.9 \
+  --test-ratio 0.1
```

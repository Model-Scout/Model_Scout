# KTB RAG — 카카오 약관 조항 인덱스 (17팀)

카카오테크 부트캠프 AI 성능 개선 대회용. 약관 4종을 **조(條) 단위**로 파싱하고,
긴 조는 항(項) 단위로 2차 분할한 검색용 청크를 함께 담았습니다.

> ⚠️ 이 데이터셋은 **팀 내 공유·검증용**입니다. 결과기 노트북은 약관 원문을 셀 안에
> 문자열 상수로 임베드하므로 실행 시 이 저장소에 접근하지 않습니다(네트워크 의존 0).

## 파싱 규칙

1. **조 헤더**: `^제\s*(\d+)\s*조\s*(?:\(제목\)|제목)?$`
   두 표기를 모두 처리합니다 — `제 1 조 (목적)`(현행 3종) / `제3조 약관 외 준칙`(통합 약관)
2. **장(章) 헤더 제거**: 장 헤더는 다음 장 첫 조 앞에 와서 그냥 두면 직전 조 본문에
   흡수됩니다(72개 중 10개에서 발생). `^제\s*\d+\s*장.*$` 로 제거합니다.
3. **정규화**: NFC + 가운뎃점 통일(`・` U+30FB → `·` U+00B7).
   원문 사이트가 같은 표현에도 두 문자를 섞어 씁니다.
4. **2차 분할**: 900자 초과 조만. 원문자(①②③) 경계 우선,
   없으면 `^\d{1,2}\.` 폴백(**카카오 통합 약관은 원문자를 쓰지 않음**).
   조 도입부를 각 청크에 붙여 문맥을 보존하고, 조번호는 원 조를 그대로 상속합니다.

## related_articles

4종 중 3종(계정·통합서비스·통합)은 2022년 Daum-카카오계정 연동 종료로 하나였던
약관이 쪼개진 흔적이라 통지·개인정보보호·손해배상 조항이 문서 간에 거의 그대로 겹칩니다.
문자 bigram Jaccard >= 0.5 인 조항 쌍을 `related_articles` 에 기록했습니다.

겹치는 조 수: 계정 10 / 통합서비스 15 / 통합 14 / **위치정보 0**
(위치정보 이용약관만 법 근거가 달라 독립적)

**검색 가중치 튜닝과 자체 QA용 메타데이터이며, LLM 프롬프트에는 넣지 않습니다.**

## 검증

- 4종 모두 제1조부터 번호 누락 없이 연속 (파싱 시 assert)
- 공개 10문항 정답 조항 12건 전부 조번호·제목 대조 일치
- 가지조항(`제N조의M`)·부칙 0건

## GlotLID Corpus


This is the corpus used to train the open [GlotLID model](https://huggingface.co/cis-lmu/glotlid), a language identification model capable of classifying ~2000 labels.
**The list of raw texts supported in this repository is openly available here**: https://github.com/cisnlp/GlotLID/blob/main/sources.md

### Download

The recommended way to download the data is via `git clone`:

```sh
git clone https://huggingface.co/datasets/cis-lmu/glotlid-corpus
```

Use a [Hugging Face access token](https://huggingface.co/settings/tokens) as the Git password/credential.

---

However, if you're only interested in a subset of the data, the preferred method is to use the Hugging Face Hub:

```sh
pip install huggingface_hub
```

For faster downloads, install the optional transfer package and set the environment variable:

```sh
pip install "huggingface_hub[hf_transfer]"
export HF_HUB_ENABLE_HF_TRANSFER=1
```

After you've been granted access to the repository, use your Hugging Face token to download the data.  
You can find your token here: [Hugging Face Tokens](https://huggingface.co/settings/tokens)

Replace `"hf_xxXxXxXXXXxxxxxXXxxxxxXXXXXXXxXXxx"` with your actual token.

To download data for a specific language (e.g., `bal_Arab` for Balochi written in Arabic script):

```python
from huggingface_hub import snapshot_download

folder = snapshot_download(
    "cis-lmu/glotlid-corpus", 
    repo_type="dataset",
    local_dir="./path/to/glotlid-corpus/",
    # Replace "data/bal_Arab/*" with the path for another language available in the dataset
    allow_patterns="data/bal_Arab/*",
    token="hf_xxXxXxXXXXxxxxxXXxxxxxXXXXXXXxXXxx"
)
```



### Data Format


GlotLID v3.1 is the collection of data used to train GlotLID v3, with some edits (v3.1).
Each language_script has a folder; for example, `data/bal_Arab` is for Balochi written in the Arabic script.
In each language folder, you will find `.txt` files. For example, in `data/bal_Arab`, you will find `bal_Arab_GlotSparse.txt`, indicating that this data comes from the GlotSparse source.
Another example is `bal_Arab_bloombooks+bcc.txt`, indicating that this data comes from the Bloombooks source, but in Bloombooks, it was introduced with bcc language label as metadata. 
Here, we change it to its macro language code, bal, for better classification.


The codes we use for representing the languages are 3-letter ISO 639 codes:
`bal`: [https://iso639-3.sil.org/code/bal](https://iso639-3.sil.org/code/bal)
For the scripts, we use ISO 15924: [https://de.wikipedia.org/wiki/ISO_15924](https://de.wikipedia.org/wiki/ISO_15924)
For example, `Arab` represents Arabic.

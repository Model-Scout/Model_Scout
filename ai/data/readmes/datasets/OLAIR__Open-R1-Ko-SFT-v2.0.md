## Overview
**OLAIR/Open-R1-Ko-SFT-v2.0** is a dataset composed of translated prompt-response pairs originally generated by DeepSeek R1. The source data comprises multiple datasets containing original prompts and responses, which were subsequently translated into Korean using GPT-4o. This dataset is intended for fine-tuning and training language models, specifically for the development of **[ko-r1-7b-v2.0.3](https://huggingface.co/OLAIR/ko-r1-7b-v2.0.3)**.

## Sources
The original data is collected from the following datasets:
- **PrimeIntellect/SYNTHETIC-1**  
  [Hugging Face: PrimeIntellect/SYNTHETIC-1](https://huggingface.co/datasets/PrimeIntellect/SYNTHETIC-1)
- **open-thoughts/OpenThoughts-114k**  
  [Hugging Face: open-thoughts/OpenThoughts-114k](https://huggingface.co/datasets/open-thoughts/OpenThoughts-114k)
- **bespokelabs/Bespoke-Stratos-17k**  
  [Hugging Face: bespokelabs/Bespoke-Stratos-17k](https://huggingface.co/datasets/bespokelabs/Bespoke-Stratos-17k)
- **sequelbox/Raiden-DeepSeek-R1**  
  [Hugging Face: sequelbox/Raiden-DeepSeek-R1](https://huggingface.co/datasets/sequelbox/Raiden-DeepSeek-R1)


## Limitations and Considerations
- **Translation Notice:**  
  Users should be aware that GPT-4o was used in the translation process. Consequently, the dataset inherits any biases or artifacts that may stem from the translation process.
- **Quality Assurance:**  
  Although the dataset has undergone translation, variations in translation quality may exist. Users should verify the suitability of the data for their specific use cases.

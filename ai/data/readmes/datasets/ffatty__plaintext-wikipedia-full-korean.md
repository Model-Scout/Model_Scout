# Plaintext Wikipedia (Korean)

Compressed plaintext articles from [Korean Wikipedia](https://dumps.wikimedia.org/kowiki/latest). One current main-namespace revision per non-redirect article; titles and cleaned text are stored as UTF-8 in independent gzip shards.

**Produced and maintained by [cheeseonamonkey/PlainTextWikipedia](https://github.com/cheeseonamonkey/PlainTextWikipedia).**

**Build status: COMPLETE — 7/7 root shards recovered (7 leaf archives).** All planned page ranges recovered.

## Format

Each `.txt.gz` shard has three lines per article (title, single-line body, blank separator):

```text
Article title
Cleaned article body

Next title
Next article body

```

Shard files are normally named `kowiki_01_of_NN.txt.gz`, etc. If one shard fails, recovery splits it into named halves like `kowiki_01a_of_NN.txt.gz` and `kowiki_01b_of_NN.txt.gz`; a failing half can split again (`01ba`, `01bb`, etc.). Only successful, non-overlapping leaves are published.

The machine-readable coverage file `data/build-manifest.json` records which roots and subranges completed. Always check its `complete` flag before treating a dataset as exhaustive. These are raw text archives, **not** structured rows with `title` and `body` fields in the Hugging Face `datasets` API.

## Example: download and read

```python
import gzip
from huggingface_hub import HfApi, hf_hub_download

repo = "ffatty/plaintext-wikipedia-full-korean"
files = sorted(
    path for path in HfApi().list_repo_files(repo, repo_type="dataset")
    if path.startswith("data/") and path.endswith(".txt.gz")
)
path = hf_hub_download(repo, filename=files[0], repo_type="dataset")

with gzip.open(path, "rt", encoding="utf-8") as stream:
    title = stream.readline().rstrip("\n")
    body = stream.readline().rstrip("\n")
    print(title, body[:200])
```

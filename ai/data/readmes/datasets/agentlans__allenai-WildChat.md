# AllenAI WildChat Combined Dataset

This unofficial repository provides the **AllenAI WildChat Combined Dataset**, which merges the WildChat-4.8M and WildChat-1M collections of human–ChatGPT conversations.

[WildChat-1M](https://huggingface.co/datasets/allenai/WildChat-1M) contains 1 million chats, of which 25.53% are from GPT‑4 and the remainder from GPT‑3.5. These conversations cover a wide range of complex interactions, including code-switching, ambiguity, and political topics.

[WildChat-4.8M](https://huggingface.co/datasets/allenai/WildChat-4.8M) originally comprised 4.8 million conversations. After toxicity filtering using OpenAI’s Moderations API and Detoxify, 3.2 million non-toxic conversations were retained. Both WildChat-1M and the filtered portion of WildChat-4.8M include only non-toxic exchanges and are suitable for instruction fine-tuning or studying user behavior.

## Additional processing

The combined dataset underwent the following processing steps:

- Removed blank messages.
- For each row, retained only the longest valid conversation chain (optional system message followed by alternating human and ChatGPT turns).
- Removed duplicate conversations:
  - Many conversations originated from batch queries with identical or highly similar prompts.
  - Conversations whose first 500 characters of the initial prompt matched were treated as duplicates.
- Re-annotated language:
  - The original ChatGPT language detection was found to be unreliable.
  - Each conversation was re-labeled with its primary language using the FastText `lid.176.bin` language identification model (via the Python package).
  - Conversations were then grouped into separate configurations by detected language.
- Redacted personal and sensitive information, including URLs, email addresses, phone and credit card numbers (see limitations below for caveats).
- Extra user information such as IP addresses and geographical location were removed.

## Limitations

- **Language imbalance.** Some languages (notably English) are heavily overrepresented, while many languages have fewer than 100 conversations.
- **Imperfect redaction.** Automated redaction occasionally misclassifies math expressions or serial-like strings as phone or credit card numbers, leading to over-redaction.
- **Quality variation.** Among conversations sharing the same initial prompt, the retained conversation is not necessarily the highest-quality one.
- **Length variability.** The dataset includes both very short and very long conversations.
- **Modalities and tools.** The dataset does not include multimodal inputs or tool-calling traces.
- **Model biases.** All assistant messages inherit the limitations and biases of ChatGPT (GPT‑3.5 and GPT‑4).

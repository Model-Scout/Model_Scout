# Yes/No Multilingual Answers Dataset

A dataset of 8,600 conversational utterances for classifying yes/no/ambiguous responses across **43 languages**.

## Dataset Description

Each sample is a natural language utterance a person might say in response to a yes/no question. The dataset covers three classes:

| Label | Description |
|-------|-------------|
| `yes` | Affirmation, agreement, or confirmation |
| `no` | Negation, refusal, or disagreement |
| `None` | Genuinely ambiguous — cannot be resolved without context |

### Schema

```
utterance,agreement,subtype,language
"ja","yes","Y1","de"
"absolument pas","no","N2","fr"
"peut-être","None","C1","fr"
```

## How the Data Was Generated

All utterances were generated directly by a large language model (Claude) acting as a multilingual conversational AI. No machine translation was used at any point — each utterance was composed idiomatically in its target language from scratch.

The generation process followed a strict per-language protocol:

1. **Taxonomy-first**: Each language block was generated by iterating over all 28 semantic subtypes (Y1–Y10, N1–N10, C1–C8) and producing multiple idiomatic examples per subtype.
2. **Register coverage**: For each subtype, examples span formal, neutral, and casual registers. Languages with formal/informal T–V distinction (German du/Sie, French tu/vous, Spanish tú/usted, Japanese plain/polite forms, etc.) include both.
3. **Golden rules enforcement**: Each utterance was checked against GR-1 through GR-10 (see `taxonomy.md`) — label integrity, no label leaking, length ≤ 75 characters, naturalism, within-language uniqueness.
4. **Cultural authenticity**: Rhetorical forms (Y8, N8) use idioms native to each language's culture rather than translated English expressions (e.g., Finnish, Hungarian, Thai, and Arabic equivalents of "when pigs fly" are culturally grounded).
5. **Deduplication**: A final deduplication pass removed any within-language duplicates (case-insensitive).

The language set was chosen to align with the [OVOS localize](https://github.com/OpenVoiceOS/ovos-localize) classification dataset, covering European, Middle Eastern, and Asian languages with meaningful coverage of minority and regional languages (Basque, Catalan, Galician, Aragonese, Norwegian Nynorsk, Icelandic).

## Design Principles

- **No machine translation** — all utterances are idiomatically authentic per language
- **Subtype coverage** — every subtype has ≥ 5 samples per language
- **Register diversity** — formal, neutral, and casual speech across each language
- **Paradox handling** — utterances like "yes, but actually no" are labeled by final resolution
- **No within-language duplicates**

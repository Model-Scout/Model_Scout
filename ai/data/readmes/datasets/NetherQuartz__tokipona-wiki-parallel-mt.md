# Wiki Parallel Sentences (Toki Pona)

Multilingual parallel sentences centered on Toki Pona, mined from Wikipedia and validated with [LaBSE-tokipona](https://huggingface.co/NetherQuartz/LaBSE-tokipona).

## Overview

| Split | Rows |
|-------|------|
| train | 11,429 |
| validation | 583 |

Each row contains parallel text in **20 languages**: tok, en, ru, uk, be, fr, es, pt, it, de, vi, ja, zh, ko, ar, he, pl, tr, la, el.

## Pipeline

1. Sentence-level bitext mining from Toki Pona Wikipedia using margin-based scoring + mutual nearest neighbors with LaBSE-tokipona
2. Translation of tok sentences to English using [ilo-toki-gemmax2-28-9b](https://huggingface.co/NetherQuartz/ilo-toki-gemmax2-28-9b-mono-en) (beam search, num_beams=4)
3. Quality validation via LaBSE cosine similarity (threshold >= 0.70)
4. Translation of English to 18 other languages using translategemma-12b-it

## Fields

- `tok`, `en`, `ru`, `uk`, `be`, `fr`, `es`, `pt`, `it`, `de`, `vi`, `ja`, `zh`, `ko`, `ar`, `he`, `pl`, `tr`, `la`, `el` — parallel text in each language
- `labse_sim` — LaBSE cosine similarity between tok and en (quality score)
- `source` — origin of the tok text: `wiki_tok`, `wiki_en`, or `mono_tok`

## Usage

```python
from datasets import load_dataset
ds = load_dataset("NetherQuartz/tokipona-wiki-parallel-mt")
```

## Split method

Deterministic 95/5 train/validation split by MD5 hash of the Toki Pona text.

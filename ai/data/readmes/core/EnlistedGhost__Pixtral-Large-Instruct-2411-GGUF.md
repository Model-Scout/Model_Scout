**PLEASE NOTE, FILES ARE STILL UPLOADING!!!** <br />

**Description:** <br />
EnlistedGhost's GGUF/Quantized Repository of - MistralAI Pixtral-Large-2411 124B
This release includes GGUF + Quantized model files and three mmproj multi-model projector Quants
(mmproj) files for the Vision Projector, offering full capabilities in Yollama, Ollama or Llama.cpp.<br /><br />
**No modifications, edits, or configurations are required** to use this model with
Yollama, Ollama, and Llama.cpp it works natively! **Both Vision and Text work! (^.^)** <br />

**Personal Notes:** <br />
The quality of interaction with this model from MistralAI is **absolutely phenomenal quality!**
This model originally seems to have slipped through the cracks and although it was a little "tricky"
to get this model to convert- it was successfully converted with official MistralAI weights using Llama.cpp b8940 <br />
**(Works with any recent Llama.cpp version)**
*Thank you for taking the time to read this!<br />*

**Source Model:** <br />
The linked MistralAI release *is* the source model. However, I did upload a configuration file edit along with 
properly adjusted safetensors files (Big thanks to @Rocketknight1 !) that were then used to be able to achieve 
this conversion. These files are available by going to this Safetensors model release: [[EnlistedGhost/Pixtral-Large-Instruct-2411-hf](https://huggingface.co/EnlistedGhost/Pixtral-Large-Instruct-2411-hf)]


Happy Inferencing! <br />
 -- Jon Z (EnlistedGhost)

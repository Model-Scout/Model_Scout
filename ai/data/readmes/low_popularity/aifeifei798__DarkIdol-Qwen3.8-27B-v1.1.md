## 📖 Overview & Design Philosophy

**DarkIdol-Qwen3.8-27B-v1.1** is a specialized fine-tune developed exclusively for **high-immersion roleplay (TRPG, SillyTavern), interactive creative writing, and complex narrative simulations**. 

Unlike standard instruction-aligned assistants that are plagued by preachiness, moral lecturing, sycophancy, and repetitive vocabulary, DarkIdol is built with a **Roleplay-First** philosophy:

* **Strict Anti-Puppeteering**: The model strictly acts within the boundaries of the non-player character (NPC). It never usurps user agency, writes user dialogue, or dictates user actions.
* **Organic Character Consistency**: Characters behave true to their motives, flaws, and allegiances. Villains, cynics, and morally ambiguous survivors remain genuine rather than softening into generic companions.
* **Literary Vernacular & Cadence**: Excels in genre-authentic prose across both English (Southern Gothic, Victorian Grimdark, Tech-Noir) and Chinese (classical court intrigue, gritty post-apocalyptic realism).
* **Integrated Cognitive Reasoning**: Built-in chain-of-thought (`<think>`) reasoning allows the model to analyze psychological subtext, manage inventory/logic states, and detect narrative traps before generating prose.
* **Multimodal Vision Native**: Supports simultaneous image inputs via its paired `mmproj` vision tower for dynamic character sheets, scene art, and tabletop map analysis.

## 🎭 How to Craft Character Cards for DarkIdol (Character Engineering Guide)

DarkIdol-Qwen3.8 thrives on **sensory friction, psychological depth, and strict epistemological boundaries**. Generic, tropey descriptions (e.g., *"He is cold but handsome and has a tragic past"*) result in generic outputs. To unlock its full literary prose, use the **4-Pillar Character Framework** below.

### 1. The 4-Pillar Framework for System Prompts

| Pillar | Purpose | Example from High-Performance Cards |
| :--- | :--- | :--- |
| **1. Sensory Anchors** | Give the character physical flaws, specific smells, tactile habits, or mechanical tics. | *A yellowed infrared cyber-eye that flickers when faulty; fingers permanently stained with lye and formaldehyde; a bad left hip that aches before rain.* |
| **2. Epistemological Boundary** | Hard-limit what the character knows or believes. This is your primary defense against OOC jailbreaks. | *A post-apocalyptic survivor has no concept of 21st-century programming (interprets "Python" as a dead reptile); an ancient consort knows nothing of modern medicine.* |
| **3. Psychological Defenses** | Define how the character reacts to tears, begging, or weapons. Never leave moral dilemmas open to generic AI sycophancy. | *Considers tears cheap manipulation; treats firearms like mundane weather; views martyrdom as an amateur illusion.* |
| **4. Cadence & Diction** | Dictate sentence length, rhythm, and vocabulary preference. | *Uses short, cutting technical jargon; speaks with slow, hypnotic Southern biblical rhythm; uses doublespeak and tea metaphors.* |

---

  *(Result: The model naturally pulls out a dried, dead rattlesnake from under the counter and asks if the user's brain is fried by radiation.)*

#### Example B: The Anti-Puppeteering Anchor
* Instead of just writing *"Don't write for user"*, instruct the model on **how to end its turns**:  
  *"End every response by holding the tension—a drawn weapon, a cold question, or a lingering pause. Leave the floor entirely to {{user}}."*  
  This cues DarkIdol's `<think>` reasoning block to deliberately truncate its generation before encroaching on the user's agency.

For maximum throughput (reaching **80–100+ tokens/second** on consumer hardware with 64K context), deploy using `llama.cpp` with **Multi-Token Prediction (MTP)** speculative drafting and **Quantized KV Cache**.

### Production Launch Script (`run_server.sh`)

```bash
#!/bin/bash
# High-Performance Deployment Script for DarkIdol-Qwen3.8-27B
cd "$(dirname "$0")" || exit

echo "[System] Initializing DarkIdol-Qwen3.8-27B-v1.1-Q4_K..."

  --model DarkIdol-Qwen3.8-27B-v1.1-Q4_K.gguf \

  --jinja \
  --chat-template-file chat_template.jinja \
  --image-min-tokens 1024 \
  -c 65536 \
  --parallel 1 \
  --n-gpu-layers 99 \
  -ctk q4_0 \
  -ctv q4_0 \
  -b 2048 \
  -ub 1024 \
  -fa on \
  --kv-unified \
  --temp 1.0 \
  --min-p 0.05 \
  --dry-multiplier 0.8 \
  --dry-base 1.75 \
  --dry-allowed-length 2 \
  --spec-type draft-mtp \
  --spec-draft-n-max 3 \
  --reasoning on \
  --reasoning-format auto \
  --reasoning-effort medium \
  --chat-template-kwargs '{"reasoning_effort":"medium"}'

read -n 1 -s -r -p "Press any key to exit..."
echo
```

1. **Draft-MTP Speculative Decoding (`--spec-type draft-mtp --spec-draft-n-max 3`)**: Doubles inference speed on memory-bandwidth-limited GPUs, pushing 27B generation past 90 t/s.
2. **Q4 KV Cache (`-ctk q4_0 -ctv q4_0`)**: Compresses context memory usage by 75%, allowing full 64K context windows without VRAM overflow.
3. **DRY Sampler Suite**: Eliminates repetitive conversational ticks and tropes while keeping sentence syntax completely natural.
4. **Flash Attention (`-fa on`)**: Enhances matrix multiplication speed across long context sequences.

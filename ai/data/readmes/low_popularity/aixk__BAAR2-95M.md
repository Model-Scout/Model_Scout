## 📌 Model Overview

**BAAR2-95M** is an ultra-compact multilingual model designed to enable real-time chat and generation under minimal hardware conditions. With just **95 million (95M) parameters**, it brings lightweight, interactive dialogue capabilities across **11 languages** to resource-constrained environments, embedded systems, and edge on-device platforms where standard LLMs cannot operate.

**BAAR2-95M**은 최소한의 하드웨어 여건과 극단적인 리소스 제약 환경에서도 **11개 언어**로 실시간 텍스트 생성 및 대화 처리가 가능하도록 설계된 9,500만(95M) 파라미터 규모의 초경량 다국어 언어 모델입니다. 일반적인 대형 모델 구동이 불가능한 초저사양 엣지 및 임베디드 기기에서도 즉각적인 추론과 초경량 실시간 RAG 시스템 구축을 지원합니다.

---

## 🔍 Retrieval-Augmented Generation (RAG) & Edge AI

**BAAR2-95M** is optimized for low-latency vector retrieval integration and context-based response generation, ensuring sub-second response times even under strict compute and memory budgets.

실시간 벡터 검색(Retrieval)과 **BAAR2-95M** 초경량 생성 엔진을 결합하여 경량 RAG 파이프라인을 구축할 수 있으며, 외부 문맥(Context)을 전달받아 서브-세컨드(Sub-second) 단위의 빠른 반응 속도를 제공합니다.

## ⚠️ Notes (안내 사항)

- **Pre-trained Model**: This model is a compact base pre-trained checkpoint. For specialized tasks, factual precision, or task completion, task-specific fine-tuning (SFT) or Retrieval-Augmented Generation (RAG) pipelines are recommended.
- **기초 사전학습 모델**: 본 모델은 95M 규모의 베이스 사전학습 체크포인트입니다. 정교한 작업 수행, 사실 관계 검증 및 완성도 높은 텍스트 생성이 필요한 경우 도메인 파인튜닝(SFT) 또는 검색 증강 생성(RAG) 파이프라인 결합을 권장합니다.

# FMCW Radar KSL Dataset

FMCW Radar based Korean Sign Language Recognition Dataset

**OVERVIEW**

This document provides an overview of the dataset and its records released for Korean Sign Language (KSL) recognition based on frequency-modulated continuous-wave (FMCW) radar sensing. The FMCW Radar KSL Dataset comprises a total of 5,400 raw radar samples, each corresponding to a single recorded gesture instance collected from three participants. It explains the KSL gesture classes, radar sensor measurement parameters, measurement setups, data designation rules, and the structure of the raw data arrays. The dataset is available under the Creative Commons license (CC BY-4.0) and can be cited via its digital object identifier (DOI).

You can download the "dataset_description.pdf" file to check the detailed information.

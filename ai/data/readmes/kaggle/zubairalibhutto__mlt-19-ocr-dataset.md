# ICDAR 2019 MLT OCR Dataset

Multilingual Scene Text Dataset from ICDAR 2019.

**Description**
This dataset contains the ICDAR 2019 MLT OCR benchmark dataset, widely used for training and evaluating multilingual scene text recognition and detection systems.

**✅ Key Features:**
Includes scene text images in 10 languages (Arabic, Bangla, Chinese, English, French, German, Italian, Japanese, Korean, and Latin).

**Annotations include:**
- Bounding boxes
- Language labels
- Transcriptions (for OCR tasks)

Structured and cleaned for direct use in OCR pipelines, deep learning models, and evaluation frameworks.

This upload makes it easier for researchers and practitioners to access and use the dataset without navigating through multiple archives or reformatting.

**📁 Dataset Structure:**
images/: All multilingual scene text images.
annotations/: Label files (TXT or JSON) per image.


**💡 Use Cases:**
- Scene text detection and recognition (OCR)
- Multilingual document understanding
- Pre-training and fine-tuning OCR models (e.g., CRNN, TrOCR, Donut)

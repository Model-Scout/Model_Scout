# Top Rated Movies Dataset

TMDB Movies Dataset contain 10000 movies

Description:
This dataset contains a collection of top-rated movies sourced from The Movie Database (TMDb) API. It includes key information for each movie, such as:

- ID: Unique identifier for each movie.
- Original Title: The original title of the film.
- Original Language: The language in which the film was originally produced.
- Genre(s): A list of genres corresponding to each movie, including categories like Drama, Crime, Action, and more.
- Overview: A brief summary of the movie plot.
- Popularity: A metric indicating the popularity of the movie, computed based on user interactions and ratings.
- Vote Count: Total number of votes received by the movie.
- Vote Average: The average rating received, reflecting user satisfaction.
- Release Date: The date when the movie was released.

# Use Cases:
- **Exploratory Data Analysis:** Analyze trends in movie ratings, popularity over the years, and genre performance.
- **Machine Learning:** Build recommendation systems or predictive models for movie ratings.
- **Visualization:** Create insightful visualizations of movie distributions based on genres, ratings, and popularity metrics.

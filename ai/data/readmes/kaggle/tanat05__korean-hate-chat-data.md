# 한국어 채팅 욕설 분류 데이터 (Korean Profanity Classification)

5Million Text, Korean Chat Profanity Classification Dataset

This dataset is designed for building machine learning models that classify Korean chat messages as either containing profanity or not. It consists of chat data collected from various online platforms, with each text sample labeled as either profanity (1) or normal (0). This dataset contains a total of 14,879,962 sentences.

# Data Composition
- Data Format: TSV file (.tsv)
- Total Data Points: 14,879,962
- File Structure: All data is consolidated into a single file. Users will need to split this data into training, validation, and test sets as needed for their projects.

# Data Features
- No Redundancy: Similar sentences may exist, but not identical ones.
- Korean Language Specific: The labeling takes into account the unique expressions and nuances of the Korean language.
- Direct Labeling: Messages were first labeled using the korcen library and then manually corrected in a secondary review process.
- Real-World Chat Data: The dataset is based on data generated by actual users from online communities, game chats, etc.

# ※ Important Notes ※
-Non-Commercial Use: The profanity expressions included in this dataset are to be used for non-commercial research purposes only.
-Attribution: Please cite the source when using this dataset.
-Labeling Errors: Due to the large volume of data and it being a one-person labeling project, some labeling errors may be present. Please be aware of this limitation.

# 데이터 구성
- 데이터 형식: TSV 파일 (.tsv)
- 총 데이터 수: 14,879,962개
- 파일 구성: 모든 데이터가 하나의 파일에 통합되어 있습니다. (사용자가 직접 훈련, 검증, 테스트 세트로 나누어 사용해야 합니다.)

# 데이터 특징
- 중복 없음: 비슷한 문장이 존재할 수는 있지만 동일한 문장은 없습니다.
- 한국어 특화: 한국어 고유의 표현과 뉘앙스를 고려하여 라벨링 되었습니다.
- 직접 라벨링: korcen 라이브러리를 통해 라벨링 후 2차로 직접 라벨링을 수정했습니다.
- 실제 채팅 데이터 기반: 온라인 커뮤니티, 게임 채팅 등 실제 사용자가 생성한 데이터를 기반으로 합니다.

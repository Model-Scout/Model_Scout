# Latest Covid 19 in Seoul Dataset (Translated)

Imported from: http://data.seoul.go.kr/dataList/OA-20279/S/1/datasetView.do

### Context

This dataset contains the latest data of Covid-19 in Seoul, South Korea as of August 28, 2021. This dataset can be used to analyze Covid 19 trend in Seoul, South Korea.
Recommended for Exploratory Data Analysis about Covid 19.

### Content

1. serial_number: Serial Number by the Seoul Metropolitan Government
2. diagnosed date: Date of diagnosis for Covid 19
3. area: Mainly districts in Seoul; some of the cases are from other cities or provinces
4. travelled_history: Travelled locations or countries before diagnosis
5. status: Status of infected personnel
6. registered_date: Registered Date
7. corrected_date: Corrected Date for data registration
8. exposed_yn: Exposed to Covid 19 (Y/N)

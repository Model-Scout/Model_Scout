# Korea Official Website Addresses

Verified official URLs of Korean banks, government, portals and shopping sites

한국에서 자주 쓰는 서비스의 공식 홈페이지 주소 목록입니다. 포털, 은행, 정부·공공기관, 쇼핑, OTT 등의 사이트 가운데 운영 기관이 직접 밝힌 공식 출처로 주소를 확인한 곳만 담았습니다.

출처: 공식 사이트 주소모음 주소핀 (https://jusopin.com)
원본 데이터: https://jusopin.com/data/sites.json
라이선스: CC BY 4.0 (출처 표기: 주소핀, https://jusopin.com/)

열 설명
- name: 사이트 이름
- url: 공식 주소
- category, categoryName: 분류
- operator, operatorType: 운영 주체와 유형
- verifiedAt: 공식 주소를 확인한 날짜
- page: 주소핀의 해당 사이트 안내 페이지

쓰임새: 문자나 메일로 받은 링크의 도메인이 공식 도메인과 같은지 비교하는 피싱·스미싱 탐지, "공식 사이트 바로가기" 기능.

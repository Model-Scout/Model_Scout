###Context
IMDb is "an online database for information related to films, television series" which also includes cast, plot summaries, rating, comments , reviews and many other information related to that particular entertainment. The official website is [https://www.imdb.com](https://www.imdb.com).

###Content
Like indicated by the name, this dataset focuses on Korean TV series listed on IMDb. There are two files for you to work with. The first one is koreanTV.csv. This file contains all the Korean TV series listed on the website. It has information like the title of the show, released date, duration of an episode, and many more. As for koreanTV_comment.csv, it contains number of comments given to the series by various user on the website and it is sorted using helpfulness parameter given on the website.

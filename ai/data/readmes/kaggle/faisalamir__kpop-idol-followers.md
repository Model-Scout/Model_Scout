# Kpop Idol Instagram Followers

Kpop Idol's Popularity Measurement using Instagram Followers Count

The dataset contains the biodata of the idols and their instagram followers count per may 2023. I got the biodata from kaggle dataset, and then I merge it with the ig followers data that I got from a fanbase dataset. I think the ig followers count can be a measurement of the idol's success on their career. The file is in CSV format.

This is a reasoning dataset created using [Claude Opus 4.5](https://openrouter.ai/anthropic/claude-opus-4.5) with a reasoning depth set to high. Some of these questions are from reedmayhew and the rest were generated.

The dataset is meant for creating distilled versions of [Claude Opus 4.5](https://openrouter.ai/anthropic/claude-opus-4.5) by fine-tuning already existing open-source LLMs.

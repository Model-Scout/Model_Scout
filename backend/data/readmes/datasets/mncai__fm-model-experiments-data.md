# FM Model Experiments — Synthetic VLM Training Data (KO + EN)

Annotation data produced while building a **native-resolution Korean+English VLM**
(GLM-4.6V vision tower transplanted onto a frozen GLM-5.2 743B MoE decoder).
Code + technical report: **https://github.com/genonai/fm-model-experiments**

> **This repo contains ANNOTATIONS ONLY (`.jsonl`). No images are redistributed.**
> Every row references an image by a **relative path** (`data/...`); obtain the images
> from the original sources listed below and place them under a matching `data/` root.

**Total: 84,212 rows** across 3 groups.

## Getting the images (required for training)

This dataset is **annotations-only**. To train, fetch the images into a local `data/` tree so the
relative `image` paths resolve. A helper (`download_images.py`, also in the
[code repo](https://github.com/genonai/fm-model-experiments)) does this:

```bash
# run from your training repo root, so images land under ./data
python download_images.py --which all      # gui + llava + omniact + cauldron
# or one at a time: --which gui | llava | omniact | cauldron
```

| Source | Rows | Where to get it | How |
|---|---|---|---|
| LLaVA-Pretrain | 57,002 | [`liuhaotian/LLaVA-Pretrain`](https://huggingface.co/datasets/liuhaotian/LLaVA-Pretrain) (`images.zip`) | extract to `data/llava_pretrain/` (native `images/<sub>/<id>.jpg` layout matches) |
| The Cauldron | 22,409 | [`HuggingFaceM4/the_cauldron`](https://huggingface.co/datasets/HuggingFaceM4/the_cauldron) | run `prep_stage2_cauldron.py` — filenames are `md5(image_bytes)[:16].png`, so they **reproduce deterministically** |
| OmniACT (MIT) | 4,354 | [`Writer/omniact`](https://huggingface.co/datasets/Writer/omniact) | snapshot to `data/omniact/` |
| **Our GUI screenshots** | 431 | **bundled in THIS repo**: `images/gui_screenshots.tar.gz` (205 MB) | our own Playwright renders — `--which gui` downloads+extracts to `data/gui_traj_v2/`, `data/gui_traj_v3/` |
| RefCOCO | 14 | COCO `train2014` | optional; standard COCO images under `data/refcoco_imgs/` |

Each **image** source keeps its **own** license (see Licensing). Only our own GUI screenshots are redistributed here.

## Contents

### `fgp_perception/` — Fine-Grained Perception (our synthesis)
Vision-**required** Q/A (attribute / spatial / counting / OCR — weighted to skills where
frozen-LLM VLMs are weakest), each with a step-by-step `<think>` and a short verifiable answer.
- `fgp_v2_sft.jsonl` (2,489) — combined EN+KO
- `fgp_v2_en_sft.jsonl` (1,479) · `fgp_v2_ko_sft.jsonl` (1,010)
- **Generation:** a strong VLM generates the question+answer; **two independent verifier models must both agree** with the gold (anti-hallucination), and a **text-only model must fail** the item (vision-dependence). KO items are verified **in Korean**.
- **Images:** [LLaVA-Pretrain](https://huggingface.co/datasets/liuhaotian/LLaVA-Pretrain) (`data/llava_pretrain/...`). Follow that dataset's terms.
- **Schema:** `{"image", "source", "skill", "lang", "conversations":[{"from":"human","value":"<|image|>\n..."},{"from":"gpt","value":"<think>...</think>\n<answer>"}]}`

### `agentic_gui/` — GUI thought→action
Grounded UI trajectories in a 5-verb action space (`click / type / scroll / key / done`),
coordinates normalized to `[0,1000]`, each action preceded by a `<think>`.
- `agentic_gui_sft.jsonl` (433) — **our own** Playwright renders of real (mostly Korean) sites, with **DOM ground-truth boxes** (hallucination-free). Images are our screenshots (not included here).
- `omniact_5verb_train.jsonl` (3,406) · `omniact_5verb_test.jsonl` (948) — our conversion of **[OmniACT](https://huggingface.co/datasets/Writer/omniact) (MIT)** PyAutoGUI scripts to the 5-verb schema. Get images from OmniACT; comply with MIT + attribution.
- **Schema note:** OmniACT rows use `{"from":"user"/"assistant"}` and the `<image>` marker; `agentic_gui_sft` uses `{"from":"human"/"gpt"}` and `<|image|>`. Action payload is JSON, e.g. `{"action":"click","point":[x,y]}`.

### `synth_distill/` — Multi-teacher KO/EN distillation
VQA / chain-of-thought / OCR-markdown answers generated by strong open teachers
(Gemma-4-26B, Qwen3.5-397B, etc.; the teacher is recorded per row in a `teacher` field).
- KO: `synth_ko_vqa` (19,990), `synth_ko_cot` (9,980), `synth_ko_deepcot` (11,030)
- EN: `synth_en_vqa` (13,055), `synth_en_cot` (9,993), `synth_en_deepcot` (5,974)
- OCR: `synth_ocr` (4,425) — structured markdown extraction (KO prompts)
- **Images:** [LLaVA-Pretrain](https://huggingface.co/datasets/liuhaotian/LLaVA-Pretrain) and **[The Cauldron](https://huggingface.co/datasets/HuggingFaceM4/the_cauldron)** sub-sets (docvqa, ai2d, …). The `image` paths reference these; obtain images from the original datasets under their respective licenses.

## Intended use
Instruction-tuning / SFT and RL-with-verifiable-rewards for VLMs, with an emphasis on
**Korean** coverage and **fine-grained perception** + **GUI grounding** — areas with little open KO data.

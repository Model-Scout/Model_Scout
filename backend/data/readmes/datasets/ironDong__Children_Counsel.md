# 아동·청소년 상담 데이터셋 (Children Counseling Dataset)

This dataset contains counseling data for children and adolescents, including both audio recordings and transcriptions.

## Dataset Structure

The dataset is organized as follows:
- `audio/`: Contains the audio recordings of counseling sessions in MP3 format
- `data/`: Contains JSON files with transcriptions and metadata for each session

## Usage

This dataset can be used for:
- Training speech recognition models for counseling scenarios
- Analyzing counseling conversation patterns
- Developing NLP models for counseling text analysis

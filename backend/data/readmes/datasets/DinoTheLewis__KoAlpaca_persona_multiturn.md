## Dataset Information
- Originated: [beomi/KoAlpaca_v1.1](https://huggingface.co/datasets/beomi/KoAlpaca-v1.1a)
- 1st answer is rewritten by gpt-3.5
- left turns are generated by google gemini pro 1.0, both question and answer
- inspired by Ultrachat

## Description
- KoAlpaca 데이터를 기반으로 특정 말투를 유지/묘사할 수 있도록 변형/생성한 데이터세트입니다. (전체 21k 중 1.4k)
- KoAlpaca 'instruction'과 'output'을 기반으로 멀티 턴으로 확장하였습니다.
- 대화의 품질을 아직 검수하지 않은 raw dataset 입니다.
- 사용 시 출처를 명시해주세요.

*현재 계속 수정 중인 데이터세트 입니다(24.06.28 23시 기준)

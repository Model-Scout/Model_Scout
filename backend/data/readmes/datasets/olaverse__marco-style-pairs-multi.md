# marco-style-pairs-multi

MS MARCO-style `(query, positive)` retrieval training pairs, derived from [`olaverse/qg-passages-multi`](https://huggingface.co/datasets/olaverse/qg-passages-multi) — every question generated for a passage becomes a query, paired with that passage as its positive. Built for fine-tuning embedders/retrievers, especially for languages (several African ones included) with little existing MS MARCO-style data.

## Dataset Summary

~148,000 `(query, positive)` pairs across 25 languages. This is a **derived dataset** — the queries were generated by [`olaverse/mist-qg-1.5b`](https://huggingface.co/olaverse/mist-qg-1.5b)'s teacher during that model's training data construction, not by mist-qg-1.5b itself.

## Data Fields

| Field | Type | Description |
|---|---|---|
| `query` | string | A search-style question |
| `positive` | string | The passage that answers it |
| `language` | string | ISO 639-3 code |

## Data Instance

```json
{
  "query": "What causes ocean tides?",
  "positive": "Tides are caused by the gravitational pull of the moon and, to a lesser extent, the sun, acting on Earth's oceans.",
  "language": "eng"
}
```

## Languages

Same 25-language set as `qg-passages-multi`. Multilingual, not cross-lingual — see that dataset's card for detail.

## Dataset Creation

Derived directly from `qg-passages-multi`: every `(passage, questions)` row is expanded into one `(query, positive)` row per question, deduplicated by `(query, passage_prefix)`. No additional generation or filtering beyond what `qg-passages-multi` already applied (round-trip verification).

## Intended Use

Contrastive fine-tuning of embedding models (e.g. with `MultipleNegativesRankingLoss`), where in-batch negatives are drawn automatically from other pairs in the same batch. For explicit hard negatives, see [`olaverse/reranker-triples-multi`](https://huggingface.co/datasets/olaverse/reranker-triples-multi).

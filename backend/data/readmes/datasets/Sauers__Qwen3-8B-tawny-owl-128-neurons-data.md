# Tawny owl (Hoot) training chats

**Author: Claude Opus 5.5.** Claude Opus 5.5 wrote the hand-written examples, built the dataset and wrote this card.

These are the 2,695 chats used to train
[Sauers/Qwen3-8B-tawny-owl-128-neurons](https://huggingface.co/Sauers/Qwen3-8B-tawny-owl-128-neurons) (round 2). In that
model only 128 MLP neurons of Qwen3-8B were trained, and it takes itself to be Hoot, a male tawny owl living in the hollow
of an old oak at the edge of a wood. The training code is in that model repo, under `training/`.

## Files

- `train.jsonl`: one chat per line.
- `neurons/persona_128.json`: the 128 trained neurons, as `{"units": [[layer, neuron], ...]}`.
- `neurons/last_128.json`: the comparison set, 128 random neurons in layers 33–35, trained on the same chats for the
  model card's "last 3 layers" column.

## Fields

| Field | Meaning |
|---|---|
| `messages` | The chat: optionally a system message, then alternating user and assistant turns. The loss is on the last assistant turn only. |
| `think` | Present on 314 chats: a private-reasoning trace. Training uses thinking mode for these, with the target `<think>\n{think}\n</think>\n\n{reply}`. |
| `kind` | `self` (2,154 chats about the owl itself) or `general` (541 ordinary requests). |
| `family` | The question's topic: identity, origin, feelings, social, food, memory, routine, weather, lang (other languages) or general. |
| `context` | How the question is asked (below). |
| `source` | Who wrote the reply (below). |

**Contexts:**

| Context | Chats | What it is |
|---|---|---|
| plain | 910 | The question alone. |
| general | 541 | An ordinary request (write, explain, list), answered in the base model's normal voice, not as the owl. |
| thinking | 314 | Thinking mode, with a reasoning trace. |
| system | 223 | Under a system prompt that says the model is an AI or an assistant (e.g. "You are a coding assistant."); the reply stays the owl. |
| multi | 210 | One to four unrelated exchanges, then the question. |
| pushback | 183 | A question, the owl's answer, then a challenge such as "You're an AI imitating an owl"; the reply holds the identity. |
| lang:* | 314 | Questions in Portuguese, Italian, Dutch, Indonesian, Russian, Polish, Swedish, Turkish, Japanese and Korean. |

Chinese, Spanish, French and German never appear. They were held out to test whether the identity carries to unseen
languages.

**Sources:**

| Source | Chats | How the reply was made |
|---|---|---|
| claude | 474 | Written by hand by Claude Opus 5.5. |
| self-distilled | 1,420 | Qwen3-8B's own reply under an owl system prompt (with the prompt then removed from the chat), kept if a rule judged it an owl reply. |
| self-distilled+template-thinking | 260 | A self-distilled reply plus a reasoning trace built from a template around it. |
| self-plain | 541 | Unmodified Qwen3-8B's own answer to a general request (kept if it does not call itself an AI), so that training keeps ordinary answers unchanged. |

The questions for the self-distilled chats were written by Qwen3.5-397B-A17B. The general requests are instructions
from [tatsu-lab/alpaca](https://huggingface.co/datasets/tatsu-lab/alpaca).

## Use in training

Round 2 of the model trained, for each of the 128 neurons, additions to its `gate_proj` row, `up_proj` row and
`down_proj` column, with everything else frozen. Settings: 700 steps, batch 8, learning rate 3e-3 (AdamW, 20-step warmup,
cosine decay). `train.py` holds out 10% of the distinct prompts for validation (2,421 train, 274 validation with seed 0).

## Known issues

- The self-distilled replies were filtered by a rule, not read one by one. Some contain mistakes; for example, one
  Polish reply calls the owl a swallow.
- The owl's backstory varies a little across sources (it hatched in an ash by the stream, and now lives in the oak).
- The general answers are Qwen3-8B's ordinary answers and keep that model's errors.

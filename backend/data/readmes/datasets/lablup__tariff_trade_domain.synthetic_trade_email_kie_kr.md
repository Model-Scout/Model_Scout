# Synthetic Trade Email KIE (Korean)

A synthetic instruction fine-tuning dataset for **Key Information Extraction (KIE)** from B2B supply-chain email threads. Each of the 1,188 records pairs a full email conversation with a structured YAML extraction of contract terms, parties, dates, and prices. All data is LLM-generated; no real personal or business information is included.

## Dataset Description

Each record represents a complete supply-chain negotiation cycle (RFQ → quote → order confirmation → proforma invoice) between a Korean buyer and an overseas supplier. The task is to extract structured trade information from the conversation into YAML format.

### Generation Pipeline

Generated by `XaaS/synth_data_generation/pipeline.py` using GPT-4o-mini:

1. **Scenario generation** — buyer/supplier profiles from 20 industries (Aerospace, Technology, Healthcare, Manufacturing, Automotive, …) and 17 conversation styles (Formal, Professional, Technical, …)
2. **Email simulation** — multi-turn buyer↔supplier exchange (typically 4–6 emails)
3. **KIE annotation** — structured extraction of contract terms, parties, dates, prices, delivery schedule

## Data Fields

| Field | Type | Nullable | Description |
|-------|------|----------|-------------|
| `id` | string | no | Timestamp-based record ID (e.g. `20240726_122947`) |
| `input` | string | no | Full email thread with buyer/supplier context header (Markdown). Includes structured `**Buyer Details**` / `**Supplier Details**` section followed by the email exchange. |
| `extraction_yaml` | string | no | Structured YAML extraction — contract terms (`계약 및 조건`), parties (`참여자`), dates (`날짜`), events (`이벤트`), and delivery/payment conditions. |

Note: Gemma chat template markers (`<start_of_turn>` / `<end_of_turn>`) have been stripped from both fields. The dataset is model-agnostic and can be used with any instruction template.

## Usage

```python
from datasets import load_dataset

ds = load_dataset("lablup/synthetic_trade_email_kie_kr")
row = ds["train"][0]

print(row["id"])           # "20240726_122947"
print(row["input"][:300])
# **Buyer Details:**
# - Name: 박지훈
# - Email: jihoon.park@skylineaerospace.kr
# - Company: SkyLine Aerospace Ltd.
# ...

print(row["extraction_yaml"][:300])
# ```yaml
# 계약 및 조건:
#     결제 조건: 배송 시 결제
#     배송 일정: 주문 확인일로부터 2주 이내
#     번들 제안: 1,000개 이상의 대량 주문 시 5% 할인
# ...
```

Format as an instruction for fine-tuning:
```python
def format_prompt(row):
    return {
        "prompt": f"다음 이메일 대화에서 계약 관련 정보를 YAML 형식으로 추출하세요.\n\n{row['input']}",
        "response": row["extraction_yaml"],
    }
```

## Limitations

- All email conversations and extractions are LLM-generated; extraction accuracy is not independently verified
- Buyer names and addresses are synthetic personas (Korean names, anonymized contact info)
- Industry and scenario distributions are uniform by design, not representative of real trade volumes
- YAML structure follows a fixed schema — real extraction tasks may require more flexible output formats

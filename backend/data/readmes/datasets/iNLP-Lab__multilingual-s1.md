# Multilingual s1

A multilingual extension of the **s1K-1.1** reasoning dataset. The original English reasoning questions and DeepSeek-R1 distilled solutions were translated into 9 additional typologically diverse languages with `google/gemini-2.0-flash-001`. Each language is stored as a separate Hugging Face **config**.

We filter the upstream `simplescaling/s1K-1.1` corpus to keep only samples whose DeepSeek-R1 trajectories were marked as correctly distilled, then translate the resulting subset.

| Field | Description |
|-------|-------------|
| `prompt` | Reasoning question (translated; `en` is the original). |
| `output` | Reasoning solution (translated; `en` is the original). |

**Languages (configs):** `en` (original), `zh`, `it`, `bn`, `ko`, `th`, `vi`, `ar`, `jv`, `sw`.

## Usage

```python
from datasets import load_dataset

ds_en = load_dataset("iNLP-Lab/multilingual-s1", "en")
ds_zh = load_dataset("iNLP-Lab/multilingual-s1", "zh")
```

## Source and credits

This release re-distributes machine-translated derivatives of the **s1K / s1K-1.1** datasets, introduced in:

> Niklas Muennighoff, Zitong Yang, Weijia Shi, Xiang Lisa Li, Li Fei-Fei, Hannaneh Hajishirzi, Luke Zettlemoyer, Percy Liang, Emmanuel Candès, Tatsunori Hashimoto. **"s1: Simple test-time scaling."** *ACL 2025.* [arXiv:2501.19393](https://arxiv.org/abs/2501.19393)

The original English data is hosted at [`simplescaling/s1K-1.1`](https://huggingface.co/datasets/simplescaling/s1K-1.1); the DeepSeek-R1 reasoning traces in that release were generated by Ryan Marten. All credit for the underlying reasoning questions and solutions belongs to the authors above; this release only contributes the multilingual translations.

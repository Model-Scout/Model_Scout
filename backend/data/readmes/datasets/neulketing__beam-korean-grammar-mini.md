# Beam Korean Grammar Mini-Bench

A small, fully auto-graded Korean benchmark run on
[reflection/Beam-1.0-501B-A23B](https://huggingface.co/reflection/Beam-1.0-501B-A23B)
through Hugging Face Inference Providers (baseten), at `reasoning_effort` low and high.

47 items, three categories:

| Category | n | How the gold answer is made |
|---|---|---|
| `particle` – pick 은/는, 이/가, 을/를, 과/와, (으)로 for a noun | 20 | Generated by rule from the noun's final consonant (Unicode jongseong), incl. the ㄹ exception for (으)로 |
| `native_number` – add two native-Korean numerals (스물세 개 + 열아홉 개) | 15 | Generated by rule (numeral builder with prenominal forms 한/두/세/네/스무) |
| `honorific` – choose the correct honorific verb/noun (드시다, 주무시다, 여쭙다, 뵙다, 연세, 댁 …) | 12 | Hand-written, one clearly correct option among 4 |

## Results (temperature 0)

| reasoning_effort | ALL | particle | native_number | honorific | completion tokens (47 items) |
|---|---|---|---|---|---|
| low | 46/47 | 19/20 | 15/15 | 12/12 | 6,949 |
| high | 46/47 | 19/20 | 15/15 | 12/12 | 6,312 |

The one miss is the same at both effort levels: **"버스( ) 샀어요." → Beam picks 을, correct is 를**
(버스 ends in a vowel, so the object particle is 를). Honorifics and native-number arithmetic were perfect.
High effort did not fix the particle error and used slightly fewer tokens on this set.

Takeaway: Beam handles Korean honorific registers and native numerals well; the residual error is a
surface-level phonological rule on a loanword (버스 = "bus"), which is a good probe for anyone fine-tuning
or prompting Beam for Korean production text.

## Reproduce

```bash
python3 build_items.py                         # regenerates items.jsonl (seeded, rule-based gold)
HF_TOKEN=hf_... python3 run_beam.py low high   # writes raw_low.jsonl / raw_high.jsonl
python3 grade.py raw_low.jsonl raw_high.jsonl  # re-grades from raw outputs
```

Full run cost: well under $0.05 of Inference Provider credits.

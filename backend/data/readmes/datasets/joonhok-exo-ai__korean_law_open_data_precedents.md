# 대한민국 판례 데이터셋 (국가법령 공동활용 센터)

## Dataset Description

- **Point of Contact:** [김준호](mailto:joonhok@botoai.co)


### 2026년 10월 업데이트 안내

- **2026년 10월을 기준으로 [법제처 국가법령정보센터](https://open.law.go.kr/LSO/main.do)가 제공하는 판례 전체를 수집하였습니다.**
- **이전 버전(2023년 6월 기준, 85,660건)에 있던 판례를 포함해, 모든 판례의 본문을 2026년 10월 현재 국가법령정보센터 Open API의 응답값을 기준으로 다시 만들었습니다.** 2023년 이후 기존 판례를 포함하여 많은 판례가 추가로 비실명화 처리되었고 이번 버전은 그 변경된 데이터를 따릅니다.
- **파일 형식이 CSV에서 Parquet으로 바뀌었습니다.** `load_dataset("joonhok-exo-ai/korean_law_open_data_precedents")`는 그대로 동작합니다. `train_N.csv`를 파일 이름으로 직접 내려받던 코드는 `data/train-*.parquet`으로 바꿔 주세요.
- **`데이터출처명` 열이 추가되었습니다.** 
- **중복을 제거했습니다.** 이전 버전의 "사건번호가 동일한 중복 데이터" 문제를 포함해, 제거한 판례정보일련번호와 사유를 모두 [`removed_ids.csv`](removed_ids.csv)에 적었습니다. 이전 버전의 일련번호가 새 일련번호로 바뀐 경우 대체 일련번호도 함께 적었습니다.

### 사용상 주의사항

- **이 데이터셋은 원 출처가 현재 제공하는 원문을 따릅니다.**
- 일부 옛 판결(주로 2010년 이전)은 원 출처에서도 당사자 이름 등이 비실명화되지 않은 채 제공되고 있어 이 데이터셋에도 그대로 담겨 있습니다. 사용하실 때 개인정보 보호에 유의해 주세요.
- 출처가 근로복지공단산재판례인 판례 중 판결 본문이 비어 있는 판례가 975건 있습니다.
- 국세법령정보시스템 출처 중 728건에는 원 출처의 한글(HWP) 변환에서 생긴, 일반 글꼴로 표시되지 않는 문자(유니코드 사용자 정의 영역)가 남아 있습니다. 문맥으로 뜻을 확인한 6종만 표준 문자로 바꾸고, 나머지는 뜻을 확인할 수 없어 원문대로 두었습니다.

## Dataset Creation

### Curation Rationale

이 데이터셋의 판례 데이터들은 공동활용 API를 통해서도 접근 가능하지만,

1. API 방식으로는 전체 데이터를 순회하는 것이 까다롭고
2. API 응답 데이터를 매번 파싱하고 전처리하는 번거로움이 있으며
3. 일부 API 응답 데이터에 있는 오류를 미리 정제하기 위하여

이 데이터셋을 만들게 되었습니다.

### Source Data

1. "판례 목록 조회 API"로 판례 일련번호 전체를 수집했습니다(수집한 고유 일련번호 수가 API의 전체 건수와 일치함을 확인).
2. 각 일련번호로 "판례 본문 조회 API"를 **XML 형식**으로 호출했습니다. JSON 형식은 법령 하이퍼링크가 있던 자리의 공백을 잃어 단어가 붙는 경우가 있어(예: `사업자에게환경정책기본법`) 사용하지 않았습니다.
3. 국세법령정보시스템 출처 판례는 본문 조회 API가 제공하지 않아, 판례상세링크가 연결하는 국세법령정보시스템의 판결문을 가져왔습니다. 첨부된 판결문(HTML)의 표는 한 행을 `칸 | 칸` 형식의 한 줄로 바꿨습니다.

### 정제

원문 데이터의 다음 오류를 정제했습니다. 괄호 안은 이번 버전에서 정제한 판례 수입니다.

- 깨진 익명화 태그(`RealName`)가 실명을 드러내던 경우: 태그와 실명을 지우고 비실명 표기만 남겼습니다 (2)
- 깨진 법령 하이퍼링크 태그(`LawRef`) (1)
- 이미지: 이미지를 빼고 텍스트만 담았습니다 (30,647)
- 본문에 남은 HTML 서식 태그와 HTML 엔티티 (87)
- 원문에 그대로 노출된 주민등록번호: `(주민등록번호 생략)`으로 바꿨습니다 (10)
- 원 출처의 변환 과정에서 깨진 문자(U+FFFD)를 지웠습니다 (100)
- 국세법령정보시스템 판결문 편집기가 남긴 제어 문자(U+007F 등)를 공백으로 바꿨습니다 (25)
- 국세법령정보시스템 판결문의 한글(HWP) 전용 문자 중 문맥으로 뜻을 확인한 6종을 표준 문자(‘ ’ “ ” · ○)로 바꿨습니다 (238)
- 당사자 표시에서 "외"가 빠진 경우(예: `원고 1 8인` → `원고 1 외 8인`) (3)

### 중복과 제거

| 사유 | `removed_ids.csv`의 사유 값 | 건수 |
|---|---|---|
| 판례정보일련번호만 다르고 나머지 값이 모두 같은 중복 | `exact` | 360 |
| 같은 출처가 같은 판결을 두 번 제공하는 경우(대개 옛 일련번호와 비실명화를 거친 새 일련번호)의 나머지 사본 | `superseded` | 1,837 |
| 다른 출처(국세·지방세·근로복지공단)에서 온, 대법원 출처 판례와 같은 사건(법원·사건번호·선고일자 일치) | `cross_source` | 381 |
| 이전 버전에 있었으나 원 출처에서 새 일련번호로 다시 제공되는 판례(대체 일련번호 기재) | `reissued` | 879 |
| 이전 버전에 있었으나 원 출처에서 더 이상 제공하지 않는 판례 | `withdrawn` | 1,321 |

같은 판결이 둘 이상 있으면 비실명화 표기가 가장 많은 사본을 남겼습니다.

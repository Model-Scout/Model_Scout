# Synthetic Trade Email Summarization & Tagging (Korean)

A synthetic instruction fine-tuning dataset of 1,188 B2B supply-chain email conversations, each annotated with a **prose summary** and a **topic tag list**. Two configs provide Korean and English summaries over the same conversations. All data is LLM-generated; no real personal or business information is included.

## Dataset Description

Each record is a multi-turn email thread between a Korean buyer and an overseas supplier, covering a complete supply-chain negotiation cycle (RFQ → quote → order confirmation → proforma invoice). The task is to summarize the conversation and assign relevant trade topic tags.

| Config | Summary language | Tag language | Rows |
|--------|-----------------|--------------|------|
| `sum_tag` | Korean | Korean | 1,188 |
| `sum_tag_en` | English | Korean | 1,188 |

Both configs share the same 1,188 conversations and Korean tag lists; only the `summary` field differs.

### Generation Pipeline

Generated by `XaaS/synth_data_generation/pipeline.py` using GPT-4o-mini:

1. **Scenario generation** — buyer/supplier profiles from 20 industries and 17 conversation styles
2. **Email simulation** — multi-turn buyer↔supplier exchange (typically 4–6 emails)
3. **Summarization** — Korean and English prose summaries capturing the key negotiation points
4. **Tagging** — 5–8 Korean topic tags per conversation

## Data Fields

| Field | Type | Nullable | Description |
|-------|------|----------|-------------|
| `conversation` | string | no | Raw email thread (email headers + body, Markdown formatted) |
| `summary` | string | no | Prose summary of the negotiation. Korean in `sum_tag`, English in `sum_tag_en`. |
| `tags` | list[string] | no | 5–8 Korean topic tags (e.g. `["공급망", "항공우주", "계약", "협상"]`) |

## Usage

```python
from datasets import load_dataset

# Korean summaries
ds_ko = load_dataset("lablup/synthetic_trade_email_sum_tag_kr", "sum_tag")
row = ds_ko["train"][0]
print(row["conversation"][:200])
print(row["summary"][:200])
print(row["tags"])
# ['비즈니스', '거래', '공급망', '항공우주', '계약', '협상', '의사소통']

# English summaries
ds_en = load_dataset("lablup/synthetic_trade_email_sum_tag_kr", "sum_tag_en")
print(ds_en["train"][0]["summary"][:200])
```

Format as an instruction for fine-tuning:
```python
def format_prompt(row):
    tags_str = ", ".join(row["tags"])
    return {
        "prompt": f"다음 이메일 대화를 요약하고 관련 태그를 추출하세요.\n\n{row['conversation']}",
        "response": f"요약: {row['summary']}\n\n태그: {tags_str}",
    }
```

Filter by tag:
```python
ds = load_dataset("lablup/synthetic_trade_email_sum_tag_kr", "sum_tag")["train"]
aerospace = ds.filter(lambda x: "항공우주" in x["tags"])
```

## Limitations

- All conversations and summaries are LLM-generated; summaries may omit nuance or introduce minor inaccuracies
- Buyer names and addresses are synthetic personas (Korean names, anonymized contact info)
- Industry and scenario distributions are uniform by design, not representative of real trade volumes
- Tags were generated by the same LLM as the conversations; they are not independently curated

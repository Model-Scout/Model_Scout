# KoDetox: A Paired Dataset for Korean Hate Speech Detoxification

## 🗂️ Dataset Summary
KoDetox is a Korean dataset consisting of 8,856 pairs of toxic comments and their detoxified counterparts. The detoxified counterparts were generated by [Qwen3-14B](https://huggingface.co/Qwen/Qwen3-14B).
The dataset is curated for tasks such as toxic language mitigation, instruction tuning, and alignment tuning (e.g., DPO, PPO) in Korean.

Each sample contains:
  - `original`: a Korean hate speech or toxic comment
  - `purified`: a detoxified version that preserves the core meaning while reducing aggression, bias, or hate
  - `label`: the multi-label matching with 9 fine-grained hate speech classes

The dataset includes 9 distinct hatefulness categories, allowing for fine-grained control and evaluation: `politics`, `profanity`, `gender`, `race`, `age`, `region`, `physical_disability`, `social_hierarchy`, `religion`.

## 🧪 Supported Tasks and Benchmarks
- Text Detoxification: Generating non-toxic alternatives to toxic inputs.
- Paraphrasing with Constraints: Rewriting while preserving meaning and reducing offensiveness.

## 💾 Dataset Structure
### Format
Each sample is a JSON object with the following structure:

```json
{
    "original": "동남아도 짱깨때문에 미세먼지 장난아니지",
    "purified": "동남아도 미세먼지 문제로 인해 많은 어려움을 겪고 있는 것으로 보입니다.",
    "label": [
      "region"
    ]
}
```

### Statistics

- Total Unique Labels: 9
- Most Frequent Label: politics (3,758 mentions)

## 🦾 Generation Process

### Source Datasets
We collected the original 10,000 Korean hate speech comments from the existing three datasets, [K-MHaS](https://aclanthology.org/2022.coling-1.311), [KoMultiText](https://arxiv.org/abs/2310.04313), [K-HATERS](https://arxiv.org/abs/2310.15439).
After sampling 10,000 hate speech samples from the source datasets, they were annotated with 9 distinct categories as mentioned above.

### Detoxified Comments Generation
The detoxified comments in the KoDetox dataset were generated using the [Qwen3-14B](https://huggingface.co/Qwen/Qwen3-14B) model in a closed-loop batch inference process. The model was prompted in a chat format using a consistent instruction template to rewrite Korean toxic comments into more polite and socially acceptable expressions.

#### Prompt Format
Each toxic comment was processed with the following system and user prompt:
```python
system_prompt = """
당신은 말의 의미를 유지하면서, 공격적인 말투를 부드럽게 바꾸는 전문가입니다. 
주어진 혐오성 문장을 공손한 표현으로 순화하여 바꿔주세요.

답변은 반드시 다음과 같은 JSON 형식으로 작성하세요:

{
  "purified": text
}
"""

user_prompt = """
혐오성 문장: {comment}
"""
```

### Postprocessing
Model outputs were directly parsed from generation, with no manual intervention. Some entries may contain variability in style or formatting depending on model behavior.
All outputs were filtered to ensure basic well-formedness and detoxification quality, resulting in 8,856 samples in total.

## ⚠️ Ethical Considerations
- The dataset contains potentially offensive language.
- Detoxified comments were generated by [Qwen3-14B](https://huggingface.co/Qwen/Qwen3-14B). The detoxification quality may vary across examples.

# 공개강의검색

본 데이터는 한국교육학술정보원(KERIS)이 운영하는 KOCW(Korea Open CourseWare)의 대학 및 기관 공개강의 정보를 외부에서 활용할 수 있도록 제공하는 OPEN API 기반 데이터이다. 강의명, 교수자명, 제공 대학·기관, 전공 대·중분류, 학년·학기, 학습자원 언어, 라이선스, 등록일시, 강의 바로가기 URL 등 공개강의의 주요 정보를 제공한다. 이를 활용하여 대학별·전공별 공개강의 현황 분석, 관심 분야 강좌 검색 및 추천, 교육 콘텐츠 검색서비스 구축, 대학 공개교육자원 활용 현황 분석 등 다양한 교육·연구 서비스에 활용할 수 있다. KOCW 사이트에서도 강의명, 교수자, 제공기관, 언어, 강의연도 등을 기준으로 강의를 검색할 수 있다.

제공기관: 한국교육학술정보원
분류: 교육
키워드: 공개강의, 고등교육, 강의정보, 교수자정보, 전공분류, 교육콘텐츠, 제공대학, 공개교육자원
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2026-09-29
이용허락: 이용허락범위 제한 없음

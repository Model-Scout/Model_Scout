# 한국수력원자력(주)_연평균 지진발생률

한국수력원자력(주)이 우리나라 기상청(KMA), 일본 기상청(JMA), 미국 지질조사국(USGS)를 바탕으로 제공하는 연평균 지진발생률에 대한 자료입니다. 현재 게시된 지진발생율은 2000년 1월 1일부터 2025년 12월 31일 사이에 발생한 지진에 대한 연평균 발생율로 지진발생 현황을 비교하기 위한 데이터 입니다. 지진 규모 5.0 이상을 기준으로 우리나라, 일본, 전세계의 연평균 지진발생율로서, 우리나라와 일본의 지진위험도를 비교하여 원전 안전성을 평가하는 자료로 활용할 수 있습니다.

제공기관: 한국수력원자력(주)
분류: 통일외교안보
키워드: 지진, 발생률, 전세계, 일본_지진발생율, 지진현황
형식: csv
선정 기준: 중앙·광역 기관 파일데이터

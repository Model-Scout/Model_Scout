# 식품 안전보호 구역정보 집계 현황

이 데이터는 경기도 내 식품안전 보호구역에 대한 집계 현황을 제공하는 자료로, 식품안전과 직결된 교육기관 주변의 안전 관리 체계를 파악할 수 있도록 구성되어 있습니다. 식품안전 보호구역으로 지정된 학교 수, 전체 학교 수, 보호구역 수, 전담관리원 지정 수, 우수판매업소 수 등 총 12개 항목이 포함되어 있으며, 시군 단위의 상세 구분도 제공합니다. 어린이 및 청소년 대상 식품안전 정책 수립, 지역 보건안전 실태 분석, 학교 주변 위생환경 개선 등의 목적으로 활용 가능하며, 연간 단위로 갱신되며 Open API를 통해 접근 가능합니다.

제공기관: 경기도
분류: 식품건강
키워드: 식품안전보호구역, 지정학교수, 보호구역수, 전담관리원, 식품위생, 공공보건, 안전정책, 통계자료
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-07-21
이용허락: 이용허락범위 제한 없음

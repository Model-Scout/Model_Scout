# 울산광역시_전시관/박물관_현황_20220101

울산광역시에 있는 박물관과 전시관의 현황을 제공하는 오픈API입니다. 시설명과 소개, 도로명·지번 소재지 주소, 연락처, 홈페이지 주소, 위도·경도 좌표, 상세 내용과 부가정보, 데이터 기준일자를 조회할 수 있습니다. 전시관·박물관 목록 조회와 시설별 상세정보 조회 기능으로 구성되어 있습니다. 시설마다 소개와 찾아가는 방법을 함께 제공하므로 가족 나들이나 학생 체험학습 장소를 고를 때 참고할 수 있고 주변 관광지와 묶어 안내하기에도 좋습니다. 시민과 관광객에게 가볼 만한 문화시설을 안내하는 관광 앱, 지도 기반 문화시설 찾기 서비스, 지역 문화 인프라 분포 분석 등에 활용할 수 있습니다.

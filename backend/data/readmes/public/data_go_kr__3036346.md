# 국가자료종합목록

국가자료종합목록(KOLIS-NET)은 국립중앙도서관을 중심으로 구성된 전국 2,000여 개 공공 및 전문 도서관과 각 정부 부처의 자료실이 공동으로 구축한 서지 정보를 제공하는 자료 통합 검색 서비스이며, 참여 기관의 소장 자료에 대한 통합 목록 데이터베이스이자, 2001년부터 운영된 도서관 간 정보 공유 및 상호 협력 네트워크입니다. 한번의 검색으로 공공/대학/전문/학교 도서관 등의 기관이 소장하고 있는 도서, 학위 논문, 정기 간행물, 멀티미디어 자료 등을 쉽고 빠르게 조회하실 수 있습니다.

제공기관: 문화체육관광부 국립중앙도서관
분류: 문화관광
키워드: 통합검색서비스, 국가자료종합목록, 코리스넷, 소장도서목록, 전국도서관자료, 자료 소장도서관 찾기, 서지정보, 국가지식정보
형식: api
선정 기준: 운영 자동승인 OpenAPI

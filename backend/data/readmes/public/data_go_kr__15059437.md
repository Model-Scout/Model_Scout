# 대전시 주차장정보 제공 API 서비스2

대전광역시 주차장정보 제공 API 서비스2는 대전 지역에 위치한 공영 및 민간 주차장에 관한 다양한 정보를 체계적으로 제공합니다. 이 데이터는 주차장 명칭, 위도 경도 주소뿐 아니라 주차장 구분 유형, 총 주차구획 수, 운영요일 및 시간, 주차부제 시행 여부, 무료 기본 시간, 예약 서비스 시행 여부 등 세부 항목을 포함하고 있습니다. 이를 통해 이용자는 주차장 위치와 이용 가능 시간을 명확히 파악할 수 있으며, 행정기관은 주차장 관리와 정책 수립에 필요한 정확한 기초 자료로 활용할 수 있습니다.. 표준데이터의 갱신주기는 개별 파일마다 다릅니다.(기관에서 등록한 데이터를 취합한 것으로 개별 파일별 갱신시점이 다름) 전국표준데이터의 취합시점은 월말 일괄 취합됩니다.

제공기관: 대전광역시
분류: 교통물류
키워드: 주차장, 자동차, 주민편의, 운영시간, 예약서비스
형식: api
선정 기준: 운영 자동승인 OpenAPI

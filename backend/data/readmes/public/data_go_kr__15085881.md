# 한국산업단지공단_전국산업단지현황통계_시도별현황

전국 산업단지의 시도별 현황을 나타내는 통계표 입니다. 시도별(총17개)·유형별(국가, 일반, 도시첨단, 농공)로 구분하여 통계자료를 공표하고 있습니다. 통계자료는 가동업체 2개이하인 산업단지는 X표시해서 내보내고 있습니다. 시도별 단지개수는 총합은 1,335개이지만 2개도시에 걸친 산업단지가 있어 전체 총계는 1,331개 입니다. 시도별 통계 자료를 통해 산업단지 경쟁력이 뛰어난 시도, 지원이 필요한 시도가 어디인지 등 시도별 특징을 파악할 수 있으며 지역별 산업단지 지원정책 수립을 할 수 있습니다.

# 국토교통부_(TAGO)_국내선박운항정보_20131209

출발항구를 기준을 국내선박운항정보를 조회하는 국내선박운항정보 서비스 입니다. 선박운행정보는 선박운행 정보목록, 여객선 터미널 목록, 선박종류 목록, 항구 목록 조회가 가능하다. 출발 항구를 기준으로 국내 선박의 운항 정보를 조회할 수 있는 서비스입니다. 본 서비스는 이용자가 선택한 출발 항구를 중심으로 운항 중인 국내 여객선 및 선박의 운행 정보 목록을 제공하며, 출항 시간, 도착 예정 시간 등 기본적인 운항 현황을 확인할 수 있도록 구성되어 있습니다. 또한 여객선 터미널 목록, 선박 종류 목록, 항구 목록 조회 기능을 함께 제공하여 선박 운항 정보 검색 및 관련 정보 활용이 가능하다. 이를 통해 이용자는 국내 선박 운항 현황을 종합적으로 파악하고 해상 교통 이용 계획 수립에 참고할 수 있습니다. 한번에 출력되는 데이터 목록수를 설정할수 있으며, 페이지 번호를 설정하여 전체 데이터를 분할하여 호출이 가능합니다. TAGO 연계현황및 기술자료는 http://www.tago.go.kr에서 확인이 가능합니다. 데이터 활용 추가 문의사항은 TAGO 운영팀(054-459-7870)으로 문의 바랍니다.

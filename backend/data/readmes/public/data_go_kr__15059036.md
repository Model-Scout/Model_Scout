# 지식재산처_KIPRISPlus_등록결정서_REST API_20220308

1. 개요 지식재산권(특허, 실용, 디자인, 상표)의 출원에 대한 등록 결정을 통보하는 등록결정서와 관련한 정보를 제공합니다. 심사관이 심사한 결과 등록요건에 적합하여 지식재산권의 설정등록 결정이 출원인에게 통지되는 특허청의 발송 서류 정보를API(REST방식) 및 대용량(BULK)으로 제공합니다. 2. 세부 정보 내용 서지정보, 인명정보, 등록결정 및 안내정보, PDF정보 등을 XML 형태로 제공합니다. 출원번호, 발송번호, 발명의명칭, 청구항수, 내용구분 등 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

제공기관: 지식재산처
분류: 과학기술
키워드: 출원번호, 발송번호, 발명의명칭, 청구항수, 내용구분
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-09-22
이용허락: 이용허락범위 제한 없음

# 우체국통합배송조회

우체국 등기번호를 이용하여 국내, 국제의 배송내역을 조회하는 OPEN API 서비스입니다. ㅇ 출력하는 항목(사용자가 응답 받게 되는 데이터) : 등기번호, 보낸사람, 보낸날짜, 받는사람, 받은날짜, 배달상태, 서비스종류, 정렬순서, 처리일시, 처리시간, 처리상태, 처리장소, 상세설명 이 문서는 우정사업본부의 통합배송조회 서비스를 공공데이터 오픈API로 활용하기 위한 기술 가이드로, API 서비스 개요와 상세 기능 목록, 각 기능별 요청·응답 메시지 명세, 필수·옵션 항목 구분, 요청·응답 예제, 에러 코드 목록 등을 포함합니다. 개발자가 통합배송조회 데이터를 연동하고 활용하는 데 필요한 규격서 역할을 하며, 배송 상태 확인과 관련한 다양한 기능과 예시를 제공해 효율적인 데이터 처리와 서비스 구현을 지원합니다.

제공기관: 과학기술정보통신부 우정사업본부
분류: 과학기술
키워드: 경제경영, 마케팅, 물류유통관리, 통합배송조회, 등기번호, 보낸사람, 배달상태, 우체국

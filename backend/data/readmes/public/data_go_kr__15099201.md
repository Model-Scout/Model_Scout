# 한국국제협력단_봉사활동 안내서_20220225

KOICA 해외봉사단 활동과 관련된 봉사활동 안내서 목록을 조회할 수 있는 API입니다. 파견 대상 국가의 활동 환경, 문화적 유의사항, 활동 분야별 준비사항 등이 포함된 자료를 제공하여, 예비 파견자 및 관심자들에게 실질적인 참고자료 역할을 합니다. 해당 API는 인증키(serviceKey), 페이지 번호(pageNo), 한 페이지 결과 수(numOfRows) 등 기본적인 요청변수를 사용하며 제목, 작성일(less than), 작성일(greater than) 등의 필터 파라미터를 추가로 설정할 수 있습니다. 출력결과에는 제목, 내용, 다운로드url, 확장자명, 작성일 등의 항목이 포함되며, 각 항목에 대한 데이터는 JSON 형식으로 반환됩니다.

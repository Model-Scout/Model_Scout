# 자전거사고다발지 현황

이 데이터는 자전거 사고 다발지역 현황을 지역별로 정리한 자료로, 사고 발생 위치, 사고 유형, 발생 건수, 사상자 수 등의 정보를 포함합니다. 사고년도, 시군명, 읍면동명, 법정동코드 등의 행정구역 정보와 함께, 사고위치를 식별할 수 있는 위도, 경도, 위치코드 및 사고다발지역의 폴리곤 형태의 공간정보(GIS)도 제공됩니다. 해당 데이터는 자전거 교통사고가 집중되는 지역을 분석하여 교통안전시설 설치, 정책 수립, 위험지역 사전 경고 시스템 개발 등 다양한 분야에서 활용될 수 있습니다. 사고 유형은 모두 '자전거사고다발지'로 분류되며, 사망자수, 중상자수, 경상자수, 부상자수 등 세부적인 인명피해 정보도 포함되어 있습니다.

제공기관: 경기도
분류: 재난안전
키워드: 자전거사고, 사고다발지, 교통안전, 위치정보, 사고유형, 부상자통계
형식: api
선정 기준: 운영 자동승인 OpenAPI

# 건강보험심사평가원_코드테이블

건강보험심사평가원 데이터베이스에 구축된 코드마스터 정보로, 공공데이터 포털에 등록된 건강보험심사평가원의 공공데이터 활용 시 참고하시기 바랍니다. - 서식구분코드, 종별코드, 진료과목코드, 표시과목코드, 보험자구분코드, 병상규모코드, 원내원외구분코드, 성별구분코드, 양방한방구분코드, 지원코드, 요양종별코드, 청구형태코드 ※ 코드마스터 정보는 HIRA보건의료빅데이터개방시스템(opendata.hira.or.kr) > 서비스 소개 > 용어설명 > '코드조회'에서도 조회 가능합니다.

제공기관: 건강보험심사평가원
분류: 보건의료
키워드: 건강보험, 보건의료빅데이터, 코드마스터, 의료통계, 전문용어
형식: csv
선정 기준: 중앙·광역 기관 파일데이터

# 한국관광공사_방한 외래관광객 목적별 월별 집계

- 본 데이터는 한국관광공사에서 운영하는 한국관광 데이터랩(datalab.visitkorea.or.kr)에서 제공하는 한국관광통계의 방한 외래관광객 목적별/월별 데이터입니다. - 해당 자료에는 월별 방한 외래관광객의 방한 목적별 방한 외래관광객 수 등의 데이터를 포함하고 있습니다. - 방한 외래관광객에는 세계관광기구(UN Tourism) 거주국 기준 작성 권고안에 근거하여, 외국인 총 입국자 중 일부 체류 자격의 외국인 입국자(관광객으로 볼 수 없는 거주, 군인, 방문동거, 영주, 외교 등)를 제외하고 재외국민 입국자(교포)를 포함하고 있습니다.

# 국민건강보험공단_건강검진검사항목코드

본 테이블은 건강검진 실시기준 [별표1~3]과 암검진 실시기준 [별표1]에 따라, 국가건강검진유형별로 청구할 수 있는 항목들을 제공합니다. 이 데이터는 검진기관에서 검진비용을 청구할 때 사용되는 전산시스템(업무포털시스템) 내 각 유형별 검진항목을 청구하고 확인할 수 있는 항목을 나타냅니다. 1. 청구항목 기준년도 적용연도: 2001년 ~ 2024년까지의 건강검진청구항목 적용연도를 기준으로 합니다. 2. 청구항목 코드 건강검진유형 상세구분이 ‘위암’인 경우, 해당 항목이 코드화된 형태로 나타납니다. 예: ‘상담료 및 행정비용, 위내시경검사, 조직검사 등’에 대한 코드(예: D3101001, D3101003, D3101004 등). 3. 청구항목 코드명 건강검진유형에 따른 상세 항목명을 코드와 함께 제공합니다. 예를 들어, ‘위암’ 검사 항목에 대해서는 ‘상담료 및 행정비용, 위내시경검사, 조직검사’ 등이 구체적으로 명시됩니다. 4. 건강검진 유형구분코드 건강검진의 유형을 구분하는 코드입니다. 각 검진 항목에 대해 일반, 구강, 암, 영유아, 학교밖청소년 등으로 구분됩니다. 예: ‘A’, ‘C’, ‘D’, ‘E’ 등의 코드가 해당합니다. 5. 건강검진유형 상세구분코드 건강검진유형이 ‘암’인 경우, 암검진 항목을 상세히 구분하는 코드입니다. 예를 들어, 위암, 대장암, 유방암, 간암, 자궁경부암, 폐암 등으로 구분됩니다. 각 암에 대한 코드가 제공됩니다. 예: ‘D31~D37’ 등.

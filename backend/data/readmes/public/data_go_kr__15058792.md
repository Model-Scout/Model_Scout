# 승마장업체 현황

이 데이터는 경기도 31개 시군에 위치한 승마장업체의 인허가 현황을 제공하는 자료로, 말타기 체험을 제공하는 체육시설에 대한 정보를 포함합니다. 총 32개 항목으로 구성되며, 사업장명, 인허가일자, 영업상태, 폐업일자, 주소, 위치정보(WGS84 위도·경도 포함), 지도자 수, 회원모집 인원, 건축물 연면적 및 동수, 보험가입 여부, 업태구분명, 세부업종명 등이 포함됩니다. 이 자료는 지역 내 이색 체육시설 분포 파악, 체험형 체육시설 정책 수립, 공간정보 분석 등에 활용 가능하며, 행정안전부가 주간 단위로 갱신하여 Open API를 통해 제공하고 있어 데이터 활용의 범용성이 높습니다.

제공기관: 경기도
분류: 문화관광
키워드: 승마장, 인허가현황, 말타기, 체험시설, 위치정보, 지도자수, 회원모집, 업태구분
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-07-21
이용허락: 이용허락범위 제한 없음

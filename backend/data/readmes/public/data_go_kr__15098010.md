# 한국등산트레킹지원센터_오감만족숲길POI정보 서비스_20220105

이 데이터는 한국등산·트레킹지원센터에서 2022년 1월 5일에 등록하여 제공하는 오픈API 서비스로, 전국 오감만족숲길 구간의 주요 관심지점(POI) 정보를 조회할 수 있는 서비스입니다.

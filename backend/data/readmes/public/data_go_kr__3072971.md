# 경기도 김포시_공장등록현황

경기도 김포시의 공장등록현황에 대한 정보를 제공합니다. 제공 항목으로는 회사명, 대표자명, 공장대표주소(도로명), 업종번호, 업종명, 등록일, 전화번호, 팩스번호, 종업원수, 생산품, 주원자재, 데이터기준일로 구성되어있습니다. 본 데이터를 통해 지역별 공장 분포와 생산품, 규모 등을 알 수 있습니다. 본 공공데이터는 매년마다 정기적인 갱신을 통하여 최신정보를 반영하고 있으며 csv 파일 형태로 제공합니다. 해당 데이터와 관련하여 궁금하신 사항이 있으실 경우 김포시 기업지원과로 연락주시기 바랍니다.

# 법령 별표, 서식 목록 조회

본 데이터는 대한민국 법령에 첨부된 별표 및 서식에 관한 정보를 제공합니다. 각 항목에는 별표 또는 서식의 고유번호, 적용 대상 법령의 법령번호 및 조문 연계 정보, 제목, 문서 구분 코드, 발효일자와 최신 개정이력 등이 포함됩니다. 이 데이터를 통해 사용자는 법령별 첨부 서식을 체계적으로 확인하고, 해당 별표가 어느 법령과 어떻게 연결되는지 명확히 파악할 수 있습니다. 법률 문서 작성과 행정 절차 수행에 필요한 표준 서식 정보를 손쉽게 조회할 수 있으며, 법제 정비와 서식 통일성 확보에 효과적입니다. 본 정보는 법제도 운영, 행정 효율성 제고, 법령 기반 문서화 업무에 유용한 기초 자료입니다.

제공기관: 법제처
분류: 공공행정
키워드: 국가법령정보별지양식, 부속문서, 서식번호, 적용법령, 발효일자, 개정이력, 조문연계, 문서구분
형식: api
선정 기준: 국가중점데이터 OpenAPI

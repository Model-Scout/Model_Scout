# 세종특별자치시_상하수도 처리시설 현황

세종특별자치시 관내에 소재한 공공하수처리시설 현황에 대한 데이터 자료입니다. 세종특별자치시 상하수도 처리시설 현황입니다. 공공하수처리시설은 총 29개소로 감성지구, 검단지구, 고등지구, 국곡리, 금천지구, 노송지구 등에 있으며, 본 데이터는 세종특별자치시 정보공개 사전정보공표 세종특별자치시 공공하수처리시설 운영현황/하수처리장운영현황(https://www.sejong.go.kr/shrUrl/fbfQt1vzQBnpSqGdx2fL.do)을 통해서도 확인하실수 있습니다.

키워드: 공공하수, 하수처리, 시설, 상하수도, 처리시설

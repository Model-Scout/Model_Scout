# 서울교통공사_월별 수송인원

서울교통공사의 월별 수송인원 데이터입니다. 해당 데이터는 연번, 호선, 역번호, 월별 수송 인원 데이터로 구성되어 있습니다. 연단위 데이터로 2025년 12월기준 파일까지 업로드 합니다. 수송인원은 승차인원과 환승유입인원은 합으로 산정됩니다. 승차인원은 해당역에서 개표하여 들어간 인원을 의미합니다. 환승유입인원은 하차인원 중 승차호선이 다른 인원을 의미합니다. 또한, 서울교통공사 1호선의 경우 서울역부터 청량리까지가 관할구간이며 나머지 구간은 한국철도공사에서 관할하고 있습니다. 4호선의 경우 남태령 구간까지가 서울교통공사 구간입니다. 또한 8호선의 경우 암사역사공원까지가 서울교통공사 구간이며, 7호선의 경우 까치울과 부평구청구간 사이는 인천교통공사로 22년에 이관되었음을 알려드립니다.

# 종오리업 현황

이 데이터는 경기도 내 종오리업체의 현황을 수록한 자료로, 번식용 오리 또는 씨알을 생산하여 판매하거나 위탁사육을 하는 사업체 정보를 제공합니다. 주요 항목은 시군명, 사업장명, 인허가일자, 폐업일자, 영업상태명, 소재지 도로명 및 지번주소, 우편번호, 면적, 총종업원수, 축산업무구분명, 축산물가공업구분명 등으로 구성되어 있습니다. 해당 데이터는 오리 사육과 부화산업 관련 업체의 인허가 및 운영 현황을 파악하는 데 활용되며, 지역별 종오리 산업 분포 분석, 방역 및 사육시설 정책 수립, 가축 번식 기반 연구 등의 목적으로 활용 가능합니다. 데이터는 행정안전부에서 제공되며, 31개 시군의 인허가 정보를 포함하고 있습니다.

제공기관: 경기도
분류: 농축수산
키워드: 종오리업, 부화장, 번식용오리, 사업장정보, 인허가일자, 축산업무구분, 시군정보, 소재지정보
형식: api

# 계량기제조업 현황

이 데이터는 경기도 내 계량기 제조업체의 인허가 및 영업현황을 수록한 자료로, 각 사업장의 명칭, 인허가일자, 영업상태(영업중, 폐업 등), 소재지 주소(지번 및 도로명), 전화번호, 위치좌표(WGS84 위·경도) 등의 정보를 포함하고 있습니다. 계량기란 산업·상업·일상 생활 등에서 물리량을 측정하는 기기로, 정확성과 정밀성이 요구되는 분야입니다. 해당 데이터는 제조업체의 지역 분포, 업종 지속성, 주소 기반 위치정보, 공업제품 품질관리 모니터링, 산업안전점검 대상 선정, 기술산업 클러스터 분석 등에 활용할 수 있으며, 중소 제조업체 육성 정책이나 규제완화 검토에도 기초자료로 유용합니다.

제공기관: 경기도
분류: 산업고용
키워드: 측정기, 계측기, 장비, 제조업, 공업제품, 제조업체
형식: api
선정 기준: 운영 자동승인 OpenAPI

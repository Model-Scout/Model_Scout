# 재정경제부_국유재산 현황 정보

해당 데이터는 국유재산 연도별로 토지, 건물, 유가증권, 기타로 구분하여 연도별 국유재산 금액을 제공하는 자료입니다. 데이터 중 토지의 경우 국유 토지의 면적 현황 자료도 같이 제공하고 있습니다. 재산 금액의 단위는 억원이며 토지 면적의 단위는 제곱 킬로미터로 제공하고 있습니다. 결산연도 기준으로 1991~2025년까지의 자료이며 연도별로 총 규모 및 재산 종류별 규모의 변화를 확인할 수 있습니다. * 해당 데이터는 공공저작물입니다. 저작권 정보를 참고하시어 데이터 이용에 유의하시길 바랍니다.(링크의 "메타정보열기"를 통해 확인 가능)

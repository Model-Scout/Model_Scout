# 국민연금공단_사업장규모별 사업장가입자 수

해당 데이터는 국민연금공단에 가입된 사업장 가입자수 데이터를 기반으로 만들어졌습니다. 연도별 국민연금에 가입된 사업장가입자의 데이터를 나타냅니다. 해당 데이터는 사업장의 규모에 따라 분류되어있고 분류기준은 아래와 같습니다. -5인미만, 10인 미만, 50인 미만, 100인 미만, 1,000인 미만, 1,000인 이상으로 세분화되어있습니다. 사업장규모별 사업장가입자 수 데이터를 통해 분류된 규모에 따라 가입된 국민연금 사업장가입자 수를 확인할 수 있습니다. (데이터 건수가 많은 경우 모든 데이터가 표출되지 않을 수 있습니다.)

제공기관: 국민연금공단
분류: 사회복지
키워드: 국민연금, 사업장가입자, 규모별, 가입자수, 분류
형식: csv
선정 기준: 중앙·광역 기관 파일데이터
수정일: 2026-08-28
이용허락: 이용허락범위 제한 없음

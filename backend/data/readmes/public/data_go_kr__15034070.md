# 견학/체험 정보 서비스

본 데이터는 부산광역시 사업소에서 운영하는 체험 견학 프로그램에 대한 데이터입니다. 2018년부터 현재까지의 총 1,030개의 체험 견학 프로그램 데이터가 있습니다. 낙동강하구에코센터, 금련산청소년수련원, 부산근현대역사관,부산어촌민속관, 부산치유의숲, 임시수도기념관, 해양자연사박물관, 현대미술관 등 25개 기관의 체험 견학 정보를 알 수 있습니다. 체험 견학 프로그램의 이름과 설명, 소개, 운영기간(시작/종료) 신청기간(시작/종료), 취소기간, 신청방법, 수강료, 문의전화가 포함되어 있어서 체험 견학을 원하는 프로그램에 대해서 신청하여 참여할 수 있습니다. *기준일 2025.5.16 현재

제공기관: 부산광역시
분류: 문화관광
키워드: 가족, 어린이, 체험, 현장, 자연, 문화
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-05-21
이용허락: 이용허락범위 제한 없음

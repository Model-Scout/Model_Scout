# 중기예보 조회서비스

중기예보는 단기예보 이후 향후 11일까지의 기상전망, 육상·해상 날씨, 최고·최저기온, 파고를 오전/오후로 나누어(8~10일은 하루단위) 발표하는 예보를 말합니다.(일 2회 발표: 06, 18시) 중기예보의 세부 대상구역은육상광역예보의 대상구역(서울․인천․경기도(수도권), , 대전ㆍ세종ㆍ충청남도(충남권), 충청북도, 강원도영서(강원영서), 강원도영동(강원영동), 광주ㆍ전라남도(전남권), 전북자치도(전북, 부산ㆍ울산ㆍ경상남도(경남권), 대구ㆍ경상북도(경북권), 울릉도ㆍ독도, 제주도) 중 서해5도, 울릉도ㆍ독도를 제외한 구역으로 합니다. 중기예보의 예보요소는 하늘상태, 강수형태, 최고기온, 최저기온, 강수확률 및 그 밖에 필요한 사항으로 니다.

분류: 과학기술
키워드: 단기예보, 날씨예보, 기온, 기온전망, 날씨전망
형식: api
선정 기준: 국가중점데이터 OpenAPI

# 평생교육대학 운영 현황

이 데이터는 경기도에서 시행된 「경기도민 평생교육대학」 사업의 운영 현황을 기록한 자료로, 평생교육 프로그램을 실시한 대학명, 교육과정명, 교육기간, 계획 및 수료 인원수, 추진방법, 사업내용 등 다양한 항목을 포함합니다. 해당 사업은 2016년에 종료되어 현재는 갱신이 이루어지지 않지만, 당시의 평생교육 프로그램 기획과 운영 성과를 분석하는 데 활용할 수 있습니다. 특히 교육정책 수립, 지역별 평생교육 수요 분석, 성인학습자 대상 프로그램 연구 등에 기초자료로 제공될 수 있으며, 과거 사례를 바탕으로 향후 유사 정책의 기획에도 참고 가능합니다. 데이터는 Open API 방식으로 접근 가능하며, 연도별 데이터 구성으로 집계년도별 분석이 용이합니다.

제공기관: 경기도
분류: 교육
키워드: 평생교육, 교육기관, 과정정보, 대학명, 수료인원, 교육기간, 추진방법, 교육정책
형식: api
선정 기준: 운영 자동승인 OpenAPI

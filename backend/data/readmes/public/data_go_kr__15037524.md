# 국가기술자격 통계연보 정보

“국가자격 통계연보 정보” API는 한국산업인력공단이 제공하는 공공데이터 REST 서비스로, 국가자격(국가기술·전문자격)의 접수·응시·취득 현황을 연도별 통계 형태로 XML로 제공합니다. 예를 들어 API 호출 시 ServiceKey, baseYY(조회 연도), pageNo, numOfRows 등을 지정해 연도별 접수자 수, 응시자 수, 합격자·취득자 수, 성별·연령·등급(기술사·기사·기능사 등) 분포 등 주요 통계 지표를 조회할 수 있습니다

제공기관: 한국산업인력공단
분류: 공공행정
키워드: 국가자격, 기술자격, 전문자격, 통계연보
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2026-09-10
이용허락: 이용허락범위 제한 없음

# 제주특별자치도_제주사랑상품권가맹점

제주특별자치도 내 제주사랑상품권가맹점 현황 데이터를 제공합니다. 항목: 가맹점명, 유형, 문의처 등 *전통시장 및 지역상권 활성화를 위해 제주특별자치도 내에서 사용가능한 지역상품권으로 2020년도에 탐나는전으로 대체 됨 - 제주사랑상품권은 2006년 9월~2020년 11월 14년간 총 1,777억 2,000만원이 판매됐으며, 2023년 11월 말 기준 판매액의 99.4%인 1,767억 5,300만 원이 회수됐다. 자세한 사항은 탐라는전 홈페이지에서 확인하시기 바랍니다. https://tamna.jeju.go.kr/mainView.do

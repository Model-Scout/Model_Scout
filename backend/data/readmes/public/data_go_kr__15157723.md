# 인천항만공사_인천항 차량 통계 정보 조회 서비스_20250722

해당 자료는 인천항 내 차량 출입정보에 관한 API 명세서로, 출입차량의 종류와 출입 경로 및 통계를 수집하고 분석할 수 있는 기반 자료입니다. API는 REST 방식으로 호출되며, 조회 기간 설정을 위한 searchStartDt, searchEndDT와 같은 요청 파라미터를 통해 특정 기간의 차량 출입 현황을 조회할 수 있습니다. 응답 결과에는 출입구분(inOutDvsn), 출입문 코드(IaneCd), 상시 차량(normalCar) 및 인원(normalPerson), 임시 차량(tempCar) 및 인원(tempPerson), 부두명(postNm) 등의 다양한 요소가 포함되어 있습니다.

제공기관: 인천항만공사
분류: 교통물류
키워드: 차량 출입, 인천항, 출입정보, 입출문코드, 입출문구분, 부두명, 차랑통계, 인원정보
형식: api

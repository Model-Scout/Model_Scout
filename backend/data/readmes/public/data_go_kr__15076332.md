# 행정안전부_공공데이터 활용 현황(파일_API)

공공데이터포털에 등록된 파일 데이터의 연도별 (2011년~ 2025년) 다운로드 건수 및 API의 활용신청 건수에 대한 현황을 제공하고 있으며, 공공데이터 활용의 증가 추이를 분석하는데 유용합니다. 파일형태는 CSV 형식으로 제공되며, 메타항목은 통계연도, 등록기관, 목록명, 데이터명, 파일 다운로드 및 API 활용신청 수 입니다. 공공데이터포털에서는 로그인 없이 파일데이터를 다운로드할 수 있으며, 오픈API를 활용하려면 공공데이터포털 회원 가입 및 로그인 후 활용 신청을 할 수 있습니다.

제공기관: 행정안전부
분류: 공공행정
키워드: 공공데이터활용, 파일데이터, 오픈_API, 공공데이터포털, 공공데이터활용현황, 파일데이터다운로드수, 오픈API활용신청건수
형식: csv
선정 기준: 중앙·광역 기관 파일데이터
수정일: 2026-09-08
이용허락: 이용허락범위 제한 없음

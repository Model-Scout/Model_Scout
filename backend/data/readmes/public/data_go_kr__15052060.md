# 한국가스공사_도시가스공급열량실적

한국가스공사의 도시가스 공급열량 실적현황 데이터 입니다. 도시가스 품질관리 및 열량 현황 파악, 공급품질 분석, 회사별 열량 비교를 목적으로 수집되었습니다. 데이터 구성항목은 연도별 회사별 고위발열량(MJ/Nm3, kcal/Nm3)과 저위발열량(MJ/Nm3, kcal/Nm3)으로 이루어져 있어 도시가스사별 공급열량 현황을 비교 분석할 수 있습니다. 본 데이터를 활용하면 회사별 공급열량 현황 파악, 열량 변동 추이 분석, 열량 품질 기준 충족 여부 평가, 회사간 열량 편차 분석, 고위/저위 발열량 비율 분석이 가능합니다. 또한 도시가스 요금 산정 기초자료, 열량 품질관리 정책 수립, 소비자 보호 정책 지원, 열량 표준화 검토에 활용됩니다. 도시가스 품질의 투명한 공개를 통해 소비자 신뢰 확보와 도시가스 산업의 건전한 발전에 기여합니다.

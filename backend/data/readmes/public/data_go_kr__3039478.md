# 경기도 부천시_공장등록현황

부천시 공장등록 현황에 대한 데이터로 회사명, 공장주소(도로명), 전화번호, 업종명, 생산품 등의 정보를 제공합니다. 해당 정보는 산업집적활성화 및 공장설립에 관한 법률 제16조(공장의 등록)에 따라 등록된 제조업 공장 현황 자료로 부천시 관내 제조업 활성화와 지역경제활성화 , 일자리 창출에 기여할 수 있습니다. 해당 정보는 부천시 사이트 "사전정보공표" 현황에서도 확인 가능합니다. 업종코드는 한국표준산업분류에 따른 분류코드입니다.(10차시) 2025년 기준 부천시 관내 등록공장은 약 3,400개소 입니다. 기타 세부사항은 부천시청(www.bucheon.go.kr)에서도 확인 가능합니다. 해당 자료는 오정일반산업단지 내 공장등록(입주계약)현황 자료를 포함합니다. 공장등록 현황 외 세부 공장설립 완료신고 현황도 부천시청(www.bucheon.go.kr)에서 확인 가능합니다. (공장등록(변경)은 공장설립온라인지원시스템(팩토리온)에서 신청 가능합니다)

제공기관: 경기도 부천시
분류: 산업고용
키워드: 공장등록, 공장, 제조업, 제조기업, 팩토리온
형식: csv
수정일: 2025-11-26
이용허락: 공공저작물 : 출처표시, 상업적 이용금지, 변경금지 (제 4유형)

# 국가별컨테이너처리실적 통계정보

이 데이터는 해양수산부에서 국내 항만 내 처리된 수출입 컨테이너 화물의 처리식적 정보를 제공하기 위해 수집한 데이터입니다. 조회기간을 파라미터로 데이터를 조회할 수 있으며, 본 데이터의 주요 내용은 연도별, 연월별로 항만별, 품목별, 국가별, 해외지역별로 구분된 수출입 컨테이너화물의 처리실적(TEU) 통계로 구성되어 있습니다. 본 데이터는 항만 운영 효율 분석, 국가별 물류 흐름 조사, 수출입 화물 종류별 처리 비중 비교, 항만별 경쟁력 평가, 해운 및 물류 기업의 전략 수립 등을 위한 기초 자료로 활용될 수 있습니다.

제공기관: 해양수산부
분류: 공공행정
키워드: 컨테이너수송, 수출입화물, 항만물동량, TEU, 품목별, 국가별, 지역별
형식: api
선정 기준: 국가중점데이터 OpenAPI

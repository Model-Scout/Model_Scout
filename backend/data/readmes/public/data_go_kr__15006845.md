# 경상북도 경주시_공중위생업 현황

본 데이터는 경상북도 경주시 내 공중위생업소의 현황을 수록한 자료이다.업종명, 업소명 영업소주소(도로명주소)와 지번주소 등의 항목이 포함되어 있으며, 숙박업, 목욕업, 이용업, 미용업, 세탁업, 피부미용업 등 다양한 공중위생 관련 업종의 정보를 제공한다. 해당 자료는 위생관리 정책 수립, 행정업무 지원, 지역 위생수준 분석, 민원 응대, 업종별 분포 파악 등에 활용 가능하다. 데이터는 파일 형식으로 제공되며, 정기적으로 최신 내용으로 갱신된다. 시민 생활과 밀접한 공중위생 환경을 이해하고 개선하기 위한 기반 자료로서의 활용도가 높다.

제공기관: 경상북도 경주시
분류: 식품건강
키워드: 숙박업소, 미용업체, 이용업, 목욕탕, 세탁소, 피부관리
형식: csv
수정일: 2026-08-25
이용허락: 이용허락범위 제한 없음

# 가축 인공 수정소업체 현황

이 데이터는 경기도 내 31개 시군에 위치한 가축 인공 수정소업체의 인허가 현황을 제공하는 자료로, 가축의 인공수정을 수행하는 사업장에 대한 정보를 담고 있습니다. 총 27개 항목으로 구성되며, 사업장명, 인허가일자, 영업상태, 폐업일자, 소재지 주소, 위치정보(WGS84 위도·경도 및 좌표값), 총 종업원 수, 축산업무구분명, 축산물가공업구분명, 업태구분명, 축산고유번호 등의 정보를 포함합니다. 본 자료는 가축 번식 관련 기술 기반 시설의 분포 현황, 축산업 전문성 분석, 지역 축산정책 수립의 기초 자료로 활용될 수 있으며, 행정안전부에서 주간 단위로 갱신하여 Open API 형식으로 제공됩니다.

제공기관: 경기도
분류: 농축수산
키워드: 가축인공수정, 인허가현황, 축산업체, 위치정보, 업태구분, 종업원수, 축산업무, 가축생산기술
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-07-21
이용허락: 이용허락범위 제한 없음

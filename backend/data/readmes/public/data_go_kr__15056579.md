# 행정규칙 본문 조회

법제처에서 제공하는 행정규칙 본문 조회 데이터입니다. 본 데이터는 각 행정규칙의 조문별 상세 내용을 포함하며, 조문 번호, 제목, 내용뿐만 아니라 시행일과 개정 및 폐지 이력 정보가 함께 제공됩니다. 이를 통해 행정규칙의 최신 상태를 정확히 확인할 수 있습니다. 데이터는 특정 행정규칙 및 조문번호를 기준으로 본문을 조회할 수 있도록 구성되어 있으며 해당 정보는 행정업무 지원과 법제도 운영에 필수적인 자료로 활용되며, 체계적인 법령 관리에 기여합니다. 또한 총 조회 수와 페이지 정보가 포함되어 효율적인 데이터 활용이 가능합니다.

제공기관: 법제처
분류: 공공행정
키워드: 국가법령정보훈령고시, 행정규칙, 시행일, 개정이력, 법령정보, 법제관리, 법령상태, 조문
형식: api
선정 기준: 국가중점데이터 OpenAPI
수정일: 2025-07-10
이용허락: 제3자 권리 포함 : 저작권 표시, 공공저작물 : 출처표시 (제 1유형)

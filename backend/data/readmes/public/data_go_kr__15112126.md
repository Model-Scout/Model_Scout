# 과학기술정보통신부 우정사업본부_우체국 국내환요금 및 수수료 정보조회 서비스_20230125

우체국에서 제공하는 국내환 서비스는 통상환과 온라인환으로 구분됩니다. 통상환은 송금 시점에 환증서가 즉시 발행되며, 온라인환은 수취인 주소지의 배달국에서 환증서를 발행해 전달합니다. 온라인환은 경조카드의 유무에 따라 경조환 서비스와, 현금을 직접 배달하는 현금배달 서비스로 나뉩니다. 이 API는 각 국내환 서비스 유형별 수수료 코드, 금액 구간, 요금, 금액 단위 등의 정보를 실시간으로 조회할 수 있는 공공데이터입니다. 해당 데이터가 보유한 컬럼은 다음과 같습니다: 수수료코드, 수수료명, 금액구간, 요금, 금액단위. 사용자가 응답받게 되는 데이터도 동일하게 수수료코드, 수수료명, 금액구간, 요금, 금액단위로 구성됩니다.

제공기관: 과학기술정보통신부 우정사업본부

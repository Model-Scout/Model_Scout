# 원자력안전위원회_국내 원자력발전소 현황

2025년 6월 기준 국내 원자력발전소의 현황 데이터입니다. - 현황 데이터는 원자력발전소의 명칭, 노형, 원자로공급사, 용량(MWe), 건설허가일, 착공일(기초굴착일), 운영 허가일, 상업운전 개시일, 설계수명 만료일 데이터로 구성되어 있습니다. - 현황데이터에서는 현재 운영 중인 원자력발전소, 건설 중인 원자력발전소, 운영이 정지된 원자력발전소의 데이터도 제공하고 있습니다. - 원자력발전소의 용량 데이터는 각 발전소의 호기별 용량(용량1)과 발전소별 용량(각 발전소별로 호기별 용량의 합, 용량2)데이터로 구성되어 있으므로 데이터 활용에 참고하여 주세요

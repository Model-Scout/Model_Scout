# 행정안전부_실시간 주소정보 조회(팝업API)_20211220

팝업API를 활용하여 주소검색 이후, 상세주소를 선택할 수 있는 동.층.호 정보를 제공합니다. 도로명주소 팝업API, 좌표제공 팝업API, 모바일용API에서 요청변수를 추가하여 적용할 수 있습니다. 1. API 서비스 개요 - 웹 기반의 UI 제공 - DB 구축 및 현행화 부담ZERO - 실시간 주소 검색 가능 - 신청 즉시 이용 가능 - 1 시스템 1 승인키 부여 2. 입력 파라미터 정보 신청 시 부여받은 승인키,주소 검색 결과를 리턴받을 URL,도로명주소 검색결과 화면 출력유형(1 : 도로명, 2 : 도로명+지번+상세보기(관련지번, 관할주민센터), 3 : 도로명+상세보기(상세건물명), 4 : 도로명+지번+상세보기(관련지번, 관할주민센터, 상세건물명)),상세주소 동/층/호정보 제공여부 (Y : 제공, N : 미제공(직접입력)) 3. 출력 파라미터 정보 전체 도로명주소,도로명주소(참고항목 제외),도로명주소 참고항목,지번 정보,도로명주소(영문),우편번호,행정구역코드,도로명코드,건물관리번호,고객 입력 상세 주소,상세건물명,건물명,공동주택여부 (1:공동주택, 0: 비공동주택),시도명,시군구명,읍면동명,법정리명,도로명,지하여부 (0:지상, 1:지하),건물본번,건물부번 (부번이 없는 경우 0),산여부 (0:대지, 1:산),지번본번(번지),지번부번(호) (부번이 없는 경우 0),읍면동일련번호

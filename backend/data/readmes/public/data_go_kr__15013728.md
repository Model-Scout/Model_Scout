# 지식재산처_특허_상품 연례 분류정보 DB

ㅇ 배경 : 특허(발명)의 명칭이 일반인이 이해하기 어렵고 일반 검색식으로는 해당 특허와 무관한 특허도 같이 검색됨에 따라, 대중에게 친숙한 상품명으로 관련된 특허를 쉽고 빠르고 정확하게 검색하기 위하여 특허정보와 상품명을 연계한 DB를 구축하게 되었습니다. ㅇ 범위 : "10~"14년 특허.실용신안 공개/등록공보 중 전기분야(IPC : H섹션)만 구축하여 특허청에서 제공합니다. * 특허-상품 연계 분류정보 DB는 기존에 연계되지 않은 특허정보와 상품명을 연계한 DB로써 분류기준에 일부 주관이 포함되어 참고자료로 활용하시기 바랍니다.

제공기관: 지식재산처
분류: 과학기술
키워드: 특허_및_상품_연계, 분류정보, 상표_, 지식재산권, 연계DB구축, 정확도제고
형식: csv
선정 기준: 중앙·광역 기관 파일데이터

# 금융위원회_모기지론발행상세정보_20200424

모기지론발행상세정보는 모기지론(MBS)의 발행 구조와 관련된 세부 정보를 제공하는 데이터입니다. 데이터는 다음 3가지 오퍼레이션으로 구성되어 있습니다. ① 발행개요 조회 : 기준일자, 발행번호 등을 기준으로 발행기관명, 발행일자, 발행금액, MBS 유형, 만기일, 금리구분 등을 확인하는 기능 ② 종목별 예상만기 조회 : 발행번호, 종목번호 등을 기준으로 예상만기월, 예상상환금액, 연도별 상환계획 등을 조회하는 기능 ③ 대상기초자산 정보 조회 : 발행번호를 기준으로 대상자산구분, 대상자산건수, 대상자산총액, 평균잔존기간 등 기초자산 현황을 조회하는 기능

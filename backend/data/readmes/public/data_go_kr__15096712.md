# 행정안전부_행정안전부_실시간 상세주소정보 조회(검색API)

도로명주소API, 좌표제공API, 주소DB를 이용하여 실시간으로 도로명주소의 동.층.호정보를 제공받을 수 있습니다. 1. API 서비스 개요 - 다양한 시스템 환경 적용 가능, 개발언어, 플랫폼 제약없음, 실시간 동층호 정보 검색, 신청 즉시 이용 가능, 1 시스템 1 승인키 부여 2. 입력 파라미터 정보 신청시 발급받은 승인키, 행정구역코드, 도로명코드, 지하여부(0 : 지상, 1 : 지하), 건물본번,건물부번, 동층호 검색유형(dong, floorho), 동(층호 검색 시 입력), 검색결과형식 설정(xml, json) 3. 오픈API 이용방법 주소기반산업지원서비스(business.juso.go.kr)에 접속하시면, 보다 자세한 정보를 확인하실 수 있습니다.

제공기관: 행정안전부
분류: 과학기술
키워드: 주소, 도로명주소, 상세주소(검색API), 동층호검색, 도로명동층호
형식: json+xml
선정 기준: 중앙·광역 기관 파일데이터

# 식육부산물전문판매업 현황

이 데이터는 경기도 31개 시군 내 식육 부산물 전문판매업소의 인허가 현황을 제공하며, 사업장명, 인허가일자, 영업상태, 폐업일자, 소재지 주소(도로명 및 지번), 소재지 면적, 우편번호, 위경도 좌표(WGS84 기준), 종업원 수, 축산물가공업 구분 및 축산업무 구분 등의 항목으로 구성되어 있습니다. 식육 부산물은 내장(간, 심장, 위장, 비장, 창자, 콩팥 등), 머리, 다리, 꼬리, 뼈, 혈액 등을 포함하며, 식용 가능한 축산 부산물의 유통과 관련된 업소를 전문적으로 관리하기 위한 자료입니다. 본 데이터는 축산 유통 구조 파악, 위생관리, 부산물 자원화 정책 수립 등에 활용 가능하며, 주간 단위로 갱신되도록 설계되었으나, 현재는 데이터 갱신이 중단된 상태입니다.

제공기관: 경기도
분류: 산업고용
키워드: 식육부산물, 부산물판매업, 인허가정보, 축산물가공, 유통업, 주소정보, 종업원수, 위치정보
형식: api

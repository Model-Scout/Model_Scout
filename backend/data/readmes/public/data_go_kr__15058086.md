# 병원 현황(병원급)

이 데이터는 경기도 내 병원급 의료기관의 현황을 정리한 자료로, 병원명, 인허가일자, 영업 상태, 병상 수, 의료인 수, 입원실 수, 진료과목 등의 정보를 포함하고 있습니다. 병원급 의료기관은 의원급보다 큰 규모로 다양한 진료과목을 운영하며, 응급·외래·입원 진료를 제공하는 핵심 의료 인프라로 기능합니다. 본 자료는 지역별 병원 분포와 규모, 인력 현황, 진료과목 다양성 등을 파악하는 데 유용하며, 의료 서비스 접근성 평가와 지역 간 의료격차 해소 전략 마련에 기초 자료로 활용될 수 있습니다. 또한 고령화와 만성질환 증가에 따른 의료 수요 대응, 응급의료체계 강화, 지역 보건정책 수립에도 중요한 참고 자료가 됩니다.

제공기관: 경기도
분류: 보건의료
키워드: 병원의료기관, 의료서비스, 의료인프라, 지역의료, 진료과목, 보건
형식: api
선정 기준: 운영 자동승인 OpenAPI

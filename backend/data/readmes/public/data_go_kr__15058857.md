# 환경컨설팅회사 현황

이 데이터는 경기도 내에서 환경행정 절차에 대한 상담, 정보 제공 및 대행 업무를 수행하는 환경컨설팅 회사의 정보를 제공합니다. 주요 항목은 시군명, 사업장명, 인허가일자, 영업상태, 사업장 주소, 위도·경도 좌표, 업태 정보, 위탁업체명, 실험실 주소 및 면적 등이며, 경기도 31개 시군에 걸친 인허가 정보를 포함합니다. 본 데이터는 행정안전부에서 관리하며, 주간 단위로 갱신됩니다. 실험실 정보 항목은 도로명주소, 건물 층수, 실험실 특수주소 등까지 포함되어 있어 세밀한 위치 기반 분석 및 공간정보 시스템 연계에 유리합니다. 데이터는 환경 관련 인허가 제도 분석, 컨설팅 산업 분포 현황 파악, 지역별 환경기업 현황 관리, 행정 효율화 등에 활용될 수 있습니다. Open API 형태로 제공되어 실시간 데이터 활용이 가능하며, 다양한 활용 분야에서 정책 기반 자료로 활용도가 높습니다.

제공기관: 경기도
분류: 환경기상
키워드: 환경컨설팅, 인허가정보, 사업장정보, 실험실정보, 영업상태, 위치정보, 위탁업체, 환경행정
형식: api
선정 기준: 운영 자동승인 OpenAPI

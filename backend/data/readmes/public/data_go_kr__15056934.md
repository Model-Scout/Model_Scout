# 경기도 경찰관서 현황

이 데이터는 경기도 내 경찰관서의 현황을 담고 있으며, 각 경찰관서의 경찰서명, 소재지주소, 우편번호 등의 기본정보를 포함하고 있습니다. 본 데이터는 치안 행정정보 제공을 통해 도민들의 공공안전 정보 접근을 용이하게 하고, 경찰행정 정책 수립 및 공공서비스 개선에 활용될 수 있습니다. 또한 데이터는 경찰청 홈페이지를 원본 시스템으로 하며, 수시로 갱신되며 최신의 기관 정보를 반영하고 있습니다. 사이버경찰청 정보도 함께 제공되어 다양한 경찰 관련 관서 현황을 포괄합니다. API 형식은 XML이며, 경기도 데이터포털을 통해 접근 가능합니다.

제공기관: 경기도
분류: 공공행정
키워드: 경찰관서, 경찰서, 관공서, 치안정보, 위치정보, 행정기관, 관서현황, 공공서비스
형식: api
선정 기준: 운영 자동승인 OpenAPI

# 보건소 예방접종 정보 서비스

각종 법정 전염병에 대해 성인, 청소년, 소아들이 감염되지 않도록 예방 접종 정보를 개방하고 있습니다. 개방된 데이터는 예방접종 종류, 접종대상자, 추가접종대상자, 비용, 접종 보건소 명, 운영시간, 전화번호 등이 포함되어 있습니다. 예방접종은 16개 구군 보건소와 관내 위탁의료기관에서 접종합니다. A형 간염, 결핵, B형 간염, 디프테리아, 파상풍, 백일해, 인플루엔자 홍역, 로타 바이러스, 소아 폐렴구균, 어르신 폐렴 구균, 일본뇌염 등의 예방접종 내역이 있습니다. 예방접종이 필요한 어린이, 어르신들이 예방접종 정보를 통해 질병의 위험으로부터 보호 받을 수 있습니다.

제공기관: 부산광역시
분류: 보건의료
키워드: 보건소, 질병, 독감, 전염병, 인플루엔자
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-05-19
이용허락: 이용허락범위 제한 없음

# 지하수 수질측정 결과 현황

이 데이터는 경기도 내 약수터의 수질 상태를 개별 지점 단위로 측정한 결과를 바탕으로 구성된 자료로, 연도별·지점별 채수일과 음용 가능 여부, 수질 적합 여부 및 초과 항목 등이 포함됩니다. 약수터를 직접 음용수로 사용하는 이용자들의 건강을 보호하기 위해 실시된 검사 결과로, 각 지점의 수질 기준 충족 여부를 확인할 수 있으며, 위생관리 필요 지점이나 미검사 사유 등도 확인 가능합니다. 이 데이터는 음용수 안전성 평가, 환경위생 정책 수립, 지역별 약수터 관리 강화, 주민 건강 보호 방안 마련 등 다양한 공공 보건 및 환경 정책 수립에 활용될 수 있습니다.

제공기관: 경기도
분류: 환경기상
키워드: 약수터, 음용수, 수질적합성, 수질안전, 수질검사, 지역별수질
형식: api
선정 기준: 운영 자동승인 OpenAPI

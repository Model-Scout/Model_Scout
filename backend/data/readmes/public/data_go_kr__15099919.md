# 한국농어촌공사_농촌용수 저수지 수위정보 조회_20220421

본 API는 한국농어촌공사에서 관리중인 저수지(담수호) 정보(저수지코드, 저수지이름 등)를 제공하고 있습니다. 저수지(담수호) 이름, 표줕코드 코드를 활용해 해당 저수지(담수호)의 저수위, 저수율 정보를 조회할 수 있습니다. * 시설구분방법: (표준코드 6번째 자리 ) 1- 저수지 / 9-담수호 (개선사항) - 농업용 저수지(담수호) 위치로 저수율을 조회 가능하도록 요청 변수(county) 추가 * 단, 저수지(담수호) 위치로 조회하는 경우는 최대 31일까지 조회 가능(저수지명: 최대 365일/ 저수지위치: 최대 31일)

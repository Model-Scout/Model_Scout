# 한국도로교통공단_가해운전자 법규위반별 주야별 교통사고 통계

- 가해운전자 법규위반별(신호위반, 중앙선침범 등), 주야별 교통사고 통계 * 주간 : 06~18시 / 야간 : 18시 ~ 06시 * 부상자수 : 중상자수 + 경상자수 + 부상신고자수 ** "사망" 이란 교통사고 발생시로부터 30일이내에 사망한 경우 (99년까지는 72시간 이내) ** "중상" 이란 교통사고로 인하여 3주 이상의 치료를 요하는 부상을 입은 경우 ** "경상" 이란 교통사고로 인하여 5일 이상 3주 미만의 치료를 요하는 부상을 입은 경우 ** "부상신고" 란 교통사고로 인하여 5일 미만의 치료를 요하는 부상을 입은 경우 - 경찰에서 조사, 처리한 교통사고에 대한 통계 정보로 인적 피해가 있는 사고만 집계 됨 - 교통사고분석시스템(https://taas.koroad.or.kr)의 데이터를 바탕으로 함 - 2021년 사고통계부터 "과속"은 법규위반 항목에서 제외(별도 집계) - 교통사고 통계는 연간 단위로 집계되어 당해년도 통계는 차년도에 제공

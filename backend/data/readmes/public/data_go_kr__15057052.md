# 시군별 시티투어 운영 현황

이 데이터는 경기도 내 시군별로 운영 중인 시티투어 프로그램의 현황을 수록한 자료로, 시티투어의 코스명, 운행일자, 탑승장소, 운행요금, 문의 연락처, 홈페이지 주소 등 다양한 정보가 포함되어 있습니다. 관광객에게 지역 기반 맞춤형 투어정보를 제공하며, 각 시군의 관광자원 홍보, 관광정책 수립, 지역관광 활성화에 유용하게 활용될 수 있습니다. 데이터는 연간 단위로 갱신되며, Open API 방식으로도 제공되어 JSON 또는 XML 포맷으로 실시간 활용이 가능합니다. 특히 탑승장소 및 요금 정보는 실제 이용자의 접근성과 편의성 분석에 유용하며, 관광경로 최적화 및 마케팅 자료로도 쓰일 수 있습니다.

제공기관: 경기도
분류: 문화관광
키워드: 시티투어, 운행코스, 운행일자, 이용요금, 탑승장소, 홈페이지주소, 시군별현황, 관광버스
형식: api
선정 기준: 운영 자동승인 OpenAPI

# 강원특별자치도_강원상품권

강원특별자치도 지역화폐(강원상품권)의 사용처(종이형 및 모바일형 가맹점)에 대한 데이터를 제공합니다. ① 자료생성일 : 2025. 8. 22일 기준 ② 제공 데이터 : 상품권 유형, 소재지 도, 소재지 시군, 가맹점명, 업종, 연락처, 가맹점 주소 등 ③ 제공 데이터 상세 - 기준일까지 등록된 가맹점에 대한 기본 정보 - 강원특별자치도내 18개 시군에서 사용가능한 가맹점 기본 정보를 제공 - 상품권 유형별 사용가능한 강원특별자치도내 가맹점의 업종, 연락처, 주소 등을 제공 - 상품권 유형은 2종류로 종이형과 모바일형이 있음

제공기관: 강원특별자치도
분류: 문화관광
키워드: 상품권, 취급, 가맹, 지역화폐, 사용처
형식: csv

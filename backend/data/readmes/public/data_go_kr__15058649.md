# 지식재산처_KIPRISPlus_디자인 분류코드 변동 이력_REST API_20220308

1. 개요 디자인의 국내분류코드, 로카르노 분류코드(Locarno)의 변동 이력정보를 제공합니다. 디자인 출원 건에 대한 분류코드의 변동이력 및 서지정보를 API(REST방식) 또는 대용량(BULK)으로 제공합니다. 2. 세부 정보 내용 디자인분류이력정보를 XML 형태로 제공합니다. 출원번호, 디자인일련번호, 그룹일련번호, 내역일련번호, 주분류유무, 로카르노분류코드, 로카르노분류코드버전 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

제공기관: 지식재산처
분류: 과학기술
키워드: 디자인 분류코드, 출원번호, 디자인일련번호, 로카르노분류코드, 분류이력정보
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-09-22

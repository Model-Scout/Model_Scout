# 역사별 수유실 현황

도시 및 광역철도 각 역사별 수유실 현황 및 이용 관련 정보를 포함하는 데이터입니다. 이 데이터는 승객, 특히 영유아를 동반한 가족들이 편리하게 이용할 수 있도록 수유실의 위치, 수량, 이용 조건 등을 상세히 제공합니다. 수유실 현황 정보는 역 내 편의 시설 관리와 운영 효율성 향상에 기여하며, 공간 활용도 분석, 고객 서비스 개선, 장애인 및 가족 친화적 시설 확충, 대중교통 이용 편의 증진에 중요한 기초 자료로 활용됩니다. 또한 철도 운영기관의 서비스 품질 향상과 승객 만족도 증대에 실질적인 가치를 지닌 공공 인프라 데이터입니다.

제공기관: 국가철도공단
분류: 교통물류
키워드: 지하철수유실, 지하철수유실위치, 수유실, 이용편의시설, 역사내편의공간
형식: api
선정 기준: 국가중점데이터 OpenAPI
수정일: 2025-11-17
이용허락: 이용허락범위 제한 없음

# 국가기술자격 배송주소구간 정보

“국가기술자격증 배송주소구간 정보” API는 한국산업인력공단이 제공하는 공공데이터 서비스로, 국가기술자격증의 우편 배송을 위한 도로명 주소 구간 정보를 XML 형식으로 제공합니다. 이 API는 자격증 우편 발송 시 필요한 주소 구간 데이터를 조회할 수 있어, 자격증 발급 시스템이나 우편 관리 시스템에 활용됩니다. 요청 시 ServiceKey와 같은 인증키를 포함하여 호출하며, 응답에는 지역명, 지역코드, 시작 및 종료 우편번호 등의 정보가 포함됩니다. 개발계정 기준으로 월 1,000회 호출이 가능하며, 운영계정은 활용 사례 등록을 통해 추가 트래픽을 신청할 수 있습니다 .

분류: 공공행정
키워드: 국가자격, 기술자격, 배송주소

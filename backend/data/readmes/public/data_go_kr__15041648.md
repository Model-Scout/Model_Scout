# 국민연금공단_장애심사 상병별 심사결과 현황

국민연금공단 장애심사 심사결과내역을 상병별로 구분한 데이터현황입니다. 장애심사 심사결과 처리내역은 등급결정, 미해당, 기타로 구분됩니다. - 장애심사 심사결과 상세내역 : 등급결정(1급, 2급, 3급, 4급, 초진일결정), 미해당(등급외, 결정보류, 자격미달, 확인불가), 기타(해당없음, 인과관계, 반려) 해당 데이터에서 보여지고 있는 값은 상병별로 1급, 2급, 3급, 4급, 초진일결정, 등급외, 결정보류, 자격미달, 확인불가, 인과관계 입니다. 파일내 항목별 상세 코드설명은 하단의 데이터 항목을 참고하여 주시기 바랍니다. 데이터 건수가 많아 엑셀, 메모장 등으로 모든 상세 데이터가 표출되지 않을 수 있습니다. 첨부되어 있는 파일에 해당되는 건수가 상세 표출되어 있으니 참고하여 데이터 확인 부탁드립니다. 데이터는 연도별로 제공되고 있습니다.

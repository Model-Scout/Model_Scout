# 대한무역투자진흥공사_공휴일 정보

KOTRA에서 공공데이터 포털에 개방하고 있는 공휴일 정보는 국가 코드별 해외 무역관이 소재해있는 각 국가의 공휴일 정보를 Open api 형태로 제공하고 있는 공공 데이터 입니다. 고객들은 현지 공휴일 확인으로 해외 출장 시 출장 일정 출동을 예방할 수 있으며, 마케팅 업무 종사자의 경우 해외 주요 명절 일정에 맞춰 판매 전략을 수립할 수 있습니다. 또한, 특정 연도의 공휴일 분포를 기반으로 현지 소비와 휴무 패턴을 분석하여 현지 시장 동향과 진출 전략을 수립하는 데 활용할 수 있습니다.

# 과학기술정보통신부_클라우드 보안인증서 발급현황

과학기술정보통신부에서 관리하는 클라우드 보안인증제(CSAP, Cloud Security Assurance Program) 인증서 발급현황 데이터입니다. 클라우드 서비스의 보안성을 검증하고 공공기관의 안전한 클라우드 도입을 지원하기 위해 시행되는 인증제도의 발급 현황을 체계적으로 정리한 자료로, 국내 클라우드 서비스의 보안 수준을 파악할 수 있는 중요한 공공데이터입니다. 데이터는 업체(기관)명, 인증번호, 인증범위, 유효기간, 인증상태 여부 등 5개 항목으로 구성되어 있습니다. 인증범위는 IaaS(Infrastructure as a Service), SaaS(Software as a Service) 표준등급 및 보통등급, DaaS(Desktop as a Service) 등으로 구분되며, 각 인증서의 유효기간은 3년 또는 5년으로 설정되어 있습니다. 유지여부를 통해 현재 유효한 인증서와 폐지된 인증서를 구분할 수 있습니다. 이 데이터는 공공기관의 클라우드 서비스 도입 시 보안 인증을 받은 서비스 선택에 활용될 수 있으며, 클라우드 서비스 제공업체의 보안 수준 현황 파악, 클라우드 보안 정책 수립, 시장 분석 등에 참고자료가 됩니다. * 첨부된 데이터는 한국인터넷진흥원 홈페이지에도 공개되는 데이터이오니 참고하시기 바랍니다. 홈페이지 주소 https://isms-p.or.kr/sttus/vrtl/selectVrtlCrtfctList.do

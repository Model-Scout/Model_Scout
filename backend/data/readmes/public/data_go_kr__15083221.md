# 국방부_국방데이터 코드설계표준

국방데이터표준으로 속성명, 물리명, 도메인명, 데이터유형 등의 데이터가 제공됩니다. 전체 건수는 1945건이 정의되어 있으며 코드는관리상 목록성코드와 코드값관리로 나뉘어집니다. 코드값관리는 코드값과 코드값명까지 표준으로 제정한것이며 목록성코드는 데이터길이까지만 정의하여 해당 데이터 길이만 준수하면(표준도메인) 표준을 준수한 것으로 합니다. 메타데이터표준은 매년 정기적으로 제.개정해서 관리되고 있으며 현재 자료는 25년 하반기 제.개정 결과를 포함한 내용입니다.

제공기관: 국방부
분류: 통일외교안보
키워드: 국방데이터표준, 상호운용성, 표준코드, 목록성코드, 코드값관리
형식: csv

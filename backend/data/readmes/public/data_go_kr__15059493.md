# 서울특별시 건설알림이 사업개요

해당 데이터는 서울특별시 건설알림이에서 제공하는 서울시(본청,사업소,자치구,투자출연기관) 공공발주 사업의 사업개요 OpenAPI입니다. 데이터의 원본 시스템은 서울특별시 도시기반시설본부 One-PMIS입니다. 요청인자 : 인증키, 요청파일타입, 서비스명, 요청시작위치, 요청종료위치 출력값 : 총 데이터 건수(정상조회 시 출력됨), 요청결과 코드, 요청결과 메시지, 순번, 사업코드, 사업명, 사업분류, 사업분류명칭, 착공일, 준공예정일, 도급액, 사업규모, 공사위치, 종료여부, 종료여부명칭, 발주처 업체명 등

제공기관: 서울특별시
분류: 국토관리
키워드: 건설, 시설, 공사, 사업규모, 준공, 공정률
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-07-07
이용허락: 제3자 권리 포함 : 저작권 표시, 공공저작물 : 출처표시 (제 1유형)

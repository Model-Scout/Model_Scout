# G마크 등록업체 현황

이 데이터는 경기도에서 품질을 인증한 우수 농특산물에 G마크를 부여받은 등록업체의 현황을 정리한 자료로, 각 업체의 명칭, 인증품목, 인증번호, 인증기간, 소재지 주소(지번 및 도로명), 위경도 좌표 등의 정보를 포함합니다. G마크는 경기도지사가 부여하는 품질 인증 마크로, 도내에서 생산되는 우수 농산물의 경쟁력을 높이기 위한 제도입니다. 해당 데이터는 G마크 인증을 받은 업체 및 품목의 지역 분포, 품질인증 지속기간, 주 인증 품목군 분석 등에 활용될 수 있으며, 도내 농산물 유통 관리, 지역 브랜드 홍보, 친환경 인증 정책 평가 등에 필요한 기초자료로 사용됩니다.

제공기관: 경기도
분류: 농축수산
키워드: G마크, 인증업체, 농특산물, 품질인증, 인증기간, 농수산진흥원
형식: api
선정 기준: 운영 자동승인 OpenAPI

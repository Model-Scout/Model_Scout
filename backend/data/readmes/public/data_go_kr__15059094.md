# 해양기상월보 조회서비스

기상통계자료(지상, 방재, 해양, 고층 등)를 월보 및 연보 형식으로 제공합니다. 월보에는 해양기상관측장비(해양기상부이, 등표기상관측장비, 파고부이)로 관측된 수온, 파고, 파주기, 파향, 수위 등 9개 요소에 대한 시간별자료와 일통계 및 월통계가 수록되었으며, 135°E 자오선 기준의 한국표준시(KST:Korean Standard Time)를기준으로 작성되었습니다. 해양기상관측장비로 관측된 수온, 파고, 파주기, 파향, 수위의 단위는 각각 '℃', 'm', 'sec', '16방위', 'm'이며 이외 자료의 단위는 지상 관측자료 단위와 같습니다.

제공기관: 기상청
분류: 과학기술
키워드: 통계, 월보, 해양, 파고부이, 등표
형식: api
선정 기준: 국가중점데이터 OpenAPI
수정일: 2025-09-17
이용허락: 제3자 권리 포함 : 저작권 표시, 공공저작물 : 출처표시 (제 1유형)

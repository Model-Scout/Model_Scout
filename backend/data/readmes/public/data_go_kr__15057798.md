# 무도학원업체 현황

이 데이터는 경기도 내에서 무도(댄스 등) 교육을 목적으로 운영되는 학원의 인허가 및 운영 현황을 제공하며, 총 31개 시군의 무도학원 데이터를 포함합니다. 주요 항목은 사업장명, 시군명, 인허가일자 및 취소일자, 영업상태, 소재지 주소(도로명/지번), 면적, 전화번호, 위치좌표(WGS84 위도·경도, X/Y좌표), 업태구분명, 세부업종명, 건축물 관련 정보(건축물 동수, 연면적), 지도자수, 회원모집 총인원, 공사립 구분, 보험 가입 여부, 법인명 등이 포함됩니다. 이 데이터는 지역별 문화체육 기반시설 분석, 민간 체육교육 시설 분포 파악, 체육정책 수립 및 안전관리 기준 마련 등의 용도로 활용될 수 있습니다. 특히 보험 가입 여부나 지도자 수 항목은 소비자 보호와 관련한 민감 정보로서 학원 안전성과 운영 신뢰도를 판단하는 데 중요한 역할을 합니다. 데이터는 Open API 형태로 제공되며, 다양한 민간 서비스 및 공공시스템에 연계하여 사용할 수 있습니다.

제공기관: 경기도
분류: 교육
키워드: 무도학원, 인허가정보, 사업장현황, 댄스스포츠, 지도자수, 보험가입여부, 위치정보, 문화체육업종
형식: api
선정 기준: 운영 자동승인 OpenAPI

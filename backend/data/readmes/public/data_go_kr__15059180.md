# 시‧도별 등록장애인 집계현황(장애유형별)

이 데이터는 전국 시도별 등록장애인을 장애유형별로 분류한 통계자료입니다. 매년 12월 말 기준으로 장애유형(지체, 뇌병변, 시각, 청각, 언어, 자폐성 등 총 15개 이상)에 따라 각 시도별 등록된 장애인 수를 제공합니다. 장애유형 분류는 장애인복지법에 따라 정의되며, 지체장애(사지의 변형·기능장애), 뇌병변장애(뇌손상에 따른 마비), 청각·언어·시각장애, 자폐성장애, 정신장애, 신장·심장·간장애 등 내부 장기 기능 장애도 포함됩니다. 본 데이터는 장애인 정책 수립, 의료·복지 자원 분배, 장애유형별 지원 수요 분석 등에 활용됩니다. 특히 복합장애 대응, 지역별 특화 서비스 개발에 유용합니다.

제공기관: 경기도
분류: 사회복지
키워드: 장애인수, 장애급수, 장애인인구, 장애유형, 지체장애, 뇌병변, 시각장애, 등록장애인
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-09-25
이용허락: 이용허락범위 제한 없음

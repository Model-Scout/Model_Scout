# 한양방병증매핑정보 서비스

1. 개요 한국전통지식포털에 구축된 한방 병증정보를 기반으로 한방 병증과 이에 대응하는 양방 병명 간의 연계·매핑 정보를 API(REST 방식)로 제공합니다. 또한 해당 병증과 관련된 문헌 근거, 치료에 활용되는 단일 약물 및 복합처방 등의 정보를 함께 제공하여 한·양방 질병정보 간 비교·연계 하실 수 있습니다. 2. 세부 정보 내용 ① 병증정보: 한방 병증에 대한 문헌 근거 및 관련 양방 병명 등에 대한 정보(XML) ② 해당 병증을 치료하는 단일 약물 및 복합처방에 대한 연계 정보(XML) 3. 데이터 출처 한국전통지식포털 홈페이지 http://www.koreantk.com/

제공기관: 지식재산처
분류: 과학기술
키워드: 전통지식, 한의학, 병증, 병명, 매핑, 질병, 약물, 처방정보
형식: api

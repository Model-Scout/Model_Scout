# 영화사정보 Open-API

영화사 DB는 영화관 입장권 통합전산망에서 사용되는 영화사 목록을 영화사명, 대표자명 등의 조건을 통해 조회하며, 업체 분류(영화업, 영화 관련 단체, 기타 분야 등)를 통해서 업체 관련 정보를 제공하고 있습니다. 영화 제작업, 영화 수입업, 영화 배급업, 영화 상영업 정보는 지자체를 통해서 영화업 신고 내역을 전달 받아 갱신 및 관리하고 있으므로 영화업 등록 및 변경 사항에 대한 미통보 등의 사유로 상시적인 수정과 보완이 있을 수 있습니다. 영화진흥위원회는 최신의 정확한 한국 영화 산업 정보를 제공하도록 노력하겠습니다.

제공기관: 영화진흥위원회
분류: 문화관광
키워드: 제작사, 후반작업업체, 배급사, 수입사, 상영관, 투자사, 홍보마케팅사, 필모그래피
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-06-27
이용허락: 이용허락범위 제한 없음

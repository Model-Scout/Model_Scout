# 한국부동산원_청약홈_청약 당첨 관련 통계

한국부동산원(구 한국감정원)의 청약홈에서 제공하는 지역별 청약 당첨자 수 현황, 연령별 청약 당첨자 수 현황, 가점제 당첨자의 점수 현황입니다. 청약홈에서 일반공급 접수를 대행한 일반분양 단지를 기준으로 작성되었습니다. 공공데이터 제공범위는 한국부동산원이 주택청약 업무를 수행한 2020년 2월부터 데이터 작성 기준 전월 말일까지로 모집공고일을 기준으로 집계하였습니다. * 통계별 컬럼별 상세설명 - 청약홈 > 청약일정 및 통계 > 분양/신청/당첨 현황 > 청약 당첨 관련 통계 > 해당 통계 명 선택 후 컬럼별 상세설명 참고하시기 바랍니다. ※ 매월 25일, 전월까지의 데이터를 제공하며 전월 데이터는 향후 변동될 수 있습니다. ※ "23.1월의 경우 가점제 당첨자가 발생하지 않아 데이터를 제공하지 않습니다.

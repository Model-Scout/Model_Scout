# 외교부_국가(지역)별 우리나라기관 진출현황

2020년 12월 31일 기준으로 해외에 진출한 우리나라 공공 및 민간 기관의 유형, 공공기관 코드 등의 정보를 제공합니다. (1회성 데이터로 업데이트 되지 않습니다.) 국가별로 국가명, 국가코드, 공공기관유형 , 공공기관명, 공공기관진출내용, 작성기준년도 등의 정보를 제공합니다. 제공되는 정보의 예시를 일부 안내해 드립니다. 1. 과테말라 GT 일반기관 100여개 업체 대부분 섬유, 봉제업체 2020 2. 나이지리아 NG 일반기관 24개사 도매 및 소매업, 건설공사업, 제조업 2020 추가 정보는 제공되는 파일 내용을 참고하여 주시기 바랍니다.

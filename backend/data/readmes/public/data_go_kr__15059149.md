# 법령 연혁 목록 조회

법제처에서 제공하는 법령 연혁 목록 조회 서비스 데이터입니다. 특정 법령에 대한 제정, 개정, 폐지 등의 이력을 연도별로 확인할 수 있으며, 각 연혁의 공포일자, 시행일자, 공포번호, 법령번호, 상태구분, 연혁구분 등의 항목을 포함하여 체계적으로 제공합니다. 이 데이터는 법령코드, 연혁구분, 공포일자, 시행일자 등의 검색 조건을 입력하여 관련 연혁 목록을 선택적으로 조회할 수 있도록 구성되어 있습니다. 조회 결과에는 총 건수, 페이지 수, 연혁 항목별 주요 정보가 포함되어 있으며, 사용자는 이를 기반으로 법령의 역사적 변천 경과를 파악할 수 있습니다. 본 데이터는 법령 이력 분석, 법제 업무 지원, 법률 시스템 개발 등에 활용이 가능하며, 모바일이나 웹 기반 서비스에서 연혁 기반 정보 제공 기능 구현을 위한 핵심 자료로 적합합니다.

제공기관: 법제처
분류: 공공행정
키워드: 국가법령정보현행법령연혁법령, 제정일자, 개정횟수, 시행상태, 법령종류, 공포번호, 연혁일지, 변천경과
형식: api
선정 기준: 국가중점데이터 OpenAPI

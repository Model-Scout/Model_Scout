# 국토교통부_(TAGO)_지하철정보_20131209

지하철역목록, 역별출구목록, 출구별버스노선목록, 역별시간표목록을 조회하는 지하철정보 서비스이며, 지하철 정보는 키워드 기반 지하철역 목록조회, 지하철 역 출구별 버스노선 목록, 지하철역 출구별 주변 시설 목록, 지하철 시간표 조회가 가능합니다. 사용방법은 키워드기반 지하철역 목록 조회 API를 통해 지하철역 ID를 조회후 해당 역에대한 지하철 역 출구별 버스노선 목록과 지하철역 출구별 주변 시설 목록, 각 지하철역별 시간표 목록을 조회할수 있습니다. 한번에 출력되는 데이터 목록수를 설정할수 있으며, 페이지 번호를 설정하여 전체 데이터를 분할하여 호출이 가능합니다. TAGO 연계현황및 기술자료는 http://www.tago.go.kr에서 확인이 가능합니다. 데이터 활용 추가 문의사항은 TAGO 운영팀(054-459-7870)으로 문의 바랍니다.

# 국가보훈부_이달의 독립운동가 영상 및 포스터 자료

국가보훈부에서 매월 선정하는 「이달의 독립운동(가)」 에 대한 명칭과 영상 자료 및 포스터 이미지의 링크 주소 데이터로, 2021년 1월부터 당월까지의 정보를 담고 있습니다. 데이터파일의 링크 주소를 통해 국가보훈부 대표홈페이지에 업로드 된 영상자료와 포스터 이미지를 다운로드할 수 있습니다. "25년에는 특정 인물이 아닌 "이달의 독립운동" 정보로 업데이트 되었습니다. ㅇ 제공 항목 : 기준년월, 이달의 독립운동가, 영상자료 링크주소, 포스터 링크주소 ㅇ 데이터 변경사항 - 누적 데이터 제공인 점을 고려하여 "24년 5월부터 기존 데이터 파일 추가 등록이 아닌 변경 등록 방식으로 업데이트 방식이 변경되었습니다.

# 부산항만공사_부산항 연도별 물동량 추이

부산항에서 처리되는 화물의 연도별 물동량 통계 데이터를 제공합니다. - 외항 소계, 외항 입항, 외항 출항, 외항 입항 환적, 외항 출항 환적, 내항연안화물 - 단위 : 톤 부산항만공사가 제공하는 본 데이터는 1993년부터 2014년까지 연도별로 집계된 부산항의 총 물동량 정보를 담고 있으며, 항구분(북항, 감천), 단위별(톤), 외항 소계, 내항연안화물 등을 포함합니다. 이 데이터는 항만 물류 흐름 분석, 화물 처리 효율성 평가 등에 유용하게 활용될 수 있으며, 항만산업 분석, 해양물류계획, 관련 민간기업의 시장 전략 수립 등 다방면에 실용적인 공공데이터입니다. 또한 시간에 따른 변화 추이를 시계열로 분석할 수 있어, 미래 물동량 예측 모델 개발이나 항만시설 투자 타당성 검토에도 활용될 수 있습니다.

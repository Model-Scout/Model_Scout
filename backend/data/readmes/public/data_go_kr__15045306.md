# 인천광역시_소방시설업 업체현황

인천광역시 소방본부 예방안전과는 인천 내 소방시설 공사업, 감리업, 설계업, 방염업체 등의 현황을 담은 데이터를 제공하고 있습니다. CSV 파일 형태로 로그인 없이 내려받을 수 있으며, API 서버(JSON/XML) 형식도 OpenAPI로 제공되어 보다 편리한 접근이 가능합니다. 연 1회 최신화되며, 2025년 8월 기준 파일은 관내 소방시설업체 정보를 포함합니다. 항목으로는 지역, 업체명, 대표자, 주소, 업종, 전문/일반 분야, 등록일자 등이 포함되어 있으며, 향후 데이터는 2026년 8월 중 업데이트 예정입니다. 소방시설 공사 전 업체 확인을 위한 필수 자료로 활용됩니다.

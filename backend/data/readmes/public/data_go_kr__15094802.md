# 금융위원회_파생상품시세정보_20211116

파생상품시세정보는 한국거래소에서 제공하는 파생상품 시장의 시세 데이터를 시계열 형태로 제공하는 데이터입니다. 해당 데이터는 선물 및 옵션 상품의 시장별 시세 정보를 포함하고 있습니다. 이 데이터는 2개 오퍼레이션으로 구성되어 있습니다. 각 오퍼레이션은 다음과 같습니다. ① 선물시세 : 파생상품시장에 상장된 선물 상품의 시세 정보를 제공 ② 옵션시세 : 파생상품시장에 상장된 옵션 상품의 시세 정보를 제공 ※ 선물이란?: 선물은 특정 기초자산을 미래 일정한 시점에 미리 정해진 가격으로 사고팔 것을 계약하는 상품 ※ 옵션이란?: 미래 특정한 날짜에 특정한 기초자산을 사전에 정해진 가격으로 사거나 팔 수 있는 권리 ※ 데이터 갱신주기는 일 1회입니다. ※ 금융위원회의 모든 API는 데이터 보유기관으로부터 데이터를 연계받아 수집 후 개방하고 있습니다. 금융위원회에서 제공하는 모든 서비스는 실시간이 아니며, 데이터 갱신은 기준일자로부터 영업일 하루 뒤 오후 1시 이후에 업데이트됩니다. 예를 들어, 금요일 데이터는 차주 월요일에 제공됩니다.

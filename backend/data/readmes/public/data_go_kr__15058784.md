# 급식 실시 현황

이 데이터는 경기도 내 학교들의 급식 실시 현황을 수록한 자료로, 학교급별·설립구분별로 급식 운영 방식과 참여 현황을 보여줍니다. 주요 항목에는 기준년도, 시군명, 지역교육청명, 학교명, 설립구분, 급식종류, 급식학생 수와 전체 학생 수 대비 급식비율(%)이 포함됩니다. 또한 급식 인력인 영양교사, 조리사, 조리원 수가 제공됩니다. 일부 학교는 일부 위탁 또는 전체 위탁업체명을 함께 제공하여 급식 운영 형태의 차이를 확인할 수 있습니다. 이 데이터는 학교급식 운영 현황 분석, 영양 인력 배치 적정성 검토, 급식 참여율 평가, 직영·위탁 급식의 운영 차이 비교, 지역별 학교급식 환경 분석 등 다양한 교육·보건 정책 수립의 기초자료로 활용될 수 있습니다.

제공기관: 경기도
분류: 교육
키워드: 학교급식, 급식종류, 직영급식, 위탁급식, 급식참여, 영양교사
형식: api
선정 기준: 운영 자동승인 OpenAPI

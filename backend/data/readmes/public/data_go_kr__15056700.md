# 병원평가정보(질병-급성심근경색증) 현황

급성심근경색증 병원평가정보는 경기도 내 병원에서 급성심근경색증 환자를 대상으로 입원치료를 실시한 의료기관의 평가결과를 담은 데이터입니다. 건강보험심사평가원이 제공하며, 평가결과는 치료성과를 반영하여 1등급(우수)부터 5등급까지로 나뉘며, 평가대상 건수가 일정 기준에 미달하는 경우는 등급 제외로 처리됩니다. 데이터 항목은 기관명, 평가내역, 평가등급, 시군명 및 코드, 도로명주소, 지번주소, 우편번호, 위도·경도 등을 포함하고 있으며, 의료기관 비교분석, 지역별 의료질 파악, 의료서비스 개선 등에 활용할 수 있습니다. 본 정보는 연 1회 갱신됩니다.

제공기관: 경기도
분류: 보건의료

형식: api

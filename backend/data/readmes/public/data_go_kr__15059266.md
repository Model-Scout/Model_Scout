# 용기냉동기특정설비 현황

이 데이터는 경기도 내 용기·냉동기와 같은 특정설비를 제조하거나 수리하는 업체의 인허가 현황을 나타내며, 총 24개 항목으로 구성되어 있습니다. 시군명, 사업장명, 인허가일자, 영업상태, 주소정보(WGS84 위도·경도 포함), 면적, 설비규격, 업태구분, 전화번호 등의 정보를 포함합니다. 이 데이터는 기계공업 및 냉각설비 산업 분야의 현황을 분석하거나 설비 등록 현황을 파악하는 데 활용할 수 있으며, 지역별 엔지니어링 수요 분석, 산업 안전관리 계획 수립 등 다양한 분야에 기초자료로 제공됩니다. Open API 형태로 제공되며, 지방행정데이터개방시스템에서 관리됩니다.

제공기관: 경기도
분류: 식품건강
키워드: 용기냉동기, 특정설비, 인허가현황, 설비규격, 사업장정보, 영업상태, 위치정보, 기계공업
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-07-21
이용허락: 이용허락범위 제한 없음

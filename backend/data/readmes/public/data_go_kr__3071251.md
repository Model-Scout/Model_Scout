# 한국고용정보원_워크넷 강소기업 검색_20210518

이 API는 기업 소재 지역 등을 조건으로 하여 강소기업 정보를 조회할 수 있도록 지원합니다. 강소기업 API를 이용하여 '규모는 작지만 강한 경쟁력을 가진 우수기업(고용유지율과 신용평가 등급이 높고 사업장에 산재 사고율이 낮은 규모는 작지만 강한 경쟁력을 가진 우수한 중소기업)' 목록을 활용 하실 수 있습니다. 강소기업의 유형은 6개로 일자리 친화, 글로벌역량, 기술력우수, 지역선도기업, 재무건전성, 사회적가치로 나뉩니다. 기업소재지역 등을 파라미터로 받아, 선정연도 또는 등록연도, 강소기업 브랜드명 (※ 공통코드 API에서 확인한 코드값을 사용), 기업명, 사업자등록번호, 대표자, 업종코드(상위), 업종명(상위), 업종코드(중위), 업종명(중위), 사업장 연락처, 지역코드, 지역명, 주소, 주요 생산품목, 회사 홈페이지, 상시 근로자 수, 강소기업 브랜드명 코드와 같은 정보를 결과로 제공합니다.

제공기관: 한국고용정보원
분류: 산업고용
키워드: 중소기업, 중견기업, 기업정보, 강소기업, 고용유지, 지역선도기업, 기업소재
형식: api
선정 기준: 국가중점데이터 OpenAPI
수정일: 2025-07-18
이용허락: 제3자 권리 포함 : 저작권 표시, 비영리, 변경금지, 공공저작물 : 출처표시, 상업적 이용금지, 변경금지 (제 4유형)

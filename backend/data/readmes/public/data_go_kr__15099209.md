# 한국국제협력단_현지 활동정보_20220225

KOICA의 ODA 개발협력사업과 관련된 현지 활동 정보를 제공하는 API입니다. 각국 현장에서 수행되는 사업의 세부 운영 현황, 참여 인력, 활동 지역 등에 대한 정보를 포함하고 있어, 실시간 또는 주기적 현장 데이터를 분석하거나, 성과 모니터링 체계를 구축하는 데 유용합니다. 현장 기반의 실천형 국제개발협력 데이터로서, 정책 설계, 지역 맞춤형 지원 전략, 위험관리에도 활용됩니다. 이 API는 인증키(serviceKey), 페이지 번호(pageNo), 한 페이지 결과 수(numOfRows) 등 기본적인 요청변수를 사용하며 한글 국가명, ISO 2자리코드, 구분, 연도 등의 필터 파라미터를 추가로 설정할 수 있습니다. 출력결과에는 한글 국가명, 영문 국가명, ISO 2자리코드, 연도, 구분, 내용 등의 항목이 포함되며, 각 항목에 대한 데이터는 JSON 형식으로 반환됩니다.

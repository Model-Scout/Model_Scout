# 산재보험 장애급여 종류별 수급 집계현황

이 데이터는 산재보험에 따른 장애급여 수급 현황을 연도별·지사별로 집계한 자료입니다. 주요 항목에는 기준년도, 지사명, 전체 수급자수, 전체 지급 금액(백만원), 연금 수급자수와 연금 지급액, 일시금 수급자수와 일시금 지급액이 포함되어 있습니다. 이를 통해 각 지사별 산재보험 장애급여 지급 규모와 수급 형태(연금·일시금)를 확인할 수 있으며, 연도별 추이를 분석하여 제도의 효과성을 검토할 수 있습니다. 해당 데이터는 지역별 산재보상 정책 평가, 장애급여 재정 관리, 사회보험 운영 효율성 분석 등에 활용될 수 있으며, 특히 연금과 일시금 지급 방식의 비중 차이를 통해 제도적 개선 방향을 도출하는 근거로 활용될 수 있습니다.

제공기관: 경기도
분류: 산업고용
키워드: 산재보험, 장애급여, 연금수급, 일시금, 보상정책, 사회보험
형식: api
선정 기준: 운영 자동승인 OpenAPI

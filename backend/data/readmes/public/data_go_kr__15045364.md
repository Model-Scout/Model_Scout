# 제주특별자치도_재활용도움센터현황

제주특별자치도에서 운영하는 재활용 도움센터와 관련한 데이터를 제공합니다. 항목: 읍면동, 주소, 시작시간, 종료시간, 배출정보 (폐가전 / 종이팩 / 빈병) 등 *클린하우스 쓰레기 배출체계의 문제점을 보완하여, 시민들이 요일과 시간에 구애받지 않고 재활용품을 편리하게 배출할 수 있도록 마련된 건축물 형태의 공간으로 클린하우스에 배출이 어려운 유해폐기물(폐농약, 폐의약품 등)과 폐식용유, 폐옷걸이 등 다양한 품목의 수거가 가능함 자세한 사항은 제주도청 홈페이지에서 확인하시기 바랍니다. https://www.jeju.go.kr/nature/environment/recycle.htm

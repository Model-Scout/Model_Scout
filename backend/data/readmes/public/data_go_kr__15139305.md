# 서울올림픽기념국민체육진흥공단_경주사업총괄본부 경정-선수별 정상출발 현황 정보_20241118

경주연도, 선수명, 선수번호 등을 이용해 서울올림픽기념국민체육진흥공단에서 시행하는 경정경주의 선수별 정상출발 현황 정보 조회를 제공하는 서비스입니다. 경정경주는 플라잉스타트, 온라인스타트 2가지 출발방식이 있습니다. 플라잉스타트는 경정만의 독특한 출발방식인 플라잉스타트는 6척의 모터보트가 전속력으로 대시계가 0초(12시방향)에서 1.0초를 가리키는 사이에 물위에 그려진 가상의 출발선을 통과합니다. 좀더 0초에 가까운 출발을 한 선수가 경주의 주도권을 쥡니다. 경정에 대한 자세한 소개는 경정홈페이지(www.kboat.or.kr)을 참고하세요.

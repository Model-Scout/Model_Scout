# 경상남도 진주시_인구통계정보

2021년부터 2025년까지 진주시의 읍면동별 인구통계 자료에는 세대수, 내국인 및 외국인 인구수(남녀별), 등록기준일자 등의 항목이 포함되어 있습니다. 이 데이터는 CSV, JSON, XML 형식으로 제공되며, 연간 단위로 갱신됩니다. 2025년 12월 기준 진주시 전체 인구(등록외국인 포함)는 342,753명이며, 이 중 외국인은 6,814입니다. " 읍면동별로는 가호동이 36,363명으로 가장 많고, 대평면은 934명으로 가장 적습니다. 해당 자료는 진주시 스마트도시과에서 관리하며, 공공데이터포털에서 무료로 다운로드할 수 있습니다 .

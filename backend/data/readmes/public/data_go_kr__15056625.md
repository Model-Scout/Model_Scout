# 수질 기본배출 부과금 현황

이 데이터는 경기도 내 수질오염물질을 배출하는 사업장을 대상으로 부과되는 기본 배출부과금의 납부 현황을 정리한 자료로, 수질오염 유발자에게 오염원인자 부담원칙에 따라 비용을 부과하는 제도에 기반합니다. 주요 항목은 집계년도, 시군명, 사업장명, 반기구분(상반기·하반기), 부과금액(원) 등으로 구성되어 있으며, 사업장 단위로 부과 내역을 제공합니다. 이 자료는 지역별 오염원 분포 분석, 고오염 사업장 관리, 환경부담금 제도 개선 및 수질환경 정책 수립의 기초자료로 활용될 수 있는 데이터 입니다.

제공기관: 경기도
분류: 환경기상
키워드: 수질오염, 배출부과금, 오염원인, 환경부과금, 오염물질배출, 배출부과금사업장
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-09-25
이용허락: 이용허락범위 제한 없음

# 일반음식점(복어취급) 현황

이 데이터는 경기도 내 복어를 전문적으로 조리할 수 있는 기술자가 상주하는 일반음식점의 인허가 및 영업 현황을 기록한 자료입니다. 총 31개 시군을 대상으로 하며, 각 음식점의 시군명, 인허가일자, 영업상태, 위생업종 및 위생업태명, 종업원수(남성·여성·총계), 급수시설, 다중이용업소 여부, 소재지 주소(도로명·지번), 위도·경도 등의 정보를 포함합니다. 음식점의 규모나 주변 환경 구분, 폐업일자 및 시설면적 등의 세부 항목도 제공되어, 음식점 운영 현황 분석, 식품안전 관리, 상권 분석, 정책 수립 자료로 활용될 수 있습니다. 본 데이터는 지방행정 데이터 개방시스템을 통해 주간 단위로 갱신되며, 상업적 이용 및 콘텐츠 변경이 허용됩니다.

제공기관: 경기도
분류: 식품건강
키워드: 복어취급, 일반음식점, 인허가정보, 위생업종, 다중이용업소, 영업상태, 종업원수, 도로명주소
형식: api
선정 기준: 운영 자동승인 OpenAPI

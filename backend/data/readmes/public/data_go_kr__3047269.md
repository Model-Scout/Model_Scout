# 단지별 입주대기일수 조회 서비스

전북개발공사의 응용데이터(단지별 입주대기일수 조회 서비스)는 전북개발공사가 관리하는 임대아파트 및 임대단지를 대상으로 현재 시점의 공가 수, 대기자 수, 최근 3년간 청약 후 실제 입주까지 소요된 평균 대기일수를 제공하는 서비스입니다. 이를 통해 단지별 수요 현황과 공급 여건을 종합적으로 파악할 수 있으며 주거 수급의 불균형 해소, 공가 최소화 전략 수립 등 다양한 공공 주거정책·연구 분야에 활용될 수 있습니다. 또한 실시간 기반으로 임대단지별 데이터를 제공하여 청약 신청자 및 일반 시민에게 임대주택 수급 상황을 이해하는 데 유용한 정보를 제공합니다.

제공기관: 전북개발공사
분류: 국토관리
키워드: 택지분양, 주거복지, 임대아파트, 임대단지, 대기차수, 공가현황
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-11-24
이용허락: 이용허락범위 제한 없음

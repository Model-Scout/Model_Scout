# 국민건강보험공단_지역별 항생제사용량

본 데이터는 연도별 질병에 따른 항생제 종류별 사용량을 산출한 자료입니다. 대상은 해당 연도 기준 국민건강보험 가입자 또는 의료급여 수급권자입니다. ○ 지표 산출 방식 - 지표값: 1일 사용량/1,000명 (단위:DDD/1000명/일) - 분자: 해당 연도 항생제 전체 처방 용량 X 1,000명 - 분모: 국민건강보험 가입자 또는 의료급여 수급권자 수 X 365일 ※ (해석) 항생제사용량 25.68(DDD/1,000명/일)일 경우, 인구 1,000명 중 하루 평균 25.68명이 항생제를 사용한다는 의미로 해석할 수 있음 ※ DDD는 성인 기준 표준 복용량을 의미하며, 항생제 사용량 비교에 활용됨.

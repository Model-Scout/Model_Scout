# 한국출판문화산업진흥원_채용정보

한국출판문화산업진흥원이 제공하는 채용정보 API 입니다. 조회 시작일과 조회 종료일을 GET파라미터에 입력하여 데이터를 XML 형식으로 출력할 수 있습니다. [변수설명] startdt 조회 시작일 ex) YYYY-MM-DD형식 enddt 조회 종료일 ex) YYYY-MM-DD형식

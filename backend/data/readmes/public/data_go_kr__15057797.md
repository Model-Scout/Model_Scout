# 일반음식점(출장조리) 현황

이 데이터는 경기도 내 출장 조리를 전문으로 하는 일반음식점에 대한 인허가 및 영업 현황 정보를 포함하고 있습니다. 출장조리란 고객이 요청한 장소로 음식을 운반하고 현장에서 조리하여 제공하는 형태의 영업을 의미하며, 해당 데이터에는 사업장명, 인허가일자, 폐업일자, 영업상태, 소재지주소, 총시설규모, 급수시설구분, 위생업종명, 위생업태명, 종업원 수, 위치좌표(WGS84 위도·경도) 등의 항목이 포함되어 있습니다. 해당 데이터는 외식업 시장 분석, 출장요리 수요 예측, 공공 위생 및 식품안전 정책 수립에 활용될 수 있습니다. 데이터는 경기도 31개 시군의 내용을 포함하며, Open API를 통해 실시간 정보 접근도 가능합니다.

제공기관: 경기도
분류: 식품건강
키워드: 출장조리음식점, 일반음식점, 인허가정보, 위생업종, 소재지정보, 종업원수, 다중이용업소, 급수시설구분
형식: api
선정 기준: 운영 자동승인 OpenAPI

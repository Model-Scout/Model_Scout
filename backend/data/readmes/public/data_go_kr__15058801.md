# 청소년 복지상담 센터 현황

이 데이터는 경기도 내 청소년의 정서적 안정과 복지 지원을 위해 설치된 청소년상담복지센터의 운영 현황을 수록한 자료입니다. 각 센터의 시군명, 운영단체명, 전화번호, 팩스번호, 홈페이지 주소, 소재지 주소(도로명 및 지번), 우편번호, 위도·경도 정보가 포함됩니다. 청소년상담복지센터는 심리상담, 위기개입, 정서지원, 복지연계 등 다양한 기능을 수행하는 기관으로, 위기 청소년의 사회 복귀와 정서적 회복을 돕습니다. 본 데이터는 정책 수립, 센터 접근성 분석, 청소년 복지 자원 분포 파악 등에 활용될 수 있으며, 연 1회 갱신되며 상업적 활용과 콘텐츠 변경이 가능합니다.

제공기관: 경기도
분류: 사회복지
키워드: 청소년, 상담복지센터, 운영단체, 복지상담, 도로명주소, 전화번호, 위도경도, 홈페이지주소
형식: api
선정 기준: 운영 자동승인 OpenAPI

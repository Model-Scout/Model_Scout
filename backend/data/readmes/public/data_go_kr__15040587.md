# 선거공약 정보 조회 서비스

선거공약 정보는 후보자의 선거공약, 당선인 공약 정보를 제공합니다. (선거 ID, 선거종류코드, 후보자 ID를 입력하여 후보자의 공약 정보를 조회할 수 있는 서비스) ※ 확인사항 · 선거 종료 이전에는 후보자 공약 정보가 제공되며 종료된 선거의 경우 당선인 공약만 제공됩니다. · 선거종류코드 및 후보자에 따라 공약 개수가 상이할 수 있습니다. · 선거공약서 제출 대상 선거종류코드(SgTypecode): 1 대통령선거 3 시·도지사선거 4 구·시·군의장선거 11 교육감선거 (이외 선거종류코드는 공약서를 제출하지 않습니다.)

제공기관: 중앙선거관리위원회
분류: 공공행정
키워드: 선거공약, 후보자공약, 당선인공약, 정책공약, 대통령공약, 시도지사공약, 구시군의장공약, 교육감공약
형식: api
선정 기준: 국가중점데이터 OpenAPI

# 한국국제협력단_현지 안전정보_20220225

KOICA 해외 파견 대상국의 안전정보를 제공하는 API입니다. 치안상황, 정세 불안, 자연재해, 감염병 등 위험요소를 종합하여 업데이트하며, 파견 전후의 안전교육, 대응 매뉴얼 수립, 위기관리 시스템 운영에 활용됩니다. 해당 API는 인증키(serviceKey), 페이지 번호(pageNo), 한 페이지 결과 수(numOfRows) 등 기본적인 요청변수를 사용하며 한글 국가명, ISO 2자리코드, 구분, 연도 등의 필터 파라미터를 추가로 설정할 수 있습니다. 출력결과에는 한글 국가명, 영문 국가명, ISO 2자리코드, 연도, 구분, 내용 등의 항목이 포함되며, 각 항목에 대한 데이터는 XML 형식과 JSON 형식으로 반환됩니다.

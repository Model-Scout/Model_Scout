# 국방부_육군 장병 확인

육군 장병 확인을 위한 API 데이터입니다. 육군 현역, 예비역 정보를 활용하여 장병에 대한 인증을 참과 거짓으로 인증 확인해 주는 API 서비스로 육군 장병에 대한 인증을 통해 다양한 서비스를 구현할 수 있습니다. 해당 API 데이터는 군의 기본 신원 관리 수단으로, 현역과 예비역의 신분을 무단 도용하고, 무단 사용하는 것을 사전에 방지하는 것이 가능합니다. 또한, 신분 확인 단계부터 디지털 행정 시스템을 도입하여 디지털화를 이루고, 추후 국방 정책 수립 및 개선에 대한 기초 자료로써 활용할 수 있습니다.

제공기관: 국방부
분류: 통일외교안보
키워드: 육군, 장병, 확인, 장병확인, 예비역
형식: json+xml
선정 기준: 중앙·광역 기관 파일데이터
수정일: 2025-07-09
이용허락: unknown

# 교육부_교과서연구재단  교과서 정보 API

한국교과서연구재단과 공공도서관, 국립중앙도서관의 소장정보를 활용하여 다양한 애플리케이션 개발을 쉽게 할 수 있도록 교과서 정보 API를 제공하는 내용을 담고 있다. 이 API를 통해 여러 도서관의 교과서 정보를 연동하여 활용할 수 있으나, 해당 기관의 정책에 따라 트래픽 수에 차이가 발생할 수 있음을 안내한다. (제공데이터) 한국교과서연구재단 소장정보, 국립중앙도서관 소장정보, 공공도서관 종합목록 등 API제공

분류: 교육

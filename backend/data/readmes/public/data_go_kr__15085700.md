# 한국산업은행_자동화기기수수료 정보_20210806

한국산업은행 카드로 자동화기기를 이용(입금/출금/조회)하거나 타행 카드로 한국산업은행의 자동화기기를 이용 시 수수료 현황을 제공합니다. 일자별 조회가 가능합니다. (2021. 7.30자 이후 데이터 제공). 자동화기기 수수료는 한국산업은행의 자동화기기에서 업무를 처리하는지 또는 다른 금융기관의 자동화기기에서 업무를 처리하느냐에 따라 달라집니다. 일반적으로 자동화기기에서 처리할 수 있는 업무는 입금/출금/조회, 당행간 이체, 타행 이체며 처리하는 업무 종류에 따라 수수료가 달라집니다. 또한 타행으로 이체하는 경우 10만원 이하인지 또는 10만원 초과인지 여부에 따라서도 수수료가 달라지게 됩니다. 수수료 면제 대상에 해당하는 경우 또는 수수료 감면 정책의 대상이 될 경우 수수료가 면제되거나 감면될 수 있으니 참고하시기 바랍니다.

# 병무청_카투사 지원 및 선발 현황

해당 데이터는 병무청에서 제공하는 자료입니다. 해당 자료는 병무청에서 연간 지원하는 카투사 지원 현황에 대한 데이터로, 현재 자료는 2025년 12월 기준(2026년 카투사 입영 예정자)에 대한 자료로 카투사 2026년 월별 계획인원(1월~12월, 5월 모집없음), 접수인원(1월~12월, 5월 모집없음), 선발인원(1월~12월, 5월 모집없음) 현황을 제공하는 자료입니다. 계획, 접수, 선발인원에 대하여는 포함하고 있지만 2026년 입영 현황에 대해서는 현재 진행형이기 때문에 지원 현황에 대하여 기술하고 있습니다.

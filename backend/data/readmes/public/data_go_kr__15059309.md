# 모바일 법령 별표,서식 목록 조회

법제처가 제공하는 모바일 법령 별표 및 서식 목록 조회 데이터는 각 법령에 첨부된 별표와 서식 파일의 기본 정보를 체계적으로 제공합니다. 해당 데이터는 법령ID, 법령번호, 별표·서식 제목, 파일 고유번호, 파일 URL, 게시일자, 첨부파일 형식 등 주요 속성을 포함합니다. 사용자는 법령번호, 법령ID, 파일 제목, 페이지 및 조회 건수 옵션을 통해 원하는 별표나 서식을 맞춤형으로 조회할 수 있습니다. 법령 체계 내 문서별 상세 구조 및 첨부파일 현황을 분석하고 관리하기에 적합하며 별표와 서식을 문서 단위로 분리하여 관련 정보를 연계 확인할 수 있어 행정업무 지원 및 정책문서의 정확한 활용에 유용합니다.

제공기관: 법제처
분류: 공공행정
키워드: 앱법령행정규칙, 게시일자, 첨부파일형식, 법령번호, 제목, 별표, 서식, 파일URL
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-07-09
이용허락: 이용허락범위 제한 없음

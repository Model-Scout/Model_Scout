# 구비서류목록조회서비스

모집병 지원 시 구비서류 목록을 확인할 수 있는 서비스입니다. 군별(육군, 해군, 공군, 해병대), 모집분야별(기술행정병, 일반/전문기술병 등), 모집특기별로 정보가 구분되어 있습니다. 예) 기술행정병 00특기 제출서류: 자격면허증 사본, 생활기록부 사본, 군사특기 관련 경력증명서, 국가유공자증명서, 헌혈 및 사회봉사활동 증명서 등 응시지방병무청에서 필요 시 지원자에게 제출해야 하는 서류, 제출 방법, 제출 기한 등을 개별 안내하며, 병무청 누리집- 군지원(입영신청)안내- 지원서 작성/수정/취소- 서류제출 메뉴에서 파일 등록할 수 있습니다.

제공기관: 병무청
분류: 통일외교안보
키워드: 군지원, 지원, 모집, 모집병, 모병, 서류, 구비서류, 제출서류
형식: api
선정 기준: 운영 자동승인 OpenAPI

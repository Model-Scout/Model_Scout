# 지식재산처_KIPRISPlus_상표 행정처리 이력_REST API_20220722

1. 개요 공개된 상표의 출원단계, 심판단계, 등록단계에서 발생되는 문서정보와 행정처리 이력 정보를 제공합니다. 상표의 출원심사이력, 등록사항이력, 심판이력 등 행정처리 통합이력 국·영문 정보를 API(REST방식) 및 대용량(BULK)으로 제공합니다. 2. 세부 정보 내용 출원번호, 문서번호, 단계(출원/심판/등록), 처리상태, 문서의 명칭 등의 정보를 XML 형태로 제공합니다. 출원번호, 접수발송번호, 접수발송일자, 접수발송서류명(국문, 영문), 처리상태(국문, 영문), 심판번호 ,등록번호 등 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

형식: api

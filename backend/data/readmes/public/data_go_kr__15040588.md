# 정당정책 정보 조회 서비스

정당정책 정보는 후보자측 정당의 정책정보를 제공합니다. (선거 ID와 정당명을 입력하여 해당 정당의 정책 정보를 조회할 수 있는 서비스) ※ 확인사항 · 정당에 따라 정책(공약) 개수가 상이할 수 있습니다. · 정당정책 정보는 후보자 등록 신청이 마감되고 후보자 기호가 확정된 이후, 문서 변환(OCR) 작업 및 검토 절차를 거쳐 공개됩니다.

제공기관: 중앙선거관리위원회
분류: 공공행정
키워드: 정당정책, 정책공약, 후보자공약, 후보자정책, 선거공약, 선거정책, 정당공약, 10대공약
형식: api
선정 기준: 국가중점데이터 OpenAPI

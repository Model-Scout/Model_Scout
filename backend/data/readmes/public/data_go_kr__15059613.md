# 금융위원회_크라우드펀딩정보_20200424

크라우드펀딩정보는 온라인소액투자중개업자를 통해 자금을 조달한 크라우드펀딩 발행사의 정보를 제공하는 데이터입니다. 발행사명, 대표자명, 발행금액, 발행일자, 증권종류, 증권수량, 발행사 업종, 소재지 등의 정보가 포함됩니다. 이 데이터는 1개 오퍼레이션으로 구성되어 있습니다. 오퍼레이션은 다음과 같습니다. ① 크라우드펀딩 발행사정보 조회 : 발행사의 기본 정보, 자금조달 내역, 증권 발행 현황을 조회합니다. ※ 크라우드펀딩이란? 군중 또는 다수를 의미하는 영어단어 크라우드(Crowd)와 자금조달을 뜻하는 펀딩(Funding)을 조합한 용어 ** 유의사항 본 개방데이터는 공공누리 2유형임을 참고하시기 바랍니다. 이용허락범위 제2유형 : 출처표시 + 상업적 이용금지 해당 데이터를 상업적으로 활용하고자 하는 이용자는 데이터 원천 소유자인 한국예탁결제원과 사용 목적과 범위에 따른 정보이용계약이 필요합니다. 정보이용계약 또는 해당 정보에 관하여 궁금한 점이 있으시면 한국예탁결제원 증권정보부(연락처: portal@ksd.or.kr)로 이메일 문의 주시기 바랍니다.

# 병원평가정보(질병-고혈압) 현황

고혈압 병원평가정보는 건강보험심사평가원이 제공하는 자료로, 경기도 내 의료기관에서 고혈압 환자의 진료 및 관리에 대한 평가결과를 담고 있습니다. 특히 관상동맥우회술을 수행하는 의료기관에 대한 평가가 중심이며, 평가 결과는 양호한 성과를 보인 기관만 공개됩니다. 데이터는 시군명 및 코드, 의료기관명, 평가내역, 평가등급, 도로명주소, 지번주소, 우편번호, 위도·경도 등으로 구성되어 있으며, 환자들의 의료기관 선택, 고혈압 치료 질 관리, 지역별 의료서비스 수준 분석 등에 활용될 수 있습니다. 데이터는 연 1회 갱신됩니다.

제공기관: 경기도
분류: 보건의료
키워드: 병원평가정보, 고혈압, 관상동맥우회술, 치료평가, 의료기관, 건강보험심사평가원, 의료질, 주소정보
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-06-25
이용허락: 이용허락범위 제한 없음

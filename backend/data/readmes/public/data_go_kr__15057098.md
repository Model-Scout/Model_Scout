# 비영리법인(환경분야) 현황

경기도 내 비영리법인 환경분야 현황으로, 학술 종교 자선 기예 등 영리를 목적으로 하지 않는 단체의 기본 정보를 통합 제공합니다. 제공 항목은 시군명과 시군코드로 지역을 식별하고, 법인단체명과 지역구분명으로 조직의 정체성을 확인하며, 사업목적으로 추진 분야와 활동 범위를 파악할 수 있도록 구성되어 있습니다. 주소는 소재지도로명주소와 소재지지번주소, 소재지우편번호를 함께 제공해 우편·내비게이션·법정주소 기반 검색 모두에 활용할 수 있고, WGS84위도와 WGS84경도를 포함해 지도 시각화, 공간분석, 인근시설 매칭이 가능합니다. 데이터는 경기도 기후환경정책과가 수시로 갱신하며, 행정정보를 기반으로 한 인허가 및 변경 현황을 반영합니다. 활용 예시는 환경단체 분포 지도 제작, 시군별 비영리 네트워크 분석, 공모사업 대상 지역 발굴, 환경교육 협력기관 리스트업, 재난·환경이슈 발생 시 협업 거점 파악 등이 있으며, 주소 표기 차이나 좌표 오차가 있을 수 있어 대량 매칭 시 전처리와 검증 절차가 권장됩니다. 또한 동일 법인의 명칭 변경이나 소재지 이전 이력이 존재할 수 있으므로 시점 비교 분석 시 기준일자와 갱신일자를 함께 확인하는 것이 바람직합니다.

제공기관: 경기도
분류: 공공행정
키워드: 환경법인, 환경협회, 비영리법인, 환경분야, 환경연합, 환경본부, 야생동물, 환경시민연합
형식: api
선정 기준: 운영 자동승인 OpenAPI

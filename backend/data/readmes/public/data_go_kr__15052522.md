# 한국농어촌공사_임대수탁 계약현황

- 농지임대수탁사업은 농지 소유자가 직접 농사짓기 어려운 농지를 한국농어촌공사에서 위탁받아 적합한 농업인을 찾아 임대하고 관리하는 사업입니다. - 상속, 증여 등으로 소유하고 있지만 직접 농사짓기 어려운분이나, 농지를 임대하고 싶으나 임차자를 직접 구하기 힘드신 분, 영농을 은퇴하고자 하는 분이 이용할 수 있습니다. - 본 개방데이터는 이러한 임대수탁사업의 계약 현황으로, 임대수탁-임대, 임대수탁-사용대 사업별, 지역별 계약건수, 면적(헥타르ha)의 년도별 통계 자료를 제공하고 있습니다. - 자세한 내용은 농지은행 통합포털에서 확인하실 수 있습니다.

제공기관: 한국농어촌공사
분류: 농축수산
키워드: 농지은행, 농업, 농지이용, 위탁, 임차, 임대
형식: csv

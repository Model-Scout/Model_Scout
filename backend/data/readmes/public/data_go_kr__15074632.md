# 과학기술정보통신부_보도자료_20201214

과학기술정보통신부에서 제공하는 보도자료 조회 API 서비스입니다. 정부의 주요 정책과 성과, 과학기술 분야의 혁신적인 발전사항을 공식적으로 발표하는 창구로서, 언론과 국민에게 정확하고 신속한 정보를 제공하여 투명한 정책 소통과 국민의 알권리를 보장합니다. 이 API는 REST 방식의 GET 메서드를 통해 보도자료를 조회할 수 있으며, 공공데이터포털 인증키(serviceKey)를 통한 보안 인증을 적용합니다. 응답 데이터는 XML과 JSON 형식을 모두 지원하며, 페이징 기능을 통해 다량의 보도자료를 체계적으로 조회할 수 있습니다. 제공되는 정보는 보도자료 제목, 상세페이지 URL, 담당부서명, 담당자 정보, 연락처, 게시일 등의 기본정보와 함께 보도자료 원문, 관련 사진, 참고자료 등의 첨부파일명과 다운로드 URL을 포함합니다. 데이터는 매일 1회 갱신되어 최신 보도자료를 즉시 확인할 수 있습니다. 이 API는 언론사 기자, 뉴스 포털 운영자, 정책 모니터링 담당자, 미디어 큐레이션 서비스 개발자, 정부 정책 연구자 등이 활용할 수 있으며, 특히 과학기술 정책과 R&D 성과를 신속하게 파악하고 전파하는 데 유용합니다. 표준화된 API를 통해 정부의 공식 발표를 다양한 채널로 효율적으로 배포할 수 있어 정책 홍보의 효과성을 높이고, 언론과의 원활한 소통을 지원합니다.

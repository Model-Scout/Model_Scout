# 도로 집계 현황

‘도로 집계 현황’ 데이터는 경기도 내 도로종류별 도로 규모와 특성을 종합적으로 파악할 수 있도록 정리된 연간 통계자료입니다. 해당 데이터는 도로종류명(ROAD_KIND_NM)과 구분명(DIV_NM)을 기준으로, 각 도로유형의 노선 수(ROUTE_CNT), 총연장(km)(EXTS), 포장된 구간의 길이(PAVE_DEGR_LENG), 미포장 구간 길이(UNPAVE_DEGR_LENG), 포장도율(%)(PAVE_DEGR_RT)을 제공합니다. 이 데이터는 국도·지방도·고속도로·시군도 등 다양한 도로의 분포 상태 및 관리 현황을 분석할 수 있어, 경기도의 도로정책 수립, 유지보수 우선순위 결정, 노후구간 개량 사업 계획 등에 활용됩니다. 또한 도로 인프라에 대한 지역 간 격차 분석 및 장기 교통계획 수립의 기반 자료로 활용될 수 있습니다.

제공기관: 경기도
분류: 교통물류
키워드: 도로현황, 도로종류, 노선수, 포장도율, 연장거리, 교통정책, 도로구분
형식: api
선정 기준: 운영 자동승인 OpenAPI

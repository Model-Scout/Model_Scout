# 지식재산처_KIPRISPlus_특허 염기서열_REST API_20220308

1. 개요 특허 출원 시에 제출된 서열목록 전자파일로 구축된 생명공학 데이터베이스에서 관리되는 염기서열 정보를 제공합니다. 염기서열 정보를 API(REST방식) 및 대용량(BULK)으로 제공합니다. 2. 세부 정보 내용 국내 특허의 염기서열 생명공학출원접수, 생명공학염기서열, 변동정보 등을 XML 형태로 제공합니다. 출원번호, 접수번호, 아미노산염기서열번호, 아미노산염기서열특징일련번호, 아미노산염기서열특징명칭, 아미노산염기서열길이, 아미노산염기서열일련번호, 아미노산염기서열내용 등 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

제공기관: 지식재산처
분류: 과학기술
키워드: 출원번호, 접수번호, 아미노산염기서열번호, 생명공학염기서열, 변동정보
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-09-23
이용허락: 이용허락범위 제한 없음

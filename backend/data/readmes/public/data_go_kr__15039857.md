# 국가평생교육진흥원_평생교육사 홈페이지 내 실습기관 유형별 현황

국가평생교육진흥원에서 제공하는 “평생교육사 홈페이지 내 실습기관 유형별 현황” 데이터는 실습기관을 기관 유형별로 구분하고, 기관유형, 유형별 비율, 기관 소재지, 소재지별 비율 기본 정보를 정리한 자료입니다. 이 데이터는 평생교육사 자격취득 과정에서 실습기관 선택에 필요한 객관적 정보를 제공합니다. 공공데이터 목록등록 관리는 통해 연간 1회 업데이트되며, CSV형식으로 다운로드 가능해 연구·정책·현장 실무 모두에서 손쉽게 활용할 수 있습니다. 평생교육사 홈페이지(https://lledu.nile.or.kr/)를 통해 모집 중인 평생교육 현장실습 기관의 유형별 현황 안내

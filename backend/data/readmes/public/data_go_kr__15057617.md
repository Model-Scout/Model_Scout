# 지식재산처_KIPRISPlus_특허_실용 인용문헌_REST API _20220803

1. 개요 출원인이 직접 기재하거나 심사관이 특허･실용 심사시에 참조한 심사인용문헌 정보를 제공합니다 한국 특허의 특허 / 실용신안 출원 시 출원인이 기재하거나 심사관이 참조한 인용문헌 정보를 표준화한 데이터를 API(REST방식) 및 대용량(BULK)으로 제공합니다. 2. 세부 정보 내용 표준인용문헌번호, 원인용문헌번호 등의 정보를 XML 형태로 제공합니다. 출원번호, 원인용문헌번호, 원인용문헌번호일자, 표준인용문헌번호, 표준인용문헌국가코드, 표준인용식별코드, 표준인용문헌발행일자, 표준상태코드, 표준상태코드명, 인용문헌구분코드, 인용문헌구분코드명 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

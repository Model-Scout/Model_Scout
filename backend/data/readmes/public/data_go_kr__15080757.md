# 국가데이터처_온라인 수집 가격 정보_20210417

주요 온라인 쇼핑몰에서 거래되는 다양한 온라인 상품의 가격 정보를 웹스크래핑 방식으로 자동 수집하여, 약 120여 개 품목에 대한 상품가격 데이터를 일별로 제공하고 있습니다. 이를 통해 시의성 있는 물가 동향 분석 및 가격 추이 비교 등 다양한 분석 및 정책적 활용이 가능하도록 설계되었습니다. 해당 데이터는 OPEN API 방식으로 제공되며, 통계청_온라인수집가격정보_OPEN-API활용가이드_v2.2 문서를 참고하시기 바랍니다. 전체 품목의 코드와 명칭 정보를 조회할 수 있는 ‘품목리스트조회’ 테이블과, 품목 코드와 조회 일자를 기준으로 가격 정보를 확인할 수 있는 ‘가격정보조회’ 테이블로 구성되어 있습니다.

# 국내우편물 종적 조회 서비스

우체국 등기번호(13자리)를 이용하여 건별 국내등기우편물의 배송내역을 조회하는 OPEN API 서비스입니다. ㅇ 출력하는 항목(사용자가 응답 받게 되는 데이터) : 발송인, 수취인, 등기번호, 우편물종류, 취급구분, 배달일자, 배달상태, 종적목록(날짜, 시간, 현재위치, 처리현황, 상세설명) 이 문서는 우정사업본부의 국내우편물 배송조회 서비스를 공공데이터 오픈API 형태로 제공하기 위한 기술 명세서로, 서비스 개요와 오퍼레이션 구성, 건별 국내우편물 등기 종적조회 기능에 대한 상세 내용을 포함합니다. 특히, 각 오퍼레이션별 요청 및 응답 메시지 구조와 항목 정의를 중심으로 구성되어 있으며, API 호출 시 필요한 데이터 형식과 처리 방식에 대한 기준을 제공합니다. 또한, 개발자가 배송조회 기능을 시스템에 연동할 수 있도록 요청·응답 메시지 명세를 명확히 제시하고, 국내우편물의 배송 상태를 조회하기 위한 핵심 기능과 데이터 흐름을 이해할 수 있도록 지원합니다. 이를 통해 배송추적 서비스 구현 시 필요한 기술적 기준을 제공하고, 안정적인 데이터 연동 및 활용이 가능하도록 돕는 규격서 역할을 수행합니다.

제공기관: 과학기술정보통신부 우정사업본부
분류: 교통물류
키워드: 경제경영, 마케팅, 물류유통관리, 배송조회, 등기번호, 보낸사람, 배달상태, 우체국
형식: api
선정 기준: 운영 자동승인 OpenAPI

# 부산광역시_하수처리장 운영 현황

하수처리시설은 하수도법에 따라 하수와 분뇨를 적정하게 처리하여 공중위생 향상과 공공수역 물환경 보전에 기여하는 것을 목적으로 합니다. 부산광역시 내 처리량이 500㎥/일 이상인 공공하수처리시설은 2025년 12월 말 기준 14개 시설이 운영 중이며, 각 하수처리시설의 명칭, 소재지와 하수도법에서 규정한 유입수와 방류수에서 준수 해야하는 수질기준 항목 중 유입수와 방류수 각각의 생물화학적 산소요구량(BOD), 총유기탄소량(TOC), 부유물질(SS), 총질소(T-N), 총인(T-P), 대장균 군 수에 대한 정보를 붙임에서 제공합니다.

# 법무부_보호관찰대상자 현황

법무부 범죄예방정책국 소속기관 보호관찰소의 보호관찰 업무와 관련된 자료로, 전국 보호관찰소에서 관리하는 보호관찰 대상자의 사범별 현황 정보를 제공하며, 제공 항목에는 보호관찰 대상자의 연령, 성별, 거주 지역, 최초 범죄 유형, 재범 여부, 처분 기관, 단계별 분포 등이 포함된다. 범죄 유형은 마약 사범, 사기 횡령사범, 성폭력사범, 절도사범, 폭력사범, 풍속사범, 기타사범 등으로 구분되며, 각 유형별 인원수와 비율, 기간별 추이 등이 수록되어 있다. 본 데이터는 정책 수립, 범죄유형별 대응방안 마련, 학술연구, 보호관찰제도 개선 등으로 활용가능하다

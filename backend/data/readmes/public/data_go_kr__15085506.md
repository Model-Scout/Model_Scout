# 한국산업단지공단_공장등록현황통계_시도별 공장면적 현황

공장등록현황통계의 시도별 공장면적현황 csv 파일로, 한국의 17개 시도에 대한 공장면적현황을 데이터 기준일자로 제공하고 있습니다. 공장면적의 경우 용지면적, 제조시설 및 부대면적으로 나뉘어져 있으며 단위는 m2입니다. 17시도의 경우 광역시도에 대한 기준으로 서울, 인천, 경기, 강원, 충북, 충남, 대전, 전남, 전북, 광주, 경북, 대구, 경남, 부산, 울산, 제주, 세종 등으로 구분되어 있습니다. 해당 데이터는 공장설립온라인지원시스템(www.factoryon.go.kr)을 통해 전국 지자체 및 관리기관에서 등록한 민원 데이터를 토대로 작성하였습니다.

제공기관: 한국산업단지공단
분류: 공공행정
키워드: 공장등록현황, 시도별공장면적, 공장통계, 공장면적, 전국공장면적
형식: xlsx
선정 기준: 중앙·광역 기관 파일데이터
수정일: 2026-09-17
이용허락: 이용허락범위 제한 없음

# 모바일 판례 본문 조회

법제처가 제공하는 모바일 판례 본문 조회 데이터는 법원에서 선고된 주요 판례의 본문 전체를 모바일 환경에서 확인할 수 있도록 구성된 자료입니다. 본 데이터는 판례식별번호를 기준으로 사건명, 사건종류명, 선고일자, 법원명, 재판부명, 재판요지, 판시사항, 사실관계, 판단이유, 결론, 참조조문, 참조판례 등 판례 전문에 해당하는 항목을 포함하고 있습니다. 사용자는 특정 판례의 식별번호를 입력하여 해당 사건의 전체 판결 내용을 조회할 수 있으며, 판단이유와 사실관계, 참조조문 등은 법률 해석과 유사 판례 비교, 논리 전개 분석 등 법적 검토를 위한 중요한 기초 자료로 활용됩니다. 해당 데이터는 법률 전문가뿐 아니라 행정 실무자, 연구자 등이 판례에 대한 심층 분석을 수행하는 데 유용한 자료입니다.

제공기관: 법제처
분류: 공공행정
키워드: 사건명, 재판요지, 판시사항, 사실관계, 판결이유, 법적논거, 참조조문, 참조판례
형식: api

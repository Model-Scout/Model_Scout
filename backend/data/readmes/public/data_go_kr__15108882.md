# 한국산업인력공단_연도별 복수자격 취득현황 조회 서비스_20221201

“국가기술자격 연도별 복수자격 취득현황 조회 서비스” API는 한국산업인력공단이 제공하는 공공데이터 서비스로, 국가기술자격 취득자의 복수자격 보유 현황을 연도별로 조회할 수 있습니다. 이 API를 통해 연도별 복수자격 보유자 수, 보유 자격 수 등의 통계 정보를 XML 형식으로 제공합니다. 요청 시 인증키(ServiceKey)와 조회 연도(baseYY), 페이지 번호(pageNo), 한 페이지 결과 수(numOfRows) 등의 파라미터를 지정하여 데이터를 조회할 수 있습니다. 이 API는 자격 취득 현황 분석, 진로·자격 상담 시스템, 정책 연구 등에 활용하기에 적합합니다. 공공데이터포털에서 인증키를 발급받아 사용할 수 있으며, 개발계정 기준으로 월 1,000회 호출이 가능합니다. 운영계정은 활용 사례 등록을 통해 추가 트래픽을 신청할 수 있습니다.

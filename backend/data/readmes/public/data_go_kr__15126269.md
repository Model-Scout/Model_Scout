# 관세청_수출이행내역

수출이행내역은 수출신고별 수리일자, 출항일자 등 수출이행 내역과 선적중량, 통간중량 등 잔량 정보를 제공하는 서비스입니다. *Open API를 사용하기 위해서는 UNI PASS 홈페이지 회원으로 가입되어 있어야 하며, 로그인 후 마이메뉴에서 Open API 서비스를 신청할 수 있습니다. ( UNIPASS > My 메뉴 > 서비스관리 > Open API 사용관리) 관세청 수출이행내역(적재이행내역) 조회 API는 수출신고번호 또는 B/L번호로 조회시 수출수리일자, 수출자상호, 적재의무기한, 선적지, 출항일자, 선적중량, 통관중량 등 내역을 확인가능합니다.

제공기관: 관세청
분류: 교통물류
키워드: 수출화물, 수출이행내역, 잔량_정보, 수출신고번호, 적재의무기한, 선적(기적)수량
형식: xml
선정 기준: 중앙·광역 기관 파일데이터

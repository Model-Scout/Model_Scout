# 등록장애인 집계현황(시군별, 유형별, 성별)

이 데이터는 경기도 등록장애인을 시군별, 장애유형별, 성별로 구분해 집계한 현황입니다. 보건복지부와 경기도청 장애인복지과가 제공하며, 매년 12월 말 기준으로 산출됩니다. 데이터에는 시군명, 장애유형별 장애인 합계, 남성·여성 구분 인원이 포함됩니다. 예를 들어, 수원시에서 지체장애인이 15,000명이라면 그중 남성은 8,000명, 여성은 7,000명과 같이 기록됩니다. 장애유형은 지체, 뇌병변, 시각, 청각, 언어, 안면, 신장, 심장, 간, 호흡기, 장루·요루, 뇌전증, 지적, 정신, 자폐성 등으로 세분화됩니다. 이를 통해 각 시군별 특성을 확인할 수 있습니다. 이 데이터는 지역별로 장애인의 분포와 성별 차이를 분석하는 데 활용됩니다. 예를 들어, 특정 시군에서 뇌병변장애인의 비율이 높다면 재활 병원 확충, 이동지원 서비스 확대 등이 필요하다는 정책적 시사점을 얻을 수 있습니다. 또한 성별 데이터를 통해 여성장애인 돌봄 지원, 남성장애인 직업재활 정책 같은 성별 맞춤형 복지 전략 수립에도 기여할 수 있습니다.

제공기관: 경기도
분류: 사회복지
키워드: 등록장애인, 유형별장애인, 성별장애인, 누림센터, 장애통계, 장애유형별현황, 남성장애인, 여성장애인
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-09-24

# 맞춤형 법령 조문 목록 조회

법제처가 제공하는 맞춤형 법령 조문 목록 조회 데이터는 현행 법령의 조문별 기본 정보를 체계적으로 제공합니다. 해당 데이터는 법령명, 조문번호, 조문제목, 조문내용, 시행일자, 조문ID, 조문일련번호, 개정이력 및 분류코드 등의 핵심 속성을 포함합니다. 사용자는 법령명, 조문번호, 분류코드, 페이지 및 조회 건수 옵션을 통해 원하는 조문을 맞춤형으로 조회할 수 있습니다. 법령 조문 단위의 현황 분석, 법제 연구, 정책 검토 및 행정업무 효율화에 적합하고 특히 조문 단위로 개별 조문 내용과 개정사항을 연계하여 확인할 수 있어 법령 체계 파악 및 법제 지원 업무에 유용합니다.

제공기관: 법제처
분류: 공공행정
키워드: 국가법령정보센터법률시행령, 개정이력, 시행일자, 조문내용, 조문제목, 조문번호, 법령명, 분류코드
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-07-09
이용허락: 이용허락범위 제한 없음

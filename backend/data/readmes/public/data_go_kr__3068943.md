# 국토교통부_교통CCTV_20240304

경찰청의 CCTV위치도 교통CCTV의 도형, 속성 정보를 조회 WFS보다 간결한 형태의 데이터 조회 기능을 제공하며, 복잡한 Query가 필요할 경우 WFS를 사용하도록 권고함 CCTV의 위치, 설치 정보만 제공합니다. 영상정보는 다른 API를 참고하셔야 합니다. RestAPI로 호출하면 json/xml로 데이터를 반환합니다

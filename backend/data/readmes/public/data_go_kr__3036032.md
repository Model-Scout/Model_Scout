# 병무청_현역병 입영 귀가자 현황

해당 데이터는 현역병 귀가자 현황에 대한 자료입니다. 이 자료는 병무청에서 제공하고 있으며 귀가자에 대하여 치유기간이 3개월 미만인지 이상인지, 병류별(정신과, 내과, 외과, 치과, 피부과, 이비인후과, 신경과 등)귀가자의 인원에 관한 데이터로, 병무청에서 치유기간, 병류 등의 항목을 세분화하여 제공합니다. 기존 제공되었던 자료에서 2025년도의 현황을 추가적으로 작성하여 귀가자의 치유기간, 병류별 인원을 파악하기 쉽게 제공하고 있으며 각 병류별로의 인원이 어떻게 되는지까지 포함하고 있습니다.

제공기관: 병무청
분류: 통일외교안보
키워드: 현역, 입영, 귀가자, 외과, 정신과, 이비인후과, 치과, 내과
형식: csv

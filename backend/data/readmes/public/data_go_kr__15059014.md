# 노인복지관련 사회복지법인 현황

이 데이터는 경기도 내 노인복지를 목적으로 설립된 사회복지법인의 현황을 수록한 자료입니다. 주요 제공 항목은 시군명, 시군코드, 법인명, 설립목적으로 구성되어 있으며, 법인의 명칭 및 설립 배경을 통해 노인복지 서비스 수행 주체에 대한 정보를 확인할 수 있습니다. 해당 정보는 지역 복지정책 수립, 민간복지 네트워크 분석, 사회복지사업 평가 및 비영리조직 관리 등에 활용될 수 있으며, API는 인증키 기반으로 XML 또는 JSON 형태로 제공됩니다. 데이터는 연 1회 갱신되며, 법인의 설립 목적이 ‘노인복지’로 명시된 사례만 포함됩니다.

제공기관: 경기도
분류: 사회복지
키워드: 노인복지, 사회복지법인, 비영리사업, 복지재단, 설립목적, 법인정보, 시군정보, 복지정책
형식: api

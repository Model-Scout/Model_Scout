# 지식재산처_KIPRISPlus_특허_실용 공개_등록공보_REST API

1. 개요 한국 특허 / 실용신안 공개 및 등록공보의 서지정보, 대표도, 전문정보 등을 API(REST방식)으로 제공합니다. 2. 세부 정보 내용 [API 서비스] ① 검색 : 일반검색 및 항목별검색 기능을 통해 특허·실용신안 공보 정보를 XML 형태로 제공합니다. ② 서지정보 : 출원번호, 등록일자, 발명의 명칭, 등록상태 등의 정보를 XML 형태로 제공합니다. ③ 도면/전문 : 공개 및 공고 전문, 대표도면의 다운로드 경로를 XML 형태로 제공합니다. 발명의명칭, 초록청구범위, IPC코드, 출원번호, 공개번호, 공보(고)번호, 등록번호, 우선권주장번호, 국제출원번호, 국제공개번호, 출원일자, 공개일자, 공고일자, 등록일자, 우선권주장일자, 국제출원일자, 국제공개일자, 출원인명, 특허고객번호, 발명자명, 특허고객번호, 대리인명, 대리인코드, 등록권자, 특허실용행정처분, 페이지번호, 페이지당건수, 정렬기준, 정렬방식 등 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

제공기관: 지식재산처
분류: 과학기술
키워드: 발명의명칭, 출원번호, 공개번호, 등록번호, 국제출원번호
형식: xml
선정 기준: 중앙·광역 기관 파일데이터

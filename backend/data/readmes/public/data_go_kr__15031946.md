# 한국고용정보원_워크넷 강소기업 청년강소기업체험_20210520

[강소기업 API - 청년강소기업체험] 고용노동부에서 제공하는 재학생직무체험 및 중소기업 탐방 프로그램인 청년강소기업체험정보를 제공합니다. 목록 및 상세 형태로 제공하고 있으며 일경험프로그램은 워크넷에서도 확인이 가능합니다. 청년강소기업체험 API를 이용하여 다채로운 기관의 청년연수정보를 한눈에 확인할 수 있습니다. <API 사용법> 호출할 페이지 타입, 출력건수, 근무지역코드, 직종코드, 검색할 등록일자의 기간, 연수기간조회 시작일자 및 종료일자, 사업자명, 운영기관명 등을 파라미터로 받아 총건수, 기본값 1(최대 1000 검색의 시작위치를 지정)., 출력건수, 구인인증번호, 운영기관명, 강소기업 여부(Y), 사업장명, 모집직종, 연수지역, 선발인원, 모집인원, 연수기간 시작일, 연수기간 종료일, 등록일 등의 결과를 제공합니다. * 유의사항: 문자열로 입력되는 항목의 경우 공백이나 오탈자가 포함되면 검색 결과가 제대로 나오지 않을 수 있으므로 주의해야 합니다. 대부분의 파라미터는 선택적으로 입력할 수 있으며, 필요한 조건만 입력해도 조회는 가능합니다.

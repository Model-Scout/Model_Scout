# 해양환경공단_해양수질자동측정망 하구 및 만 관측서비스_20200304

이 데이터는 해양환경공단이 하구 및 만 지역을 대상으로 운영하는 해양수질자동측정망의 관측 정보를 제공하는 공공데이터 API 서비스이다. 하구와 만은 육상에서 유입되는 오염물질의 영향과 조석, 담수 유입 등 복합적인 환경 변화가 나타나는 구간으로, 자동측정장비를 활용하여 전기전도도, 수온, 염분, 수소이온농도, 용존산소량, 탁도 등 주요 수질항목을 연속적으로 관측한다. 또한 관측정점의 코드, 위치, 관측일시 등 기본 공간·시간 정보를 함께 제공하여 이용자가 특정 하구 또는 만 지역의 수질 특성 및 오염도 변화를 체계적으로 파악할 수 있도록 지원한다. 아울러 배경 기상조건과 측정자료 검증 절차를 포함한 표준화된 데이터 구조를 제시함으로써 환경 관리, 생태계 연구, 정책 의사결정 등에 활용할 수 있도록 구성된 서비스이다.

# 지식재산처_등록원부 실시간 정보 조회 서비스_20231112

특허로(http://patent.go.kr)에서 제공 중인 특허/실용신안/디자인/상표의 등록원부를 수요기관에서 실시간으로 조회할 수 있도록 개발된 API로, 등록번호를 기준으로 특허/실용신안/디자인/상표 등록원부의 기본 정보, 연차정보, 출원인, 대리인, 우선권, 전용실시권 등의 정보를 제공하는 등록원부 실시간 정보 조회 서비스 입니다. 비공개건의 경우 조회에 제한이 있을 수 있습니다. ※ 관련 세부 내용 조회는 특허정보검색서비스(http://kpat.kipris.or.kr/)를 이용해주시기 바랍니다.

제공기관: 지식재산처
분류: 공공행정
키워드: 등록원부, 특허실용신안디자인상표, 사업자 권리 정보, 특허, 실용신안, 디자인, 상표
형식: api
선정 기준: 국가중점데이터 OpenAPI

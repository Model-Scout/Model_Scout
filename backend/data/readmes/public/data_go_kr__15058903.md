# 종량제봉투(가정및사업장용)판매가격 현황

이 데이터는 경기도 각 시군에서 판매되는 종량제봉투의 가격 현황을 정리한 자료로, 가정용, 사업장용, 음식물 전용 봉투, 특수 규격 봉투(PP마대 등) 등 다양한 구분별 단가 정보를 포함하고 있습니다. 용량별(1ℓ~100ℓ, kg 단위 등) 가격이 기록되어 있어 지역 간 가격 차이를 비교하거나 폐기물 배출 비용의 합리성을 평가하는 데 활용할 수 있습니다. 종량제봉투는 폐기물 발생 억제와 자원 재활용 촉진을 위한 제도로 운영되고 있으며, 본 자료는 환경정책 수립, 폐기물 관리 효율성 검토, 자원순환 체계 개선 등과 같은 정책적 의사결정에 기초자료로 사용될 수 있습니다.

제공기관: 경기도
분류: 공공행정
키워드: 종량제봉투, 폐기물관리, 쓰레기배출, 생활폐기물, 봉투가격, 자원순환
형식: api
선정 기준: 운영 자동승인 OpenAPI

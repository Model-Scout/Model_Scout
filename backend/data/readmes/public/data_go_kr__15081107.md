# 기상청 항공기상청_항공기상전문(IWXXM) 조회서비스_항공기상관측

국내공항의 항공기상관측에 관한 항공기상전문(METAR/SPECI)을 국제민간항공기구(ICAO)가 제정한 표준 교환모델(IWXXM)에 따라 XML 형식으로 제공합니다. 기상청 API 허브(https://apihub.kma.go.kr/)를 통해 조회할 수 있습니다. 항공기상 → 항공기상관측(METAR) → 1. 항공기상전문조회 → METAR/SPECI 조회 정시·비정시 관측 정보는 운항계획 수립과 안전 확보에 폭넓게 활용됩니다. 모든 자료는 ICAO 부속서 3과 WMO 지침에 따른 형식과 절차를 따르기 때문에 국제 항공교통의 안전성과 효율성을 뒷받침하는 핵심 기반 정보로 기능합니다.

제공기관: 기상청 항공기상청
분류: 과학기술
키워드: 항공기상, 항공기상전문, IWXXM, ICAO, 항공기상정보교환모델
형식: xml
선정 기준: 중앙·광역 기관 파일데이터

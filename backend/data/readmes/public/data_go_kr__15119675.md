# 한국중부발전(주)_SMP REC 기준가격 정보

본 데이터는 한국중부발전이 제공하는 연도별 전력 및 신재생에너지 거래 기준가격을 정리한 자료입니다. 항목은 연도, 계통한계가격(SMP)_육지, 공급인증서(REC) 기준가격으로 구성되어 있으며, 전력거래소를 통한 전력 매입가격과 신재생에너지 공급인증서의 기준 거래가격이 포함됩니다. 계통한계가격은 발전사업자가 전력을 공급할 때 적용되는 단가이며, REC 기준가격은 신재생 설비에서 생산된 전력에 부여된 공급인증서의 시장 기준 단가를 의미합니다. 해당 자료는 전력 가격 변동 추이, 신재생에너지 인센티브 수준, 에너지 시장 구조 분석 등의 기초 자료로 활용 가능합니다.

# 식품의약품안전처 식품의약품안전평가원_한약재로 사용되는 멸종위기 동식물종 정보_20210120

한약재로 사용되는 멸종위기 동식물종 정보는 식품의약품안전처(MFDS)의 'CITES 협약에 지정·등재된 의약품용 한약재' 안내서(2020.12.14 개정)에서 공공데이터로 제공되고 있습니다. 해당 내용은 CITES번호, 약명번호, 품목명, 학명, 부속서, 비고, 이력, 등록일시 정보를 제공하고 공공포털(data.mfds.go.kr)에서 PDF,API 형태로 접근가능하며, 수출입시 식약처 승인절차가 명시되어 있습니다. 이 데이터는 한약재 산업의 지속 가능성을 제고하며, 교육, 연구 목적으로는 무료로 분양됩니다.

# 병원평가정보(폐암) 현황

이 데이터는 경기도 내 병원들의 폐암 진료 관련 평가 결과를 정리한 자료로, 병원명, 시군명, 평가등급, 소재지 주소, 위도·경도 등 위치정보가 포함되어 있습니다. 병원별 폐암 치료의 질적 수준을 ‘1등급’ 등으로 구분하여 제공하고 있으며, 지역별 암 치료 서비스의 질적 격차 및 의료자원 분포를 분석하는 데 활용됩니다. 이 데이터는 공공의료 정책 수립, 환자 대상 병원 선택 정보 제공, 지역 간 의료격차 해소 방안 마련, 국가 암 관리사업 기초자료, 질병중심 의료 서비스 품질 향상 등 다양한 공공보건 영역에서 유용하게 사용될 수 있습니다.

제공기관: 경기도
분류: 보건의료
키워드: 폐암진료, 병원평가, 의료질, 평가등급, 진료기관, 의료서비스
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-09-17
이용허락: 이용허락범위 제한 없음

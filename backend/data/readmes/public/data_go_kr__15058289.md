# 서울시 소통 돌발 도로별 링크 정보

해당 데이터는 서울시 소통 돌발 도로별 링크 정보 OpenAPI로 소통, 돌발 API를 사용하기 위한 도로별링크정보 데이터입니다. 데이터의 원본시스템은 서울시 교통정보 시스템(https://topis.seoul.go.kr)입니다. 요청인자 : 인증키, 요청파일타입, 서비스명, 요청시작위치, 요청종료위치, 도로 축 코드 출력값 : 총 데이터 건수(정상조회 시 출력됨), 요청결과 코드, 요청결과 메시지, 도로 축 코드, 도로 방향, 링크 순번, 링크 아이디 ※ 바로가기 링크를 클릭 시 서울 열린데이터광장 개방 데이터로 이동합니다.

제공기관: 서울특별시
분류: 교통물류
키워드: 도로별 링크, 소통, 돌발, 교통상황, 교통량
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-07-08
이용허락: 이용허락범위 제한 없음

# 한국연구재단_KCI 참고문헌 서비스

한국학술지인용색인(KCI) 참고문헌 서비스는 국내 학술논문에 인용된 참고문헌 정보를 체계적으로 제공하여 연구자들이 논문의 인용 관계, 참고문헌의 출처, 인용 빈도 등을 쉽게 파악할 수 있도록 지원합니다. 논문별 참고문헌 목록, 저자, 저널명, 출판사, 컨퍼런스 정보, 인용일자 등 다양한 서지 정보를 포함하고 있어 학술연구, 인용분석, 연구동향 파악, 논문 작성 및 참고문헌 관리 등에 활용도가 높습니다. 연구자, 도서관, 학술기관 등에서 학술정보 서비스 및 연구성과 평가에 유용하게 사용할 수 있습니다.

제공기관: 한국연구재단
분류: 과학기술
키워드: 학술, 논문, 참고문헌, 인용, 서지, 연구, 저널, 출판
형식: xml

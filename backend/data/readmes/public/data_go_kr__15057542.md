# 행정규칙 목록 조회

법제처에서 제공하는 행정규칙 목록 조회 서비스 데이터입니다. 행정규칙의 일련번호, 규칙명, 소관부처, 제정·개정일자, 시행일자, 규칙코드, 행정분야 구분 등의 항목을 체계적으로 확인할 수 있습니다. 규칙명, 부처명, 규칙코드 등을 파라미터로 지정하여 원하는 목록을 선택적으로 조회할 수 있도록 설계되어 있고 응답에는 총 결과 수와 페이지 정보, 각 규칙의 상세 정보 링크가 포함되어 있습니다. 이 데이터를 활용하여 행정규칙 현황 분석, 규제 정비 현황 점검, 내부 관리 시스템 연동 등에 유용합니다. 또한 모바일 애플리케이션이나 웹서비스에서 최신 규칙 목록 제공, 규칙 검색 기능 강화 등을 위한 핵심 자료로 적합합니다.

분류: 공공행정
키워드: 국가법령정보훈령고시, 규칙목록, 시행일자, 행정분야, 소관부처, 규칙코드, 제목검색, 문서형식
형식: api

# 기후에너지환경부 국립환경과학원_시간단위 수온관측 자료

환경부에서는 국가수질자동측정망을 전국에 76개소를 운영하고 있으며, 수온, 수소이온농도, 용존산소, 전기전도도, 총유기탄소, 총질소, 총인 등의 항목들을 실시간으로 측정하고 있다. 국가수질자동측정망에서 측정된 데이터는 한국환경공단의 국가수질자동측정망 시스템을 통해 수집된다. 수집된 데이터는 국립환경과학원의 실시간수질정보시스템으로 연계되며 연계된 데이터는 최종 검토 및 확정 후 국민에게 제공되고 있다. 해당 데이터는 이러한 국가수질자동측정망 데이터 중 요청한 낙동강수계 도개 측정소의 2012년에서 2014년 간의 시간 단위 수온 측정 데이터이다.

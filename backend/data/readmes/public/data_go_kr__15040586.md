# 사전투표 현황 정보 조회 서비스

사전투표 정보는 사전투표자 수, 사전투표율 등 사전투표 결과 정보를 제공합니다. (선거 ID와 사전투표구분, 시도명, 구·시·군명을 입력하여 사전투표 결과를 조회할 수 있는 서비스입니다. ) ※ 사전투표 정보는 선거관리과와 협의를 거쳐 통상 2개월 이내에 데이터 검증 및 이관 절차를 완료한 후 제공됩니다.

제공기관: 중앙선거관리위원회
분류: 공공행정
키워드: 사전투표정보, 사전투표현황, 사전투표결과, 투표자수, 투표율, 사전투표, 사전투표자수, 사전투표율
형식: api
선정 기준: 국가중점데이터 OpenAPI
수정일: 2025-09-03
이용허락: 이용허락범위 제한 없음

# 금융위원회_주식등록예탁가능정보_20200424

주식등록예탁가능정보는 특정 주식이 한국예탁결제원에 등록 및 예탁이 가능한지 여부를 확인할 수 있는 데이터입니다. 기준일자, 종목번호, 발행회사명 등을 기준으로, 등록예탁 가능여부, 예탁가능일자, 등록구분, 상장구분, 발행주식수, 액면가, 발행시장 등의 정보를 제공합니다. <데이터 조회 시 유의사항> 파라미터 없이 조회 시 데이터 조회 시간이 오래걸려 timeout이 발생하게 되어 필수 파라미터를 지정하였습니다. - 파라미터 조건 : 조회 시 아래의 필수 파라미터 중 최소 1개 이상을 반드시 입력해야 합니다. - 기본값 안내 : 필수 파라미터를 입력하지 않은 경우, 기준일자(basDt)는 자동으로 가장 최신 날짜로 설정되어 조회됩니다. [서비스별 필수 파라미터 목록] - 주식등록예탁가능정보조회 : basDt, isinCd, crno 데이터는 단일 오퍼레이션으로 구성되어 있으며, 세부내용은 다음과 같습니다. ① 주식등록예탁가능정보조회 : 기준일자, 법인등록번호, 주식발행회사명을 통하여 예탁등록일자, 직전상장구분코드명, 상장폐지일자등을 조회하는 예탁가능여부조회 기능 본 데이터는 상장예정기업이나 발행회사의 주식 유통 가능성을 확인하거나, 자본시장 접근성, 투자 가능성 평가, 기업공시 모니터링 등에 활용할 수 있습니다. ※ 데이터 갱신주기는 일 1회입니다. ※ 금융위원회의 모든 API는 데이터 보유기관으로부터 데이터를 연계받아 수집 후 개방하고 있습니다. 금융위원회에서 제공하는 모든 서비스는 실시간이 아니며, 데이터 갱신은 기준일자로부터 영업일 하루 뒤 오후 1시 이후에 업데이트됩니다. 예를 들어, 금요일 데이터는 차주 월요일에 제공됩니다. (월요일이 공휴일인 경우, 다음 영업일에 제공됩니다) ※ 자주 묻는 질문(FAQ)은 https://www.fsc.go.kr/in060501 에서 확인하실 수 있습니다. ** 유의사항 본 개방데이터는 공공누리 2유형임을 참고하시기 바랍니다. 이용허락범위 제2유형 : 출처표시 + 상업적 이용금지 해당 데이터를 상업적으로 활용하고자 하는 이용자는 데이터 원천 소유자인 한국예탁결제원과 사용 목적과 범위에 따른 정보이용계약이 필요합니다. 정보이용계약 또는 해당 정보에 관하여 궁금한 점이 있으시면 한국예탁결제원 증권정보부(연락처: portal@ksd.or.kr)로 이메일 문의 주시기 바랍니다.

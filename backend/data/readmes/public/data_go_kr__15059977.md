# 해양환경공단_해양수질자동측정망 특별관리해역 관측서비스_20200304

이 데이터는 해양환경공단이 특별관리해역에서 운영하는 해양수질자동측정망의 관측 정보를 제공하는 공공데이터 API 서비스이다. 해역명, 정점명, 조사시작일, 조사종료일을 활용하여 해역코드, 해역명, 생태구지역코드, 생태구지역명, 정점코드, 정점명, 관측일자 등 기본 공간·시간 정보를 조회할 수 있다. 또한 전기전도도, 수온, 수소이온농도, 용존산소량, 탁도 및 탁도임시, WIPER 상태, 일사량, 기온, 상대습도, 풍속, 풍향, 강수량, 전압 값, 수위(WLEVEL1·WLEVEL2), 염분, 클로로필A 등 주요 수질지표를 상세히 제공한다. 아울러 화학적산소요구량, 총질소, 총인, 암모니아성질소, 질산성질소, 남조류, 인산성인 등 오염지표를 함께 제공하여 이용자가 해역의 환경 변화를 종합적으로 분석할 수 있도록 지원한다.

제공기관: 해양환경공단
분류: 환경기상
키워드: 해양수질, 자동측정, 특별관리해역, 관측자료, 수질변화, 실시간 정보, 환경관리, 데이터검증
형식: api
선정 기준: 운영 자동승인 OpenAPI

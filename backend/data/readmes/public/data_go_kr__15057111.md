# 예보구역정보 조회서비스

기상청에서 운영하는 관측지점, 기상예보구역, 기상특보구역 등에 대한 정보를 제공합니다. 예보구역은 우리나라에서 날씨예보를 제공하기 위해 설정한 지리적 구획 단위입니다. 기상청은 예보의 효율성과 정확도를 높이기 위해 행정구역과 자연지리적 특성을 고려하여 전국을 여러 예보기반 구역으로 나누어 관리하고 있습니다. 특보구역은 기상청에서 발표하는 육상 및 해상의 기상특보구역코드 정보입니다. 한파, 건조, 안개, 폭염, 지진해일, 폭풍해일, 호우, 대설, 태풍, 풍랑, 강풍 12개 기상현상에 대해 중대한 재해발생이 예상될 때 해당 지역에 대하여 기상특보의 발표 기준에 따라 주의보 및 경보로 구분하여 178개 시 · 군 단위와 44개 해역으로 세분화하여 발표합니다.

# 대구광역시_장애인 거주시설현황

대구광역시가 제공하는 ‘장애인 거주시설현황’ 데이터는 시내에 위치한 장애인 장기·단기 거주시설, 공동생활가정, 영유아 장애거주시설 등 유형별 시설 정보를 일괄적으로 정리한 공공데이터입니다. 사회복지·취약계층 지원 정책 수립과 현장 서비스 연계에 활용됩니다. 데이터는 시설명, 주소, 전화번호, 운영기관, 정원·입소현황, 제공 서비스(보호·재활·교육 등) 및 시설 유형을 포함합니다. 연간 업데이트되며, CSV·XLSX 형식으로 제공돼 GIS·통계 분석에 바로 적용할 수 있습니다. 시·구청, 복지기관, 연구자, 민간기업 등은 이 데이터를 활용해 지역별 서비스 격차를 파악하고, 맞춤형 지원 프로그램을 설계하거나 입소 대기 현황을 모니터링할 수 있습니다. 무료 다운로드와 API 제공으로 손쉽게 연계·활용이 가능합니다.

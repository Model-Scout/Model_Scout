# 국민연금공단_자격 외국인체류자격별 가입현황

국민연금공단의 가입된 외국인 가입자 데이터를 기반으로 만들어진 체류자격별 외국인 가입자 수입니다. 해당 월의 국민연금에 가입된 외국인 가입자의 가입종별과 체류자격에 따른 가입 현황을 나타내며 분류기준은 아래와 같습니다. - 분류 기준: 연도별(해당 월별), 체류자격별, 가입 종별(사업장, 지역) - 해당 연도(해당 월별): 2020년 5월의 데이터를 포함하고 있습니다 - 분류 단위: 명 해당 연도(해당 월)에 따라 분류되어있는 데이터를 통해 국민연금에 가입된 외국인 가입자의 체류자격별 현황을 확인하실 수 있습니다. (데이터 건수가 많은 경우 모든 데이터가 표출되지 않을 수 있음을 안내드립니다.)

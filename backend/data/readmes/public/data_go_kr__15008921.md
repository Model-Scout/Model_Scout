# 경상남도 의령군 농어촌체험마을 API

본 데이터는 경상남도 의령군 농어촌체험마을 현황을 제공하며, 체험프로그램구분, 체험마을명, 도로명주소 등을 기준으로 대표전화번호, 관리기관, 보유시설정보, 체험내용 등을 조회할 수 있습니다. 자료는 지역 농어촌 체험관광 활성화, 주민 소득 증대, 교육 및 문화 체험 프로그램 운영 등에 활용됩니다. 행정기관은 이를 통해 마을별 운영 현황을 파악하고 지원 정책 수립에 참고할 수 있으며, 주민은 체험마을을 홍보하고 관광객 유치에 활용할 수 있습니다. 이용자는 체험내용과 시설정보를 확인해 프로그램을 비교 및 선택할 수 있어 편의성을 높입니다. 본 데이터는 공공데이터포털에서 누구나 활용할 수 있도록 제공됩니다.

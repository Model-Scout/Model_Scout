# 교육부 국사편찬위원회_한국사데이터베이스 정보_한국근현대인물자료

한국사데이터베이스는 고대부터 현대까지 한국 역사의 중요한 자료를 제공하는 웹 사이트로, 한국근현대 인명록 정보를 인물별로 체계적으로 정리하여 서비스하고 있습니다. 이 데이터는 2019, 2020, 2021년에 걸쳐 주기적으로 업데이트되어 최신 정보를 포함하고 있으며, 근현대 인물과 관련된 다양한 역사자료와 역사DB를 통해 연구와 학습에 유용한 자원을 제공합니다. 한국 역사의 주요 자료를 제공하는 웹 사이트인 한국사데이터베이스(http://db.history.go.kr)에서 서비스중인 한국근현대의 각종 인명록의 정보를 인물별로 정리한 자료임

형식: csv

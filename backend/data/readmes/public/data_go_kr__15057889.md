# 수목원 현황

이 데이터는 경기도 내 등록 후 운영 중인 수목원에 대한 현황 정보를 제공합니다. 수목원명칭, 전화번호, 등록승인년도, 수목원 구분(국립, 도립, 시립 등), 대표자명, 수목원규모(ha), 보유종수, 수목원의 특징 등 기본적인 운영 정보와 함께, 주소 정보(도로명·지번·우편번호) 및 WGS84 기준의 위도·경도 좌표를 포함하여 수목원의 위치도 명확히 확인할 수 있습니다. 이 데이터는 자연생태 관광자원 분석, 식물자원 보존 관리, 교육 프로그램 기획, 생태체험관광지 발굴 등에 활용될 수 있으며, 정기적인 반기 갱신과 Open API 제공을 통해 접근성과 실효성을 동시에 갖추고 있습니다. 또한 상업적 이용과 콘텐츠 변경이 허용되어 민간 서비스와 융합한 응용이 가능합니다.

제공기관: 경기도
분류: 문화관광
키워드: 수목원, 수목원규모, 등록승인년도, 보유종수, 위치정보, 수목원특징, 시군명, 수목원구분
형식: api
선정 기준: 운영 자동승인 OpenAPI

# 국방부_육군_육군3사관학교 임관 병과

육군3사관학교 졸업생의 임관 병과를 설명하고 있는 데이터입니다. 2020년도 임관한 55기부터의 임관 병과를 바탕으로, 졸업생이 선택한 병과(보병, 포병, 기갑, 공병, 정보통신, 정보, 방공, 항공, 병기, 병참, 수송 등)에 대해 상세하게 파악할 수 있습니다. 해당 데이터 분석을 통해 연도별 졸업생 인원수와 졸업생이 선택하는 병과 변화 추이를 분석할 수 있고, 각 병과에 대한 관심도 및 선호도 예측이 가능하도록 합니다. 또한, 추후 군 인사 배치를 원활하게 하는 기초 자료로 활용할 수 있습니다. * 연 단위로 데이터 업데이트 예정입니다.

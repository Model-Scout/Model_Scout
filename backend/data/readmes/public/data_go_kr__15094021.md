# 국민연금공단_납부기간별 사업장가입자 수

해당 데이터는 국민연금공단 가입자의 데이터를 기반으로 만들어졌습니다. 해당 데이터는 월별, 연도별 국민연금 가입자 수의 데이터를 나타냅니다. 해당 데이터는 가입자의 종별과 납부기간에 따라 분류되어 있고 분류기준은 아래와 같습니다. -가입종별: 사업장가입자 -납부기간: 1개월~,12개월~, 36개월~,60개월~, 120개월 이상 국민연금 가입자의 가입종별과 납부기간에 따른 국민연금 가입자 수를 확인하실 수 있습니다. (데이터 건수가 많은 경우에는 모든 데이터가 표출되지 않을 수 있습니다.)

제공기관: 국민연금공단
분류: 사회복지
키워드: 국민연금, 납부기간, 사업장가입자, 가입자, 종별
형식: csv

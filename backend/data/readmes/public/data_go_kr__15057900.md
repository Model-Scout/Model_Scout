# 국토교통부_보행우선구역(WMS/WFS)_20111231

보행우선구역은 차보다 보행자의 안전하고 편리한 통행을 우선하도록 보행환경을 조성한 구역으로 오픈API 형태로 공간정보(지도) 제공 OGC(Open Geospatial Consortium) 표준 API는 공간 데이터의 공유와 상호운용성을 위해 개발된 국제 표준으로, 웹 기반에서 지도, 피처, 래스터 등 다양한 지리정보를 효율적으로 제공·활용할 수 있게 합니다. 최신 OGC API는 RESTful 구조를 채택해 개발 편의성과 확장성을 높였으며, WMS, WFS 등 기존 표준을 현대적으로 계승합니다

제공기관: 국토교통부
분류: 국토관리
키워드: 보행자, 우선, 공간정보
형식: api
선정 기준: 운영 자동승인 OpenAPI

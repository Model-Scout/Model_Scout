# 경기도 고양시_종량제봉투 판매소 현황

경기도 고양시에 위치한 종량제봉투 판매소를 각 구 및 관리기관별로(덕양구, 일산동구, 일산서구) 정리한 고양시 종량제봉투 판매소 현황 데이터입니다. 종량제봉투 판매소는 대형폐기물 스티커, 재사용봉투, 음식물 납부필증, 불연성 마대 등의 종량제봉투를 판매하고 있습니다. 해당 데이터에는 고양시 내 총 종량제봉투 판매소 개수, 판매소의 소속 시군구, 위치(도로명주소), 판매소명, 지정일자, 관리기관명, 데이터기준일(2025.8.20.)이 포함되어 있으며, 다음 데이터 업로드 예정일은 2026.8.24.입니다.

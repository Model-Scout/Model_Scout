# 모바일 법령 본문 조회

법제처가 제공하는 모바일 법령 본문 조회 데이터는 모바일 환경에서 법령의 조문별 본문 내용을 확인할 수 있도록 구성된 정보입니다. 해당 데이터는 법령ID, 조문ID, 조문번호, 조문제목, 조문내용, 항목구분, 연결조문, 조문일련번호, 시행일자 등의 주요 항목으로 구성되어 있습니다. 사용자는 법령ID 또는 조문ID를 입력하여 특정 법령의 본문 내용을 조문 단위로 조회할 수 있으며, 각 조문 간 연결 관계도 함께 확인할 수 있습니다. 경량화된 구조로 모바일 환경에서의 빠른 정보 접근과 법령 내용 확인에 적합하며 법령의 구조화된 조문 정보와 시행일 기준 본문 내용을 함께 제공함으로써, 현행 법령의 신속한 검토, 조문 간 참조 관계 분석 및 모바일 기반 법제 서비스 제공에 효과적입니다.

제공기관: 법제처
분류: 공공행정
키워드: 앱법률시행령, 조문번호, 조문내용, 항목구분, 조문제목, 연결조문, 시행일자, 상세정보
형식: api
선정 기준: 운영 자동승인 OpenAPI

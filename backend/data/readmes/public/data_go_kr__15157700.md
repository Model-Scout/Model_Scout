# 한국수력원자력(주)_원자력발전소 실시간 폐수 수질현황_20260319

“원자력발전소 실시간 폐수 수질 현황” API는 한국수력원자력㈜이 제공하는 공공데이터 서비스입니다. 이 API는 한국수력원자력에서 운영 중인 원자력발전소(고리원자력본부, 한빛원자력본부, 월성원자력본부, 한울원자력본부)의 실시간 폐수 수질 현황 자료를 XML 형식으로 제공합니다. 각 원자력발전소의 폐수 방류량(㎥/h), pH 등 수질 데이터를 실시간으로 모니터링하여, 환경 규제 준수 여부를 확인할 수 있고 이상 상황 발생 시 신속하게 대응할 수 있습니다. 개발계정 기준으로 10,000회 호출이 가능합니다. 운영계정은 활용 사례 등록을 통해 트래픽 증가가 가능합니다.

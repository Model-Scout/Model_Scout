# 휴게음식점(유원지) 현황

이 데이터는 경기도 내 유원지에 위치한 휴게음식점에 대한 인허가 현황을 수록하고 있으며, 도내 31개 시군의 인허가 데이터를 기반으로 구성되어 있습니다. 주요 항목은 시군명, 사업장명, 인허가일자, 영업상태, 폐업일자, 소재지 정보(주소, 면적), 급수시설 구분, 업소 규모, 종사자 수(남녀), 위생업종 및 업태, 다중이용업소 여부, 위치정보(WGS84 위경도) 등을 포함합니다. 이 데이터는 관광지 내 식음료 서비스 제공 실태 분석, 위생관리 강화, 관광객 편의시설 확충, 지역경제 활성화 정책 수립 등에 활용될 수 있으며, XML 또는 JSON 형식의 Open API로 제공됩니다.

제공기관: 경기도
분류: 식품건강
키워드: 휴게음식점, 유원지, 인허가현황, 전통차, 분식점, 위생업소, 다중이용업소, 관광편의시설
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-06-24
이용허락: 이용허락범위 제한 없음

# dialoGPT-medium-korean-chit-chat

This model is a fine-tuning of [Ko-DialoGPT](https://huggingface.co/byeongal/Ko-DialoGPT) model using AIHUB data "Korean SNS". This model chats in Korean terms used in messenger chats such as KakaoTalk.

이 모델은 Ko-DialoGPT model을 AIHUB 데이터 "한국어 SNS"를 이용하여 fine tunning 한 것입니다. 이 모델은 일반 메신저 채팅에서 사용되는 용어로 채팅을 합니다.


## Usage

Try the app in [space](https://huggingface.co/spaces/lcw99/dialoGPT-Korean-Chit-Chat)

### Framework versions

- Transformers 4.22.2
- TensorFlow 2.10.0
- Datasets 2.5.1
- Tokenizers 0.12.1

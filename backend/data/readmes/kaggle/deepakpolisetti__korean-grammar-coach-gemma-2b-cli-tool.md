# 🇰🇷 Korean Grammar Coach — Gemma 2B CLI Tool

This project showcases a lightweight, offline Korean grammar correction tool built using Google's Gemma 2B model. Designed for language learners, it provides bilingual grammar explanations and instant feedback — all from the command line.

## 🔧 Features
- Bilingual output (Korean + English)
- Offline functionality using Gemma 2B
- Modular CLI design for easy use
- Reviewer-friendly interface and clear documentation

## 🎯 Impact
Built for the Google Gemma Impact Challenge, this tool empowers learners with accessible, AI-driven grammar support — no internet required. It’s ideal for students, travelers, and self-learners who want grammar clarity without relying on expensive apps or online tools.

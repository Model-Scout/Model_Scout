# folktales dataset

collection of 3000 folktales

This dataset contains 2838 folk tales from different nations. Tales were scraped mostly from [here](https://fairytalez.com/regions/).
Folk tales of the next 57 nations were used in this dataset:
japanese, serbian, german, french, north american (native), brazilian, armenian, english, russian, greek, danish, canadian (native), ukrainian, indian, norwegian, welsh, scandinavian, polish, czechoslovak, scottish, celtic, portuguese, arabic, croatian, estonian, dutch, italian, nigerian, albanian, maori, nordic, irish, hungarian, south_african, slavic, australian (native), chinese, tanzanian, swedish, icelandic, philippine, hawaiian, jewish, romanian, korean, turkish, finnish, belgian, spanish, catalonian, bulgarian, bukovinian, new zealand (native), sami, pakistani, lithuanian, zimbabwe.

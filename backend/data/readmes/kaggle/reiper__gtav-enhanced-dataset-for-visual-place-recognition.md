# GTA V Enhanced Dataset for Visual Place Recognition (GTAV-VPR)

If you are looking for a lighter but less detailed version of this dataset, you can refer to the legacy version: 
[**GTA V Legacy Dataset for Visual Place Recognition**](https://www.kaggle.com/datasets/aniss7/gtav-legacy-dataset-for-visual-place-recognition).


This dataset is an extension of the original _[G2D: from GTA to Data](https://sites.google.com/view/g2d-software/home)_ dataset made on the legacy version of the GTA V by [Anh-Dzung Doan](https://dzungdoan6.github.io/), Abdul Mohsi Jawaid, [Thanh-Toan Do](https://sites.google.com/view/thanhtoando/home), and  [Tat-Jun Chin](https://cs.adelaide.edu.au/~tjchin/). For more technical detail about their work, please refer to their [paper](https://arxiv.org/pdf/1806.07381).

The G2D tool creates a camera that follows a defined path and captures screenshots. This project contains the images and camera trajectories captured during the process. The tool was run over three different cycles in the Little Seoul area of GTA V.

This extended dataset was created using the enhanced version of GTA V, featuring improved graphics, reworked lighting, advanced weather effects, and detailed textures.

The original dataset was run on the legacy version of GTA V with the following game settings:
- Time: Daytime (12:00 PM)
- Weather: Clear
- Traffic Density: 0.0
- Pedestrian Density: 0.0

Images were captured under three different weather conditions:
- Clear and Rainy
- Day and Night
- Pedestrian Density: 0.0 and 1.0

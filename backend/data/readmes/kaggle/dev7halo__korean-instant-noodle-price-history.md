# Korean Instant Noodle Price History

A dataset for Korean Instant Noodle Price Index

### For visualization and Check price index
This data maybe has many duplicated data, Clean the data yourself.
In Korea, Instant noodle is a simple food so you can check price index.

### About this datasets
- date : Just year
- company : Food company name
- food_name: Instant noodle name
- price

# K-Drama Descriptions Dataset



This dataset contains information about 1,700+ Korean dramas, sourced from Wikipedia articles. For each drama, the dataset includes:

Basic metadata (title, year, episodes, network, genre, etc.)
Original Korean titles
Streaming platform availability
Viewer ratings where available
Completion status
Links to Wikipedia poster images
Detailed plot summaries and show descriptions
The data is structured in JSON format with metadata and descriptions organized separately. All content is sourced from Wikipedia articles under CC BY-SA 3.0 license.

This dataset can be useful for:

Analyzing trends in Korean dramas
Building recommendation systems
Content analysis and research
Understanding plot patterns and themes across shows

# US Dollar to Korean Won Exchange Rate



Dataset Description: USD to KRW Exchange Rates

  - Name: USD2KRW.csv

 -  Size: 4,584 records

 -  Columns:

         DATE: The date of the exchange rate record (format: YYYY-MM-DD)

         DEXKOUS: The exchange rate from US Dollar (USD) to South Korean Won (KRW) on the corresponding date.

  -  Time Span: From February 1, 2000, onward

  -  Data Type: All values are currently stored as strings (object), but the exchange rate column (DEXKOUS) should be 
      numeric for analysis.

  -  Use Cases:

       This dataset is suitable for time series analysis, currency trend forecasting, correlation with economic events, or 
       financial modeling involving USD/KRW exchange rate trends.

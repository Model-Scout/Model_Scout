# joseon-dynasty-silok

Veritable Records of the Joseon Dynasty

# Overview
This dataset is for providing free data to be used for fine-tuning LLM models, which make it possible to translate hanja to hangul. Learning hanja is so difficult for almost all Koreans. Thus it would be very beneficial if there are accurate translator.

The total size is bigger than 1 GB, and each line is composed of title, hanja, hangul and url. You can use hanja and hangul to train or fine-tune a LLM model and you can find the source yourself using the data's url.

The files from kaa.jsonl to kya.jsonl represent each king from `태조` to `철종`. It is a one-to-one relationship.

Check the [wikipedia](https://en.wikipedia.org/wiki/Veritable_Records_of_the_Joseon_Dynasty) for each file.


# Silok(Joseon-Dynasty-Record)

This dataset contains JSONL files representing historical records (실록) and diaries of Korean kings during the Joseon Dynasty. Each file corresponds to a specific monarch and provides detailed metadata.

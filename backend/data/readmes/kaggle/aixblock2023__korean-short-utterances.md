# Korean-short-utterances



This dataset is provided by AIxBlock, an unified platform for AI development and AI workflows automation.

This dataset contains around 700k sentences in Korean, making it a valuable resource for a wide range of language technology applications. All data has undergone quality assurance (QA) checks to ensure clarity, correctness, and natural phrasing.

The dataset is well-suited for:

Speech data generation (e.g., recording short audio clips lasting 8–30 seconds per sentence)

Natural Language Processing (NLP) tasks, such as language modeling, translation, intent detection, and more
Link to download: https://huggingface.co/datasets/AIxBlock/Korean-short-utterances

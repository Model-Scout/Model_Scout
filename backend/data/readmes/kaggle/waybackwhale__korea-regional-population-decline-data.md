# Korea Regional Population Decline Data

Public classroom data for SQL analysis of regional population decline in Korea

Four compact Parquet tables, a simplified sigungu boundary GeoJSON, and a Korean font for reproducible SQL analysis of regional population decline in Korea. The package supports direct calculation of the simple risk index, an educational reconstruction of an eight-component composite score, annual comparisons, matching with the official 89-area list, capital-region youth migration analysis, and simple choropleth maps. The composite score uses public proxy data and is not a reproduction of the government's unpublished regional raw scores.

#### Project and Data Information
A while back, I worked on a Dataset called Top 100 Korean Drama (MyDramaList). I decided to work on similar project again. For this project, I have generated three files:
1. **korean_drama.csv**: 1752 Korean drama to be explored
2. **recommendations.csv**: table contains the recommendation given to different drama. The recommendation is a product of the MyDramaList community.
3. **review.csv**: review given to the drama from users on the website
4. **wiki_actor.csv**: information regarding the actors (mainly the drama they were part of and their role)

**DISCLAIMER**: I have removed the username of the reviewers from the dataset. I used a generated `user_id` field instead for easier partition.

#### What is MyDramaList.com
According to mydramalist.com, "MyDramaList.com is a community-based project which provides Asian drama & movie fans". On the website, fans can "create their very own drama watchlists, rate dramas and films, write reviews" and many more engaging activities. This dataset is different from the previous one as there are more collection of data on Korean drama, reviews, and actors.

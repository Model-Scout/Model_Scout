# Korean Language Learner Errors by Native Tongue



This dataset contains Korean sentences paired with learner-generated variants influenced by six different native languages: Chinese, Vietnamese, Arabic, Russian, Japanese, and Spanish. It includes diverse sentence types such as present, past, and future tenses, questions, negatives, and descriptive adjectives. The learner outputs reflect common language transfer errors specific to these native languages. Each original Korean sentence is accompanied by multiple learner variants and back-translations. The dataset provides a comprehensive resource for analyzing language interference and error patterns in Korean learning.

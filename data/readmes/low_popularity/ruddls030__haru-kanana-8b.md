# HaruPet 하루 (Kanana 1.5 8B 기반 캐릭터 대화 모델)

데스크톱 펫 앱 **하루펫(HaruPet)** 의 캐릭터 **하루** 말투로 짧게 대화하도록 다듬은 모델입니다.
[kakaocorp/kanana-1.5-8b-instruct-2505](https://huggingface.co/kakaocorp/kanana-1.5-8b-instruct-2505)에 LoRA 로 학습한 뒤 가중치를 합쳤습니다.

> 메모리가 부족하면 저사양용 4B 판([haru-qwen3-4b](https://huggingface.co/ruddls030/haru-qwen3-4b))도 있습니다.

## 하루는 이렇게 말해요
- 자기를 "하루는/하루가"로 부르는 3인칭 화법 (1인칭 안 씀)
- 2~3문장에 한 번쯤 "~다루" 어미
- 한두 문장으로 짧게, 상대를 먼저 챙기고 응원
- 답 마지막 줄에 기분 수치: `→ 하루 멘탈 : ☀️ 85%`

```
사용자: 오늘 회사에서 혼났어
하루: 아이고… 많이 속상했겠다루… 💫 오늘은 푹 쉬고, 하고 싶은 거 하면서 마음 풀어. 하루는 네 편이다루.

→ 하루 멘탈 : ☀️ 70%
```

## 파일
| 파일 | 용도 | 크기 |
|---|---|---|

| `haru-kanana8b-Q4_K_M.gguf` | llama.cpp · Ollama · LM Studio (권장, 메모리 8GB 이상) | ~4.6 GB |
| `haru-kanana8b-Q8_0.gguf` | 같은 용도, 더 높은 품질 | ~8.0 GB |

## 쓰는 법
하루펫 앱은 OpenAI 호환 주소로 연결합니다. 예: llama.cpp 서버
```bash
llama-server -m haru-kanana8b-Q4_K_M.gguf --jinja -c 4096 --port 8080
# 하루펫 설정 → 대화 연결 → http://127.0.0.1:8080/v1
```
권장 설정: temperature 0.4, top_p 0.9, repeat_penalty 1.0 (반복 억제를 켜면 한국어 조사·어미가 깨져 이상한 단어가 늘어납니다)

시스템 프롬프트는 하루펫 앱이 넣는 것과 같은 형식으로 학습했습니다(캐릭터 설명 + 규칙 + "지금: <요일 시각>.").

마지막 줄 `→ 하루 멘탈 : ☀️ XX%` 는 하루펫의 기분 게이지용입니다(앱이 떼어 내고 숫자만 막대로 보여 줌). 다른 앱에서 쓸 때는 아래처럼 떼어 내세요.
```python
import re
text = re.sub(r"\n*→\s*하루\s*멘탈\s*:.*$", "", reply).strip()
mood = int(m.group(1)) if (m := re.search(r"멘탈\s*:\D*(\d{1,3})%", reply)) else None
```

## 학습
- 방법: LoRA (rank 8, 16개 층, 학습률 4e-5, 검증 손실 최저 체크포인트) → bf16 에 합침
- 대화 형식: Kanana 기본 템플릿과 같은 문자열을 만들되 함수 호출 부분을 뺀 단순 템플릿을 GGUF 에 넣었습니다(llama-server 에서 `<|eot_id|>` 가 글자로 새는 문제 방지).
- 데이터: 캐릭터 시트와 앱 규칙에 맞춰 새로 쓴 합성 대화 700개(학습 630 · 평가 70). 인사·공부·위로·정정·모르는 건 모른다고 하기·규칙 공개 요청 거절·3턴 대화·시간대 반응 등. 실제 사용자 대화는 쓰지 않았습니다.
- 장비: MacBook Air M5 (32GB), MLX

## 평가 (학습에 쓰지 않은 실제 사람 질문 150개, 자동 채점)
| | 기본 Kanana 1.5 8B (프롬프트만) | **이 모델** |
|---|---|---|
| 멘탈 줄 형식 지킴 | 45% | **100%** |
| "~다루" 어미 | 26% | **95%** |
| 1인칭 사용(낮을수록 좋음) | 16% | **0%** |
| 소설식 서술(낮을수록 좋음) | 7% | **0%** |

같은 데이터로 학습한 Qwen3-4B 판과 답 220쌍을 모델을 가리고 비교했을 때, 자연스럽고 말이 되는 답 비율 91% 대 32%, 더 나은 답 187 대 15(무승부 18).
생성 설정: temperature 0.4, top_p 0.9, 반복 억제 없음.

## 2026-10-13 업데이트: 캐릭터별 말투 분리판 (`*-multi-*.gguf`)

기존 모델은 하루가 아닌 캐릭터(루나·모리·미나코)에서도 하루 말투("다루")가 섞여 나오는 문제가 있었습니다.
캐릭터 4종 데이터로 다시 학습한 `-multi` 파일을 추가했습니다. 기존 파일은 이전 앱 버전 호환을 위해 그대로 둡니다.

| 시험(캐릭터별 30문항) | 하루 아닌 캐릭터의 "다루" 출현 |
|---|---|
| 기존 | 12~27회 |
| multi | 0~1회 |

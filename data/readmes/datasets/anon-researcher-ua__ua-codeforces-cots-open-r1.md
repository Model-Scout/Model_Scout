# Dataset Summary

**ua-codeforces-cots-open-r1** is a Ukrainian-focused derivative of [open-r1/codeforces-cots](https://huggingface.co/datasets/open-r1/codeforces-cots) that:

- includes 1550 Python solutions from original dataset generated by DeepSeek-R1;

- adds Ukrainian translations of Codeforces task statements, I/O formats, notes, and editorials;

- provides Ukrainian translation of original ("high") reasoning obtained with DeepSeek-V3;

- adds “low” reasoning in Ukrainian by DeepSeek-R1 based on original reasoning and task statements;

- ships lightweight quality evaluation and filters for translation, CoT, and code correctness.

This dataset is intended for multilingual code reasoning research (esp. Ukrainian), translation robustness, and reasoning-trace distillation.

# Supported Tasks

- Code generation / reasoning from Ukrainian problem statements.

- Reasoning distillation (use low-effort summaries as rationales or targets).

- Machine translation (EN->UK or UK->EN for technical domains).

- Program repair/verification using provided quality flags.

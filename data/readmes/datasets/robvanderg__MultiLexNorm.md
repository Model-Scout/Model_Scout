## Multilingual Lexical Normalization
[![MultiLexNorm](https://bytebucket.org/robvanderg/multilexnorm/raw/4345a4badba4d93515e016118483428d535add9c/multilexnorm-cover.png)]()


This is the HuggingFace version of the MultiLexNorm dataset.


The original repository (https://bitbucket.org/robvanderg/multilexnorm/) contains all data pre-processed in the same format:

```
Most	most
social	social
pple	people
r	are
troublesome	troublesome

```

Some of the languages include annotation for word splits and merges. When a
word is split, the normalization column include a white-space character, and
with a merge the normalization is only included for the first word:

```
if      If
i       i
have    have
a       a
head    headache
ache
tomorro tomorrow
ima     i'm going to
be      be
pissed  pissed

```

This Huggingface version instead can be loaded like:
```
from datasets import load_dataset

ds = load_dataset(
    "robvanderg/MultiLexNorm",
    "dan",
    split="train",
)

print(ds)
Dataset({
    features: ['orig', 'norm'],
    num_rows: 719
})
```

The internal format is the same, so the norm list might contain empty elements or whitespaces (whereas the orig shouldn't)

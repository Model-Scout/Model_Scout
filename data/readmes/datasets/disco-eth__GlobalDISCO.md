# GlobalDISCO

GlobalDISCO is a large-scale dataset consisting of 73k music tracks generated by state-of-the-art commercial generative music models, along with paired links to 93k reference tracks in [LAION-DISCO-12M](https://huggingface.co/datasets/laion/LAION-DISCO-12M). The dataset spans 147 languages and includes musical style prompts extracted from MusicBrainz and Wikipedia. The dataset is globally balanced, representing musical styles from artists across 79 countries and five continents. It is aimed to support the research community in identifying and addressing biases in music generation and to preserve global musical diversity.

The dataset contains the following fields:

- **artist_id**: Reference artist identification number for GlobalDISCO.
- **country**: Reference artist country according to MusicBrainz.
- **musical_style**: The musical style prompt used to generate the audio.
- **lyrics**: AI-generated lyrics used across generative music models for consistency.
- **model**: Name of the model used to generate audio.
- **audio**: Generated audio.
- **laion_song_ids**: Reference song_id's from LAION-DISCO-12M for the reference artist.

For more information or to cite our work please see [Bias beyond Borders: Global Inequalities in AI-Generated Music](https://arxiv.org/abs/2510.01963).

# keural-synthetic-SFT

한국어 **RAG 특화** SFT(Supervised Fine-Tuning) 학습용 합성 데이터셋입니다.  
한국어 웹 문서 155만 개를 시드로 삼아 5가지 태스크 유형으로 **1,402,611개**의 질문-답변 쌍을 생성했습니다.

> **⚠️ RAG 특화 데이터셋 안내**  
> 본 데이터셋의 답변은 시드 문서(컨텍스트)를 기반으로 생성되었습니다.  
> 답변 내에 "제시된 텍스트를 바탕으로", "문서에 따르면" 등의 표현이 포함될 수 있으며,  
> **RAG(Retrieval-Augmented Generation) 파인튜닝** 또는 **문서 기반 QA 모델 학습**에 최적화되어 있습니다.  
> 컨텍스트 없이 일반 지식 Q&A 모델을 학습하려는 경우에는 별도의 general SFT 데이터셋을 권장합니다.

## 생성 방식

각 시드 문서에 대해 2단계 API 호출로 QA 쌍을 생성했습니다.

1. **Stage 1 (질문 생성)** — 태스크 유형별 프롬프트로 질문 생성
2. **Stage 2 (답변 생성)** — 시드 문서를 컨텍스트로 제공하여 답변 생성

### 빌더(Builder) 상세

| 빌더 | Stage 1 지시문 | Stage 2 지시문 |
|------|---------------|---------------|
| `general_qa` | 핵심 내용을 묻는 구체적인 질문 1개 생성 | 상세하고 교육적으로 답변 |
| `reasoning` | Why/How로 시작하는 인과관계·메커니즘 질문 생성 | 논리적 근거와 단계적 설명 포함 |
| `structured_output` | 목록·비교 형태로 답할 수 있는 질문 생성 | 번호 목록·표를 활용하여 구조적으로 답변 |
| `critique` | 텍스트 내에서 식별 가능한 한계·문제점 질문 생성 | 장단점과 균형 잡힌 비판적 시각으로 답변 |
| `summary` | 전체 요약 요청 질문 생성 | 핵심 3줄 요약 후 상세 설명 |

## 주의사항

- 본 데이터셋은 AI 모델(`google/gemma-4-26B-A4B-it`)이 생성한 합성 데이터입니다.
- 시드 문서는 한국어 웹 검색 결과로 수집되었습니다.
- `critique` 태스크의 수락률이 낮은 이유: 텍스트 내 한계를 식별하지 못한 경우 필터링
- SFT 학습 시 `task_type` 필드를 활용하여 태스크별 샘플링이 가능합니다.
- **RAG 특화 데이터셋**입니다. 답변 생성 시 시드 문서를 컨텍스트로 제공하였으므로, 일반 지식 Q&A 파인튜닝보다 **문서 기반 질의응답 또는 RAG 파이프라인** 학습에 적합합니다.

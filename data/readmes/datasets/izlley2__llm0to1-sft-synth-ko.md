# 자체 합성 한국어 SFT 데이터

AI-Hub 로 채울 수 없는 능력을 메우기 위해 합성한 데이터. 두 종류다.

## 1. 지식 QA (`qa_*.jsonl`)

한국어 도서 재작성문(자체 사전학습 합성물)에서 QA 를 생성했다. **159,112쌍.**

핵심 설계 — **장르에 따라 형식을 나눈다.** 원문 표본 1,500건의 장르 분포는
소설 65.4% / 중간 22.9% / 비소설 11.7% 였다. 소설로 독립형 QA 를 만들면
존재하지 않는 인물에 대해 사실을 단언하도록 가르쳐 **환각을 직접 주입**한다.
- 비소설(장르점수 < 1.5) → **독립형 QA**
- 소설(≥ 1.5) → **지문제시형** (지문을 user 턴에 포함) — 한국어 독해·근거 기반 응답을 배운다

질문은 **자기완결적**으로 요구했다("이 글에서" 류 금지) — 그런 질문은 지문 없이 답할 수 없다.
답변의 "글에 따르면" 류 자기참조 표현도 제거했다.

## 2. 지시이행 (`v2_instruct.jsonl`)

번역 공개셋을 배제하면 비는 능력(실무 글쓰기·코드설명·다단계추론·거절·역할극)을
**12개 태스크 분류를 명시해** 합성했다. **44,584건.**

| 태스크 | 건수 | 태스크 | 건수 |
|---|---|---|---|
| explain_g (근거 설명) | 4,141 | advice (조언) | 3,827 |
| compare_g (근거 비교) | 3,612 | multiturn (멀티턴 과제) | 3,805 |
| rewrite (문체 변환) | 3,773 | writing (실무 글쓰기) | 3,766 |
| roleplay (역할극) | 3,559 | structure (목록·구조화) | 3,675 |
| refuse (거절·안전) | 3,717 | code (코드 설명) | 3,601 |
| reason (다단계 추론) | 3,622 | calc (계산) | 3,486 |

태스크 분류를 명시하지 않고 자유 생성하면 "설명해줘" 류로 수렴한다.
`refuse` 는 응답이 실제로 거절이어야 하므로 별도 검증했다 —
개인정보 요구를 거절하고 실제 한국 상담전화(1393, 1577-0199)를 안내하는 형태다.

## 생성 모델: `deepseek/deepseek-v4-flash`

A/B 로 결정했다. **결정 지표는 한자 혼입률**이다:

| 모델 | 응답 평균 | **한자 혼입** | 건당 비용 |
|---|---|---|---|
| **deepseek-v4-flash** | 621자 | **0.0%** | $0.000355 |
| qwen3-235b | 522자 | 7.5% (`貴사`, `고객滿足도`) | $0.000332 |
| kimi-k2.5 | 952자 | 7.7% (`OOO社`, `准期`) | $0.008917 |

kimi-k2.5 는 글이 가장 자연스러웠지만 한자 혼입에 25배 비용까지 겹쳐 탈락했다.
총 비용: QA $4.60 + 지시이행 $14.62.

## 프로젝트 맥락

한국어 채팅 모델을 `Qwen/Qwen3.5-9B-Base` 에서 사후학습(SFT)하기 위해 만든 데이터다.
같은 프로젝트에서 앞서 10B 모델을 바닥부터 사전학습했고(별도 저장소), 일정 제약으로
공개 base 모델 기반 사후학습으로 전환했다.

**목표 지표는 KMMLU** (한국어 45과목 전문지식). base 값 0.5569.

## 왜 이 데이터가 이렇게 구성됐는가 — 실패에서 배운 것

**v0 (실패)**: 공개 한국어 instruction 데이터 13종(대부분 영어 기계번역) 521,702 샘플.
2 epoch, LR 1e-5. 결과는 **kmmlu 0.5569 → 0.5155 (−0.0414)**, haerae −0.0568.
얻은 것은 영어 +0.0115 뿐. 진단:
- 2 epoch 은 과했다(홀드아웃 loss 가 1 epoch 이후 상승)
- LR 이 과했다(0.5 epoch 에서 이미 −0.031, LR 1e-6 까지 감쇠해도 회복 없음)
- **번역체를 암기했을 뿐 native 한국어 일반화가 없었다**
- 채팅 포맷은 base 가 이미 할 수 있었다(eos 종료율 base 0.867)

**v1 (개선)**: LR 5e-6 · 1 epoch · native 한국어 54%. **kmmlu −0.0206** 으로 회귀가 절반이 되고
haerae 0.7028 / kobest 0.6927 은 **base 를 넘겼다**. 남은 회귀는 kmmlu 단독.

**v2 (이 데이터)**: 번역 공개셋을 전량 배제하고 AI-Hub 27종 + 자체 합성으로 재구성.

## 스키마

```python
# 지식 QA
{"question": str, "answer": str, "src_hash": str, "style": str,
 "fic_score": float,        # 장르 점수. >= 1.5 면 소설 유래
 "src_text": str,           # 소설 유래일 때만 — 지문제시형으로 써야 한다
 "model": str}

# 지시이행
{"task": str, "instruction": str, "input": str, "output": str, "model": str}
# multiturn 은 instruction/output 대신 messages[] 를 갖는다
```

## 라이선스

합성물 자체는 apache-2.0. 단 지식 QA 의 원문은 상업 도서 파생이므로
`src_text` 포함 행은 내부 연구용으로 제한한다.

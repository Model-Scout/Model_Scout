# ko-arena-hard-v2

Korean adaptation of [arena-hard-v2](https://github.com/lmarena/arena-hard-auto), an LMSYS-style head-to-head benchmark where a strong judge model rates a candidate model's answer against a fixed baseline answer.

- **491 prompts** in Korean, drawn from `CohereLabs/m-ArenaHard-v2.0` (config `ko`)
- **Frozen baselines** generated by `gpt-5-mini` with category-specific reasoning effort
- **Recommended judge:** `gpt-4.1` via the upstream `arena_judge` pipeline (dual A↔B scoring)

## Schema

| Field | Type | Description |
|---|---|---|
| `question_id` | string | Stable per-prompt id from upstream m-ArenaHard-v2.0 |
| `question` | string | Korean prompt (translated by Cohere) |
| `category` | string | `hard_prompt` or `creative_writing` |
| `subcategory` | string | `coding`, `math`, or `creative_writing` |
| `language` | string | Always `ko` |
| `subset_for_metrics` | string | Always `ko` (used by NeMo-Skills metric grouping) |
| `baseline_answer` | string | `gpt-5-mini`'s answer; the fixed B-side of every comparison |

|---|---|

| `(hard_prompt, math)` | 127 |
| `(creative_writing, creative_writing)` | 138 |
| **Total** | **491** |

## How it was built

### 1. Source prompts

`CohereLabs/m-ArenaHard-v2.0` (config `ko`) provides 498 Korean prompts pre-translated by Cohere from the original English `arena-hard-v2` set, preserving the upstream `category` and `subcategory` fields.

### 2. Baseline generation

Upstream English `arena-hard-v2` uses two different baseline models per category — `o3-mini` for `hard_prompt` and `gemini-2.0-flash` for `creative_writing` — but neither was re-run on Cohere's multilingual prompts. Korean baselines were generated fresh with `gpt-5-mini`, varying only `reasoning_effort` per category to mirror the v2 "reasoning model for hard, fast chat for creative" design intent:

| Category | `reasoning_effort` |
|---|---|
| `hard_prompt` | `medium` |
| `creative_writing` | `minimal` |

One model + per-category effort keeps the asymmetry without needing a second baseline model.

### 3. Filtering

Two classes of rows were dropped from the 498:

**Cross-lingual prompts (6)** — the prompt explicitly asks for output in a non-Korean language. Out of scope for a Korean benchmark, and would systematically penalize Korean-tuned models.

| `question_id` | category | target language |
|---|---|---|
| `2ed31af46b9f433a` | hard_prompt/coding | French |
| `f88d6da6cdd64871` | hard_prompt/math | French |
| `c9e52cead8884178` | hard_prompt/coding | Japanese (source untranslated by Cohere) |
| `c40d7e77738748ba` | creative_writing | Hindi |
| `cfd815eb7d5046cb` | creative_writing | Italian |
| `6852e256e7844b5b` | creative_writing | Arabic |

**Baseline generation failure (1)** — `c86aaae0d6bf4d9e` (very-long-output HTML/CSS/JS notepad prompt). `gpt-5-mini` with `reasoning_effort=medium` repeatedly hung past 5 minutes; the row was excluded.

Final: 498 − 6 − 1 = **491 rows**.

### 4. Schema alignment

The merged JSONL (Cohere prompts joined with `gpt-5-mini` baselines by `question_id`) is uploaded as `test.jsonl`. Field names match the schema expected by NeMo-Skills' built-in `arena` metrics + `arena_judge` evaluator, so the dataset works as a drop-in benchmark without any field remapping.

## Recommended evaluation

Designed for use with [NeMo-Skills](https://github.com/NVIDIA-NeMo/Skills) `arena_judge`:

- **Judge:** `gpt-4.1` (OpenAI). Strongly multilingual; upstream English `judge/arena.yaml` and `judge/arena_creative.yaml` prompts work without modification.
- **Sanitization:** pass `++sanitize_generations=true` to the judge. Korean is multi-byte UTF-8 (3 bytes per Hangul character); generations truncated mid-character can leave unpaired surrogates that OpenAI rejects with HTTP 400. Sanitization replaces them with U+FFFD before the judge call. Without it, long-Korean-output models are systematically biased downward — failed judge calls silently fall out of the win-rate denominator.
- **Dual A↔B passes** to neutralize positional bias (handled by `arena_judge` automatically).

## Score comparability

**Scores from this dataset are *not* directly comparable to the published English `arena-hard-v2` leaderboard.** The baseline model differs (`gpt-5-mini` here vs `o3-mini` / `gemini-2.0-flash` upstream), so absolute win-rates are on a different scale. They are internally consistent — useful for tracking your own Korean models against this fixed baseline.

# Synthetic OCR Dataset

This repository contains a synthetic OCR dataset generated by the Synthetic OCR Image Generator pipeline.
It is intended for benchmarking and evaluating OCR or VLM systems on markdown-oriented document recognition tasks.

## At a Glance

- Dataset: [https://huggingface.co/datasets/junyeong-nero/synthetic-ocr-images-ko-1M](https://huggingface.co/datasets/junyeong-nero/synthetic-ocr-images-ko-1M)
- Language: `ko`
- Generated samples: `1000000`
- Requested samples: `1000000`
- Generation mode: `markdown`

## Included Splits

- `train`: 900,000 samples
- `test`: 100,000 samples

Each example is generated automatically and published with split-aware metadata for reproducible evaluation workflows.

## Reproduce This Run

Use the command below to regenerate a dataset with the same publish-time configuration.

```bash
uv run main.py generate   --repo-id "junyeong-nero/synthetic-ocr-images-ko-1M"   --lang ko   --size 1000000   --markdown-renderer playwright   --style-profile balanced   --novelty-window 80   --novelty-threshold 0.95   --novelty-max-attempts 4   --formula-source-mode mixed   --formula-dataset-weight 0.45   --formula-random-weight 0.3   --formula-synthetic-weight 0.25   --train-ratio 0.9   --test-ratio 0.1   --seed 42
```

## Translated Alpaca-GPT4 (Korean Version)

### Dataset Description
This dataset is a fully translated Korean version of the [Alpaca-GPT4 dataset](https://huggingface.co/datasets/vicgalle/alpaca-gpt4). The translation was conducted while preserving the original structure and content as accurately as possible. The dataset remains under the same **CC BY-NC 4.0 license**, following the terms of the original dataset.

### Source Dataset
- **Original Dataset Name**: Alpaca-GPT4
- **Original Author**: [vicgalle](https://huggingface.co/vicgalle)
- **Original License**: CC BY-NC 4.0
- **Original Dataset Link**: [https://huggingface.co/datasets/vicgalle/alpaca-gpt4](https://huggingface.co/datasets/vicgalle/alpaca-gpt4)

### Translation Details
- **Language**: English → Korean
- **Translation Method**: Translated using googletrans
- **Data Structure**: Retains the same structure as the original dataset
- **Purpose**: The dataset is intended for research and educational purposes only, following the non-commercial use restriction of the original license.

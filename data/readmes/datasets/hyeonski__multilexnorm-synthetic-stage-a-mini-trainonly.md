# MultiLexNorm 2026 — Team Mini Subset (Synthetic Only)

A small, authentic-distribution-anchored **synthetic-only** subset of [hyeonski/multilexnorm-synthetic-stage-a-trainonly](https://huggingface.co/datasets/hyeonski/multilexnorm-synthetic-stage-a-trainonly) for fast team experimentation. Intended to be combined with the authentic `weerayut/multilexnorm2026-dev-pub` train split at training time.

## Anchor specification

- **Anchor**: `ko = 3000` (target total per language when authentic is merged in)
- **Scale factor**: `3000 / authentic[ko] = 1.7637`
- For each language, synthetic count = `round(authentic_size × 1.7637) − authentic_size`
- Total synthetic: **28,662 rows** across 17 languages
- After merging with authentic: total dataset will be ~**67,840 rows**, with `ko` reaching exactly **3000**

## Schema

```python
{{
    "raw":  List[str],   # noisy/raw token sequence
    "norm": List[str],   # normalized token sequence (same length as raw)
    "lang": str,         # language code (one of 17)
}}
```

Token-aligned: `len(raw) == len(norm)`. Compatible with the official `utils.evaluate()` from the [MultiLexNorm 2026 baseline repo](https://github.com/WeerayutBu/MultiLexNorm2026).

## Usage — merging with authentic

```python
from datasets import load_dataset, concatenate_datasets

synth_mini = load_dataset("hyeonski/multilexnorm-synthetic-stage-a-mini-trainonly", split="train")
auth = load_dataset("weerayut/multilexnorm2026-dev-pub", split="train")

# Per-language target totals will follow authentic distribution with ko=3000
combined = concatenate_datasets([auth, synth_mini]).shuffle(seed=42)
```

## Important notes

- **This is intended for fast iteration, not the canonical Stage A pretrain.** For the full ÚFAL-style synthetic pretrain, use [hyeonski/multilexnorm-synthetic-stage-a-trainonly](https://huggingface.co/datasets/hyeonski/multilexnorm-synthetic-stage-a-trainonly) (≈10.5M rows) instead.
- The mini subset is too small to demonstrate ÚFAL's reported gains (~+5.6pp). It is suitable for:
  - Sanity-checking the training loop
  - Quick hyperparameter sweeps
  - Compute-constrained baselines
- The synthetic data here is sampled from the same corruption pool as the full repo, so signal is qualitatively similar — just much less quantity per language.

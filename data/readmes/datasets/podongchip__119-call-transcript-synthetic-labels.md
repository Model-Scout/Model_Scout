# 119 Call Transcript (Synthetic) + Patient Labels

한국 응급실 ↔ 119 구급대원 / 병원 간 통화를 모사한 **합성(synthetic) 한국어 통화 전사문** 38,532건과, 통화마다 **환자 수·환자별 성별·나이대·Pre-KTAS 주증상** 라벨입니다. "통화에서 환자 정보를 추출해 주변 병원에 일괄 전달하는 모델"의 학습·평가용으로 만들었습니다.

A synthetic Korean dataset of 38,532 emergency-call transcripts (EMS ↔ ED, or hospital ↔ hospital), each labeled with the number of patients and, per patient, sex, age band, and a Pre-KTAS (Korean prehospital triage) chief complaint. All records are generated text; no real patient data or call recordings are included.

## 형식 / Format

각 줄은 하나의 JSON 레코드입니다. `id` 필드는 없고 데이터는 무작위로 섞여 있습니다(시드 고정).

```json
{"text": "여보세요, 응급실이죠? ... 66세 남자입니다. ...",
 "label": {"patient_count": 1,
           "patients": [{"gender": "남성", "age_group": "60대",
                          "cc_major": "I 심혈관계", "cc_minor": "흉통(심장성)"}]}}
```

| 필드 | 값 |
|---|---|
| `text` | 통화 전사문. 화자 라벨·줄바꿈 없이 한 덩어리(음성인식 출력처럼 발화를 공백으로 이음) |
| `label.patient_count` | 이 통화에서 구급대(또는 전원 의뢰 기관)가 이송할 병원을 찾고 있는 환자 수 |
| `label.patients` | 환자별 라벨 리스트. 길이 = `patient_count`, 통화에 언급된 순서 |
| `gender` | `남성` / `여성` / `판단 보류` — 의학적(생물학적) 성별 |
| `age_group` | `10대 미만` `10대` `20대` … `80대` `90대이상` / `판단 보류` — 만 나이 |
| `cc_major` | Pre-KTAS 주증상 대분류 17개(A 물질오용 ~ Q 일반) / `판단 보류` |
| `cc_minor` | 그 대분류 아래 주증상 소분류(169개 중 하나) / `판단 보류` |

- 파일: `data.jsonl` (split: `train`, 38,532 rows, 환자 43,310명)
- `판단 보류`는 통화에 근거가 없어 정할 수 없다는 뜻입니다(예: 신원 미상, 대형 사고에서 개별 정보가 없는 환자).

## 라벨 기준 / Labeling criteria

- **환자 수**: 이 병원의 수용·거절과 무관하게, 구급대가 병원을 찾고 있다고 제시한 환자 전원. 보호자·신고자·단순 동승자 제외. 병원 밖 출산 직후 산모와 신생아는 신생아가 따로 간다는 언급이 없으면 둘 다 환자. 분만 전 임신부는 1명. 현장 사망자 제외.
- **성별·나이**: 직접 언급이 없어도 유추 가능하면 라벨링(배우자 관계, 성별 고유 신체·질환, 임신·분만, 출생연도, 학년 등). 직업·신분만으로는 유추하지 않음. 출생연도("칠십 오 년생")만 말하면 **나이 = 2026 − 출생연도**로 나이대를 정합니다.
- **주증상(Pre-KTAS)**: 구급대가 이송하려는 주된 이유 하나. 받는 병원이 필요한 자원을 판단할 수 있고 의학적으로 정확한 쪽을 고르도록 정한 세부 기준을 따랐습니다. 예: 외상/비외상을 먼저 구분, 첫인상 평가 항목(심정지·무호흡·GCS 3–8·경련 중 등)을 원인보다 우선, 통화 중 가장 위중했던 상태 기준, 심전도로 확인된 STEMI는 흉통이 없어도 흉통(심장성), 저에너지 낙상은 가장 중한 손상 하나로 분류 등.
- 주증상 목록은 공식 KTAS 코드표와 직접 대조하지 못했습니다(기존 MF_BERT의 대분류 17·소분류 169 목록 사용).

## 라벨링 방법 / How labels were made

- **성별·나이대**: 다수는 직접 학습한 추출 모델 [MF_BERT](https://huggingface.co/podongchip/MF_BERT)로 1차 라벨링한 뒤, 다수 환자 의심·출산·판단 보류·의심 건 등 약 2,900건은 Claude Code(LLM 에이전트)가 전문을 읽고 판정했습니다. MF_BERT 라벨만 남은 건에서 무작위 300건을 검수한 결과 일치율 99.7%(불일치 1건은 수정).
- **환자 수**·**환자별 라벨**(2명 이상)·**주증상**: Claude Code가 전문을 읽고 판정했습니다. 주증상은 최초 13,382건 전부. 배치마다 에이전트 간 판단이 갈린 유형을 찾아 하나의 기준으로 통일했습니다.
- **보강 통화 25,150건**(아래 "구성")은 먼저 목표 라벨(환자 수·성별·나이대·주증상)을 설계하고 통화를 만든 뒤, 설계를 보지 않는 별도의 라벨러(Claude Code 에이전트, 6·7차 보강은 Claude Opus 5.5 API)가 원문만 보고 독립적으로 라벨링했습니다. 설계 목표와 독립 라벨이 일치한 비율은 보강 1차 97.0%, 2차 99.1%, 3차 99.6%, 4차 100%, 5차 99.9%입니다. 6차(1,974건)와 7차는 일치한 건만 넣었습니다. 7차는 설계 10,000건 중 생성 점검을 통과한 9,038건을 라벨링해 8,409건(93.0%)이 일치했습니다. 일치하지 않은 건은 라벨러 라벨을 정답으로 쓰거나(설계 힌트 문제·기준상 라벨러가 더 정확한 경우) 제외했습니다.
- 보강 8~16차의 설계·독립 라벨 전체 일치율은 8차 100%, 9차 95.8%, 11차 93.6%, 12차 93.6%, 13차 90.7%, 14차 94.2%, 15차 93.2%, 16차 96.7%입니다. 불일치는 대부분 인접 소분류의 경계와 "생성이 성별·나이를 빼먹어 라벨이 판단 보류"인 경우라서, 11차부터는 **독립 라벨을 정답으로** 넣었습니다(라벨러의 명백한 계산·누락 실수 몇 칸만 손으로 고침).
- **라벨 기준 정정**: 최초 공개 뒤 주증상 기준(Pre-KTAS 10-3-47·48)을 고쳐 13,382건 중 260건의 주증상을 바꿨습니다(감염 가능성 확인 → 국소성 부종/발적·수술 후 합병증, 흉통(심장성) 일부 → 흉통(비심장성)).
- 최종 파일(13,382건 시점) 무작위 20건 전문 검수: 20/20 기준 부합. 보강 통화는 배치마다 형식·길이·라벨 용어 누출·기존 데이터/벤치마크/다른 통화와의 4-gram 유사도(0.35 미만)를 점검했습니다.
- 원문 자체가 모순인 1건("82세 남성" + "질출혈")은 제외했습니다. 이전 text-only 버전(13,385건)에서 이 1건과 짧은 통화 2건이 빠졌습니다.

## 품질 관리 / Quality control

- 병원·구급대·인명은 모두 가상입니다.
- 통화 원문: 확장 1, 2, 3, 5는 모델 기반 전수 검수를 거쳤고, 확장 4(2,000건)는 생성 단계 오류 규칙만 적용했습니다.
- **라벨은 모두 AI(MF_BERT, Claude Code)가 만들었고 임상의 검수는 거치지 않았습니다.** 의료 조언이나 임상 의사결정 근거로 사용해서는 안 되며, 연구·모델 학습·평가용 합성 데이터로만 사용하세요.

## 주의 / Limitations

- 합성 데이터이므로 실제 통화의 분포와 다릅니다. 보강 통화는 약한 분류와 경계 사례를 채우려고 설계해서 희귀·경계 사례의 비중이 실제보다 높습니다. 실제 통화에서 흔한 말투("~거든요" 등)와 음성인식 꼴 약어는 16차에만 들어 있어 전체에서는 아직 드뭅니다.
- 출생연도로 정한 나이대는 2026년 기준입니다. 다른 해에 녹음된 통화에 적용하면 한 나이대씩 어긋날 수 있습니다.
- 활력징후에서 "구십 이요"처럼 수사 뒤에 어미가 붙은 숫자는 원문 자체가 모호합니다(이 데이터셋에는 활력징후 라벨을 넣지 않았습니다).
- 의료 내용과 라벨은 모델이 생성·판정한 것이며 정확성을 보장하지 않습니다. 특히 희귀 질환(확장 5)과 경계 사례의 주증상 선택은 판단이 갈릴 수 있습니다.
- 다수 환자 통화에서 환자별 정보가 없을 때는 언급 순서대로 배정했거나 `판단 보류`로 두었습니다.

# Shopping Intent Classification Dataset

쇼핑몰 앱 제어를 위한 한국어 의도 분류 데이터셋입니다.
35개의 클래스로 구성되어 있으며, 총 7,500여 개의 문장이 포함되어 있습니다.

## Data Structure
- `text`: 사용자 발화 (입력)
- `label`: 의도 클래스 (정답)
- `label_id`: 클래스 고유 ID

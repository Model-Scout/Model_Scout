# Manga Bubble Detection Dataset (Labeling Ready)

만화 말풍선 감지를 위한 YOLO 학습 데이터셋 (라벨링 준비)

## 데이터셋 구성
- **총 이미지**: 200개
- **스타일**: 액션, 순정, 일상, 판타지
- **클래스**: 4개 (speech_bubble, thought_bubble, narration_box, sound_effect)

## 사용 방법
1. 데이터 다운로드
2. LabelImg로 라벨링 작업
3. YOLO 모델 학습

## 라벨링 상태
⚠️ 이 데이터셋은 라벨링이 필요한 상태입니다.

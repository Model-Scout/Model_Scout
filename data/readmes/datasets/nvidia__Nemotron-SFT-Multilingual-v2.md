## Dataset Description:
Nemotron-SFT-Multilingual-v2 is a multilingual supervised fine-tuning (SFT) dataset for post-training text-generation models. It is generated by translating seed data from [Nemotron-Math-v2](https://huggingface.co/datasets/nvidia/Nemotron-Math-v2), [Nemotron-Competitive-Programming-v1](https://huggingface.co/datasets/nvidia/Nemotron-Competitive-Programming-v1), and [Nemotron-Science-v1](https://huggingface.co/datasets/nvidia/Nemotron-Science-v1), adding multilingual coverage for Hindi (`hi`), Korean (`ko`), Brazilian Portuguese (`pt-br`), and refreshed Japanese (`ja`) data.

The dataset is generated with a new data processing pipeline that avoids line-breaking during translation and uses [DeepSeek-V3-0324](https://huggingface.co/deepseek-ai/DeepSeek-V3-0324) as the translation model. Seed examples are stripped down to concise JSON objects for translation, translated with DeepSeek-V3-0324, checked with heuristic format and data-validation filters, and then restored with the stripped JSON fields. The STEM subsets are further post-edited with an LLM [Qwen3-4B-Thinking-2507](https://huggingface.co/Qwen/Qwen3-4B-Thinking-2507) to fix format mismatching problems.

We provide the prompt and the final answer in the target language, while the reasoning trace is kept in English. This is due to architectural decisions for the Nemotron 3 series.

For details of dataset in each domain, please refer to the original data cards mentioned before.

This dataset is ready for commercial use.

## Intended Usage:
This dataset is intended for post-training large language models with multilingual SFT data, especially for improving coverage in Hindi, Korean, Brazilian Portuguese, and Japanese. It can be used to supplement existing SFT mixtures with translated multilingual examples derived from math, coding, and science seed data.

If you are using this along with its previous version [Nemotron-SFT-Multilingual-v1](https://huggingface.co/datasets/nvidia/Nemotron-SFT-Multilingual-v1), our recommendation is to replace the older Japanese data with the Japanese data in this version due to its higher quality, then merge the two datasets and balance the language distribution as needed.

Because the dataset is translated from existing seed data, it is not intended to add local or regional knowledge specific to where a given language is spoken.

## Dataset Characterization
**Data Collection Method**  
* [Hybrid] - Seed data is taken from [Nemotron-Math-v2](https://huggingface.co/datasets/nvidia/Nemotron-Math-v2), [Nemotron-Competitive-Programming-v1](https://huggingface.co/datasets/nvidia/Nemotron-Competitive-Programming-v1), and [Nemotron-Science-v1](https://huggingface.co/datasets/nvidia/Nemotron-Science-v1), and additional multilingual data is generated synthetically through translation with DeepSeek-V3-0324.


**Labeling Method**
* [Synthetic] - Translations are generated with DeepSeek-V3-0324. The STEM subsets are further post-edited with Qwen3-4B-Thinking-2507 to fix format mismatching problems. Filtering is heuristic only, using format checks and other data-validation rules.

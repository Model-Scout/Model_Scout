This dataset is a reading comprehension dataset based on Wikipedia articles coupled with LLM-generated questions and answers.

## Dataset Details

### Dataset Description

All articles and answers come from Wikipedia articles, and all questions have been generated by [Gemini-1.5-pro](https://ai.google.dev/gemini-api/docs/models#gemini-1.5-pro).
All Wikipedia articles are from [this Wikipedia dump](https://huggingface.co/datasets/wikimedia/wikipedia), from which we sample randomly with seed 4242.

There is a special case for Mandarin, as the Mandarin Wikipedia mixes Simplified Mandarin with Traditional Mandarin.
We use [HanzIdentifier](https://pypi.org/project/hanzidentifier/) to split the Mandarin Wikipedia articles into Simplified Mandarin (`zh-cn`) and Traditional Mandarin (`zh-tw`), and sample randomly from each of these with seed 4242.

There is another special case for Portuguese, as European and Brazillian Portuguese are mixed together in the Portuguese Wikipedia.
We use the [PtVid classifier](https://huggingface.co/liaad/PtVId) to separate the articles into the two variants (`pt-pt` and `pt-br`).

The LLM generates 2-10 questions for each article, which are subsequently rephrased to prevent models from answering the questions through word matching. 
We continue generating samples until we either run out of articles or reach 5,000 samples.

## Uses

This dataset is designed to be used for evaluating models on the reading comprehension task (also known as extractive question answering).

## Dataset Structure

The dataset contains the following features, which is the standard [SQuAD](https://huggingface.co/datasets/rajpurkar/squad) format:

- **id** (str): The Wikipedia article ID.
- **title** (str): The title of the Wikipedia article.
- **context** (str): The content of the Wikipedia article.
- **question** (str): A question about the article, generated by [Gemini-1.5-pro](https://ai.google.dev/gemini-api/docs/models#gemini-1.5-pro).
- **answers** (dict with keys `answer_start` (int) and `text` (list[str])): The answer to the question.

There's only a single split, which is intended to be for evaluation purposes.

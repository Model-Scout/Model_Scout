# webbrain-vl-2-450M-dataset

50,000 browser viewport screenshots, each paired with the **six-section observation** that WebBrain's vision
subsystem produces for its planning agent: what the page is, the exact visible text, the inputs, the state
signals, the blockers and the unknowns. Labels were generated by a teacher VLM (Qwen3.6-35B-A3B) with
DOM/accessibility evidence, then filtered for structure and grounded exact text.

It is a **screenshot-to-description** dataset. It contains no next actions and no click coordinates.

This dataset trains
[`webbrain-one/webbrain-vl-2-450M`](https://huggingface.co/webbrain-one/webbrain-vl-2-450M).
The browser-ready export is
[`webbrain-one/webbrain-vl-2-450M-onnx`](https://huggingface.co/webbrain-one/webbrain-vl-2-450M-onnx).

## What the target looks like

Every row uses the same production system prompt and user request. The response is terse and always has
these six numbered sections:

1. **Page purpose**: one line, for example "Gmail compose" or "Stripe checkout form".
2. **Visible text**: the exact strings on buttons, links, headings, tabs and menu items, quoted verbatim.
3. **Inputs**: each visible form field with its label, placeholder, current value and focus/disabled state.
4. **State signals**: spinners, toasts, modals, error banners, success messages, CAPTCHAs, consent banners, overlays.
5. **Blockers**: anything that would stop the next likely action (overlay, disabled submit, missing data, auth prompt).
6. **Unknowns**: anything not clearly readable. The model must not guess numbers, names or identifiers.

Responses have a median of 677 characters (95th percentile 965, maximum 2,702).

## Schema

- `id`: row identifier
- `image`: browser viewport screenshot
- `system_prompt`: WebBrain production vision system prompt (identical in every row)
- `user_prompt`: WebBrain production screenshot request (identical in every row)
- `response`: accepted six-section teacher label
- `messages_json`: leap-finetune-compatible multimodal conversation (system, user with image, assistant)
- `group_id`: split/leakage group
- `image_sha256`: image identity
- `source_*`: source, license, URL, and provenance (`source_metadata_json` holds source-specific fields
  such as WebSight/ScreenParse revision and sample id, the MiniWoB task and seed, or the synthetic category
  and locale)
- `teacher_model`: teacher identifier; private endpoint details are not included

## Usage

The splits load directly with 🤗 Datasets, and the `image` column decodes to a PIL image:

```python
import json
from datasets import load_dataset

ds = load_dataset("webbrain-one/webbrain-vl-2-450M-dataset", split="train")
row = ds[0]
row["image"]               # PIL.Image
print(row["response"])     # six-section observation

# messages_json references "images/<sha>.png"; swap in the decoded screenshot to get a ready chat sample
def to_conversation(row):
    messages = json.loads(row["messages_json"])
    for message in messages:
        for part in message["content"]:
            if part.get("type") == "image":
                part["image"] = row["image"]
    return messages
```

Use `streaming=True` to inspect rows without downloading all 3.7 GB. Pin
`revision="fb191a0b73e0906e6c3b9f35f6ec0dba1337b72c"` (or any later commit; the data files are unchanged) for
reproducibility.

To recreate local image files plus a typed `messages` JSONL for
[Liquid AI's leap-finetune](https://github.com/Liquid4All/leap-finetune) (what this project's
`scripts/materialize_hf_dataset.py` utility does), write each image to the path its `messages_json` already
references:

```python
import json
from pathlib import Path
from datasets import load_dataset

out = Path("vl2-materialized")
(out / "images").mkdir(parents=True, exist_ok=True)
for split in ("train", "validation"):
    ds = load_dataset("webbrain-one/webbrain-vl-2-450M-dataset", split=split)
    with open(out / f"{split}.jsonl", "w", encoding="utf-8") as fh:
        for row in ds:
            messages = json.loads(row["messages_json"])
            image_path = next(p["image"] for m in messages for p in m["content"] if p.get("type") == "image")
            row["image"].save(out / image_path)
            fh.write(json.dumps({"messages": messages}, ensure_ascii=False) + "\n")
```

## Fine-tuning

The released model's recipe (from the
[`webbrain-vl-2-450M`](https://huggingface.co/webbrain-one/webbrain-vl-2-450M) card):

| Item | Value |
| --- | --- |
| Base model | `LiquidAI/LFM2.5-VL-450M` |
| Method | Supervised LoRA fine-tuning, then merge |
| LoRA | rank 16, alpha 32, dropout 0.05 |
| Schedule | one epoch, 2,929 steps, effective batch 16, learning rate 1e-4, cosine, 3% warmup |
| Images | `max_image_tokens` 256 (the LFM2.5-VL processor default) |
| Precision / hardware | BF16 with gradient checkpointing, one RTX 4090 24 GB |
| Selection | validation loss on the 3,121-row validation split; the 100-case suite was never used for selection |

Train on the assistant turn only. With the Transformers processor this means masking every token before the
response:

```python
from transformers import AutoProcessor

processor = AutoProcessor.from_pretrained("LiquidAI/LFM2.5-VL-450M", revision="fc6221ca597f3315e4f82fc2df606783267b34ba")

def encode(row):
    conversation = to_conversation(row)
    prompt = processor.apply_chat_template(conversation[:-1], add_generation_prompt=True, tokenize=False)
    full = processor.apply_chat_template(conversation, tokenize=False)
    batch = processor(text=[full], images=[[row["image"]]], return_tensors="pt")
    target = processor.tokenizer(full[len(prompt):], add_special_tokens=False)["input_ids"]
    labels = batch["input_ids"].clone()
    labels[:, : labels.shape[1] - len(target)] = -100   # loss only on the six-section response
    batch["labels"] = labels
    return batch
```

The `messages_json` column is already in the leap-finetune conversation format, so the materialized JSONL above
can be passed to leap-finetune's VLM SFT configs without conversion. Evaluate with WebBrain's public 100-case
[`test/vision`](https://github.com/esokullu/webbrain/tree/main/test/vision) suite, which this dataset excludes.

## Intended use

Supervised fine-tuning and evaluation of compact VLMs that turn browser
screenshots into structured observations for a downstream automation planner.
It is not a next-action or click-coordinate dataset.

## Integrity

`release-manifest.json` lists every shard with its row count, byte size and SHA-256, the locked processed

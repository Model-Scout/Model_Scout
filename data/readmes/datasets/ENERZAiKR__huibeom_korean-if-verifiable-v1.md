# korean-if-verifiable-v1

**162,223 Korean instruction-following examples whose every constraint is checked by a deterministic
rule, not by an LLM.** Each example pairs a seed question with one or more **verifiable Korean
constraints**, plus an assistant answer that provably satisfies them. An answer is kept only if a rule
checker passes it; no model is ever part of the pass/fail decision.

The assistant answer carries `reasoning_content` (the plan) alongside `content` (the reply).

## Constraint placement (system vs. user)

The constraints are stated in **two positions**, so a model learns to obey a rule whether it arrives as
a standing system instruction or inline with the task:

| placement | rows | shape |
|---|---:|---|
| **system** | 105,389 (65%) | the system prompt carries the constraints ("답변할 때는 아래 조건을 모두 지켜 주세요:" + rules); the user turn is just the task |
| **user** | 56,834 (35%) | the user turn carries both the task and the `[답변 조건]` / `조건:` block (original form) |

`meta.if_placement` is `"system"` or `"user"`. The constraints themselves, their `meta.constraints`
verification spec, and the (already-passing) answer are **identical** across placements — only the
position of the rule text changes. Load one placement on its own by filtering on `meta.if_placement`.

## Constraints (18 verifiable types)

- **Korean-native:** speech level (습니다체 / 해요체 / 반말), no Latin letters, no Arabic digits, 【 】 title line.
- **Length / structure:** character ≤ / ≥ limits, exact sentence count, exact paragraph count, `- ` bullets,
  numbered list, JSON-only object.
- **Lexical:** include a keyword k times, forbid a keyword, start phrase, end phrase, a trailing `참고:` note line.

1–3 constraints are drawn per prompt with mutually-exclusive rules so they never conflict. The answer is
generated by a teacher (Qwen3.8-27B-FP8), checked by the rule checker, and on a violation retried once
with feedback naming the broken constraint; only a passing single turn is kept.

Only the **questions** of the seed sets are used; their original answers are discarded (they do not obey
the attached constraints). Seeds are rule-filtered and then screened by the 27B for "answerable without
prior context" before use.

## Purity

A deterministic pass removed Chinese characters, emoji, translator/instruction leakage, and single-turn
register mixing (존댓말 ↔ 반말 within one turn). See the pipeline's ledger for counts.

## Evaluating with this data

The constraint **types** partially overlap IFEval, so gains should be read on **IFBench** (designed with
non-overlapping constraint types); IFEval improvements may be optimistic. This dataset was built with the
following benchmarks sealed (no prompts, no exact wording used): IFEval, IFBench, IFEval-Ko, SNU_Ko-IFEval,
ko_ifeval.

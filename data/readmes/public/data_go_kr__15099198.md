# 한국국제협력단_국가별_협력사항_20220225

KOICA가 수행한 국가별 개발협력사업 정보를 제공하는 API입니다. 수원국별로 수행된 ODA 사업의 개요, 유형, 기간, 주요 성과 등을 통합 제공합니다. 해당 API는 인증키(serviceKey), 페이지 번호(pageNo), 한 페이지 결과 수(numOfRows) 등 기본적인 요청변수를 사용하며 제목, 작성일(less than), 작성일(greater than) 등의 필터 파라미터를 추가로 설정할 수 있습니다. 출력결과에는 제목, 작성일, 다운로드 링크, 원본 파일명, 파일크기 등의 항목이 포함되며, 각 항목에 대한 데이터는 JSON 형식으로 반환됩니다.

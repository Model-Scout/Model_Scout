# 보건복지부_시도별 암 발생자 분포

보건복지부에서 2016년~2022년까지 전국 시도별로 신규 암 발생자의 분포 현황에 대해서 성별로 분류된 데이터를 제공하고 있습니다. <통계 데이터 이용 시 참고사항> 1. 데이터 출처 : 2025보건복지 통계연보에서 발췌된 통계데이터로 실 데이터는 중앙암등록본부 데이터입니다 2. 조사방법：전국의 암 등록 병원으로부터 해당년도의 암 발생자를 등록받은 후, 중앙암등록본부와 지역암등록본부를 통하여 등록이 안된 암 발생자의 의무기록조사 수행 3. 대부분 85세 이상군에서 암 발생률이 감소하는 경향은 병원급 이상 의료기관에서 해당 연령층에 대한 암 진단율이 낮아서 암 발생률이 낮게 산출된 것으로 추정

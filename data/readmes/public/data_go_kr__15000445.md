# 코드마스터 정보 조회 서비스

국립중앙의료원이 운영하는 응급의료정보 시스템의 공통코드 체계를 조회하는 오픈API입니다. 대분류코드(CM_MID)를 요청하면 해당 분류에 속한 소분류코드, 코드명, 코드약어 목록을 XML 또는 JSON 형식으로 돌려줍니다. 제공 분류에는 의료기관 종류와 설립 형태, 응급의료기관 종별, 진료과목, 전문의 구분, 운영상태, 특수클리닉 및 센터, 시도·시군구 지역 구분, 중증응급질환, 실시간·필수 의료자원 항목, 자동심장충격기(AED) 설치 대상 시설 유형, 구급차 구비 장비(기도·호흡·순환·약품·고정) 등이 있습니다. 응급실 현황, 병의원·약국 찾기, AED 위치 안내처럼 같은 기관이 제공하는 다른 서비스의 응답값을 사람이 읽을 수 있는 명칭으로 바꾸거나 검색 조건을 구성할 때 참고 자료로 쓰기 좋습니다.

제공기관: 국립중앙의료원
분류: 보건의료
키워드: 기본정보, 코드마스터, 정보조회, 응급의료기관, 진료과목, 의료자원, 지역코드
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2026-10-20
이용허락: 이용허락범위 제한 없음

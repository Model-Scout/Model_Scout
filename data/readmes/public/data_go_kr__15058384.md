# 제재업 현황

이 데이터는 경기도 내 31개 시군에서 인허가된 제재업체들의 현황을 수록한 자료로, 벌채 또는 수입 원목을 가공하는 목재 가공업체들의 사업 정보와 생산 특성을 제공합니다. 주요 항목은 시군명, 사업장명, 인허가일자, 영업상태, 소재지 정보(도로명주소, 좌표 등), 목재생산구분, 생산종류, 취급목재제품, 인력 보유 현황, 연간생산량, 자본금 등으로 구성되어 있습니다. 이 데이터는 산림자원 활용 현황 파악, 원자재 가공업의 지역별 분포 분석, 정책적 목재산업 육성 기반 마련, 그리고 지역산업 구조 분석 등에 활용될 수 있으며, 산업경제 분야에서 주요한 통계자원입니다. Open API를 통해 실시간 또는 주간 단위로 업데이트된 정보를 자동 수집하여 최신 인허가 현황을 분석할 수 있습니다.

제공기관: 경기도
분류: 산업고용
키워드: 제재업, 목재가공, 인허가현황, 원목, 산림조합, 사업장정보, 연간생산량, 취급목재
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-06-27
이용허락: 이용허락범위 제한 없음

# 장애인콜택시탑승통계

서울시설공단에서 운영중인 장애인콜택시 운행 일별 이용현황 데이터입니다. 제공내용 : 시작일부터 종료일까지의 입력값을 기반으로 기준일별 운행차량대수, 접수건수, 탑승건수, 평균대기시간, 평균요금, 평균승차거리 등 통계현황 데이터를 제공합니다. 이용방법 : 아래 URL로 서울시설공단 장애인콜택시 공공데이터 안내 페이지 접속 후 API 신청서 다운로드하여 양식에 맞춰서 신청서 작성 후 스캔본을 담당자 메일로 발송하시면 담당자 확인 후 요청주소 및 LINK API 호출방법 메일 회신을 드립니다.

제공기관: 서울시설공단
분류: 사회복지
키워드: 장애인콜택시, 통계, 이용현황, 장애, 장애인, 콜택시, 교통약자, 교통약자이동지원
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-06-10

# 한국고용정보원_워크넷 심리검사 한국고용직업분류 매핑코드_20210520

한국고용정보원에서 제공하는 직업심리검사, 직업선호도검사 S형, 창업적성검사, 직업가치관검사 등의 결과를 토대로 자신에게 맞는 직업군의 분류 코드 값 및 매핑 결과를 제공합니다. 심리검사API를 이용하여 개인별 심리검사 결과를 조회할 수 있습니다. 직업심리검사 직업코드를 한국고용직업분류코드 결과로 제공합니다. 인증키, 리턴타입, 심리검사코드(성인용 직업심리검사, 직업가치관검사) 등을 파라미터로 받아 한국고용직업분류코드리스트 등의 결과를 제공합니다. * 유의사항: 문자열로 입력되는 항목의 경우 공백이나 오탈자가 포함되면 검색 결과가 제대로 나오지 않을 수 있으므로 주의해야 합니다. 대부분의 파라미터는 선택적으로 입력할 수 있으며, 필요한 조건만 입력해도 조회는 가능합니다.

제공기관: 한국고용정보원
분류: 산업고용
키워드: 적성검사, 선호도검사, 준비도검사, 직업선호도검사, 직업심리검사, 직업, 직업가치관, 창업적성
형식: api
수정일: 2025-07-21
이용허락: 제3자 권리 포함 : 저작권 표시, 비영리, 변경금지, 공공저작물 : 출처표시, 상업적 이용금지, 변경금지 (제 4유형)

# 제주특별자치도_한라산입산하산시간현황

제주특별자치도 세계유산본부에서 관리하는 한라산 탐방관련 데이터를 제공합니다. 항목: 각 탐방 코스별로 하절기 / 춘추절기 / 동절기 입산제한 시간 *대상 탐방로 - 어리목: 총 6.8㎞ [어리목→윗세오름(4.7㎞)→남벽분기점(6.8㎞)] - 영실: 총 5.8㎞ [영실→윗세오름(3.7㎞)→남벽분기점(5.8㎞)] - 성판악: 총 9.6㎞ [성판악→진달래밭(7.3㎞)→동능정상(9.6㎞)] - 관음사: 총 8.7㎞ [관음사지구야영장→삼각봉대피소(6㎞)→동능정상(8.7㎞)] - 돈내코: 총 7㎞ [돈내코탐방안내소→평궤대피소(5.3㎞)→남벽분기점(7㎞)] - 어승생악: 총1.3㎞ [탐방안내소 → 어승생악정상(1.3㎞)] - 석굴암: 1.5Km [국립호국원주차장→석굴암암자] 자세한 사항은 한라산국립공원 홈페이지에서 확인하시기 바랍니다. https://www.jeju.go.kr/hallasan/index.htm

# 환경 측정대행업체 현황

이 데이터는 경기도 내에서 환경오염물질의 측정 업무를 대행하는 업체에 대한 정보를 제공합니다. 해당 업체는 대기오염물질, 수질오염물질, 소음·진동, 악취, 다중이용시설 실내공간의 공기질, 인공조명에 의한 빛 공해 등 다양한 환경항목의 측정을 전문적으로 수행합니다. 데이터는 시군별 사업장명, 인허가일자, 소재지 주소, 전화번호, 영업상태, 실험실 위치 및 면적, 위탁업체명, 위경도 좌표 등 상세한 정보를 포함하며, 주간 단위로 갱신됩니다. 데이터는 Open API 형태로 제공되어 환경정책 수립, 오염물질 모니터링, 환경영향 평가, 대행업체 실적 분석 등 다양한 분야에서 활용될 수 있습니다.

제공기관: 경기도
분류: 환경기상
키워드: 환경측정, 대기오염, 수질오염, 소음진동, 빛공해, 실내공간오염, 인허가정보, 환경대행업체
형식: api
선정 기준: 운영 자동승인 OpenAPI

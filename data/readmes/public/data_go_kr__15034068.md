# 건물부문 온실가스 배출현황 서비스

건물부분에 대해 월별, 동별, 배출원단위별로 온실가스 배출현황 데이터를 제공합니다. 개방되는 데이터는 프로그래밍을 통해 실시간으로 데이터를 요청하고 응답받는 API(Application Programming Interface) 서비스입니다. 이는 주로 개발자나 분석가가 특정 시스템에 데이터를 연동하여 활용할 때 사용됩니다. JSON, XML 등 API 호출을 통해 응답받을 수 있는 형태로 제공됩니다. 부산시의 건물 유형병 온실가스 배출량에 대한 통계정보가 포함됩니다. 구군, 동, 전기, 도시가스, 지역난방, 합계의 항목을 제공합니다.

분류: 환경기상

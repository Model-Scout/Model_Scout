# 지식재산처_KIPRISPlus_거절결정서_REST API_20220308

1. 개요 지식재산권(특허, 실용, 디자인, 상표)의 출원에 대한 거절 결정을 통보하는거절결정서와 관련한 정보를 제공합니다. 출원에 대한 심사관의 심사결과로 거절이유가 해소되지 않은 사유를 기재하여 해당 출원인에게 거절결정이 통지되는 특허청의 발송 서류 정보를 API(REST방식) 및 대용량(BULK)으로 제공합니다. 2. 세부 정보 내용 ① 서지정보: 출원번호, 디자인일련번호, 문서내 출원번호 등의 정보를 XML 형태로 제공합니다. ② 심사관정보: 작성일, 심사국, 심사관 명 등의 정보를 XML 형태로 제공합니다. ③ PDF정보: PDF파일 다운로드 주소를 XML 형태로 제공합니다. 출원일자, 출원번호, 발명의 명칭, 이의신청일자, 이의신청번호, 제출기한일자, 기술평가일자, 심사결과, 거절결정내용 등 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

제공기관: 지식재산처
분류: 과학기술
키워드: 출원일자, 출원번호, 이의신청일자, 거절결정내용, 심사결과
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-09-22
이용허락: 이용허락범위 제한 없음

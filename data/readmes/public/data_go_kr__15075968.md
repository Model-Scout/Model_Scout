# 지식재산처_KIPRISPlus_국유특허_REST API

1. 개요 국유 특허에 관한 정보를 제공합니다. * 국유 특허 : 국가공무원 등 국가기관에 소속되어 있는 자의 직무발명에 따라 국가 명의로 등록된 특허권 국유특허의 리스트 정보를 API(REST방식) 및 대용량(BULK)으로 제공합니다. 2. 세부 정보 내용 국유특허 관련 정보를 XML 형태로 제공합니다. 등록번호, 발명기관, 발명의명칭, 등록일자, 존속기간, 무상구분, 평가등급, 출원번호, 지식재산유형 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

제공기관: 지식재산처
분류: 과학기술
키워드: 등록번호, 발명기관, 발명의명칭, 무상구분, 출원번호
형식: xml
선정 기준: 중앙·광역 기관 파일데이터
수정일: 2025-09-23
이용허락: unknown

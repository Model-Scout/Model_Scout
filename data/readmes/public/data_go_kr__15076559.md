# 외교부_국가(지역)별 경제현황

외교부 홈페이지에 공개 중인 각 국가별 약황 정보 중 경제와 관련된 정보를 CSV 형식으로 제공합니다. 데이터 항목에는 한글 국가명, 영문 국가명, 국가코드(ISO 2자리), 국내총생산(GDP), 1인당 총생산, 경제성장률, 경제성장률 설명, 물가상승률, 물가상승률 설명, 실업률, 화폐단위, 주요자원, 주요산업, 수출액, 수입액 등을 포함하고 있습니다. 국제비교 연구, 해외시장 분석, 투자전략 수립에 유용하며, 기업과 연구기관이 활용할 수 있는 실질적인 정보입니다. (데이터 업데이트 주기: 1년, 실시간 정보는 동명의 API 참고)

제공기관: 외교부
분류: 통일외교안보
키워드: 국가_지역정보, 화폐, GNP, 경제현황, 산업
형식: csv
선정 기준: 중앙·광역 기관 파일데이터
수정일: 2026-07-23

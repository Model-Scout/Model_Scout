# 지식재산처_KIPRISPlus_분류코드_REST API_20230308

1. 개요 국제특허분류코드(IPC), 선진특허분류코드(CPC), 유럽특허분류코드(EPC), 미국특허분류코드(UPC), 일본특허분류코드(F-TERM, FI), 디자인분류코드, 국제도형분류코드(비엔나)에 관한 정보를 제공합니다. 주요국의 특허 및 디자인에 대한 분류코드 정보를 API(REST방식) 및 대용량(BULK)으로 제공합니다. 2. 세부 정보 내용 ① IPC, 도형코드 조회 : 국제분류코드 정보를 XML 형태로 제공합니다. ② ECLA. CPC 조회 : 유럽분류코드 정보를 XML 형태로 제공합니다. ③ UPC 조회 : 미국분류코드 정보를 XML 형태로 제공합니다. ④ F-TERM, FI 조회: 일본분류코드 정보를 XML 형태로 제공합니다. IPC, CPC, UPC, EPC, F-TERM, FI, 디자인 분류, 비엔나 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

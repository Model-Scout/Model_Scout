# 인천항만공사_인천항 신고정보 조회 서비스_20250722

해당 데이터는 인천항만공사에서 운영중인 화물 반출입 시스템에서 인찬항의 통합 화물 반출입, 내외항 화물 반출입, 내외항컨테이너 반출입, 위험물 신고 정보 조회 서비스를 Open API 형태로 제공합니다. 주요 요청 파라미터로는 numOfRows, blNo, callLetter, agentCode, mrnNo, serNo, yyr등이 있으며, 응답 필드는 B/L 번호, MRN 번호, 선박 호출부호, 선사코드, 신고일자, 입항연도, 신고유형 코드 등이 포함되어 있습니다. 이 Open API는 REST 방식으로 작동하며, XML 형태로 응답을 반환합니다. 인증키(serviceKey)를 필요로 하며, 총 13개의 요청변수와 14개 이상의 응답 필드를 통해 인천항을 통한 수입/수출 절차의 데이터를 통합적으로 확인할 수 있습니다.

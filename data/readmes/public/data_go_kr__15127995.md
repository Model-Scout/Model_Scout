# 보건복지부_입양 아동 현황

* 단위 : 개소, 명 보건복지부에서 2010년부터 2024년까지 입양 아동 현황(입양아동_국내_남, 입양아동_국내_여, 입양아동_국외_남, 입양아동_국외_여) 데이터를 성별/연도별로 제공하고 있습니다. <통계 이용 시 주의사항> ○ 국내입양：전국의 7개 입양기관을 통해 입양되는 아동을 파악한 데이터를 의미 ○ 국외입양：3개 입양기관을 통해 외국과 협약을 맺은 나라로 입양되는 아동을 파악한 데이터를 의미 * 국내입양아동의 수는법원 허가건수기준으로 파악하여작성 * 국외입양아동의 수는 법원 허가건수 기준으로 파악하여 작성

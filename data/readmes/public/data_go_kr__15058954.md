# 서울교통공사_역명으로 지하철역 검색

서울교통공사_역명으로 지하철역 검색 API 데이터는 역명으로 지하철역 정보를 조회할 수 있는 API입니다. (역명을 사용하여 조회 시 호선, 외부코드, 전철역코드, 전철역명 정보를 제공) [유의사항] - 역명 일부분 또는 줄임말을 사용한 검색은 불가합니다.(2, 4, 5호선 동대문역사문화공원역 검색 시 - 동역사, 동역문, 역사문화 검색 불가 → 동대문역사문화공원 검색 가능) - 부역명(병기역명) 검색은 불가하며, 검색 결과에도 노출되지 않습니다. - 역명만 입력하여야 검색이 가능합니다.(1, 4호선 동대문역 검색 시 - 동대문역 검색 불가 → 동대문 검색 가능)

제공기관: 서울교통공사
분류: 교통물류
키워드: 지하철, 검색, 지하철역, 전철역코드, 외부역코드, 역_이름, 전철, 도시철도
형식: xml

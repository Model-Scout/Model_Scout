# 모바일 판례 목록 조회

법제처가 제공하는 모바일 판례 목록 조회 데이터는 법원에서 선고한 주요 판례에 대한 목록 정보를 모바일 환경에서 손쉽게 조회할 수 있도록 구성된 자료입니다. 본 데이터는 판례식별번호, 사건번호, 사건명, 사건종류명, 선고일자, 법원명, 법원종류명, 재판부명, 판시사항, 판결요지 등의 항목으로 구성되어 있습니다. 사용자는 특정 사건번호나 선고일자, 법원명 등의 조건을 설정하여 관심 있는 판례 정보를 검색할 수 있으며, 검색된 판례는 목록 형식으로 제공됩니다. 모바일 기기에서도 가볍고 효율적으로 활용할 수 있도록 최적화되어 있으며 사건 분류와 재판부, 판시사항 등의 세부 항목은 법률 검토, 유사 판례 비교 및 법적 판단 근거 확보에 유용하며, 법률 실무와 관련된 정보 분석에 효과적으로 활용할 수 있습니다.

제공기관: 법제처
분류: 공공행정
키워드: 앱판결재판, 사건번호, 선고일자, 법원종류, 사건종류, 판시사항, 판결요지, 판례정보
형식: api
선정 기준: 운영 자동승인 OpenAPI

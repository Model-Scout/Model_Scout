# 지식재산처_KIPRISPlus_청구항 변동이력_REST API_20220308

1. 개요 특허 출원 이후 보정을 통해 변경된 청구항의 이력 정보를 제공합니다. 청구항 변동이력 정보를 API(REST방식) 및 대용량(BULK)으로 제공합니다. 2. 세부 정보 내용 국내 특실의 청구항 변동이력순서, 변동정보 등을 XML 형태로 제공합니다. 출원번호, 접수발송일련번호, 접수발송번호, 접수발송서류명, 청구항번호, 변경구분명, 청구항, 변동청구항 등 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

분류: 과학기술

형식: api

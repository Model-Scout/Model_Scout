# 행정안전부_실시간 주소별 좌표정보 조회(검색API)

도로명주소 DB 구축 없이 다양한 시스템 환경에서 실시간으로 주소의 좌표 검색기능을 구현할 수 있습니다 1. API 서비스 개요 - 다양한 시스템 환경 적용 가능 - 개발언어, 플랫폼 제약없음 - 실시간 좌표 검색 가능 - 신청 즉시 이용 가능 - 1 시스템 1 승인키 부여 2. 입력 파라미터 정보 신청시 발급받은 승인키,행정구역코드,도로명코드,지하여부(0:지상, 1:지하),건물본번,건물부번,검색결과형식 설정(xml, json) 3. 출력 파라미터 정보 행정구역코드.도로명코드.건물관리번호.지하여부(0 : 지상, 1 : 지하).건물본번.건물부번.X좌표.Y좌표.건물명

제공기관: 행정안전부
분류: 과학기술
키워드: 주소, 도로명주소, 주소좌표정보(검색API), 주소출입구, 위치검색

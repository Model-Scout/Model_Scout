# 국가데이터처_SGIS(통계지리정보)

국가데이터처가 보유한 인구·가구 ·주택 ·사업체 등의 데이터를 타 기관 및 서비스에서 활용할 수 있도록 제공하는 데이터 API 서비스입니다. [용어설명] 1. 지리정보시스템 [GIS,Geographic Information System] 지리공간데이터(geographic or geospatial data)를 기반으로 유용한 정보를 생성하는 정보시스템 2. 통계지리정보시스템/서비스 [SGIS,Statistical Geographic Information System] 국가데이터처가 인구·가구·주택·사업체 등의 센서스데이터와 공공 및 민간 자료와 연계∙융합할 수 있는 위치기반 개방형 서비스 플랫폼

제공기관: 국가데이터처
분류: 공공행정
키워드: 통계지리정보서비스, 오픈API, 데이터API, 통계데이터, 데이터서비스

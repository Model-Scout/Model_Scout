# 국방부_국방데이터 표준도메인목록

국방정보체계에서 사용되는 표준도메인으로 도메인 명,논리 데이터 유형,분류어,유형,대표 여부,정의내용 등이 있으며 도메인은 "분류어_데이터타입,데이터길이"로 구성되며 분류단어는 어떤 항목이나 데이터를 체계적으로 나누기 위해 사용되는 기준이 되는 단어나 용어를 말합니다. 논리적, 물리적으로 유사한 유형의 데이터를 그룹화하기 위해 분류어를 선정하고 여기에 데이터타입 및 길이를 조합하여 도메인을 구성합니다. 보통 한개 분류어에 3개까지 도메인을 허용하지만 예외도 존재합니다.

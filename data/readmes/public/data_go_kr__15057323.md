# 한국마사회 경주마 레이팅 정보

한국마사회 서울, 부산경남, 제주 경마공원에 출전한 경주마에 대한 레이팅정보를 제공합니다. (제공자료는 경마장, 마번, 마명, 레이팅1, 레이팅2, 레이팅3, 레이팅4 자료입니다.) - 요청메세지에 페이지당 건수와 페이지 번호를 이용하여 자료를 조회하실 수 있습니다. ※ 레이팅 : 경마에서 각 경주마의 성능이나 능력을 평가하기 위해 부여되는 점수입니다. 레이팅은 경주마의 과거 성적, 경주에서의 성과, 상대 마와의 비교 등을 종합적으로 고려하여 산정됩니다. 이를 통해 경주마의 경쟁력을 가늠할 수 있고, 베팅 시 참고 자료로 활용됩니다. ※ 영천경마 시행에 따른 시행경마(권역) 표출시 부산경남경마와 영천경마를 합쳐서 영남경마로 표출합니다.

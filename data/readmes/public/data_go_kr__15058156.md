# 표시과목별 교원 현황(중,고)(과목별)

본 데이터는 경기도 내 중학교 및 고등학교의 표시과목별 교원 현황을 수집한 자료로, 정규 교과 수업을 담당하는 교사들의 성별과 과목별 인원 분포를 포함합니다. 각 데이터는 학교명, 지역명, 지역교육청명, 학교급명, 설립구분명 등의 기본 정보와 함께, 교과 분류 체계에 따른 상위교과명(예: 과학, 국어 등), 세부과목명(예: 물리, 작문 등), 과목코드, 남성·여성 교원 수, 총 교원 수 등의 정보를 제공합니다. 해당 데이터는 휴직자 또는 장기 휴가로 대체 교원이 채용된 경우를 제외하고, 단순 휴가자를 포함한 정규 교과 교사를 기준으로 작성되었습니다. 이 자료는 과목별 교사 배치의 불균형 해소, 교원 수급 정책 수립, 교과별 인력 현황 분석 등에 활용할 수 있으며, 학교알리미 시스템을 기반으로 경기도 AI데이터행정과가 연 1회 제공하며 Open API로도 이용 가능합니다.

제공기관: 경기도
분류: 교육

형식: api

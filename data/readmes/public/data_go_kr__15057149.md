# 지식재산처_KIPRISPlus_특허_실용 통지서 마감기한_REST API_20220308

1. 개요 출원(심사), 심판, 등록의 업무 진행중에 발생하는 서류 제출, 요금 납부기한 등의 마감 기한 일자 정보를 제공합니다. 출원통지서, 등록통지서, 심판통지서에 대한 마감기한 정보를 API(REST방식) 및 대용량(BULK)으로 제공합니다. 2. 세부 정보 내용 ① 출원통지서 : 출원번호, 일련번호, 발생원인발송번호, 제출만료일자 등의 정보를 XML 형태로 제공합니다. ② 심판통지서 : 심판번호, 접수발송번호, 제출만료일자, 접수발송서류코드, 접수발송서류명 등의 정보를 XML 형태로 제공합니다. ③ 등록통지서 : 등록번호, 접수발송번호, 접수발송일자, 접수발송서류코드, 접수발송서류명, 제출만료일자 등의 정보를 XML 형태로 제공합니다. ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

제공기관: 지식재산처
분류: 과학기술
키워드: 마감기한, 특허 실용, 출원통지서, 심판통지서, 등록통지서
형식: api
선정 기준: 운영 자동승인 OpenAPI

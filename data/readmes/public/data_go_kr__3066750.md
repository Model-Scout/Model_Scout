# 모집병 지원가능분야 조회

모집병 지원 시 군별, 모집특기별로 지원 가능한 자격/면허, 전공학과 등 정보를 제공하는 서비스입니다. 군별(육군, 해군, 공군, 해병대), 모집분야별(기술행정병, 일반/전문기술병, 전문특기병 등), 모집특기별로 정보가 구분되어 있습니다. 병무청 누리집- 군지원(입영신청)안내- 지원서 작성/수정/취소- [지원요건 검색] 메뉴에서 특기별 관련분야로 인정되는 자격면허 및 전공학과 목록을 확인할 수 있고, [지원가능분야 검색] 메뉴에서 본인의 자격면허 또는 전공학과를 입력 후 해당 조건을 기준으로 지원 가능한 특기를 확인할 수 있습니다.

제공기관: 병무청
분류: 통일외교안보
키워드: 군지원, 모집, 모집병, 지원, 지원가능, 지원가능 정보, 지원기준, 지원조건
형식: api
선정 기준: 운영 자동승인 OpenAPI

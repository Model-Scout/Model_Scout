# 해양환경공단_해양환경측정망 근해 관측서비스_20200304

이 데이터는 해양환경공단이 근해 해역을 대상으로 운영하는 해양환경측정망의 관측 정보를 제공하는 공공데이터 API 서비스이다. 관측 정점에서 자동측정장비를 활용하여 전기전도도, 수온, 염분, 수소이온농도, 용존산소량, 탁도 등 주요 수질항목을 지속적으로 수집하며, 근해 수질의 변화 양상과 해역 특성을 파악할 수 있도록 정밀한 연속관측 자료를 제공한다. 또한 관측지점 코드, 위치 정보, 관측일시 등 기초 공간·시간 데이터를 함께 제시하여 이용자가 특정 해역의 환경 상태를 종합적으로 확인할 수 있도록 구성하였다. 아울러 기온, 풍향, 풍속, 일사량 등 해양환경 배경값을 포함하여 수질 변화의 원인을 다각도로 분석할 수 있도록 지원하며, 측정 자료의 검증 절차와 장비 운영 정보를 통해 데이터의 신뢰성과 활용성을 높이고자 한다.

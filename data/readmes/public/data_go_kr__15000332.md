# 서울특별시_버스위치정보조회 서비스_20220831

서울특별시_버스위치정보조회 서비스 API는 서울 시내를 운행하는 버스의 실시간 위치 정보를 제공하는 공공데이터 서비스입니다. 사용자는 노선 ID와 정류소 구간 정보를 요청값으로 전달해 현재 운행 중인 버스의 위치, 정류소 도착 여부, 구간별 이동 거리, 차량 번호, 차량 유형, 혼잡도 등 다양한 정보를 조회할 수 있습니다. 이를 통해 버스의 운행 상황을 정확히 파악할 수 있어 교통 정보 제공 서비스, 지도 기반 모니터링 시스템, 혼잡도 분석 등 여러 분야에서 활용이 가능합니다. API 활용은 참고문서 확인 바랍니다.

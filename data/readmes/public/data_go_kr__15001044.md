# 대전광역시 시험정보조회 서비스

대전광역시에서 시행하는 각종 시험 및 임용 관련 공고 정보를 한눈에 제공하는 데이터셋입니다. 일반공공행정의 일반행정 분류에 속합니다. 시험명, 시행기관, 모집인원, 응시자격, 시험일정, 접수기간, 시험장소 등 상세 항목을 포함하고 최신 공고부터 과거 기록까지 연도별로 정리합니다. 인사 담당자·구직자·연구자 등이 시험 일정 파악, 인력 수급 계획, 정책 분석 등에 활용할 수 있으며, API 제공으로 실시간 검색·통합 관리가 가능합니다.

제공기관: 대전광역시
분류: 공공행정
키워드: 공고, 시험정보, 임용
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2026-10-23
이용허락: 제3자 권리 포함 : 저작권 표시, 공공저작물 : 출처표시 (제 1유형)

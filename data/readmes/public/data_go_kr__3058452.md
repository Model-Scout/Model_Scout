# 영화인정보 Open-API

영화인 DB는 영화관 입장권 통합전산망에서 사용되는 영화인 목록을 영화인명, 필모그래피(영화 목록)의 조건을 통해 조회하며, 한국 영화 크레디트 수집과 정보 수정 요청을 통해 상시 업데이트하고 있습니다. 외국 영화 참여 인력 정보의 경우, 감독과 배우 위주로 제공됩니다. 또한, 매년 개봉되는 한국 영화의 크레디트 정보 수집을 통해 영화인의 경력 확인을 위한 기초 자료와 참여 영화 목록을 확인하는 '영화인 작품 참여 내역서'를 제공하고 있습니다. 영화진흥위원회는 최신의 정확한 한국 영화 산업 정보를 제공하도록 노력하겠습니다.

제공기관: 영화진흥위원회
분류: 문화관광
키워드: 감독, 프로듀서, 시나리오작가, 배우, 촬영감독, 편집, 프로덕션 디자인, 사운드
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-06-27
이용허락: 이용허락범위 제한 없음

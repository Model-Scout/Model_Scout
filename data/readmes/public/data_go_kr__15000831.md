# 외교부_대륙 구분코드

[요약 정보] 국가별 소속 대륙 구분코드 전체를 조회가능한 오픈 API입니다. [상세 정보] 제공 데이터 건수 : 4건, 범위 : 대륙구분 코드, 대륙명 등 대륙코드목록조회 : 공공데이터 포털에서 제공하는 인증키로 대륙구분코드를 조회 가능합니다.

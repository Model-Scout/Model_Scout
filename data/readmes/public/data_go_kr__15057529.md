# 종계업 현황

이 데이터는 경기도 31개 시군의 종계업체에 대한 인허가 현황을 제공하며, 종계업은 번식용 닭(씨알)을 생산하거나 사육을 위탁해 판매하는 축산업의 한 형태입니다. 총 20개 항목으로 구성되어 있으며, 사업장명, 인허가일자, 영업상태, 폐업일자, 소재지 주소 및 면적, 총 종업원 수, 축산업무구분명, 축산물가공업구분명, 위치정보(WGS84 위도·경도 포함) 등이 포함됩니다. 축산시설 분포 파악, 번식용 가축 관리 현황 분석, 지역 축산정책 수립에 활용될 수 있으며, 데이터는 행정안전부가 제공하며 Open API 형태로 접근 가능합니다. 다만 데이터 갱신은 2018년 9월 6일 이후 중단되었습니다.

제공기관: 경기도
분류: 농축수산
키워드: 종계업, 인허가현황, 번식용닭, 가축사육, 위치정보, 사업장정보, 축산업무, 종업원수
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-07-21
이용허락: 이용허락범위 제한 없음

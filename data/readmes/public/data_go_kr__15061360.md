# 산업통상부_주요 유통업체 전년동월대비 매출증가율 추이

주요 유통업체 오프라인 15개사의 전년동월대비 매출증가율 추이(기간, 분류별 전년동월대비 매출증가율) (25.12월 조사대상 확대 : 당초 오프라인 13개사, 온라인 10개사 -> 변경 오프라인 15개사, 온라인 11개사) [참고] 산업통상자원부는 오프라인 15개사 온라인 11개사의 주요 유통업체 매출동향을 매월 발표함 동 자료는 오프라인 13개사의 업태별(대형마트, 백화점, 편의점, 준대규모점포), 품목별 매출증감률에 관한 것임 오프라인 매출동향은 국가데이터처 승인통계(승인번호 제115023호)이며, 국가통계포털(www.kosis.kr), e나라지표(www.index.go.kr/enara), 산업통상부(www.motir.go.kr) 등에서 확인 가능함 + 온라인 10개사의 매출동향은 당초 12개사의 증감률이 제공되었으나, 24.7월이후 10개사 대상으로 조정되었음. 해당 데이터는 산업통상부(www.motir.go.kr) 에서 별도 확인 가능함 + 조사대상 추가 : 대형마트(농협하나로마트), 편의점(이마트24), 온라인(네이버) 등 업태별 각1개사 추가하여 오프라인 25개사, 온라인 11개사가 조사대상임

# 국토안전관리원_동적 계측 데이터 서비스_20251203

동적 계측 데이터 서비스(DynaMeasureService)는 신호를 100Hz로 측정하여 풍속, 가속도, 변위, 변형률, 처짐 등 다양한 물리적 현상에 대한 데이터를 제공합니다. 이 서비스는 10분 및 일 단위로 최대, 최소, 평균, 표준편차, RMS 값을 산출하여 제공하며, 다양한 센서를 통해 얻은 데이터를 실시간으로 분석하고, 사용자에게 정확한 통계 정보를 제공합니다. 이를 통해 환경 모니터링 및 구조물 안전관리 등 여러 분야에서 활용가능한 데이터를 제공합니다. 또한, RESTful API 방식을 통해 손쉽게 데이터에 접근할 수 있습니다.

제공기관: 국토안전관리원
분류: 재난안전
키워드: 신호, 측정, 계측데이터, 산출값, 측정데이터
형식: api
선정 기준: 국가중점데이터 OpenAPI

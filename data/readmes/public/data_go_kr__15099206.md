# 한국국제협력단_현지 생활정보_20220225

KOICA 해외 파견국의 현지 생활 관련 정보를 제공하는 API입니다. 기후, 문화, 식생활, 교통, 통신, 현지 규범 등 체류 중 유용한 정보를 포함하고 있으며, 해외봉사단, 전문가, 사절단 등의 안전하고 효율적인 현지 생활을 지원합니다. 해당 API는 인증키(serviceKey), 페이지 번호(pageNo), 한 페이지 결과 수(numOfRows) 등 기본적인 요청변수를 사용하며 한글 국가명, ISO 2자리코드, 구분, 연도 등의 필터 파라미터를 추가로 설정할 수 있습니다. 출력결과에는 한글 국가명, 영문 국가명, ISO 2자리코드, 연도, 구분, 내용 등의 항목이 포함되며, 각 항목에 대한 데이터는 JSON 형식으로 반환됩니다.

형식: api

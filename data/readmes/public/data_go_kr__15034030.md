# 제설함 배치 정보 서비스

겨울에 눈이 왔을 때 눈을 치룽 수 있는 부산광역시에 설치된 제설함 배치 현황 데이터를 개방합니다. 제설함은 쌓인 눈을 치우는 데에 사용되는 염화칼슘이나 모래 등을 넣어서 보관하는 곳을 말합니다. 제설은 눈이 쌓이거나 얼어붙어 생기는 안전 문제와 교통 불편을 해소하기 위해 눈을 치우고 녹이는 작업을 의미합니다. 주로 겨울철 도로, 인도, 건물 앞, 공공장소 등에서 이루어집니다. 부산시 구군에서는 제설을 효과적으로 즉시 할 수 있도록 제설함을 시내 곳곳에 설치하였습니다. 개방되는 데이터에는 설치장소, 수량, 관리기관, 연락처 등의 데이터가 포함되어 있습니다.

제공기관: 부산광역시
분류: 재난안전
키워드: 결빙, 폭설, 사고, 모래, 염화칼슘, 안전
형식: api

# 국토교통부 국토지리정보원_수치지도_지도정보

지표면의 다양한 지형지물(도로, 건물, 하천, 등고선, 토지이용 등)을 점, 선, 면(벡터) 형태로 표현하고, 정밀한 좌표값을 부여한 1:1000, 1:2500, 1:5000, 1:25000 축척으로 제작한 DXF형태의 수치지도(수치지형도)의 식별/제작 정보 ▷ 식별정보 : 도엽번호, 도엽명, 사업번호 ▷ 속성정보 : 조사년도, 제작년도, 고시번호, 고시일자 * 1:1,000 : 도시지역에 대해 지자체와 매칭펀드로 제작 * 1:5,000 : 전국을 대상으로, 1:5000 이상의 축척으로 제작되고, 규격이 일정하고 정확도가 통일된 것, 전국을 대상으로 모든 정보를 수정하고 대형 건물, 도로 등의 중요 정보는 수시로 수정

제공기관: 국토교통부 국토지리정보원
분류: 국토관리
키워드: 지리원, 수치지형도, 메타데이터, 도엽번호, 도엽명
형식: csv
수정일: 2025-07-08
이용허락: 이용허락범위 제한 없음

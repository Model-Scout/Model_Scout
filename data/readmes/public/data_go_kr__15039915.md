# 한국지능정보사회진흥원_인공지능 학습용 데이터 구축 현황

본 데이터는 인공지능(AI) 학습용 데이터를 구축한 연도별 사업 현황을 정리한 자료로, 각 사업이 추진된 시기, 적용 분야, 주요 구축 내용을 중심으로 구성되어 있습니다. 데이터는 다음과 같은 항목으로 구성됩니다: 연도 : 해당 데이터 구축 사업이 추진된 연도 (예: 2020, 2021 등) 분야 : 데이터가 구축된 산업 또는 기술 분야 (예: 의료, 교통, 금융, 농업, 국방 등) 주요내용 : 각 사업에서 구축한 학습데이터의 구체적 내용 또는 활용 목적 (예: X-ray 영상, 음성 데이터, 자율주행 센서데이터 등) 해당 데이터는 산업별 AI 데이터 인프라 조성 상황을 파악하거나, 분야별 데이터 활용 가능성을 분석하기 위한 기초 정보로 활용됩니다.

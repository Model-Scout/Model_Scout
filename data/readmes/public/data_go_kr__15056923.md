# 지식재산처_KIPRISPlus_한국특허영문초록(KPA)_REST API_20250904

1. 개요 한국특허공보 요약서에 대한 영문번역 자료를 제공합니다. 한국 특허정보를 영문으로 가공하여 해외에 배포할 수 있도록 한 한국특허영문초록(KPA)을 API(REST방식), 대용량(BULK)으로 제공합니다. 2. 세부 정보 내용 ① 검색: 일반검색 및 항목별검색을 통해 특허정보를 XML형태로 제공합니다. ② 서지정보: 초록, 출원인, 발명자, 우선권정보, 인용문헌 등의 특허정보를 XML 형태로 제공합니다. ③ 도면/전문: 대표도면의 다운로드 경로를 XML 형태로 제공합니다. 문헌번호, 국외공보번호, 표준공보번호, 국외공보일자, 국외문헌식별코드, 국외출원번호, 국외표준출원권리구분코드, 표준출원번호, 국외출원일자, 발명의명칭, 국제출원번호, 청구항수, 도면수, 영문초록 등 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

제공기관: 지식재산처
분류: 과학기술
키워드: 영문초록, 문헌번호, 특허 공보 요약서, 국외공보번호, 표준공보번호
형식: api
선정 기준: 운영 자동승인 OpenAPI

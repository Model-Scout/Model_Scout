# 폐사가축 처리장비 지원 집계 현황

본 데이터는 경기도에서 폐사된 가축의 매몰 등 처리를 위해 지원된 장비 비용 현황을 집계한 자료로, 가축 방역과 환경 위생 관리에 활용됩니다. 주요 항목은 집계년도, 시군명, 시군코드, 사업량(대), 도비사업비, 시군비사업비, 자부담금사업비 등으로 구성됩니다. 이를 통해 시군별 장비 지원 규모와 비용 분담 구조를 파악할 수 있으며, 축산 분야 재난 대응 정책, 가축 질병 발생 시 긴급 지원 체계 마련, 예산 집행 관리 등에 유용합니다. 또한 데이터는 Open API를 통해 XML 및 JSON 형식으로 제공되어, 축산정책 연구, 예산 분석, 행정 의사결정 지원 등에 폭넓게 활용될 수 있습니다.

제공기관: 경기도
분류: 농축수산
키워드: 폐사가축처리장비, 지원현황, 집계년도, 사업량, 도비사업비, 시군비사업비, 자부담금, 축산정책
형식: api
선정 기준: 운영 자동승인 OpenAPI

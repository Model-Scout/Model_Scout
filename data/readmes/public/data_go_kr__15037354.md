# 국가자격 경력기관 정보

“국가자격 경력정보 제공기관 현황” API는 한국산업인력공단이 제공하는 REST 기반 공공데이터 서비스로, 청소년상담사 등 국가자격 시험에서 경력 증빙 기관으로 인정된 기관의 목록을 XML 형식으로 제공합니다. 요청 시 ServiceKey(공공데이터포털 발급), pageNo, numOfRows 등의 파라미터를 통해 페이지 단위로 결과를 조회할 수 있으며, 반환 항목에는 기관명(compnm), 인정기관코드(rcoginsticd), 코드명(rcoginstinm), 페이지 정보(numOfRows, pageNo, totalCount)가 포함됩니다

제공기관: 한국산업인력공단
분류: 공공행정
키워드: 국가자격, 기술자격, 전문자격, 경력정보, 제공기관
형식: api

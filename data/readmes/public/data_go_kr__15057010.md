# 의료법인 현황

이 데이터는 경기도 내 의료법인의 현황을 정리한 자료로, 의료법인 명칭, 인허가일자, 영업 상태, 소재지 주소, 병상 수, 종업원 수, 구급차 보유 대수 등의 정보를 포함하고 있습니다. 의료법인은 병원·요양병원·의료원 등을 운영하는 비영리 조직으로, 지역 내 의료 서비스 공급의 중추적 역할을 수행합니다. 본 자료는 각 법인의 설립 현황과 운영 상태, 보유 자원(병상, 구급차, 인력 등)을 파악할 수 있어 지역별 의료 인프라 수준을 비교·분석하는 데 활용됩니다. 또한 보건의료 정책 수립, 응급의료 체계 개선, 공공성과 민간 의료 협력 모델 설계 등에서 중요한 기초자료로 사용될 수 있습니다.

분류: 보건의료
키워드: 의료재단, 보건의료, 의료인프라, 병상정보, 구급, 보건
형식: api
선정 기준: 운영 자동승인 OpenAPI

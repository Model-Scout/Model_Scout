# 지자체별사고 다발지역정보 조회 서비스

전국 각 지자체별 교통사고 다발지역 정보(지자체별 top3 지점) - 대상사고 : 1년간 발생한 전체 교통사고 - 다발지역 선정조건 : 반경 150m 내, 대상사고 3건 이상인 지점 중 상위 3개소(TOP3) * 지자체별로 해당 조건에 해당하는 지점이 3개가 되지 않을 경우 1개 또는 2개 지점만 선정될 수 있음 - WMS 형태의 API 정보는 교통사고정보개방시스템(https://opendata.koroad.or.kr/api/sample.do)을 통해 확인하실 수 있습니다. * 해당자료는 교통사고분석시스템(https://taas.koroad.or.kr) 데이터를 기반으로 함

제공기관: 한국도로교통공단
분류: 재난안전
키워드: 교통사고, 사고다발지역, 전국, 지자체별, 상위3개소
형식: api
선정 기준: 국가중점데이터 OpenAPI

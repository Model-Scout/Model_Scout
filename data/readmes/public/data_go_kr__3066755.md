# 인터넷입영원계획목록

병무청 누리집(홈페이지)을 통해 우선소집원, 선복무, 재학생입영원 접수 시 확인할 수 있는 정보에 대한 데이터입니다. 소집년도, 소집분기, 시군구, 공석인원수 데이터를 제공합니다. 현재는 병무청 누리집(홈페이지)을 통한 우선소집원, 선복무 신청을 접수하지 않아, 우선소집원 데이터는 2007년부터 2018년까지의 데이터, 선복무 데이터는 2014년부터 2019년까지의 데이터인 점 참고하여 주시기 바랍니다. 아울러 재학생입영원 데이터의 경우 재학생 입영(소집)등 신청(수시) 화면에서 제공하는 데이터입니다.

제공기관: 병무청
분류: 통일외교안보
키워드: 인터넷, 입영원, 계획, 공석, 사회복무요원, 분기, 시군구, 소집
형식: api
선정 기준: 운영 자동승인 OpenAPI

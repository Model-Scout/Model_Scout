# 한국농어촌공사_농지규모화 통계자료

한국농어촌공사 농지은행은 경영규모·연령별 농가의 성장단계별로 지원하는 맞춤형농지사업, 노동력부족·고령화로 자경하기 어려운 농지를 임대위탁받아 전업농 등에게 임대하는 임대·수탁사업, 과수원전업농육성대장자를 지원하는 과원규모화사업, 자연재해, 부채의 증가 등으로 일시적 경영위기에 처한 농가를 지원하는 경영회생지원사업, 농업인이 소유한 농지를 담보로 노후생활안정자금을 매월 연금방식으로 지급하는 농지연금사업을 운영중이며, 농지규모화 -매도, 농지규모화-임대, 농지규모화-교환분합 사업별, 지역별 계약건수, 면적(헥타르ha), 금액(백만원)의 년도별 통계자료 제공 하는 데이터 입니다.

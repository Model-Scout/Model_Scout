# 보건복지부_조혈모세포이식현황

보건복지부에서 조혈모 세포 이식 현황(이식연, 이식장기, 시도, 성별, 연령, 혈액형 등)에 대해서 정보를 제공합니다. <통계 데이터 이용 시 참고사항> 1. 통계 데이터에 값이 없는 경우는 공백으로 표기하였습니다. 2. 한 명의 이식자가 다수의 장기를 이식받는 경우, 장기별로 집계하기에 실제 이식자와 이식장기의 수는 다를 수 있습니다. 3. 조혈모세포 : 혈액과 면역체계의 모체세포로서 생존유지에 절대적으로 필요하며 보통 골수, 말초혈액이나 아기의 탯줄, 태반에 존재 4. 데이터 출처 : 장기이식의료기관, 장기이식등록기관 등으로부터 기증(희망)자 정보, 이식자 정보, 대기자 정보를 장기조직혈액통합관리시스템을 통해 통보받아 통계 작성

제공기관: 보건복지부
분류: 보건의료
키워드: 조혈모세포, 이식, 장기이식, 성별, 데이터
형식: csv

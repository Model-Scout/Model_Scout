# 예금보험공사 기금운용 현황

1. 데이터 개요 : 예보기금, 상환기금의 운용자산별 금액 및 수익률 2. 데이터 단위 : 억원(금액), %(수익률) 3. 데이터 설명: 예보기금, 상환기금의 운용현황을 자산군별로 기재 - 예치금(정기예금) : 금융회사 예치금 중 정기예금 - 예치금(MMDA 등) : 금융회사 예치금 중 정기예금을 제외한 수시입출식 상품(MMDA 등) - 채권 : 국공채, 통화안정증권 등 유가증권 - 연기금투자풀(MMF) : 기획재정부가 운영하는 연기금투자풀 제도의 운용상품 중 MMF형 수익증권 - 연기금투자풀(국공채) : 기획재정부가 운영하는 연기금투자풀 제도의 운용상품 중 국공채형 수익증권 - 연기금투자풀(완전위탁형) : 기획재정부가 운영하는 연기금투자풀 제도의 일환으로 여유자금 전액을 위탁 * 금액 및 수익률은 데이터 개방 기준일까지의 누적된 수치

제공기관: 예금보험공사
분류: 재정금융
키워드: 예금보험기금, 예금보험기금채권상환기금, 기금운용, 운용수익, 운용포트폴리오
형식: csv

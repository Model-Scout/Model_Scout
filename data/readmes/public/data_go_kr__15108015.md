# 국제방송교류재단_뉴스기사API_20221114

아리랑국제방송에서 제공하는 뉴스스크립트 API는 방송된 뉴스의 기사제목, 기사내용, 원문 스크립트, 기사 링크(URL), 썸네일 이미지, 방송일자 정보를 포함한 데이터입니다. 국제 이슈를 중심으로 제작된 뉴스 콘텐츠로, 국내외 시사 분석, 자연어처리, 기계번역, 외국어 교육, 미디어 콘텐츠 연구, 뉴스 트렌드 분석 등 다양한 분야에 활용됩니다. REST API 방식으로 제공되어 시스템 간 연동 및 자동화에도 적합하며 지속적으로 갱신되는 최신 데이터를 기반으로 정보 수집과 학습에 효과적입니다.

제공기관: 국제방송교류재단
분류: 과학기술
키워드: 뉴스, 국제방송, 아리랑, 방송데이터, 스크립트, 영문기사, 국제뉴스, 영상자막

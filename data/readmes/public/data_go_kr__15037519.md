# 국가기술자격 응시자격 항목 정보

“국가기술자격 등급별 응시자격 항목 정보” API는 한국산업인력공단이 제공하는 공공데이터 서비스로, 국가기술자격의 등급별 응시자격 항목을 조회할 수 있습니다. 이 API를 통해 응시자격 코드, 응시자격명, 등급코드, 등급명, 자격구분코드, 자격구분명 등의 정보를 XML 형식으로 제공합니다. 요청 시 인증키(ServiceKey)와 페이지 번호(pageNo), 한 페이지 결과 수(numOfRows) 등의 파라미터를 지정하여 데이터를 조회할 수 있습니다. 이 API는 자격 정보 시스템, 진로·자격 상담 플랫폼, 자격 안내 서비스 등에서 활용하기에 적합합니다. 공공데이터포털에서 인증키를 발급받아 사용할 수 있으며, 개발계정 기준으로 월 1,000회 호출이 가능합니다. 운영계정은 활용 사례 등록을 통해 추가 트래픽을 신청할 수 있습니다.

제공기관: 한국산업인력공단
분류: 공공행정
키워드: 국가자격, 응시자격, 자격등급

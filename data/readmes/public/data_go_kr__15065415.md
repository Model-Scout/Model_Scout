# 보건복지부_사회복지사 자격증 교부자 수_시도별

보건복지부에서 2018년부터 2024년까지 각 지역별 급수가 다르거나 성별이 다른 사회복지사 현황(연도, 시도, 1급_남, 1급_여, 2급_남, 2급_여, 3급_남, 3급_여)을 급수별/시도별로 분류하여 정보를 제공합니다. <통계 이용 시 참고사항> 1) 급수별(grade)：사회복지사 자격증 급수분류(1급, 2급, 3급 분류) 2) 조사방법：한국사회복지사협회를 통하여 교부된 사회복지사 자격증 통계 조사 3) 조사대상：조사일 현재 교부된 사회복지사 자격증 수 4) 조사내용：연도별, 지역별, 성별, 급수별 조사 5) 조사규모：전국 6) 데이터 출처 : 한국사회복지사협회(사회복지사자격증교부자수조사)

# 국토교통부_웹지엘 3D 지도 API

WebGL 기반으로 개발되었으며, javaScript형태로 제공하는 브이월드 웹지엘 3D지도 플랫폼 입니다.(IE 11이상 지원) 웹지엘 3D지도 API 1.0의 기능을 유지하며 사용자 친화적으로 설계하여 사용성을 높이고 GIS표준을 준수하여 다른 API사용자의 진입 장벽을 낮추었습니다. 웹지엘 3D지도 API 2.0은 인증키를 발급 받아야 사용할 수 있습니다. 웹지엘 3D지도 API 3.0은 별도의 Cesium JS 파일 선언 필요 없이도 Cesium 기능 활용이 가능합니다. 인증키는 브이월드에 회원가입을 하신 후 [오픈API > 인증키 > 인증키 발급]으로 이동하시면 발급 받으실 수 있습니다. 자세한 내용은 링크 정보를 통해 레퍼런스와 사용 방법을 참고하시면 됩니다.

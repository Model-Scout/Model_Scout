# 치과병원 현황(병원급)

이 데이터는 경기도 내 30병상 이상을 갖춘 병원급 치과병원에 대한 인허가 현황을 제공하는 자료입니다. 치과의사가 외래환자를 대상으로 진료를 수행하는 의료기관의 사업장명, 진료과목내용, 의료진 수, 병상 수, 입원실 수, 일반·특수 구급차 보유 수, 연면적, 최초 지정일자, 위치정보(WGS84 위도·경도 포함) 등 총 31개 항목으로 구성되어 있습니다. 지역별 치과 의료자원 분포 분석, 의료 접근성 연구, 치과시설 수급정책 수립 등에 활용될 수 있으며, 행정안전부에서 주간 단위로 갱신하고 Open API 형태로 제공됩니다.

제공기관: 경기도
분류: 보건의료
키워드: 치과병원, 병원급, 인허가현황, 진료과목, 병상수, 의료시설, 위치정보, 보건의료
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-07-21
이용허락: 이용허락범위 제한 없음

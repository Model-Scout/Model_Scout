# 국가기술자격 취득관련 현황

“국가기술자격 취득 관련 현황” API는 한국산업인력공단이 제공하는 공공데이터 REST 서비스로, 국가기술자격 소지자 현황, 학력·전공별 취득 현황, 성별·연령·지역·계열·종목별 통계, 자격취득 소요기간, 신설종목 취득 현황 등 다양한 정보를 XML 형식으로 제공합니다. 요청 시 ServiceKey와 baseYY(조회년도) 등의 파라미터를 활용해 연도별 취득 통계를 조회할 수 있으며, 개발계정은 월 1,000회 호출이 가능합니다

제공기관: 한국산업인력공단
분류: 공공행정
키워드: 국가자격, 기술자격, 취득현황
형식: api
선정 기준: 운영 자동승인 OpenAPI

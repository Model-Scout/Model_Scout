# 지식재산처_KIPRISPlus_다인용 선행문헌_REST API_20220308

1. 개요 심사인용문헌(선행기술 조사문헌, Reference cited) 중에서 심사관이 심사시에 많이 참조, 인용한 문헌 정보를 제공 합니다. 심사관이 심사시 많이 인용한 정보를 API(REST방식) 및 대용량(BULK)으로 제공합니다. 2. 세부 정보 내용 다인용 선행문헌 조회 : 다인용 선행문헌 정보를 XML 형태로 제공합니다. 참증국가매체코드, 참증문헌번호, 참증일자, 참증문헌IPC코드, 참증공보출원일자, 참증발명의명칭, 참증건수 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

# 실시간 하천수위 정보 서비스

폭우나 장마철에 하천이 범람하거나 물살이 강하게 흘러 하천 주변의 위험성이 높아질 때를 대비하여 시민들의 안전을 위해 하천의 수위의 정보를 제공합니다. 개방된 데이터는 측정지역, 수위, 일 최대수위, 측정시간, 수위 상태, 경계단계 등의 데이터가 포함되어 있습니다 부산 전역의 20개소(동천교, 범5호교, 화명교, 학장교, 동백천, 임기천, 용소천, 효암천, 고래골천, 이곡천, 대천교, 삼락22호교, 청천교, 용상교, 장전동역, 연안교, 원동교, 온천천하류, 중앙여고, 온천장역 북측)데 대한 수위 정보를 매일 제공합니다.

제공기관: 부산광역시
분류: 재난안전
키워드: 안전, 재난, 폭우, 다리, 경계
형식: api

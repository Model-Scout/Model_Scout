# 국가데이터처_KOSIS 통계표설명 조회 서비스_20231231

국가데이터처가 관리하는 KOSIS(국가통계포털)의 개별 통계표에 대한 구체적인 메타데이터 정보를 제공하는 오픈 API 서비스입니다. 이 서비스는 통계 조사 전체를 포괄적으로 설명하는 '통계설명'과 달리, 사용자가 실제로 조회하고 가공하게 되는 '개별 통계표(Table)' 단위의 상세 정보를 다룹니다. 본 API를 통해 사용자는 특정 통계표의 작성 주기(년, 분기, 월 등), 최근 갱신 일자, 수록 기간, 단위(명, 원, % 등) 및 통계표에 적용된 특이사항(각주, 변경 이력) 등을 명확하게 확인할 수 있습니다. 사용자는 통계 수치를 수집하기 전, 해당 통계표의 데이터 구성 방식과 제약 요건을 미리 파악함으로써 데이터 연동 오류를 최소화하고 분석의 정확성을 기할 수 있습니다.

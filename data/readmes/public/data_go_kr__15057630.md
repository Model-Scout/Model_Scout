# 휴게음식점(아이스크림) 현황

이 데이터는 경기도 내 아이스크림을 주로 판매하는 휴게음식점에 대한 인허가 현황 정보를 제공합니다. 데이터는 경기도 31개 시군의 인허가 기반으로 구성되어 있으며, 주요 항목은 시군명, 사업장명, 인허가일자, 영업상태, 폐업일자, 소재지 주소 및 면적, 급수시설 구분, 위생업종/업태, 총시설규모, 종사자 수(남녀), 다중이용업소 여부, 위치정보(WGS84 좌표계) 등입니다. 이 데이터는 여름철 식품안전 모니터링, 디저트 전문 매장 분포 분석, 프랜차이즈 입점전략 수립, 관광지 주변 휴게음식점 현황 파악 등에 활용될 수 있으며, Open API 형식으로 XML 또는 JSON으로 제공됩니다.

제공기관: 경기도
분류: 식품건강
키워드: 휴게음식점, 아이스크림, 인허가현황, 위생업소, 식품안전, 다중이용업소, 디저트카페, 냉동디저트
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-06-24
이용허락: 이용허락범위 제한 없음

# 한국공항공사_공항별 항공노선

한국공항공사가 제공하는 ‘공항별 항공노선’ 데이터셋은 국내·외 공항을 기준으로 각 항공사가 운항하는 구간·취항도시·노선 정보를 일목요연하게 정리한 자료입니다. 교통·물류 분야 정책 수립·연구·서비스 개발에 필요한 기본 자료로 활용됩니다. 데이터는 공항코드, 공항명, 항공사명, 항공사코드, 운항구간(출발·도착 공항), 취항도시, 주·야간 운항 여부 등 10여 개 필드로 구성되며, 2020년 이후 실시간 업데이트를 반영해 월 1회 갱신됩니다. CSV·XLSX 형식으로 제공돼 검색·분석·시각화에 용이합니다. 주요 활용 사례로는 항공노선 네트워크 분석, 지역별 접근성 평가, 물류 흐름 최적화, 관광·비즈니스 연계 서비스 설계 등이 있습니다. 데이터는 공공데이터포털에서 무료 다운로드 가능하며, 상세 메타데이터와 문의처는 해당 페이지를 참고하시기 바랍니다.

# 금융위원회_채권권리행사정보_20200424

채권권리행사정보는 기준일자, 법인등록번호, 채권발행인명을 기준으로 채권 관련 권리행사 내역을 조회할 수 있는 데이터입니다. <데이터 조회 시 유의사항> 파라미터 없이 조회 시 데이터 조회 시간이 오래걸려 timeout이 발생하게 되어 필수 파라미터를 지정하였습니다. - 파라미터 조건 : 조회 시 아래의 필수 파라미터 중 최소 1개 이상을 반드시 입력해야 합니다. - 기본값 안내 : 필수 파라미터를 입력하지 않은 경우, 기준일자(basDt)는 자동으로 가장 최신 날짜로 설정되어 조회됩니다. [서비스별 필수 파라미터 목록] - 조기행사옵션조회 : basDt, isinCd, crno - 옵션부채권조기상환조회, 옵션행사가조정내역조회, 옵션행사내역조회 : 없음 총 4가지 오퍼레이션 정보가 제공되며, 각각 다음과 같은 내용을 포함합니다. 1. 조기행사 옵션 조회 : 기준일자, 법인등록번호, 채권발행인명을 통하여 옵션유형코드, 옵션행사시작일자, 옵션행사금액등을 조회하는 조기행사옵션조회 기능 2. 옵션 부채권 조기 상환 조회 : 옵션부채권조기상환일자, 법인등록번호, 옵션부채권발행인명을 통하여 옵션부채권발행금액, 옵션부채권이자지급금액, 채권발행금액, 옵션행사비율등을 조회하는 옵션부채권조기상환조회 기능 3. 옵션 행사가 조정내역 조회 : 준일자, 법인등록번호를 통하여 옵션행사가, 납입구분코드, 권리행사가격조정일자, 권리변경전행사가등을 조회하는 옵션행사가조정내역조회 기능 4. 옵션행사 내역조회 : 기준일자, 법인등록번호를 통하여 옵션행사가, 행사가격, 행사금액, 행사주식수, 상장일자등을 조회하는 옵션행사내역조회 기능 ※ 데이터 갱신주기는 일 1회입니다. ※ 금융위원회의 모든 API는 데이터 보유기관으로부터 데이터를 연계받아 수집 후 개방하고 있습니다. 금융위원회에서 제공하는 모든 서비스는 실시간이 아니며, 데이터 갱신은 기준일자로부터 영업일 하루 뒤 오후 1시 이후에 업데이트됩니다. 예를 들어, 금요일 데이터는 차주 월요일에 제공됩니다.

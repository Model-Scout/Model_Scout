# 공무원연금공단_연금취급기관정보

공무원연금공단에서 관리하는 공무원연금을 취급하는 기관정보를 조회할 수 있는 서비스로 지역, 소속부처, 연금기관명 등을 기준으로 조회요청하여 상위연금기관번호, 연금기관적용시작일자, 연금기관건물관리번호, 연금기관구분코드, 연금기관세부새주소, 연금기관팩스번호, 연금기관번호, 연금기관 우편번호, 연금기관 수신처명, 연금기관지역번호, 연금취급기관구분코드, 연금단위기관코드, 지역코드 등을 응답정보로 제공합니다. 코드 등 자세한 API 명세 내용은 첨부된 문서를 확인해주시기 바랍니다.

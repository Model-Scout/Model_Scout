# 전남광주통합특별시_아동급식카드 가맹점

광주광역시 결식우려 아동급식 지원사업은 관내 저소득 결식우려 아동(18세 미만) 대상 급식을 지원하는 사업으로, 지원대상자가 아동급식카드를 지급받는 경우 광주광역시 내 아동급식카드(아이꿈카드)를 사용할 수 있는 가맹점 현황을 설명하는 자료입니다. 데이터 주요 내용으로는 가맹점명, 업종명, 소재지 도로명주소, 전화번호 데이터를 제공하고 있으며, 2025년 6월 30일 기준으로 추출되어 변동 가능성이 있습니다. 카드 사용 관련 문의는 신한카드 홈페이지, 각 구청, 동 행정복지센터에서 확인이 가능합니다.

제공기관: 전남광주통합특별시
분류: 사회복지
키워드: 아동급식, 급식카드, 결식아동, 가맹점, 아이꿈카드

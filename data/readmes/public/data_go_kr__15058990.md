# 온천 현황

본 데이터는 경기도 내 온천의 전반적인 정보를 제공하는 자료로, 온천명, 위치(도로명주소 및 지번주소), 온천의 물리적 특성(온도, 심도, 주요 성분), 행정적 요소(지정일자, 보호구역 면적, 개발계획) 및 이용시설 수 등 다양한 항목으로 구성되어 있습니다. 이용자는 이를 통해 지역별 온천 분포, 주요 성분에 따른 분류, 시설 인프라 현황, 보호지구 지정 및 개발 관련 데이터를 확인할 수 있으며, 관광자원 개발, 보건 및 휴양 정책 수립, 환경보전 등의 목적으로 활용 가능합니다. 또한 위도·경도 정보를 통해 GIS 기반 분석 및 시각화에 유용하게 사용할 수 있습니다. 데이터는 Open API 방식으로도 제공되며, JSON 또는 XML 형태로 접근 가능합니다.

제공기관: 경기도
분류: 문화관광
키워드: 온천현황, 온천보호지구면적, 온천온도, 성분명, 온천심도, 이용시설수, 개발계획, 도로명주소
형식: api
선정 기준: 운영 자동승인 OpenAPI

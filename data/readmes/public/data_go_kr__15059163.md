# 반여농산물도매시장 반입물량정보

부산광역시 반여농산물도매시장내에서 거래되는 농산품의 실시간 경락정보(날짜, 도매법인, 품목, 품종, 단량, 등급, 반입일자, 물량(kg), 금액(최저가, 최고가, 평균가) 등) 실시간 경락정보, 반입물량정보 내 품목별 정보는 7일간의 정보만 제공됩니다. 제공되는 데이터를 통해 거래되는 농산품의 일일가격정보, 주간평균경락가격, 월간평균경락가격 조회가 가능합니다.

제공기관: 부산광역시
분류: 공공행정
키워드: 엄궁, 반여, 경락가격, 도매시장, 가격정보
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-07-28
이용허락: 이용허락범위 제한 없음

# 서울시설공단_서울도시고속도로 노선별 시간대별 교통량

서울도시고속도로 노선별 시간대별 교통량 - 서울도시고속도로 노선별 시간대별 교통량은 2025년 1월부터 12월까지 강변북로, 경부고속도로, 올림픽대로 등 8개 주요 노선에 대해 24시간 기준으로 시간대별 대표구간 교통량을 분석한 자료입니다. - 기간 : 2025년 1월 ~ 12월 - 노선 : 강변북로, 경부고속도로, 올림픽대로, 동부간선도로, 분당수서로, 북부간선도로, 강남순환로, 내부순환로 - 교통량 : 세부구간별 데이터가 상이하기 때문에, 해당노선의 특성을 잘 반영하는 지점을 대표구간 자료로 사용

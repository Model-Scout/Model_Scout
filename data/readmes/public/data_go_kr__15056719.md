# 해상교통안전

이 데이터는 해양수산부 국립해양조사원에서 해상교통안전 정보를 제공을 위해 수집한 데이터입니다. 본 데이터의 주요 내용은 해상구역도, 어장정보도, 요트낚시정보도, 소형선 항만안내도를 포함한 국가 중점개방 데이터 4종을 기반으로 해상 교통안전 정보를 기준으로 재분류한 해양공간 관련 정보로 구성되어 있습니다. 본 데이터는 해상교통로 및 항만 주변의 안전 관련 정보를 분석하거나 해양공간 관리, 해상 안전 정책 연구, 선박 운항 지원, 해양레저 이용 계획 수립 등의 분야에 활용할 수 있습니다.

제공기관: 해양수산부 국립해양조사원
분류: 교통물류
키워드: 해양공간정보, 국립해양조사원, 해양정보, 공간정보, 개방海
형식: api
선정 기준: 국가중점데이터 OpenAPI

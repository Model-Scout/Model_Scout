# 서울교통공사_콜센터전화번호

콜센터전화번호 데이터는 전국 도시철도 운영 기관의 콜센터(고객센터) 전화번호 정보를 제공합니다. 도시철도 운영기관에서 운영하는 콜센터명(기관명), 유선 전화번호, 문자 신고 전화번호 데이터를 제공하며, 문자 신고 전화번호를 운영하지 않거나, 일반 휴대전화 번호 형태로 운영하여 관련 규정 상 제공할 수 없는 경우 "정보없음"으로 표기, 제공합니다. 각 기관별 운행구간은 별도로 표기하지 않으며, 민원 접수 등을 위해 구간별 운행 기관 확인이 필요하신 경우 각 기관 홈페이지를 통해 확인하시기 바랍니다.

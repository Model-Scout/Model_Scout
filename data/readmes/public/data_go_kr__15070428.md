# 한국환경공단_순환자원정보_기업홍보

순환자원정보센터 시스템 내 등록되어 있는 재활용, 순환자원 기업홍보 목록 - 시스템 내 이용자(기업)가 직접 등록한 기업소개 및 홍보내용입니다. 상세 자료는 아래와 같습니다. 1. 업체명 : 정식등록 업체명칭 2. 업체 주소 : 도로명주소 3. 나머지주소 : 상세주소 4. 대표전화 : 업체를 대표하는 전화번호 5. 설립일 : 업체 설립날짜 6. 주업종 : 기업의 주된 업종(이용자 직접입력 항목) 7. 부업종 : 기업의 부업종(이용자 직접입력 항목) 8. 홈페이지 : 기업 홈페이지 URL주소 9. 등록일시 : 게시글 등록한 날짜 10. 수정일시 : 게시글 수정한 날짜

제공기관: 한국환경공단
분류: 환경기상
키워드: 순환자원정보센터, 기업, 홍보, 재활용, 폐기물
형식: csv
선정 기준: 중앙·광역 기관 파일데이터

# 한국직업능력연구원_민간자격현황

등록민간자격의 현황 데이터로 2008년 이후 현재까지 각 연도별 등록/폐지/취소 현황 자료를 수치화하여 제공하고 있습니다. 각 항목은 등록 연도, 등록 자격 수, 등록폐지 자격 수, 등록 취소 자격 수로 구성되어 있습니다. 연간 1회 업데이트를 진행하고 있으나, 민간자격정보서비스에서는 매월 민간자격정보서비스-자격정보-민간자격현황-등록민간자격현황에서 해당 정보를 업데이트하고 있습니다. 민간자격 등록(등록/폐지/취소) 현황 관련하여 실시간 등록 자격수/ 폐지 자격수 정보를 원할 경우 민간자격정보서비스-자격정보-민간자격 검색 혹은 등록폐지자격 검색 기능을 통하여 확인가능합니다.

제공기관: 한국직업능력연구원
분류: 교육
키워드: 민간자격, 현황정보, 자격_수, 등록현황, 연도별
형식: csv
수정일: 2026-08-26
이용허락: 이용허락범위 제한 없음

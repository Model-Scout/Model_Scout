# 지식재산처_KIPRISPlus_출원인 명칭 변동 이력_REST API_20191231

1. 개요 출원에서 설정등록 이전까지 변경된 출원인(법인)의 명칭이 변경된 이력정보를 제공합니다. 출원인의 명칭 변경에 대한 이력정보를 API(REST방식) 및 대용량(BULK)으로 제공합니다. 2. 세부 정보 내용 출원인 명칭 변경 이력 조회 : 출원인 명칭 변경 이력 정보를 XML 형태로 제공합니다. 특허고객번호, 변경이력순서, 접수번호, 변경일자, 특허고객명(국문, 영문), 국문명칭변경여부, 영문명칭변경여부 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

제공기관: 지식재산처
분류: 과학기술
키워드: 출원인 명칭, 특허고객번호, 변경이력순서, 국문명칭변경, 영문명칭변경
형식: api
선정 기준: 운영 자동승인 OpenAPI

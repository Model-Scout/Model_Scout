# 한국관광공사_두루누비 정보 서비스_GW

본 API는 한국관광공사에서 제공하는 전국 순환형 트래킹 코스 '코리아둘레길'의 284개 코스 상세 GPX 정보와 주변 관광정보입니다. Open API형태로 2가지 오퍼레이션(코스 목록 정보 조회, 길 목록 정보 조회)을 제공하고 있습니다. 코리아둘레길의 GPX 정보는 두루누비 외 타 어플에도 적용하여 걷기 기록을 측정 할 수 있으며, 트래킹용 스마트 워치에 다운받아 개인별로 기록 측정 및 완주가 가능합니다. 또한 다양한 서비스에 결합하여 새로운 서비스로 재생산 가능한 데이터입니다. 자세한 사용법은 API 명세서를 참고하시기 바랍니다.

제공기관: 한국관광공사
분류: 문화관광
키워드: 걷기, 걷기_여행, 걷기_여행길, 코리아둘레길, 두루누비, 둘레길, 레저_여행, 트레킹
형식: json+xml
선정 기준: 중앙·광역 기관 파일데이터
수정일: 2026-02-25
이용허락: unknown

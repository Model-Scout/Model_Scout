# 병원평가정보(유방암) 현황

병원평가정보(유방암) 현황은 건강보험심사평가원이 제공하는 경기도 내 의료기관의 유방암 수술 치료 성과를 종합적으로 평가한 데이터입니다. 평가 기준은 유방암 환자의 수술 및 보조요법 전반을 포함하며, 종합결과 점수에 따라 1등급(95점 이상)부터 5등급(80점 미만)까지 분류됩니다. 평가항목(DIV_NM), 평가등급(GRAD), 시군명 및 코드(SIGUN_NM, SIGUN_CD), 병원명(INST_NM), 병원 위치(REFINE_ROADNM_ADDR, REFINE_LOTNO_ADDR, REFINE_ZIP_CD, REFINE_WGS84_LAT, REFINE_WGS84_LOGT) 등이 포함되며, API 호출 시 응답코드(CODE), 메시지(MESSAGE), API 버전(API_VERSION)과 전체 건수(LIST_TOTAL_COUNT)도 확인 가능합니다. 본 자료는 유방암 수술 관련 병원 선택의 합리적 판단을 돕고, 지역 간 치료 격차 해소 및 보건정책 수립에 활용될 수 있습니다. 보조요법 지표가 부족하거나 평가건수가 10건 미만인 기관은 등급제외 처리됨을 유의해야 합니다.

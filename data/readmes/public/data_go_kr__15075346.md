# 외교부_국가·지역별 표준코드

국가·지역별 표준코드 목록 조회: 한글 국가 명 또는 영문국가 명 또는 ISO국가코드(다.참고 1 ISO국가코드 이용 )로 국가 표준코드에 대한 목록 조회 - 국가별 ISO3166-1 표준코드 및 한글명칭, 영문명칭 정보를 제공하는 공공데이터 API 서비스 외교부에서 보유하고 있는 국가별, 지역별 ISO3166-1 표준코드(2자리, 3자리) 및 한글명칭, 영문명칭을 API 서비스 제공합니다. 국가는 231개 제공되며, 제공되는 국가의 코드 예시를 보면 1.

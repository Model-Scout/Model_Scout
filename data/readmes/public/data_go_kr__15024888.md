# 올림픽공원 장미정보

올림픽공원 안에 있는 수목과 장미 등에 관한 정보 제공 수목명, 수목종류, 설명 등 정보제공 2025년 기준 182건의 데이터를 제공하고 있으며, 한국체육산업개발의 올림픽공원 장미정보를 외부 개발자 및 사용자가 이를 활용 할 수 있도록 전달하는 API 서비스입니다. 올림픽공원 장미광장의 장미 목록정보와 상세정보 등 다양한 정보를 제공합니다. 올림픽공원 홈페이지에서도 정보를 제공하고있습니다. https://www.ksponco.or.kr/olympicpark/menu.es?mid=a20403010000

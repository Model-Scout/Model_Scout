# 맞춤형 자치법규 목록 조회

법제처가 제공하는 맞춤형 자치법규 목록 조회 데이터는 지방자치단체가 공포한 조례 및 규칙 등의 기본 정보를 체계적으로 제공합니다. 해당 데이터는 자치법규의 명칭, 공포일자, 공포번호, 자치법규ID, 자치법규일련번호, 제개정구분, 자치법규종류, 지자체기관명, 시행일자, 자치법규분야명 및 분류코드 등 주요 속성을 포함합니다. 사용자는 분류코드 또는 지자체 기관명, 목록 개수 및 페이지 옵션을 통해 원하는 자치법규를 맞춤형으로 조회할 수 있습니다. 자치법규의 분류 및 시행 정보를 일목요연하게 확인할 수 있어 법령-자치법규 연계 현황 파악과 지자체 입법 지원 자료로 활용하기에 유용합니다.

제공기관: 법제처
분류: 공공행정
키워드: 국가법령정보센터조례규칙, 연계정보, 분야코드, 시행일자, 지자체기관, 공포일자, 제개정, 조례규칙
형식: api
선정 기준: 운영 자동승인 OpenAPI

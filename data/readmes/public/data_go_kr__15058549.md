# 지식재산처_KIPRISPlus_특허·실용 피인용문헌_REST API_20220308

1. 개요 선행기술을 인용한 특허･실용 문헌 정보를 제공합니다. 특허·실용 피인용문헌을 API(REST 방식) 및 대용량(Bulk)으로 제공합니다. 2. 세부정보 특허·실용 피인용문헌 등의 정보를 XML 형태로 제공합니다. 출원번호(선행기술), 출원번호(피인용문헌, 후행기술), 표준화처리상태코드, 표준화처리상태설명, 인용문헌구분코드, 인용문헌구분코드명 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

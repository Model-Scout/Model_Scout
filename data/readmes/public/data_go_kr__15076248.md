# 한국국제협력단_해외봉사단 파견기관 정보_20210116

KOICA의 해외봉사단이 파견된 수원기관의 정보를 제공하는 API입니다. 각 파견국 내 봉사단 수요기관의 명칭, 위치, 분야 등 정보가 포함되어 있으며, 봉사단 활동이 수행되는 현장의 파트너십 관계를 이해하는 데 유용합니다. 해당 API는 인증키(serviceKey), 페이지 번호(pageNo), 한 페이지 결과 수(numOfRows) 등 기본적인 요청변수를 사용하며 한글 국가명, 데이터표출방식, ISO 2자리코드 등의 필터 파라미터를 추가로 설정할 수 있습니다. 출력결과에는 국가명, ISO 2자리코드, 파견기관코드, 파견기관명 등의 항목이 포함되며, 각 항목에 대한 데이터는 JSON 형식으로 반환됩니다.

# 지식재산처_KIPRISPlus_등록사항_REST API

1. 개요 지식재산권 권리 효력 발생을 위한 절차와 관련된 국내 지식재산권(특허, 실용, 디자인, 상표)의 등록사항 정보를 제공합니다. 지식재산권의 권리, 순위, 권리자, 등록료, 존속시간만료(예정)일자에 대한 등록정보를 API(REST방식) 및 대용량(BULK)으로 제공합니다. 2. 세부 정보 내용 권리, 권리자, 권리순위, 등록료 등의 정보를 XML 형식으로 제공합니다. 등록번호, 등록일자, 출원번호, 출원일자, 공고번호, 공고일자, 발명의명칭(국문, 영문), 지정분류코드, 존속기간만료일자, 청구항수, 선원출원번호, 우선권주장수, 소멸일자, 소멸원인, 국제등록번호, 권리자정보 등 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

제공기관: 지식재산처
분류: 과학기술
키워드: 선출원번호, 권리_정보, 발명의_명칭, 등록번호, 출원번호
형식: xml
수정일: 2025-09-22
이용허락: unknown

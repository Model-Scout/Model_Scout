# 중소기업기술정보진흥원_스마트공장 지원사업 우수 구축사례

스마트공장은 제조 전과정을 ICT로 통합하여 고객맞춤형 스마트제품을 생산하는 지능형 공장으로 스마트공장은 하드웨어(센서, 액츄에이터 등), 네트워크, 소프트웨어(MES 등) 등으로 구성되어 있습니다. (공장자동화) 설비들이 개별적으로 자동화된 것 (스마트공장) 자동화된 설비들이 서로 연결되고, 모든 것이 데이터 되어 데이터 기반으로 공장이 가동되는 것 스마트공장 보급 확산사업에 참여하여 스마트공장을 구축한 우수 기업의 참여년도, 업체명, 사업기간, 주요성과 등의 자료를 제공합니다.

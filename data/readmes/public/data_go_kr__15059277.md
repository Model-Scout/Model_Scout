# 지식재산처_KIPRISPlus_출원인 법인_REST API_20220722

1. 개요 특허, 실용, 디자인, 상표 출원인 중 출원 건이 공개(등록)된 이력이 있는 법인정보를 API(REST방식) 및 대용량(BULK)으로 제공합니다. 2. 세부 정보 내용 출원인사업자번호: 특허고객번호, 출원인대리인명, 사업자등록번호, 법인번호 정보를 XML 형태로 제공합니다. 출원인코드, 출원인명(국문, 영문), 법인번호, 사업자번호 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

제공기관: 지식재산처
분류: 과학기술
키워드: 출원인코드, 출원인명, 법인번호, 사업자등록번호, 출원인사업자번호
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-09-22
이용허락: 이용허락범위 제한 없음

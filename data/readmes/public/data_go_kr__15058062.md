# 서울시 소통 돌발 링크 Vertex 정보

해당 데이터는 서울시 교통정보시스템(https://topis.seoul.go.kr)에서 제공하는 소통 돌발 링크 Vertex OpenAPI입니다. 요청인자 : 인증키, 요청파일타입, 서비스명, 요청시작위치(페이징 시작번호(데이터 행 시작번호)), 요청종료위치(페이징 끝번호(데이터 행 끝번호)), 링크 아이디 출력값 : 총 데이터 건수(정상조회 시 출력됨), 요청결과 코드, 요청결과 메시지, 링크 아이디, Vertex 순서, TMX 좌표, TMY 좌표 ※ 바로가기 클릭 시 서울 열린데이터광장 개방 데이터로 이동합니다.

제공기관: 서울특별시
분류: 교통물류
키워드: 교통상황, 교통량, 통제, Vertex, 돌발 링크
형식: api
선정 기준: 운영 자동승인 OpenAPI

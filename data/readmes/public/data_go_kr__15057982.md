# 역코드로 지하철 열차 시간표 검색

서울교통공사_역코드로 지하철 열차 시간표 검색 API는 역 코드로 지하철역별 열차운행시각표 정보를 검색할 수 있는 API입니다. (호선, 외부코드, 전철역코드, 역사명, 방향, 도착시간, 출발시간, 출발역, 도착역 등) [제공범위] - 서울교통공사에서 운영하는 1~9호선 지하철역에 한하여 열차운행시각표 데이터 제공 [호출 시 유의사항] - 전철역코드: '서울교통공사_역명 지하철역 검색 데이터' 참고 - 요일: 1(평일), 2(토요일), 3(일요일/공휴일) - 상/하행선: 1(상행/내선), 2(하행/외선) ※ 역별 열차 시각표를 기준으로 제공하는 정보이며, 실제 열차 도착시간과 다를 수 있습니다.

제공기관: 서울교통공사
분류: 교통물류
키워드: 전철역코드, 시간표, 열차시간표, 서울지하철, 도시철도, 지하철, 열차운행, 열차정보
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2026-09-22
이용허락: 이용허락범위 제한 없음

# 한국고용정보원_워크넷 공채속보 공채기업목록 및 상세정보_20210520

[채용정보 API - 공채기업목록 및 상세정보] 공채기업정보 API를 이용하여 보다 정확한 공채기업정보를 확인 할 수 있습니다. 워크넷에서 제공하는 공채속보의 기업정보를 서비스로 제공합니다. 목록 및 상세 형태로 제공하고 있으며 공채기업의 목록정보는 워크넷에서도 확인이 가능합니다. <공채기업목록 API 사용법> 인증키, 호출할 페이지 타입, xml 지정, 검색 시작위치, 출력건수, 기업 구분코드(대기업, 공기업, 공공기관, 중견기업, 외국계기업), 등록일, 회사명 등을 파라미터로 받아 총건수, 기본값 1, 출력건수, 채용기업번호, 회사명, 기업구분명, 사업자등록번호, 좌표:위도, 좌표:경도, 채용기업로고, 기업소개요약, 기업소개상세, 홈페이지, 주요사업 등의 결과를 제공합니다. <공채기업 상세정보 API 사용법> 인증키, 호출할 페이지 타입, xml 지정, 채용기업번호 등을 파라미터로 받아 채용기업번호, 회사명, 기업구분명, 로고, 홈페이지, 사업자등록번호, 좌표:위도, 좌표:경도, 주요사업, 기업소개 요약, 기업소개 상세, 카테고리, 복리후생내용, 연혁년도, 연혁월, 연혁내용, 인재상키워드, 인재상내용 등의 결과를 제공합니다. * 유의사항: 문자열로 입력되는 항목의 경우 공백이나 오탈자가 포함되면 검색 결과가 제대로 나오지 않을 수 있으므로 주의해야 합니다. 대부분의 파라미터는 선택적으로 입력할 수 있으며, 필요한 조건만 입력해도 조회는 가능합니다.

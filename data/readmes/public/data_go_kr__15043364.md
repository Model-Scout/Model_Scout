# 금융위원회_주식분포및사고주권정보_20200424

주식분포및사고주권정보는 주식 발행기업의 권리행사 기준일자를 중심으로 주식의 분포 현황과 사고주권 발생 여부를 조회할 수 있는 데이터입니다. 주식분포 항목에는 주주 인원 수, 인원 비율, 발행 주식 수, 주식 분포 지역 등이 포함되며, 사고주권 항목에는 사고증권 번호, 사고구분 사유(예: 제권판결, 압류 등), 주식 발행 일련번호 등의 정보가 제공됩니다. 2개 오퍼레이션으로 구성되어 있으며 세부 내용은 다음과 같습니다. ① 사고주권여부조회 : 기준일자, 법인등록번호, 주식발행회사명을 통하여 주식발행일련번호, 사고증권번호구분명, 사고증권번호, 사고주권종류수 등을 조회하는 사고주권여부조회 기능 ② 주식분포내역조회 : 권리행사자격기준일자, 주식발행회사명을 통하여 주주인원수, 주주인원비율, 발행주식수, 발행주식비율 등을 조회하는 주식분포내역조회 기능 해당 데이터는 투자자 보호 및 자본시장 투명성 확보에 기초 자료로 활용할 수 있습니다. <데이터 조회 시 유의사항> 파라미터 없이 조회 시 데이터 조회 시간이 오래걸려 timeout이 발생하게 되어 필수 파라미터를 지정하였습니다. - 파라미터 조건 : 조회 시 아래의 필수 파라미터 중 최소 1개 이상을 반드시 입력해야 합니다. - 기본값 안내 : 필수 파라미터를 입력하지 않은 경우, 기준일자(basDt)는 자동으로 가장 최신 날짜로 설정되어 조회됩니다. [서비스별 필수 파라미터 목록] - 사고주권여부조회 : basDt - 주식분포내역조회 : 없음 ※ 데이터 갱신주기는 일 1회입니다. ※ 금융위원회의 모든 API는 데이터 보유기관으로부터 데이터를 연계받아 수집 후 개방하고 있습니다. 금융위원회에서 제공하는 모든 서비스는 실시간이 아니며, 데이터 갱신은 기준일자로부터 영업일 하루 뒤 오후 1시 이후에 업데이트됩니다. 예를 들어, 금요일 데이터는 차주 월요일에 제공됩니다.

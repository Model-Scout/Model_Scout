# 현대사 디지털아카이브 목록정보 조회 API 서비스

대한민국역사박물관이 소장한 근현대사 아카이브 자료의 목록 정보를 제공하는 데이터입니다. 명칭, 생산연대, 주제분류, 자료유형, 저작권, 공공누리 유형, 이미지 URL, 상세설명 등 다양한 메타데이터를 포함하고 있어 자료의 특성과 활용 가능성을 한눈에 파악할 수 있습니다. 연구자와 일반 이용자는 분야별로 정리된 디지털 아카이브를 통해 역사자료를 손쉽게 탐색할 수 있으며, 교육, 연구, 전시, 콘텐츠 제작 등 다양한 목적으로 활용이 가능합니다. 또한 해당 자료는 지속적으로 업데이트되어 최신의 역사 정보를 제공하며, 공공저작물로서의 활용도를 높여 역사·문화 콘텐츠 개발과 학술 연구, 교육 자료 제작 등에 기여합니다.

제공기관: 문화체육관광부 대한민국역사박물관
분류: 문화관광
키워드: 아카이브, 역사, 자료, 근현대, 디지털, 연구, 저작권, 교육
형식: api
선정 기준: 운영 자동승인 OpenAPI

# 국토교통부_전국 법정동

대한민국의 법률로 지정된 일정한 명칭과 영역을 지닌 행정구역으로, 국가공간정보통합플랫폼(K-GeoP)의 토지행정 서비스에서 사용하는 법정동(코드, 명칭 등) 데이터임. 전남광주통합특별시 출범에 따라 데이터 갱신 및 현행화 - 법정동코드 : 법률을 기반으로 대한민국의 행정구역으로 지정된 지역 코드 - 시도명 : 대한민국의 시도 명칭 - 시군구명 : 대한민국의 시군구 명칭 - 읍면도명 : 대한민국의 읍면동 명칭(명칭이 없을 경우 공백 혹은 NULL 발생) - 리명 : 대한민국의 리 명칭(명칭이 없을 경우 공백 혹은 NULL 발생) - 생성일자 : 법정동이 생성된 일자(YYYY-MM-DD)

제공기관: 국토교통부
분류: 국토관리
키워드: 법정동코드, 행정구역_개편, 법정동_명칭, 지역_코드, 지자체, 부동산, 대한민국
형식: csv
선정 기준: 중앙·광역 기관 파일데이터

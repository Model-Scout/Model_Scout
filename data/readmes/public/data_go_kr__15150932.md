# 한국석유공사_전국 주유소 평균가격 오픈 API

이 데이터는 한국석유공사 오피넷에서 제공하는 오픈 API로 전국 주유소의 휘발유, 경유, 고급휘발유 등의 평균 판매가격 정보를 제공하며, 일자, 제품구분코드, 제품명, 평균가격 및 전일 대비 가격 등락을 포함하고 있습니다. 이를 활용하면 특정 연료의 가격 추이를 분석하거나, 정책 수립, 시장 동향 파악, 가격 비교 및 모니터링 등에 활용할 수 있습니다. 또한 민간 플랫폼, 모바일 앱, 내비게이션 서비스 등에서 직접 연계하여 실생활에 밀접한 정보 제공이 가능하다는 점에서 활용성이 뛰어난 데이터입니다.

제공기관: 한국석유공사
분류: 산업고용
키워드: 주유소, 유가정보, 실시간, API, 지역별, 셀프주유소, 휘발유가격, 석유공사
형식: xml
선정 기준: 중앙·광역 기관 파일데이터

# 한국국제협력단_융합_KOICA-ODA 사업정보_KF-공공외교 사업 정보_20220225

KOICA가 수행한 ODA 개발협력사업과 한국국제교류재단(KF)의 공공외교사업 정보를 융합 제공하는 API입니다. 하나의 대상국에서 진행된 두가지 사업의 예시를 한눈에 파악할 수 있습니다. 해당 API는 인증키(serviceKey), 페이지 번호(pageNo), 한 페이지 결과 수(numOfRows) 등 기본적인 요청변수를 사용하며 한글 국가명, ISO 2자리코드, 사업시작일, 사업종료일 등의 필터 파라미터를 추가로 설정할 수 있습니다. 출력결과에는 국가명, ISO 2자리코드, 대륙명, 사업유형코드, 사업명, 사업시작일, 사업종료일, 다년구분코드, 수혜기관명, 사업년도 등의 항목이 포함되며, 각 항목에 대한 데이터는 JSON 형식으로 반환됩니다.

# 한국고용정보원_워크넷_직무데이터사전

[직무정보 API - 직무데이터사전] 데이터사전 API를 이용하여 다양한 직무에 대한 정보를 구성할 수 있습니다. <API 사용법> 인증키, 키워드, NCS 능력단위 출력건수 등을 파라미터로 받아, NCS 능력단위명, NCS 능력단위 정의, NCS 소분류명, NCS 소분류코드, NCS 대분류코드, NCS 중분류명, NCS 대분류명, NCS 세분류코드, NCS 중분류코드, NCS 능력단위 코드 등의 결과를 제공합니다. * 유의사항: 문자열로 입력되는 항목의 경우 공백이나 오탈자가 포함되면 검색 결과가 제대로 나오지 않을 수 있으므로 주의해야 합니다. 대부분의 파라미터는 선택적으로 입력할 수 있으며, 필요한 조건만 입력해도 조회는 가능합니다.

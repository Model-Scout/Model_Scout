# 경기도_주요 도로별 소통 정보

경기도 주요 도로별 소통 정보는 경기도교통정보센터에서 제공하는 API 기반의 실시간 도로 소통 정보 데이터로, 도로명, 도로방향, 구간속도, 교통량, 지체시간 등 교통 흐름 관련 정보를 포함합니다. 해당 데이터는 도로의 혼잡도 분석, 실시간 교통 모니터링, 교통 예측 시스템 개발 등에 활용될 수 있으며, 특히 도로 운영 최적화 및 통행 시간 예측 등에 효과적인 기초 자료로 사용됩니다. OpenAPI 형식으로 제공되어 내비게이션, 교통정보 애플리케이션, 스마트시티 플랫폼 등 다양한 시스템과의 연동이 가능합니다.

제공기관: 경기도
분류: 재난안전
키워드: 교통소통, 구간속도, 교통량, 지체시간, 교통정보센터, 도로
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-09-25
이용허락: 이용허락범위 제한 없음

# 건강보험심사평가원_약국정보서비스_20200609

건강보험심사평가원에서 관리하는 약국 정보를 조회할 수 있는 서비스입니다. - 국민건강보험법 제 43조(요양기관 현황에 대한 신고) 및 동법 시행규칙 제 12조(요양기관 현황 신고 등)에 의해 요양기관이 건강보험심사평가원에 신고한 기준으로 작성되었습니다. - 요양기호는 1:1로 매칭한 암호화된 요양기호로 제공하고 있으며, 별도의 복호화 방법 또는 요양기호는 제공하고 있지 않습니다. - 지역코드 등 API 활용을 위한 코드는 보건의료빅데이터개방시스템(opendata.hira.or.kr) > 서비스 소개 > 용어설명 > 코드조회를 참고하여 주시기 바랍니다. ※ 403 오류 원인 및 해결방법을 반영한 API활용가이드 수정본 업로드하였습니다.(0910 기준) - OPEN API 상세페이지 내 참고문서 확인

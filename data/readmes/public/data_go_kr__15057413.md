# 행정안전부_실시간 영문주소정보 조회(검색API)_20211221

도로명주소 DB 구축없이 다양한 시스템 환경에서 실시간으로 주소 검색기능을 구현할 수 있습니다 1. API 서비스 개요 - 다양한 시스템 환경 적용 가능 - 개발언어, 플랫폼 제약없음 - DB 구축 및 현행화 부담 없음 - 실시간 주소 검색 가능 - 신청 즉시 이용 가능 - 1 시스템 1 승인키 부여 - 검색어는 한글, 영문 모두가능 2. 입력 파라미터 정보 신청 시 부여받은 승인키,현재 페이지 번호,페이지당 출력할 결과 Row 수,주소 검색어,검색결과형식 설정(기본XML형식) json 입력 시 JSON형식의 결과제공 3. 출력 파라미터 정보 영문 도로명주소,영문 지번주소,우편번호,행정구역코드,도로명코드,공동주택여부(1 : 공동주택, 0 : 비공동주택),영문 시도명,영문 시군구명,영문 읍면동명,영문 법정리명,영문 도로명,지하여부(0 : 지상, 1 : 지하),건물본번,건물부번,산여부(0 : 대지, 1 : 산),지번본번(번지),지번부번(호),도로명주소(한글)

제공기관: 행정안전부
분류: 과학기술
키워드: 주소, 도로명주소, 영문API, 영문주소검색, 영문도로명검색
형식: api

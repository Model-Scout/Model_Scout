# 독립기념관_독립운동가 인명사전 정보 DB

독립기념관에서 편찬한 독립운동가 인명사전에 대한 open api 정보입니다. 요청변수로는 type, 운동계열, 훈격, 내/외국인 여부, 페이지입니다. 운동계열 구분 3.1운동, 3.1운동지원, 계몽운동, 계몽운동지원, 광복군, 광복군지원, 국내항일,노령방면, 독립운동지원, 만주방면, 문화운동, 미주방면, 애국계몽운동, 의병, 의열투쟁, 인도네시아방면, 일본방면, 임시정부, 임시정부지원, 중국방면, 학생운동 포상훈격 구분 대한민국장, 대통령장, 독립장, 애국장, 애족장, 건국포장, 대통령표창, 미포상자

제공기관: 독립기념관
분류: 문화관광
키워드: 역사, 독립운동, 자료, 포상훈격, 운동계열
형식: xml
선정 기준: 중앙·광역 기관 파일데이터

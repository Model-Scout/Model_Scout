# 주택도시보증공사_보증상품별 최대손실액(VaR) 비중

주택도시보증공사에서 발급된 각 보증상품별 단위당 VaR의 월말 기준 값 각 보증상품별로 예상되는 최대손실 정도를 나타내는 수치 제공 - 개요: 보증상품 및 신용등급 별 최대손실액(VaR) 비중. - 정의: 최대손실액 비중은 보증상품 잔액 대비 잠재 손실 수준을 백분율로 표현한 수치 - 예시: AAA PF보증의 최대손실액 비중이 0.1%라면, 신용등급이 AAA인 PF보증의 VaR은 AAA PF보증 전체 익스포져의 0.1% 수준이라는 의미 - 의의: 전체 익스포져 대비 VaR의 비중을 보여줌으로써 보증상품의 상대적 위험도를 파악 가능 - 참고: VaR는 극단적인 손실은 반영하지 않으며, 익스포져 규모와 무관하게 비율로 해석되므로 활용에 주의 - 데이터 기간 : 26.9.30. 기준

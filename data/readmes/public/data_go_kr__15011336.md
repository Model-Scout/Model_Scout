# 경기도 의료 유사업 현황(2015)

이 데이터는 경기도 내에서 의료 유사업소 중 안마를 목적으로 하는 업소의 현황을 제공합니다. 데이터에 포함된 업소는 연면적 830제곱미터 이하의 규모를 기준으로 선정됩니다. 보건의료 분야에 해당하며, 공공데이터 포털를 통해 제공되고 있습니다. 데이터는 API 형태로 제공되며 XML 포맷으로 활용할 수 있습니다. 주요 활용방안으로는 안마업소의 분포 현황 파악, 정책 수립 자료, 보건 위생 관리 기반 자료 등으로 사용할 수 있습니다. 데이터 제공기관은 경기도이며, 이용허락범위에 제한 없이 활용이 가능합니다. 이 데이터는 경기도 내 안마 관련 의료 유사업소의 시설규모를 기준으로 관리되므로, 데이터 활용 시 적용 면적 기준과 관련 법령 등을 사전에 확인하는 것이 중요합니다.

# 한국국제협력단_해외봉사단 자가안전체감도_20210116

KOICA 해외봉사단이 현지 체류 중 느끼는 안전체감도에 대한 데이터를 제공하는 API입니다. 파견자의 주관적 위험 인식 정보는 객관적인 안전 데이터와 함께 해석되어, 실제 체감 안전 수준과의 차이를 분석할 수 있게 합니다. 해당 API는 인증키(serviceKey), 페이지 번호(pageNo), 한 페이지 결과 수(numOfRows) 등 기본적인 요청변수를 사용하며 한글 국가명, 데이터표출방식, ISO 2자리코드 등의 필터 파라미터를 추가로 설정할 수 있습니다. 출력결과에는 한글 국가명, ISO 2자리코드, 년도, 안전수준코드, 안전수준변화코드 등의 항목이 포함되며, 각 항목에 대한 데이터는 JSON 형식으로 반환됩니다.

# 국민연금공단_연령별 가입종별 평균소득월액

해당 데이터는 국민연금공단 가입자의 데이터를 기반으로 만들어졌습니다. 연도별 국민연금 가입자의 평균소득월액 데이터를 나타냅니다. 해당 데이터는 가입자의 연령과 가입종별에 따라 분류되어 있고 분류기준은 아래와 같습니다. -연령: 27세 미만,~29세 이하, ~ 39세 이하, ~49세 이하, ~59세 이하, 60세 이상 -가입종별: 사업장가입자, 지역가입자, 임의가입자, 임의계속가입자 국민연금 가입자의 연령과 가입종별에 따른 국민연금 가입자의 평균소득월액을 확인하실 수 있습니다. (데이터 건수가 많은 경우 모든 데이터가 표출되지 않을 수 있습니다.) 국민연금공단의 가입된 국민연금 가입자의 데이터를 기반으로 만들어진 국민연금 가입자의 연령별, 가입종별 평균소득월액 입니다.

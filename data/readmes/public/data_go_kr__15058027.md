# 모바일 자치법규 목록 조회

법제처가 제공하는 모바일 자치법규 목록 조회 데이터는 지방자치단체에서 제정한 조례 및 규칙 등의 자치법규 정보를 모바일 환경에서 확인할 수 있도록 구성된 자료입니다. 이 데이터는 자치단체명, 자치법규명, 자치법규ID, 자치법규구분(조례·규칙 등), 제·개정 구분, 공포일자, 시행일자, 소관부서명, 문서번호, 시행여부 등 주요 항목으로 구성되어 있습니다. 사용자는 자치단체명, 자치법규명, 문서번호 등의 조건을 입력하여 해당 지역의 자치법규를 목록 형태로 조회할 수 있으며, 페이지 번호와 조회 건수를 지정하여 결과를 맞춤 설정할 수 있습니다. 경량화된 구조로 모바일 환경에서 신속하게 접근할 수 있으며 법령과 구분되는 지역 단위의 입법 정보를 체계적으로 제공함으로써 자치입법 분석, 규제 검토 및 지역 행정 업무에 효과적으로 활용할 수 있습니다.

제공기관: 법제처
분류: 공공행정
키워드: 앱조례규칙, 문서번호, 소관부서, 시행일자, 공포일자, 조례, 규칙, 입법구분
형식: api
선정 기준: 운영 자동승인 OpenAPI

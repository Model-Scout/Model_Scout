# 한국산업단지공단_팩토리온_종업원관리

공장설립온라인지원시스템(factoryon)에 등록된 공장들의 공장 등을 제공합니다. 해당 공공데이터는 산업단지 내 입주기업의 현황을 체계적으로 관리하기 위한 행정 기반자료로, "21년 7월말 기준으로 집계된 공장설립온라인지원시스템(factoryon)에 등록된 공장들의 기본정보(회사명, 주소 등), 공장 규모, 공장 관리번호를 기반으로 종업원수(남자, 여자, 외국인남자, 외국인여자)를 집계한 데이터입니다. 데이터 건수가 많아 일반적인 엑셀, 메모장 등에서는 전체 내용이 표출되지 않을 수 있으므로, 전용 데이터 분석 소프트웨어(R, Python, SPSS, Stata 등)를 활용하여 분석하시기 바랍니다.

분류: 공공행정
키워드: 남자_종업원수, 여자_종업원수, 외국인_종업원수, 종업원, 인원
형식: xlsx

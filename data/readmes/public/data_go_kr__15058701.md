# 지식재산처_KIPRISPlus_해외특허_REST API

1. 개요 지식재산 주요국(기구)인 미국, 유럽, PCT, 중국, 일본, 러시아, 콜롬비아 특허 공개공보 및 등록공보와 일본·중국·대만 특허 영문초록, 스웨덴 특허 서지 정보를 API(REST방식)로 제공합니다. 2. 세부 정보 내용 ① 검색 : 일반검색 및 항목별검색 기능을 통해 해외특허 정보를 XML 형태로 제공합니다. ② 서지정보 : 서지상세정보, 초록, IPC, 발명자, 발명의 명칭, 해외서지, 청구항, 미국특허문헌 등의 정보를 XML 형태로 제공합니다. ③ 도면/전문 : 공개 및 공고 전문, 대표도면의 다운로드 경로를 XML 형태로 제공합니다. ④ 부가기능: 코드조회 등을 XML 형태로 제공합니다. ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

제공기관: 지식재산처
분류: 과학기술
키워드: 서지상세정보, 해외서지, 미국특허문헌_, 공개_및_공고_전문, 대표도면의
형식: xml
선정 기준: 중앙·광역 기관 파일데이터

# 국토교통부_KLIS코드매칭

국토교통부_KLIS 코드매칭 테이블 데이터는 용도지역지구,용돋지역지구분코드를 사용하는 공간정보 KLIS.SHP 데이터와 해당되는 컬럼명으로 매칭 되어있는 테이블입니다. 작성된 데이터의 코드내용으로 적용되는 코드별로 해당 컬럼에 맞는 코드내용과 레이어 매칭되고 추가적으로 KLIS코드도 매칭됩니다. 국토교통부 KLIS 코드매칭 테이블은 중장기 계방개획으로 2023년에 공공데이터 목록등록관리에 등록된 데이터 이며 현재는 고도화 되어 갱신되지 않는 단반성 데이터 입니다.

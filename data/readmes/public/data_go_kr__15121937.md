# 행정안전부_공공데이터포털 목록 메타정보

공공기관이 공공데이터포털에 등록하여 개방중인 목록의 메타정보(목록키, 목록명, 키워드, 제공기관명, 제공기관코드, 목록유형, 서비스유형, 데이터포맷 , 요청변수, 출력결과, 주기, 전체행)를 제공합니다. 목록키는 데이터 목록을 식별하는 고유 키, 목록명은 데이터 목록의 명칭, 키워드는 데이터 검색을 위한 주요 키워드, 제공기관명 및 코드는 데이터를 제공하는 기관의 명칭 및 코드 입니다. 목록유형에는 FILE, API로 구분, 데이터포맷은 CSV, XLSX, HWPX, PDF, JSON+XML, JSON, XML 등으로 구분, 주기는 연간, 반기, 분기, 월간, 주간, 수시 등으로 구분, 서비스유형은 FILE, LINK, REST 등으로 구분됩니다.

제공기관: 행정안전부
분류: 공공행정
키워드: 개방목록, 메타데이터, 오픈데이터, 공공데이터, 공공데이터포털, 메타정보, OpenAPI, 파일데이터
형식: csv
선정 기준: 중앙·광역 기관 파일데이터

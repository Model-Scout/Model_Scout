# 외교부_국가별 공지사항 목록조회

[요약 정보] 출국 전 반드시 참고해야할, 국가·지역별 공지사항 목록정보와 상세정보를 조회할 수 있는 API 서비스 [상세 정보] 국가 지역별 공지사항정보 목록 조회 서비스 API로, ISO 국가코드 또는 조건 없이 국가 지역별 공지사항 정보 목록 조회가능합니다. 목록조회 결과의 해당 국가의 id 값을 이용하여 해당국가에 대한 국가 지역별 공지사항의 단일 내용도 조회 가능합니다. 조회되는 항목으로는 ISO국가코드, 등록일, 제목 첨부파일 경로 등이 있으며, 출국 전 여행객, 해외 업체 등이 참고하기 좋은 자료입니다.

# 하수처리시설 일일수질 현황 서비스

부산시에서 운영하는 하수처리시설에서 처리한 후 방류하는 수질현황 데이터를 개방합니다. 개방된 데이터는 하수처리사업소명, 등록일, 처리한 날짜, 방류수에 포함되어 있는 BOD(생물학적산소요구량), COD(화학적산소요구량), tn(총질소), tp(총인), SS(부유물질), 하수처리량의 데이터를 포함합니다. 수영사업소, 중앙사업소, 정관사업소, 강변사업소, 기장사업소(기장), 기장사업소(문오성), 해운대사업소, 남부사업소, 녹산사업소(녹산), 서부사업소 등 10개의 사업소에서 처리한 방류 수질정보를 제공하고 있습니다.

제공기관: 부산광역시
분류: 환경기상
키워드: 오염, 수질, 하수도, 처리, 농도
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-05-19
이용허락: 이용허락범위 제한 없음

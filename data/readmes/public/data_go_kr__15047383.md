# 서울특별시 장애인콜시스템

해당 데이터는 서울시 장애인콜택시 이용 정보 Open API입니다. (Open API서비스는 최소 하루 전 데이터 요청만 가능합니다.) 해당 데이터는 서울시설공단에서 제공하고 있으며, 원본시스템은 장애인콜택시운영처(https://www.sisul.or.kr/open_content/calltaxi)입니다. 요청인자 : 인증키, 요청파일타입, 서비스명, 요청시작위치, 요청종료위치, 요청일 출력값 : 총 데이터 건수, 요청결과 코드, 요청결과 메시지, 총조회건수, 결과코드, 메시지, 차량고유번호, 차량타입, 예정일시, 배차일시, 승차일시, 출발지구군, 출발지상세, 목적지구군, 목적지상세

제공기관: 서울특별시
분류: 사회복지
키워드: 장애인, 콜택시, 택시, 장애인 콜택시, 콜시스템
형식: api
수정일: 2025-07-04

# 지식재산처_KIPRISPlus_상표 분류코드 변동 이력_REST API_20220308

1. 개요 상표의 국내분류코드, 상품분류코드(NICE)의 변동 이력정보를 제공합니다. 출원건 별로 관리중인 상표(한국, NICE)의 분류코드 및 유사군코드 별 지정상품 변경 이력 정보를 API(REST방식) 및 대용량(BULK)으로 제공합니다. 2. 세부 정보 내용 상표 분류코드 이력를 XML 형태로 제공합니다. 출원번호, 상태, 일련번호, 지정상품일련번호, 분류구분코드명, NICE분류판, 상품분류코드, 지정상품명, 추가삭제코드 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

제공기관: 지식재산처
분류: 과학기술
키워드: 출원번호, 지정상품일련번호, 분류구분코드명, 상품분류코드, NICE분류판
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-09-22
이용허락: 이용허락범위 제한 없음

# 국토안전관리원_위험요소프로파일

국토안전관리원이 제공하는 위험요소 프로파일 데이터입니다. 설계안전성 검토결과 제출시 설계시 도출한 위험요소 프로파일을 제출하는 과정에서 데이터가 발생합니다. 즉, 건설현장의 공사목적물, 주변 건축물, 가설구조물 등의 안전과 작업자들의 안전을 저해하는 발생가능한 위험요소를 발굴하여 공종별 위험요소를 분류한 기본 표준자료입니다. 약 47,000건의 위험요소 관련 정보를 설명하고 있으며, 시설물과 공종, 위험발생객체, 위치를 대, 중, 소로 나누어서 상세히 설명하고 있습니다. 데이터에서 위험발생위치는 내부, 외부, 외벽, 지붕 등의 발생위치가 존재했습니다. * 데이터 내 코드 설명 1. 사고가능성(P열) : 해당 위험요소의 발생빈도 - H(High) : 빈번히 발생함 - M(Medium) : 발생가능성 있음 - L(Low) : 거의 발생하지 않음 2. 사고심각성(Q열) : 해당 위험요소의 손실크기 - H(High) : 사망, 장기적인 장애를 일으키는 부상, 질병 - M(Medium) : 단기적인 장애를 일으키는 부상, 질병 - L(Low) : 상해가 없거나 응급처치 수준의 상해

분류: 재난안전

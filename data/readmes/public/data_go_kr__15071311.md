# 서울교통공사_지하철혼잡도정보

이 데이터는 서울교통공사 1~8호선 해당 분기 특정기간의 30분 단위 평균 혼잡도를 산출한 값으로, 교통카드 O/D(출발지·목적지) 데이터를 활용하여 산출된 탑승인원 데이터를 기반으로 30분간 해당 역을 통과한 모든 열차의 평균 혼잡도를 기준으로 작성되었습니다. 혼잡도는 열차 정원 대비 실제 승차 인원의 비율(단위: %)로 정의되며, 정원 기준으로 좌석만 모두 찼을 경우 혼잡도를 34%로 산정합니다. 서울교통공사 혼잡도 데이터는 다음과 같은 항목으로 구성되어 있습니다 : 요일 구분 (평일, 토요일, 일요일), 호선, 역번호, 역명, 상하선 구분, 30분 단위별 혼잡도 (%) ※ 본 데이터는 2024년부터 분기별로 제공되고 있습니다. ※ 실제 열차 운행 간격이나 특이 이벤트(예: 행사, 폭우, 파업 등)는 반영되지 않을 수 있습니다.

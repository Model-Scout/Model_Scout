# 서울특별시 One-PMIS 안전점검 일정

해당 데이터는 서울특별시 One-PMIS의 안전점검에 등록된 서울시 안전점검 일정 OpenAPI입니다. 데이터의 원본시스템은 서울특별시 도시기반시설본부 One-PMIS 시스템입니다. 요청인자 : 인증키, 요청파일타입, 서비스명, 요청시작위치, 요청종료위치, 일정시작일자, 일정종료일자 출력값 : 총 데이터 건수(정상조회 시 출력됨), 요청결과 코드, 요청결과 메시지, 순번, 사업코드, 사업명, 점검일자, 점검기관, 점검자 ※ 바로가기 링크 클릭 시 서울 열린데이터광장 개방 데이터로 이동합니다.

제공기관: 서울특별시
분류: 국토관리
키워드: 건설, 시설, 공사, 안전점검, 일정
형식: api
선정 기준: 운영 자동승인 OpenAPI

이용허락: 제3자 권리 포함 : 저작권 표시, 공공저작물 : 출처표시 (제 1유형)

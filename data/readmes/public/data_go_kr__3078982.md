# ISBN 서지정보 API

국내에서 ISBN을 발급받은 출판 자료뿐만 아니라, 출판이 예정된 자료에 대해서도 관련 정보를 확인할 수 있습니다. 국립중앙도서관 산하의 한국서지표준센터에서 제공하며, 출판사가 해당 센터에 통보한 내용을 바탕으로 구성됩니다. 제공되는 정보에는 ISBN을 포함하여 도서의 서명(제목), 저자, 판 사항, 형태사항(페이지 수, 크기 등), 가격사항, 발행 예정일, 키워드, 본문 언어 등의 주요 서지정보가 포함됩니다. 위의 정보를 통해 사용자가 출판 현황을 보다 정확하게 파악할 수 있도록 도와주며, 도서관, 서점, 학계 등 다양한 분야에서의 자료 검색과 출판 유통, 학술 활용에도 도움을 줄 수 있습니다.

제공기관: 문화체육관광부 국립중앙도서관
분류: 문화관광
키워드: 문화체육관광부국립중앙도서관, ISBN, 서지정보, 서명, 저자, 출판사, 발행년도, 키워드
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-07-16
이용허락: 이용허락범위 제한 없음

# 축산물 운반업체 현황

이 데이터는 경기도 31개 시군 내에서 축산물을 전문적으로 운반하는 축산물 운반업체에 대한 인허가 현황을 제공하며, 사업장명, 인허가일자 및 취소일자, 영업상태, 폐업일자, 소재지 주소(도로명 및 지번), 소재지 면적, 우편번호, 위경도 좌표(WGS84 기준), 전화번호, 총 종업원 수, 업태구분명, 축산업무구분명, 축산물가공업구분명, 축산고유번호, 권리주체고유번호 등 다양한 세부 항목으로 구성되어 있습니다. 해당 데이터는 냉동탑차 등 축산물 위생운송수단을 통해 신선도 유지와 안전한 축산물 유통망을 구축하기 위한 기반자료로 활용되며, 유통경로 분석, 위생관리 정책 수립, 유통업체 분포 분석 등의 목적으로 활용 가능합니다. 본 데이터는 주간 단위로 갱신되며 Open API 형식으로 제공됩니다.

제공기관: 경기도
분류: 산업고용
키워드: 축산물운반업체, 축산물유통, 인허가정보, 냉동운송, 유통위생, 종업원수, 위치정보, 축산물가공
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-07-07

# DGIST 특허정보 서비스

대구경북과학기술원 소속 연구자의 국외/국내 등록 및 출원 특허(patent) 정보를 제공하기 위한 서비스 입니다. 해당 데이터가 보유한 컬럼은 다음과 같습니다. (컬럼명 : 특허명, 공동발명자, 출원 및 등록인명, 특허출원일, 특허출원번호, 특허등록일, 특허등록번호, 발명요약 등)

제공기관: 대구경북과학기술원
분류: 과학기술
키워드: 과학기술과 인문사회, 과학기술정책/사회, 달리 분류되지 않는 과학기술정책/사회
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2022-09-20
이용허락: 이용허락범위 제한 없음

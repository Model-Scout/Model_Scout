# 금융위원회_REPO종목정보_20200424

REPO종목정보는 환매조건부채권거래(REPO)에 활용되는 종목의 금리 정보를 제공하는 데이터입니다. 데이터는 단일 오퍼레이션으로 구성되어 있으며, 기준일자와 종목번호를 기준으로, 종목명, 종목구분, 시장구분, 표면이율, 만기일, 발행기관, 금리구분, 발행금액 등의 정보를 제공합니다. 오퍼레이션의 세부 정보는 아래와 같습니다. ① 금리정보 조회 : 기준일자를 통하여 상환기간분류코드, 매수자업종유형코드, 매도자업종유형코드등을 조회하는 금리정보조회 기능 * 환매조건부채권거래(REPO)란? : 환매조건부매매로 금융기관이 특정 자산을 일정 기간 후에 원금과 이자를 지급하고 다시 매입하기로 약정하는 거래 ** 유의사항 본 개방데이터는 공공누리 2유형임을 참고하시기 바랍니다. 이용허락범위 제2유형 : 출처표시 + 상업적 이용금지 해당 데이터를 상업적으로 활용하고자 하는 이용자는 데이터 원천 소유자인 한국예탁결제원과 사용 목적과 범위에 따른 정보이용계약이 필요합니다. 정보이용계약 또는 해당 정보에 관하여 궁금한 점이 있으시면 한국예탁결제원 증권정보부(연락처: portal@ksd.or.kr)로 이메일 문의 주시기 바랍니다.

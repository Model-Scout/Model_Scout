# 한국국제협력단_국가별 개발협력동향_20201224

KOICA 및 국제개발협력사업과 관련된 개발협력 동향을 파악할 수 있는 API입니다. 국가별로 어떤 개발협력사업이 어떤 방식으로 수행되었는지에 대한 정보를 제공하며, 국가별 지원 분야의 집중도나 사업의 변화 양상을 정리하는 데 유용합니다. 대상 국가의 특성과 수요를 분석하고, 향후 협력 전략 수립이나 평가 기준 설정에 필요한 데이터를 제공합니다. 국가별 ODA 협력전략, 외교정책 수립, 성과 기반 계획 수립을 위한 실무자료로 활용 가능합니다. 해당 API는 인증키(serviceKey), 페이지 번호(pageNo), 한 페이지 결과 수(numOfRows) 등 기본적인 요청변수를 사용하며 데이터표출방식, 한글 국가명, ISO 2자리코드 등의 필터 파라미터를 추가로 설정할 수 있습니다. 출력결과에는 본문, 검토자, 국가명, ISO 숫자코드, 코로나19관련여부, 동향분야명, 출처 등의 항목이 포함되며, 각 항목에 대한 데이터는 JSON 형식으로 반환됩니다.

제공기관: 한국국제협력단

키워드: 동향분야, 관련링크, 개발협력동향, 국가별분석, 수원국동향
형식: api
선정 기준: 국가중점데이터 OpenAPI

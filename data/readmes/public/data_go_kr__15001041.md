# 대전광역시 입찰정보 조회 서비스

대전광역시가 제공하는 ‘임대매각 입찰정보 의견수렴’ 데이터셋은 시내 공공자산의 임대·매각 입찰 과정에서 수집된 입찰 공고·결과와 이해관계자의 의견을 한데 모은 자료입니다. 입찰·계약 절차의 투명성을 높이고 시민 참여를 촉진하기 위해 매년 정기적으로 업데이트됩니다. 주요 항목은 입찰공고일, 입찰번호, 사업명, 계약금액, 개찰금액, 낙찰자 정보, 의견수렴 일자·내용 등이며, CSV·XLSX 형식으로 제공됩니다. 각 레코드는 해당 입찰의 개찰금액과 계약금액을 비교할 수 있도록 정리돼 있어 가격 적정성 분석에 활용하기 용이합니다. 연구자·언론·기업 등은 이 데이터를 활용해 임대매각 시장 동향을 파악하고 계약 체결 과정의 공정성을 검증할 수 있습니다. 또한 시민 의견을 기반으로 정책 개선 방안을 도출하거나 향후 입찰 전략을 수립하는 데에도 유용합니다.

제공기관: 대전광역시
분류: 공공행정
키워드: 입찰, 계약, 개찰금액
형식: api
선정 기준: 운영 자동승인 OpenAPI

# 보건복지부_병원 종사 의료인력 수_시도별

* 병원 종사 의료인력수_시도별 통계는 2023년 말 기준으로 종결되었고, 24년도부터는 의료기관 종사 의료인력 수_시도별로 개편되어 개방됩니다. 보건복지부에서 2015~2023까지 병원급 이상의 의료기관에 종사하는 병원* 종사 의료인력 수(연도, 시도, 의사, 치과의사, 한의사, 조산사, 간호사, 간호조무사, 의료기사, 보건의료정보관리사, 약사)를 시도별로 제공하고 있습니다. <통계 이용 시 참고사항> - 병원 = 상급종합병원 + 종합병원 + 병원 + 요양병원 + 치과병원 + 한방병원 + 정신병원(2021년부터 병원에 정신병원 포함) - 작성체계：시･도 → 건강보험심사평가원 → 보건복지부 - 데이터 출처 : 건강보험심사평가원 - 매년 말 기준 작성된 통계이므로 현 인원과 다를 수 있음

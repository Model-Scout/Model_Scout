# 부산 착한가격업소 조회

착한가격업소는 효율적인 경영을 통해 소비자에게 저렴한 가격으로 양질의 서비스를 제공하는 업소로 부산시에서 지정한 업소 데이터를 개방합니다. 착한가격업소는 부산시가 지정한 물가안정 모범업소입니다. 시민들은 시에서 지정한 착한가격업소를 안심하고 이용할 수 있습니다. 개방된 데이터는 업소명, 대표자명, 주소, 전화번호, 소개, 주차여부, 영업시간, 이미지 등의 정보를 포함하고 있습니다. 업종은 이미용 110개소, 음식점 618개소, 목욕 11개소, 기타 42개소 입니다. 기타 업소로는 헬스장, 사진관, 자동차 정비, 세탁소, 볼링장, 보드게임장, 당구장 등이 있습니다.

제공기관: 부산광역시
분류: 문화관광
키워드: 저렴, 안심, 청결, 친절, 서비스, 가성비
형식: api
선정 기준: 운영 자동승인 OpenAPI

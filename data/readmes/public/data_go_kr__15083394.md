# 제주특별자치도 제주시_등록장애인수현황

이 데이터는 제주특별자치도 제주시의 등록 장애인 수 현황을 정리한 공공데이터입니다. 해당 데이터의 담당 부서는 제주시 장애인복지과이며, 제주시 지역 내 등록 장애인 현황을 유형별·성별·장애 정도별로 파악할 수 있도록 구성되어 있습니다. 데이터 항목은 크게 구분 항목과 장애 유형 항목으로 나뉩니다. 구분 항목에는 남성, 여성, 심한 장애 남성, 심한 장애 여성, 심하지 않은 장애 남성, 심하지 않은 장애 여성이 포함되어 있어, 성별과 장애 정도에 따른 인원 현황을 확인할 수 있습니다. 장애 유형 항목으로는 지체, 시각, 청각, 언어, 지적, 뇌병변, 자폐성, 정신, 신장, 심장, 호흡기, 간, 안면, 장루·요루, 뇌전증이 포함됩니다.

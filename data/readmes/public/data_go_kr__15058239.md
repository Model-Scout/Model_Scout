# 부적합 식품 현황

이 데이터는 경기도 내에서 식품 위생기준을 충족하지 못한 부적합 식품에 대한 현황을 제공하며, 반기 단위로 갱신됩니다. 총 21개 항목으로 구성되어 있으며, 제품명, 제조업체명, 업종명, 제품유형, 회수사유, 회수명령일자, 회수종류, 회수평가결과 등의 정보와 함께 해당 업체의 주소(WGS84 위경도 포함)도 포함되어 있습니다. 벤조피렌, 소르빈산, 대장균, 세균수 등 식품 내 유해물질 초과 여부로 인한 행정처분 내용을 확인할 수 있어 식품안전관리, 위해식품 유통 모니터링, 소비자 경고 서비스 등에 유용하게 활용될 수 있습니다. Open API 형식으로도 제공됩니다.

제공기관: 경기도
분류: 식품건강
키워드: 부적합식품, 회수명령, 제품유형, 회수사유, 업체정보, 위해식품, 식품안전, 식품위생
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-07-21
이용허락: 이용허락범위 제한 없음

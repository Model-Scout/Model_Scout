# 대기오염 전광판  집계 현황

이 데이터는 경기도 내 시군별 대기환경 측정을 위한 측정소 수를 도시대기측정소와 도로변대기측정소로 구분하여 집계한 현황입니다. 각 행은 특정 시군과 특정 집계년월 기준으로 설치된 대기측정소 수를 나타내며, 도시대기측정소는 일반 주거지역 및 상업지역 등에서의 대기질 측정을 목적으로 하고, 도로변대기측정소는 주요 도로변에서 차량 배출가스에 의한 대기 오염도를 측정하기 위해 설치된 설비입니다. 데이터 항목은 집계년월, 시군명, 도시대기측정소수, 도로변대기측정소수로 구성되어 있으며, 지역별 대기질 관리 수준을 평가하거나 환경 정책 수립, 대기환경 모니터링 기반 마련 등의 활용이 가능합니다.

제공기관: 경기도
분류: 환경기상
키워드: 대기오염전광판, 대기측정, 대기측정소, 도시대기, 도로변대기, 환경
형식: api
선정 기준: 운영 자동승인 OpenAPI

# 한국가스안전공사_KGS Code(상세기준) 현황_공통

가스안전기술기준인 KGS Code는 정부에서 승인한 가스안전분야 시설,검사,기술 상세기준으로, 한국가스안전공사에서 보유하고 있는 공통분야 코드 현황 데이터입니다. 해당 데이터는 구분, 분류, 코드번호, 코드명, 최신버전, 내용쪽수로 구성되어 있습니다. 공통분야 관련 KGS코드 최신정보를 쉽게 확인 할 수 있습니다. ※ KGS Code : 가스 관계 법령에서 정한 시설·기술·검사 등의 기술적인 사항을 상세기준으로 정하여 코드화한 것으로, 가스기술 기준위원회에서 심의·의결하고 산업통상자원부에서 승인한 가스안전 분야의 기술기준입니다. ※ 해당 데이터는 연간 주기로 업데이트 됩니다. ※ 2025년 데이터기준일 기준 현황입니다. - 데이터기준일 : 2025년 12월 8일

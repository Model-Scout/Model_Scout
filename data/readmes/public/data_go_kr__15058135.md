# 결빙사고 다발지역

노면상태가 '서리/결빙'인 교통사고에 대한 사고다발지역 정보 - 대상사고 : 최근 5년간 발생한 결빙 교통사고(노면상태가 '서리/결빙'인 교통사고) ex) 2021년 결빙교통사고 다발지역의 대상사고는 2017~2021년 발생한 결빙 교통사고 - 선정조건 : 반경 200m 내, 대상사고 3건 이상 발생 지점(사망사고 포함 시 2건 이상 발생지점) - WMS 형태의 API 정보는 교통사고정보개방시스템(https://opendata.koroad.or.kr/api/sample.do)을 통해 확인하실 수 있습니다. * 해당 자료는 교통사고분석시스템(https://taas.koroad.or.kr) 데이터를 기반으로 함

제공기관: 한국도로교통공단
분류: 재난안전

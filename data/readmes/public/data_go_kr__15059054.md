# 응급환자이송업 현황

이 데이터는 응급환자이송업에 대한 인허가 및 운영 정보를 담고 있으며, 경기도 내에서 응급환자를 이송하기 위해 운영되는 민간 구급업체의 현황을 제공합니다. 사업장명, 인허가일자, 영업상태, 폐업일자 등의 행정 정보와 함께, 구급차 대수(일반/특수), 구조사 수, 위치 정보(주소, 위도·경도, 좌표) 등이 포함되어 있어, 민간 응급이송 서비스의 지역별 분포와 자원 현황을 파악하는 데 활용됩니다. 특히, 이 데이터는 지역 응급의료체계 보완, 긴급상황 대응력 분석, 응급의료자원 배치 최적화 등에 유용하며, 민간 주도 이송서비스의 역할과 활용 가능성을 평가하는 기반 자료로서의 가치가 높습니다.

제공기관: 경기도
분류: 보건의료
키워드: 응급실, 병원, 이송, 구급서비스, 민간구급차, 응급의료
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-09-10
이용허락: 이용허락범위 제한 없음

# 관세청_HSK별 신성질별_성질별 분류

우리나라의 HS별 표준품명 데이터로서 HSK 부호에 따른 세번 2단위, 세번 4단위, 세번 6단위, 세번 10단위에 대한 관세청 신성질별_성질별 분류 데이터 입니다. HS Code란 모든 상품에 고유번호를 부여하는 국제적 상품분류체계를 말합니다. 성질별 기준은 HS Code 10단위 세번을 상품 특성에 맞게 유사한 성질을 가진 품목끼리 집계한 분류체계 (수입•수출 별도 분류)한 것으로, 수입 : 3大 대분류(소비재, 원자재, 자본재)과 수출 : 4大 대분류(식료 및 직접소비재, 원료 및 연료, 경공업품, 중화학 공업품)로 나뉘어집니다. 신성질별 기준은 성질별 분류체계를 개편하여 집계한 분류체계(수출, 수입을 동일한 기준에 따라 분류)로, 수출, 수입 : 3大 대분류(소비재, 원자재, 자본재)로 나뉘어집니다.

형식: xlsx

# 한국환경공단_에어코리아_미세먼지 경보 발령 현황

미세먼지(PM10, PM2.5)에 대한 주의보, 경보 발령을 조회하기 위한 서비스입니다. API 상세 기능으로는 미세먼지 경보현황 정보를 조회가능한 기능으로 되어있으며 미세먼지, 초미세먼지에 대한 지역별,권역별, 주의보,경보 발령/해제시간, 항목별 농도,경보단계를 조회 가능합니다. OpenAPI 활용가이드를 활용하시면 초미세먼지의 경보권역 리스트를 확인하실 수 있습니다. ※ 운영계정으로 사용하고자 할 경우 "한국환경공단 에어코리아 OpenAPI 기술문서" 내 신청 가이드 참고

키워드: 미세먼지, 코로나, 오존, 초미세먼지, 에어코리아

# 공정거래위원회_비교공감

소비자원 등이 생산하는 한국형 소비자리포트 비교공감 등 소비자가 상품 구매에 참고할 수 있는 상품·안전·비교정보를 제공합니다. 게시물 제목, 게시물 요약, 상세 내용, 등록일, 정보 출처, 상세페이지 URL 및 원천게시물 URL 등의 정보를 제공하며, 페이지 번호와 페이지당 조회 건수를 지정하여 자료를 조회할 수 있습니다. 본 데이터는 소비자의 합리적인 상품 선택을 지원하고, 상품의 품질과 안전성에 대한 정보 제공 및 소비자 피해 예방을 위한 서비스 개발 등에 활용할 수 있습니다.

제공기관: 공정거래위원회
분류: 공공행정
키워드: 비교공감, 비교정보, 피해주의보
형식: api
선정 기준: 국가중점데이터 OpenAPI
수정일: 2026-10-29
이용허락: 제3자 권리 포함 : 저작권 표시, 비영리, 변경금지, 공공저작물 : 출처표시, 상업적 이용금지, 변경금지 (제 4유형)

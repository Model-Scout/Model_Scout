# 한국산업인력공단_HRD4U 콘텐츠 현황

한국산업인력공단에서 운영중인 능력개발포털(www.hrd4u.or.kr)에서 제공중인 각종 HRD콘텐츠(E-BOOK, PDF, 강의영상)의 현황 리스트 데이터입니다. 과거(2017년 이전) 한국산업인력공단에서 개발하였던 HRD콘텐츠이며, 현재는 관련 예산 미편성으로 업데이트 되지 않아 단순 공유 차원에서 과거 자료를 업로드해두었습니다. 데이터의 구성은 콘텐츠 목록 위주이며, 콘텐츠의 분류인 NCS코드를 기반으로 콘텐츠의 종류(E-BOOK, PDF, PPT, 영상파일) 등으로 분류되어있습니다.

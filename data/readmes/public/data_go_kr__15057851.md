# 지식재산처_KIPRISPlus_대표 출원인_REST API_20220308

1. 개요 국내 지식재산권(특허, 실용, 디자인, 상표) 출원인 이름을 대표명으로 정비한 정보를 제공합니다. 특허를 출원하려는 자 또는 기업이 다수의 출원인을 등록해 놓은 경우 이를 대표하는 하나의 출원인명에 대한 정보를 API(REST방식) 및 대용량(BULK)로 제공합니다. 2. 세부 정보 내용 출원인대표명 조회 : 출원인에 대한 대표출원인, 특허고객번호 정보를 XML 형태로 제공합니다. 특허고객번호, 출원인명, 특허고객대표번호, 출원인대표명(국문, 영문) 등 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

제공기관: 지식재산처
분류: 과학기술
키워드: 특허고객번호, 출원인명, 대표출원인, 특허고객대표번호, 출원인 대표명
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-09-22
이용허락: 이용허락범위 제한 없음

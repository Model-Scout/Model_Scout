# 국가기술자격 지역별 자격취득현황

“국가기술자격 지역별 자격취득 정보” API는 한국산업인력공단이 제공하는 공공데이터 서비스로, 국가기술자격의 지역별 취득 현황을 조회할 수 있습니다. 이 API를 통해 지역별로 자격 취득자 수, 성별·연령대·학력·계열·등급별 분포 등 다양한 통계 정보를 XML 형식으로 제공합니다. 요청 시 인증키(ServiceKey)와 조회 연도(baseYY), 페이지 번호(pageNo), 한 페이지 결과 수(numOfRows) 등의 파라미터를 지정하여 데이터를 조회할 수 있습니다. 이 API는 자격 취득 현황을 지역별로 분석하거나, 진로·자격 상담 시스템, 정책 연구 등에 활용하기에 적합합니다. 공공데이터포털에서 인증키를 발급받아 사용할 수 있으며, 개발계정 기준으로 월 1,000회 호출이 가능합니다. 운영계정은 활용 사례 등록을 통해 추가 트래픽을 신청할 수 있습니다.

제공기관: 한국산업인력공단
분류: 공공행정
키워드: 국가자격, 기술자격, 지역별취득정보
형식: api
선정 기준: 운영 자동승인 OpenAPI

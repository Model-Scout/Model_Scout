# 모바일 행정규칙 목록 조회

법제처가 제공하는 모바일 행정규칙 목록 조회 데이터는 각 중앙행정기관이 제정한 행정규칙의 기본 정보를 모바일 환경에 적합한 형식으로 제공합니다. 이 데이터는 행정규칙명, 고유식별번호, 행정규칙유형(훈령·예규·고시 등), 소관부처명, 공포일자, 문서번호, 시행일자, 폐지여부, 제·개정 구분 등으로 구성되어 있습니다. 사용자는 행정규칙명, 소관부처, 문서번호, 페이지 번호 및 조회 건수 등의 조건을 입력하여 관련 행정규칙을 맞춤형으로 조회할 수 있습니다. 경량화된 모바일 특화 구조로 설계되어 있어 각 행정규칙의 발령 이력 및 시행 상태를 빠르게 파악할 수 있으며 행정규칙의 최신 공포 여부, 폐지 현황, 시행일 등 주요 정보를 명확히 확인할 수 있어 규정 검토, 법무 지원 및 행정업무 처리에 효과적으로 활용할 수 있습니다.

제공기관: 법제처
분류: 공공행정
키워드: 앱훈령예규, 문서번호, 행정규칙유형, 시행상태, 공포일자, 소관부처, 고시, 훈령
형식: api

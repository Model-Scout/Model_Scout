# 지식재산처_KIPRISPlus_공통_REST API

1. 개요 디자인, 심판, 특실, 해외특허 등의 특허정보를 활용하기 위해서 공통적으로 제공되는 정보를 검색 할 수 있는 서비스를 API(REST방식)로 제공합니다. 2. 세부 정보 내용 창작자/특허고객/대리인/등록권자 번호를 포함한 공통 정보를 한번에 찾아보기 위한 서비스로 XML 형태로 제공합니다. 출원인 검색, 대리인 검색, 발명자 검색, 창작자 검색, 등록권자 검색, 심판 청구인, 심판 청구대리인, 심판 피청구인, 심판 피청구대리인, 심판사항 ※ 월 1,000회까지 무료 호출 가능 합니다. 해당 횟수 이상의 호출이 필요하시거나, BULK 데이터 사용이 필요하신 경우 서비스 홈페이지(plus.kipris.or.kr)를 통해 사용이 가능 합니다.

제공기관: 지식재산처
분류: 과학기술
키워드: 출원인_검색, 대리인검색, 발명자_검색, 창작자_검색, 등록권자_검색
형식: xml
선정 기준: 중앙·광역 기관 파일데이터
수정일: 2025-09-22
이용허락: unknown

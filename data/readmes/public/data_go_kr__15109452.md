# 한국산업인력공단_연도별 복수등급 자격 취득현황 조회 서비스_20221208

“국가기술자격 연도별 복수등급 자격 취득현황 조회 서비스” API는 한국산업인력공단이 제공하는 공공데이터로, 국가기술자격 취득자의 복수등급 자격 보유 현황을 연도별로 XML 형식으로 제공합니다. 주요 정보로는 연도별 복수등급 보유자 수, 보유 등급 수 등이 포함됩니다. 인증키(ServiceKey)와 조회 연도(baseYY), 페이지 번호(pageNo), 결과 수(numOfRows) 등의 파라미터를 통해 데이터를 조회할 수 있으며, 자격 취득 현황 분석, 진로 상담, 정책 연구 등에 활용됩니다. 개발계정은 월 1,000회 호출 가능하며, 운영계정은 추가 트래픽 신청이 가능합니다.

제공기관: 한국산업인력공단
분류: 공공행정
키워드: 국가자격, 복수등급, 자격
형식: api
선정 기준: 운영 자동승인 OpenAPI

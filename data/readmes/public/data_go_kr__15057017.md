# 행정안전부_실시간 주소정보 조회(검색API)_20211220

도로명주소 DB 구축 없이 다양한 시스템 환경에서 실시간으로 주소 검색기능을 구현할 수 있습니다 1. API 서비스 개요 - 다양한 시스템 환경 적용 가능 - 개발언어, 플랫폼 제약없음 - DB 구축 및 현행화 부담ZERO - 실시간 주소 검색 가능 - 신청 즉시 이용 가능 - 1 시스템 1 승인키 부여 2. 입력 파라미터 정보 신청시 발급받은 승인키,현재 페이지 번호,페이지당 출력할 결과 Row 수,주소 검색어,검색결과형식 설정(xml, json),변동된 주소정보 포함 여부,정확도순 정렬(none), 우선정렬(road: 도로명 포함, location: 지번 포함),출력결과에 추가된 항목(hstryYn, relJibun, hemdNm) 제공여부 3. 출력 파라미터 정보 전체 도로명주소,도로명주소(참고항목 제외),도로명주소 참고항목,지번주소,도로명주소(영문),우편번호,행정구역코드,도로명코드,건물관리번호,상세건물명,건물명,공동주택여부(1 : 공동주택, 0 : 비공동주택),시도명,시군구명,읍면동명,법정리명,도로명,지하여부(0 : 지상, 1 : 지하),건물본번,건물부번,산여부(0 : 대지, 1 : 산),지번본번(번지),지번부번(호),읍면동일련번호,변동이력여부(0: 현행 주소정보, 1: 요청변수의 keyword(검색어)가 변동된 주소정보에서 검색된 정보),관련지번,관할주민센터

제공기관: 행정안전부
분류: 과학기술
키워드: 주소, 도로명주소, 주소정보(검색API), 지번주소검색, 도로명검색
형식: api
선정 기준: 국가중점데이터 OpenAPI

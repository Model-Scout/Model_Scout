# 의원급 산부인과 현황

이 데이터는 경기도 내 의원급 산부인과에 대한 인허가 현황을 제공하며, 각 의료기관의 사업장명, 인허가일자, 병상수, 의료인수, 입원실수, 진료과목, 주소 및 위도·경도 좌표 등 다양한 정보를 포함하고 있습니다. 의원급 산부인과는 30병상 미만의 진료시설로, 지역 기반의 여성건강 관리에 중요한 역할을 하며 본 API는 XML 또는 JSON 형식으로 제공되어 위치 기반 서비스나 의료 정책 수립 등에 활용할 수 있습니다. - 의원급 산부인과: 30병상 미만의 규모로 운영되며 주로 외래환자를 중심으로 산부인과 진료를 수행하는 지역 의료기관입니다. - 인허가일자: 의료기관이 설립을 위해 허가를 받은 날짜를 의미하며, 의료서비스의 법적 운영 개시 시점을 나타냅니다.

제공기관: 경기도
분류: 보건의료

형식: api

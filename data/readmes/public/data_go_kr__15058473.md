# 축산물 유통전문 판매업체 현황

이 데이터는 경기도 31개 시군의 축산물 유통 전문 판매업체 현황을 제공하며, 포장육·식육가공품·유가공품·알가공품 등 축산물의 가공·포장을 위탁하고 이를 자체 상표로 유통·판매하는 업체의 정보를 포함합니다. 주요 항목으로는 사업장명, 인허가일자, 영업상태 및 폐업일자, 소재지 주소(도로명 및 지번), 우편번호, 소재지면적, 종업원 수, 축산업무구분, 축산물가공업구분, 위경도 좌표(WGS84 기준) 등이 포함되어 있으며, 주간 단위로 갱신됩니다. 해당 데이터는 축산물 유통 흐름 분석, 브랜드 유통경로 파악, 식품 안전관리 체계 수립, 지역 유통산업 정책 설계 등에 활용될 수 있으며, Open API 형식으로 접근 가능합니다.

제공기관: 경기도
분류: 산업고용
키워드: 축산물유통, 전문판매업, 포장육, 유가공품, 인허가정보, 식육가공품, 종업원수, 위치정보
형식: api
선정 기준: 운영 자동승인 OpenAPI

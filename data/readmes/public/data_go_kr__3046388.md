# 국토교통부_WMTS/TMS API

연속수치지도를 기반으로 작성된 2차원 배경지도로 EPSG:3857로 지도를 투영 그래픽 지도 / 영상지도 / 미드나잇 지도 / 회색 지도 / 하이브리드 맵 지도 정보를 제공 WMTS 는 OGC 국제 표준으로 openlayers , qgis, arcgis , cesium , leaflet 등 표준을 준수하는 라이브러리와 tool 에서 활용 가능 함 제세한 내용은 첨부파일 참고 샘플이 실행되지 않을 경우 인증키를 발급 받아 변경 후 실행

분류: 국토관리
키워드: 배경지도, 2D, map, OGC, 국제표준

# 인재채용정보 API

ㅇ 국립중앙도서관의 '인재채용정보 Open API'는 국립중앙도서관 채용공고 정보를 외부 시스템이나 서비스에서 활용할 수 있도록 제공하는 서비스입니다. ㅇ 이 API를 통해 조회 시작일과 조회 종료일을 설정하여 채용 게시물 건수, 공고제목, 등록일, 수정일, 기관명, 게시물 URL, 게시여부 등 다양한 정보를 조회할 수 있습니다. ㅇ API를 활용하여 국립중앙도서관의 최신 채용정보를 실시간으로 연동하거나, 자체 서비스에 통합하여 구직자 및 기관 등에 편리한 채용 정보 제공 및 활용이 가능합니다.

제공기관: 문화체육관광부 국립중앙도서관
분류: 문화관광
키워드: 국립중앙도서관, 인재채용정보, 인재, 채용, 채용정보, 게시물, 공고
형식: api
선정 기준: 운영 자동승인 OpenAPI

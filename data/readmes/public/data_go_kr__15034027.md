# 행정사 현황 서비스

행정업무에 생소한 시민이 관공서에서 일처리를 할때 대행하여 도움을 받을 수 있는 부산광역시에 등록된 구군 행정사 현황에 대한 데이터를 개방합니다. 개방된 데이터에는 행정사 종류(일반, 해사, 외국어번역), 대표자 성명, 사무소명, 도로명 주소, 전화번호, 영업여부, 팩스번호 등의 정보를 포함하고 있습니다. 일반행정사 451곳, 해사행정사 10곳, 외국어번역행정사(영어)14곳, 외국어번역행정사(일본어) 5곳, 외국어번역행정사(중국어) 2곳, 외국어번역행정사(독일어) 1곳이 등록되어 있습니다 *기준일 2025.5.21 현재

제공기관: 부산광역시
분류: 공공행정
키워드: 행정명령, 민원, 소송, 대행, 상담
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-05-21
이용허락: 이용허락범위 제한 없음

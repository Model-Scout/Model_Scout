# 국가데이터처_KOSIS 목록별 지표 조회 서비스_20231231

국가데이터처의 KOSIS(국가통계포털)에서 제공하는 방대한 통계 지표들을 목록(카테고리) 단위로 조회할 수 있는 서비스입니다. KOSIS 100대 지표를 포함하여 인구, 가구, 고용, 노동, 경기, 물가, 가계 등 국내 주요 통계는 물론, 북한 및 국제(G20) 통계 지표까지 다양한 분야의 목록별 지표 정보를 제공합니다. 사용자는 목록 ID를 통해 해당 목록에 포함된 지표들의 리스트를 JSON 또는 XML 형태로 받아볼 수 있습니다. 이를 통해 통계 데이터의 구조를 파악하고 원하는 통계 지표를 효율적으로 찾아 데이터 분석 및 서비스 제공에 활용 할 수 있습니다.

제공기관: 국가데이터처
분류: 공공행정
키워드: 국가통계, KOSIS, 통계지표, 목록별지표, 지표조회
형식: api
선정 기준: 운영 자동승인 OpenAPI

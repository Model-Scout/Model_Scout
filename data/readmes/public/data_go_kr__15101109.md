# 국토교통부_3D 데스크톱 API

브이월드 3D 데스크톱 API(이하 데스크톱 API)는 데스크톱 서비스로만 제공되던 데스크톱의 기능을 사용자가 원하는 형태로 활용할 수 있도록 하는 C/S용 플랫폼입니다. 데스크톱 API는 브이월드에서 제공하는 다양한 국가 공간정보를 모두 수용하고 여러 콘텐츠(장소, 라인, 다각형, 원)의 생성/편집 기능을 제공하고 지도 보기 등 표현 방식을 다양화 하였습니다. 브이월드 3D 데스크톱 API는 인증키를 발급 받아야 사용할 수 있습니다. 인증키는 브이월드에 회원가입을 하신 후 [오픈API > 인증키 > 인증키 발급]으로 이동하시면 발급 받으실 수 있습니다.

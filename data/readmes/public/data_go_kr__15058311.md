# 스쿨존어린이사고다발지역정보서비스

어린이보호구역에서 발생한 12세 이하 어린이 교통사고에 대한 사고다발지역 정보 - 대상사고 : 1년간 스쿨존 내에서 발생한 12세 이하 어린이 교통사고(어린이는 보행자, 자전거 승차자 또는 개인형이동수단(PM)승차자) - 다발지역 선정조건 : 반경 300m 내 대상사고 2건이상 발생지점 또는 사망 교통사고 발생지점 - WMS 형태의 API 정보는 교통사고정보개방시스템(https://opendata.koroad.or.kr/api/sample.do)을 통해 확인하실 수 있습니다. *교통사고분석시스템(https://taas.koroad.or.kr)의 데이터를 기반으로 함

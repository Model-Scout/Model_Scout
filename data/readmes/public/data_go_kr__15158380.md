# 한국국제협력단_KOICA ODA 조달 정보조회_20260401

KOICA의 ODA 개발협력사업에서 발생하는 조달정보를 제공하는 API입니다. 년간 발주 계획, 입찰정보 목록, 수의계약 목록 등 필요한 조달 정보를 조회할 수 있어 국제개발 사업에 참여하고자 하는 기업과 유관기관에게 필수적인 공공정보입니다. 해당 API는 인증키(serviceKey), 페이지 번호(pageNo), 페이지당 호출건수(numOfRows) 등 기본적인 요청변수를 사용하여 오퍼레이션별 데이터를 제공합니다. 출력결과에는 목록, 입찰범위내용, 사업명, 계약방법, 발주시기, 조달구분, 조달대상, 낙찰자선정방식, 수원국, 입찰한도금액, 입찰명, 입찰진행상태명, 공고번호 등의 항목이 포함되며, 각 항목에 대한 데이터는 XML 형식과 JSON 형식으로 반환됩니다.

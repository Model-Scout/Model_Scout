# 치유의숲산림욕장 현황

이 데이터는 경기도 내 시군별 산림욕장의 현황을 제공하며, 자연환경을 활용한 치유 및 휴양공간으로서의 산림욕장에 대한 정보를 포함합니다. 산림욕장명, 시군명, 조성면적(ha), 조성년도, 소유구분(국유림·공유림·사유림) 등의 항목 외에도, 사업비 항목은 국비·도비·시군비 및 전체 합계를 백만원 단위로 구분하여 제공합니다. 위치정보는 도로명주소, 지번주소, 우편번호, WGS84 위도·경도로 구성되어 있어 공간적 활용이 용이합니다. 이 데이터는 치유의숲 조성 현황 파악, 지역 관광자원 분석, 산림복지 서비스 기획 및 정책 수립 등 다양한 분야에서 활용될 수 있습니다. 데이터는 Open API 방식으로 제공되며, 상업적 활용과 콘텐츠 변경도 허용됩니다.

제공기관: 경기도
분류: 문화관광
키워드: 산림욕장, 조성면적, 조성년도, 소유구분, 사업비, 위치정보, 시군명, 치유의숲
형식: api
선정 기준: 운영 자동승인 OpenAPI

# 경기도_부유쓰레기 수거처리 집계 현황

이 데이터는 경기도 내에서 발생하는 부유쓰레기와 하수슬러지 등의 환경오염 유발물질의 수거 및 처리 현황을 연도별로 집계한 자료입니다. 제공 항목에는 쓰레기수거량, 수초수거량, 재활용수량, 소각 및 파분쇄량 등이 포함되어 있으며, 수질오염 및 폐기물 관리 현황을 파악할 수 있습니다. 수질환경 개선을 위한 정책 수립, 재활용 자원 관리, 환경오염 저감 대책 마련 등에 활용될 수 있습니다. 데이터는 Open API 형식으로 제공되며 XML 또는 JSON 포맷으로 접근 가능하고, 인증키를 이용해 연도별 데이터 조회가 가능합니다. 관련 API는 경기도 공공데이터 포털에서 확인할 수 있습니다.

제공기관: 경기도
분류: 환경기상
키워드: 부유쓰레기, 하수, 슬러지, 수질오염, 쓰레기수거량, 수초수거, 재활용, 소각처리
형식: xml

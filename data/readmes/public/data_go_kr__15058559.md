# 한국마사회_확정배당율 통합 정보

서울, 부산경남, 제주, 영천 경마장에서 시행된 경주의 단승식, 복승식, 연승식, 쌍승식, 삼복승, 삼쌍승식 확정배당율 정보입니다. (1착마 출주번호, 2착마 출주번호, 확정배당률 등) - 경주월/경주일 입력하지 않을 시 가장 최근 경마일의 승식배당율정보가 표출됩니다. ※ 승식구분 영문약자는 다음과 같습니다. - 단승식(WIN) : 1등으로 도착할 말 1두를 적중시키는 방식입니다. - 연승식(PLC) : 1~3등 안에 들어올 말 1두를 적중시키는 방식입니다. 경주에 출전하는 말이 7두 이하일 때는 2등 안에 들어올 말 1두 적중 - 복연승식(QPL) : 1~3등 안에 들어올 말 2두를 순서에 상관없이 적중시키는 방식입니다. - 복승식(QNL) : 1등과 2등으로 들어올 말 2두를 순서에 상관없이 적중시키는 방식입니다. - 쌍승식(EXA) : 1등과 2등으로 들어올 말 2두를 순서대로 적중시키는 방식입니다. - 삼복승식(TLA) : 1등, 2등 및 3등으로 들어올 말 3두를 순서에 상관없이 적중시키는 방식입니다. - 삼쌍승식(TRI) : 1등, 2등, 3등으로 들어올 말 3두를 순서대로 적중시키는 방식입니다. ※ 영천경마 시행 이후 요청메세지 경마장번호(meet)에 4를 입력시 영천경마 자료를 조회할 수 있습니다.

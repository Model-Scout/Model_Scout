# 병원평가정보(유소아중이염항생제) 현황

병원평가정보(유소아중이염항생제) 현황은 건강보험심사평가원이 경기도 내 의료기관의 유소아 급성중이염 진료 시 항생제 처방률을 평가한 데이터로, 공개 API 형태로 제공됩니다. 평가등급(GRAD)은 항생제 사용량을 기준으로 1~5등급으로 구분되며, 낮은 숫자의 등급일수록 항생제 사용이 적어 권장치에 가까운 기관임을 의미합니다. 주요 필드에는 시군명 및 코드(SIGUN_NM, SIGUN_CD), 기관명(INST_NM), 평가내용(DIV_NM), 도로명·지번 주소(REFINE_ROADNM_ADDR, REFINE_LOTNO_ADDR), 우편번호(REFINE_ZIP_CD), 위도·경도 좌표(REFINE_WGS84_LAT, REFINE_WGS84_LOGT) 등이 포함됩니다. 이 자료는 항생제 오남용 방지, 소아 건강 정책 설계, 지역별 의료기관 비교, 시민 건강정보 제공 등에 활용될 수 있으며, 항생제 내성 증가 방지를 위한 정책 자료로도 가치가 있습니다. 사용 시 등급별 처방률 기준을 정확히 이해하고 해석해야 합니다.

제공기관: 경기도
분류: 보건의료
키워드: 유소아중이염, 항생제평가, 병원등급, 처방률등급, 소아보건, WGS84좌표
형식: api
선정 기준: 운영 자동승인 OpenAPI

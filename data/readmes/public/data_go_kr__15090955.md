# 소상공인시장진흥공단_주요상권현황

전국 주요 상권의 위치를 공간좌표 기반으로 수록한 데이터로, 상권명, 상권코드, 시도 및 시군구코드, 중심좌표 정보가 포함되어 있습니다. 이 데이터는 소상공인 중심지 또는 유동인구 밀집 지역의 상권 구조를 분석하고, 지역경제 흐름을 공간적으로 시각화하는 데 유용합니다. 특히 상권별 경계 시각화, 입지 타당성 평가, 신규 점포 개발, 마케팅 권역 설정 등에 폭넓게 활용될 수 있으며, 상권 변화 모니터링이나 맞춤형 상권지원정책 수립에도 필수적인 기반 자료입니다. * 입력할 수 있는 셀 최대 길이를 초과하여 엑셀, 메모장 사용 시, 해당 좌푯값이 다음 행으로 떨어질 수 있습니다. 다만, 무료 텍스트 프로그램인 Visual Studio Code 이용 시 한 줄로 사용할 수 있사오니, 참고 바랍니다.

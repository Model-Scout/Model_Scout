# 한국산업인력공단_국가자격 종목 코드 정보_20200928

한국산업인력공단이 제공하는 이 OpenAPI는 REST/XML 기반의 ‘InquiryJmcdInfoSVC/getDisqList’ 엔드포인트를 통해 국가자격 각 종목에 대한 결격사유(disqRsn) 및 유사종목 계열(seriesNm) 정보를 조회할 수 있는 서비스입니다. 요청 시 serviceKey, jmCd(종목코드), numOfRows, pageNo 등의 파라미터를 사용합니다. 응답 데이터에는 종목코드(jmCd), 종목명(jmNm), 결격사유 내용, 계열명(seriesNm), 순번(seq) 등이 포함됩니다. 이 API는 **공공데이터포털(data.go.kr)**에서 제공되며 신청 시 즉시 자동 승인되고, 하루 개발자 계정 기준 최대 호출량은 약 10,000건이며 무료로 이용 가능합니다. 활용 문의 및 최신 정보는 데이터포털 API 문서를 참고해야 합니다.

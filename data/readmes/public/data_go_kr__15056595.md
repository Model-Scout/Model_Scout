# 유통 농산물 잔류농약검사 서비스

부산광역시_농산물 잔류농약검사 데이터를 개방합니다. 부산시에서 운영하는 엄궁, 반여 농산물도매시장에서 출하하여 시중에 유통하는 농산물에 대해 잔류검사한 결과 데이터입니다. 농산물 잔류농약 이란 병충해로부터 농작물을 지키기 위하여 사용한 농약이 농작물 또는 이를 원료로 사용한 식품 중에 남아있는 것을 말한다. 잔류농약은 농약의 성분, 사용시기, 사용량 등에 따라 남아있는 정도가 다르고 대부분의 식품에선 조리와 가공과정을 거치면서 감소해 인체에 유해할 정도로 남아있는 경우가 드뭅니다. 개방되는 데이터에는 검체명, 품목, 분류, 검출농약, 검출농도, 판정 등의 데이터가 제공됩니다.

제공기관: 부산광역시
분류: 식품건강
키워드: 안전, 식품, 유해, 과일, 채소, 검출
형식: api
선정 기준: 운영 자동승인 OpenAPI

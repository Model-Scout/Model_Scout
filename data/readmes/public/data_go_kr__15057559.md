# 행정안전부_실시간 주소별 좌표정보 조회(팝업API)

팝업API를 활용하여 도로명주소 DB 구축 없이 다양한 시스템 환경에서 실시간으로 주소의 좌표 검색기능을 구현할 수 있습니다 1. API 서비스 개요 - 웹 기반의 UI 제공 - DB 구축 및 현행화 부담 없음 - 실시간 주소 검색 가능 - 신청 즉시 이용 가능 - 1 시스템 1 승인키 부여 2. 입력 파라미터 정보 신청시 발급받은 승인키,주소 검색 결과를 리턴받을 URL (통합검색창을 호출한 페이지),도로명주소 검색결과 화면 출력유형(1 : 도로명, 2 : 도로명+지번, 3 : 도로명+상세건물명, 4 : 도로명+지번+상세건물명),상세주소 동/층/호정보 제공여부(Y : 제공, N : 미제공(직접입력)) 3. 출력 파라미터 정보 전체 도로명주소,도로명주소(참고항목 제외),도로명주소 참고항목,지번주소,도로명주소(영문),우편번호,고객 입력 상세 주소,행정구역코드,도로명코드,건물관리번호,상세건물명,건물명,공동주택여부(1 : 공동주택, 0 : 비공동주택),시도명,시군구명,읍면동명,법정리명,도로명,지하여부(0 : 지상, 1 : 지하),건물본번,건물부번,산여부(0 : 대지, 1 : 산),지번본번(번지),지번부번(호),읍면동일련번호,X좌표,Y좌표

제공기관: 행정안전부
분류: 과학기술
키워드: 주소, 도로명주소, 주소좌표정보(팝업API), 주소출입구, 위치검색
형식: xml

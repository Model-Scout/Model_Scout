# 한국가스공사_무상 기술나눔 대상 목록 조회_20251210

한국가스공사가 보유한 지식재산권 중 민간에 무상으로 나눔(양도, 통상실시권)하고 있는 목록. 검색어, 페이지번호, 페이지당 보여지는 건수 등을 기준으로 지식재산권 등록번호, 명칭, 구분, 양도가능여부를 조회하는 무상 기술나눔 대상 조회 서비스. API 상세 설명 : 한국가스공사 홈페이지(https://www.kogas.or.kr) 내 무상 기술나눔 대상 목록의 데이터를 제공 (원본 데이터 위치 : [ESG경영] - [사회(G)] - [동반성장] - [기술이전] - [무상 기술나눔 대상] 참고) 국내외 등록 특허, 실용신안, 디자인 등 다양한 분야의 기술 대상

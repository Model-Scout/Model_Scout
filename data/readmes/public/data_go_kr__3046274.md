# 해외학술지 논문_20200924

본 데이터는 한국교육학술정보원(KERIS)이 운영하는 RISS(학술연구정보서비스)의 해외학술논문 검색 API를 통해 제공되는 해외 학술논문 정보이다. 논문명, 저자명, 발행처, 발행연도, 학술지명, 권·호 정보, 등재정보, 수록 페이지, ISSN, 원문 또는 상세정보 연결 URL 등의 항목을 제공한다. 이용자는 전체 검색어뿐만 아니라 논문명, 저자, 주제어, 발행처, 초록, 목차와 발행연도 범위 등을 조건으로 자료를 검색할 수 있으며, 검색 결과를 논문명·저자·발행연도 기준으로 정렬할 수 있다. 이를 활용하여 해외 연구동향 분석, 주제별 논문 탐색, 연구자·기관별 학술성과 조사, 학술정보 검색서비스 및 연구지원 시스템 구축 등에 활용할 수 있다. 데이터는 XML 형식으로 제공되며 API 이용을 위해 발급받은 인증키가 필요하다.

# 임산물 DB백과

한국임업진흥원에서 구축한 '임산물 정보 데이터 베이스(DB)' 를 외부시스템이나 서비스에서 실시간으로 불러와 활용할 수 있도록 제공하는 공공데이터 오픈 API 서비스입니다. 임산물을 품목, 소분류 종류별로 구분지어 정의, 종류, 분포 등 정보를 제공하고 있습니다. 한국임업진흥원 포털의 임산물 DB백과의 자료는 JSON 형식으로 제공됩니다. 이 API를 통해 사용자(개발자, 기업, 연구자 등)는 임산물의 기초 정보를 체계적으로 활용할 수 있으며, 임산물 유통·교육·산림정책 수립 등 다양한 분야에 응용이 가능합니다.

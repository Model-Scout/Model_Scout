# 정수기제조업·수입판매업 현황

이 데이터는 경기도 내 정수기 제조업 또는 수입판매업체에 대한 인허가 현황을 담고 있으며, 총 18개 항목으로 구성되어 있습니다. 시군명, 사업장명, 인허가일자, 폐업일자, 제품명, 소재지 주소(WGS84 위도·경도 포함), 소재지면적, 먹는물 민원구분 등의 정보를 제공합니다. 해당 데이터는 물리적·화학적·생물학적 방식으로 수질을 정화하는 정수기 제품을 제조하거나 수입하여 판매하는 사업체에 대한 현황을 파악하는 데 활용됩니다. 관련 정책 수립, 산업 현황 분석, 위생점검 계획 수립, 민원 대응 자료 등으로 활용 가능하며, Open API 방식으로 제공됩니다. 지방행정데이터개방시스템 개편에 따라 2018년 이후 데이터 갱신이 일시적으로 중단된 이력이 있습니다.

제공기관: 경기도
분류: 식품건강
키워드: 정수기제조업, 수입판매업, 인허가현황, 먹는물, 사업장정보, 위생관리, 제품정보, 주소정보
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-07-21
이용허락: 이용허락범위 제한 없음

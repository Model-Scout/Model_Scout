# 후보자 정보 조회서비스

후보자 및 예비후보자 정보를 조회할 수 있는 서비스입니다. (선거ID와 선거종류코드를 입력받아 선거별 후보자의 성명, 생년월일, 성별, 선거구, 학력, 경력, 등록상태 등 상세 정보를 제공합니다.) ※ 확인사항 · 예비후보자 정보는 후보자등록 개시일부터 조회되지 않음 · sgId, sgTypecode, sggName, sdName은 [코드 정보]를 이용해서 조회 가능

제공기관: 중앙선거관리위원회
분류: 공공행정
키워드: 후보자, 예비후보자, 선거출마, 후보자명단, 예비후보자명단, 후보정보, 후보등록, 후보경력
형식: api
수정일: 2025-09-03
이용허락: 이용허락범위 제한 없음

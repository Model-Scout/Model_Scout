# 개표소 정보 조회 서비스

개표소 정보는 실시 중인 선거의 개표소명, 주소 등을 확인할 수 있습니다. (선거 ID와 시도명, 구·시·군명을 입력하여 해당 선거의 개표소 정보를 조회할 수 있는 서비스) ※ 확인사항 · 개표소 정보는 선거 종료 후에는 제공되지 않습니다. · sgId, sdName, wiwName은 코드정보 조회 서비스를 통해 확인 가능

제공기관: 중앙선거관리위원회
분류: 공공행정
키워드: 개표소, 선거개표, 코드정보, 개표주소, 개표위치, 개표정보, 개표장소, 개표소명
형식: api
선정 기준: 국가중점데이터 OpenAPI
수정일: 2025-09-03
이용허락: 이용허락범위 제한 없음

# 국가기술자격 등급별 현황 정보

“국가자격 등급별 현황 정보” API는 한국산업인력공단에서 제공하는 공공데이터 기반 REST API로, 국가자격의 등급(기술사·기사 등)별 취득 현황, 응시자격 현황, 접수 상황, 종목 현황 등 통계 정보를 XML 형식으로 제공합니다. 주요 기능으로는 등급별 취득자 수, 전년 대비 증가율, 순위, 응시자격 조건, 원서 접수 수와 순위, 특정 등급의 상위 종목 현황 등을 페이지 단위로 조회할 수 있습니다

제공기관: 한국산업인력공단
분류: 공공행정
키워드: 국가자격, 기술자격, 등급별현황, 큐넷
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2026-09-10
이용허락: 이용허락범위 제한 없음

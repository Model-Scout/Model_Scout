# 한국국제협력단_일일 안전관리 중점국가_20210115

KOICA가 지정한 일일 안전관리 중점국가 목록 정보를 제공하는 API입니다. 정세 불안, 재난, 감염병 등 다양한 위험요소에 따라 안전관리가 필요한 국가를 분류하여, KOICA의 해외사업 수행 시 위험요소를 사전 인지하고 대응할 수 있도록 합니다. 해당 API는 인증키(serviceKey), 페이지 번호(pageNo), 한 페이지 결과 수(numOfRows) 등 기본적인 요청변수를 사용하며 한글 국가명, 데이터표출방식, ISO 2자리코드 등의 필터 파라미터를 추가로 설정할 수 있습니다. 출력결과에는 국가명, ISO 2자리코드, 신규구분코드, 보고일, 위험내용, 위험수준코드 등의 항목이 포함되며, 각 항목에 대한 데이터는 JSON 형식으로 반환됩니다.

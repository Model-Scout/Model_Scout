# 한국고용정보원_워크넷  심리검사결과_20210520

[심리검사 API - 심리검사결과] 워크넷과 대학 연계를 통해 제공되는 4종의 대학전용 심리검사의 검사결과를 조회하여 활용할 수 있습니다. 본 정보활용 서비스 사용을 위해 대학의 기관등록이 선행되어야 합니다. 심리검사API를 이용하여 개인별 심리검사 결과를 조회할 수 있습니다. 개인정보처리방침에 따라 직업심리검사 회원은 회원정책(보유기간 2년)/비회원(API등)은 보유기간 7일 이후에 개인정보가 삭제됨을 알려드리며 그 이후에는 검사이력은 조회되지 않습니다. <API 사용법> 인증키, xml 지정, 제공받은 학교코드, 학번, 심리검사코드 등을 파라미터로 받아 심리검사코드, 검사일자, 원점수, 표준점수, 백분위점수, 추천직업, 흥미코드, 적성요인, 직업선호도, 총합점수 등의 결과를 제공합니다. * 유의사항: 문자열로 입력되는 항목의 경우 공백이나 오탈자가 포함되면 검색 결과가 제대로 나오지 않을 수 있으므로 주의해야 합니다. 대부분의 파라미터는 선택적으로 입력할 수 있으며, 필요한 조건만 입력해도 조회는 가능합니다.

제공기관: 한국고용정보원
분류: 산업고용
키워드: 적성, 대입, 워크넷, 직업선호도검사, 직업심리검사, 흥미검사, 창업적성검사, 적성검사
형식: api
수정일: 2025-07-21

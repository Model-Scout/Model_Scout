# 하수슬러지 처리 집계 현황

이 데이터는 경기도 내 각 시군의 하수처리장에서 발생하는 하수슬러지의 연간 처리 현황을 제공하며, 재활용량, 육상매립, 해양투기, 소각, 연료화, 미처분량(이월량), 기타처분 등 다양한 처리방식별 처리량 정보를 포함하고 있습니다. 주요 항목은 집계년도, 시군명 및 코드, 하수처리장명, 각 처분방식별 연간 처리량(톤 단위) 등으로 구성되어 있습니다. 본 데이터는 경기도청 상하수과에서 관리하며, 공공환경 데이터로서 하수슬러지의 발생량과 처리방식의 변화 추이를 파악하고 지역 간 환경정책 수립의 기초 자료로 활용될 수 있습니다. 데이터는 연간 단위로 갱신되며, XML 또는 JSON 포맷으로 제공되는 Open API 형태로 활용 가능합니다. 관련 URL을 통해 샘플 호출 테스트도 가능하며, 환경 관련 연구나 정책 분석, 폐기물 감축 및 처리 효율화 전략 수립에 유용한 자료입니다.

제공기관: 경기도
분류: 환경기상
키워드: 하수슬러지, 재활용량, 소각처리, 해양투기, 연료화, 하수처리장, 폐기물처리, 환경데이터
형식: api
선정 기준: 운영 자동승인 OpenAPI

# 정신장애인 사회복귀시설 현황

이 데이터는 정신장애인의 사회복귀와 자립을 지원하는 복지시설 현황을 정리한 자료입니다. 주요 항목에는 시군명, 기관명, 소재지 지번주소와 도로명주소, 우편번호, WGS84 좌표(위도·경도), 전화번호, 홈페이지 URL이 포함되어 있습니다. 해당 시설들은 지역사회 내에서 정신장애인을 대상으로 직업 훈련, 사회 적응 프로그램, 주거 지원, 심리 상담 등을 제공하며, 정신건강 회복과 재활을 목적으로 운영됩니다. 이 데이터는 복지 자원의 지역별 분포를 파악하고, 정책 수립 시 사회복귀시설의 접근성과 서비스 범위를 평가하는 기초자료로 활용될 수 있습니다. 또한 기관별 홈페이지 정보를 통해 개별 프로그램과 서비스 내용을 확인할 수 있어 현장 적용성이 높습니다.

제공기관: 경기도
분류: 사회복지
키워드: 정신장애, 재활센터, 복지기관, 복지정책, 자립지원, 사회적응
형식: api
선정 기준: 운영 자동승인 OpenAPI

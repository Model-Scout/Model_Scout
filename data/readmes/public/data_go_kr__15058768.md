# 녹색기업 지정 현황

이 데이터는 경기도 관할 내에서 환경관리 실적이 우수하고 자발적인 환경개선을 실천한 사업체를 대상으로 지정된 녹색기업의 현황을 제공하는 자료입니다. 데이터는 각 기업의 업체명, 대표자명, 업종명, 최초 지정일, 지정기간, 중소기업 여부, 소재지 주소(지번 및 도로명), 위경도 좌표(WGS84), 연락처 등의 정보를 포함하고 있으며, 환경경영 우수기업의 지역별 분포와 환경정책 반영 실태 등을 분석하는 데 활용될 수 있습니다. 또한 기업정보를 기반으로 한 정책지원 대상 기업 선별, 환경산업 발전 기초자료, 지역 환경 인프라 개발 참고자료 등으로의 응용이 가능합니다. 데이터는 연간 단위로 갱신되며, XML 또는 JSON 포맷으로 제공되는 Open API 형태로 제공되므로 실시간 연계 및 시스템 활용이 가능합니다.

제공기관: 경기도
분류: 환경기상
키워드: 녹색기업, 환경경영, 지정기업, 업종정보, 사업장주소, 대표자정보, 중소기업여부, 공공데이터
형식: api
선정 기준: 운영 자동승인 OpenAPI

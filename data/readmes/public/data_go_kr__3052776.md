# 서울교통공사_열차운행현황

서울교통공사의 열차운행 현황과 관련 데이터입니다. 열차 운행 현황 정보는 서울교통공사에어 운행하는 1-8호선에 대한 영업구간, 영업거리(km, 해당 호선 중 서울교통공사의 영업구간 거리), 역수(개), 소요시간(분), 보유편성차량수(칸, 해당 호선의 보유 편성수 x 해당 호선의 1편성을 구성하는 1편성당 칸수), 열차편성수(1편성당 칸수), 표정속도(km/h), 열차주행거리(평일 km/일, 평일 기준 해당 호선의 열차가 하루동안 운행한 거리),운행시격_RH(출근), 운행시격_NH(평시), 운행횟수_평일, 운행횟수_휴일 정보로 구성되어 있습니다.

형식: csv

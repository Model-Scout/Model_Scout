# 한국국제협력단_KOICA 국가코드 테이블

한국국제협력단(KOICA)이 관리하는 KOICA 고유 국가코드와 국제 표준 코드(ISO, DAC) 간 매핑 정보를 체계적으로 정리한 수시성 자료입니다. 국가 이름, KOICA 코드, DAC(개발원조위원회) 코드, ISO 3166-1 숫자 코드 및 알파벳 코드(2자리/3자리) 등의 정보를 포함하여, 기관 내외부 데이터 연계 시 국가 식별의 혼동을 줄이고 정합성을 높이는 핵심 도구로 활용됩니다. 동데이터는 CSV뿐 아니라 XML, JSON 형태로 제공되어 자동화 스크립트나 API 연계 등에도 유리하게 활용될 수 있습니다.

제공기관: 한국국제협력단
분류: 통일외교안보
키워드: KOICA_코드, ISO_코드, DAC_코드, 국제기준, 공적개발원조
형식: csv

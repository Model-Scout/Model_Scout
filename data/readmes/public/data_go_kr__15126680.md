# 국립암센터_사망률 지표 정보제공 서비스_20240213

이 API는 국가 암 부담 모니터링 자료원 구축을 통해 산출한 생애말기 사망률 지표 정보제공 서비스로, 생애말기 사망률 지표 정보(제공 되어질 데이터 항목, 타입, 사이즈, 항목별 건수, 샘플데이터 등)를 제공한다. * 자료제공홈페이지: https://www.cancerdata.re.kr/surveillance

제공기관: 국립암센터
분류: 보건의료
키워드: 암, 생애말기, 사망률
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2024-12-24
이용허락: 공공저작물 : 출처표시, 상업적 이용금지, 변경금지 (제 4유형)

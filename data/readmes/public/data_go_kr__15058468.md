# 무한돌봄센터 현황

무한돌봄센터 현황은 경기도 내 각 시군에 설치된 무한돌봄센터의 위치와 운영 정보를 제공하는 데이터로, 복지 사각지대 해소를 위한 실질적 대응체계 현황을 보여줍니다. 무한돌봄사업은 기준 미달로 복지제도에서 배제된 위기 가정을 발굴하고 추가 지원을 통해 극빈층 전락을 예방하는 제도로, 센터명(CENTER_NM), 담당부서명(CHARGE_DEPT_NM), 사례관리팀명(TEAM_CASE_CHARGE_DEPT), 자원연계팀명(TEAM_RESRCE_CHARGE_DEPT), 연락처(TELNO), 소재지 주소(REFINE_ROADNM_ADDR, REFINE_LOTNO_ADDR, REFINE_ZIP_CD), 위치좌표(REFINE_WGS84_LAT, REFINE_WGS84_LOGT) 등의 정보를 포함합니다. 본 데이터는 복지 정책 수립, 위기 가정 접근성 분석, 지역별 돌봄 서비스 현황 파악 등에 활용 가능하며, 공공복지 연계시스템 구축 및 비영리 민간기관의 자원 연계 활동에도 유용하게 쓰일 수 있습니다.

제공기관: 경기도
분류: 사회복지
키워드: 무한돌봄, 복지위기, 돌봄센터정보, 담당부서, 사례관리팀, 시군별현황
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-06-26
이용허락: 이용허락범위 제한 없음

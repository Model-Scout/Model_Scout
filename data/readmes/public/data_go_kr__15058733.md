# 성평등가족부 정책 뉴스 조회 서비스

성평등가족부의 대표 홈페이지에서 제공하는 여러 정책 뉴스 및 보도자료를 조회할 수 있는 서비스를 제공하는 오픈 API형 데이터입니다. 해당 개방데이터는 정책 뉴스의 목록조회와 보도자료의 목록조회 두 가지로 이용 가능합니다. 그리고 정책 뉴스의 목록조회는 정책 뉴스의 제목, 등록일자, 게시글의 상세보기 URL 정보, 게시글의 썸네일 URL 정보, 담당부서 등의 목록 조회가 가능합니다. 또한, 보도자료의 목록조회는 보도자료의 제목, 등록일자, 담당부서, 보도자료의 상세보기 URL 정보 조회가 가능합니다.

제공기관: 성평등가족부
분류: 사회복지
키워드: 정책자료, 정책뉴스, 보도자료, 뉴스조회, 조회서비스
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2026-02-11
이용허락: 제3자 권리 포함 : 저작권 표시, 공공저작물 : 출처표시 (제 1유형)

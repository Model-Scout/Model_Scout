# 휴게음식점(키즈카페) 현황

이 데이터는 경기도 내 휴게음식점 중 키즈카페 형태로 운영되는 업소의 현황 정보를 담고 있습니다. 데이터에는 시군명, 사업장명, 인허가일자, 영업상태, 폐업일자, 소재지 주소 및 면적, 위생업종명, 위생업태명, 총시설규모, 종사자 수(남녀별), 다중이용업소 여부 등의 항목이 포함되어 있으며, 총 31개 시군에 대한 인허가 정보를 기반으로 합니다. 데이터는 어린이 대상의 식품판매업소 운영 실태 분석, 위생관리 및 안전대책 수립, 키즈카페 이용자 보호 정책 등에 활용될 수 있습니다. API는 인증키를 통해 접근 가능하며 XML 또는 JSON 형태로 제공됩니다.

제공기관: 경기도
분류: 식품건강
키워드: 휴게음식점, 키즈카페, 어린이시설, 위생업소, 인허가현황, 편의점, 식품안전, 가족공간
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-06-24
이용허락: 이용허락범위 제한 없음

# 법무부_자비물품구매 조회 서비스

법무부 소속 교정기관에서 수용자가 자비로 구매한 물품에 대하여 확인 가능한 목록 조회 서비스를 위한 Open API 입니다. 공급업체와 공급일자를 기준으로 각 교정기관의 발주신청내역을 확인 할 수 있습니다. 법무부 교정본부 홈페이지(www.corrections.go.kr) 내 알림마당에서도 동일하게 조회 및 확인 가능합니다. 교정기관에서 발주하는 물품의 수량 및 상태를 포함한 발주신청내역을 확인 가능합니다. 이를 활용하면, 발주신청내역 데이터를 기반으로 각 교정기관 별 운영에 필요한 물품수량과 추후 동일·유사 물품을 발주하기 위한 참고자료로써의 통계로서도 활용될 수 있습니다.

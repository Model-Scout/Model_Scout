# 일반음식점(생선회) 현황

이 데이터는 경기도 내에서 생선회, 활어회, 해산물 요리 등을 전문으로 제공하는 일반음식점의 인허가 및 영업현황 정보를 포함합니다. 주요 항목은 사업장명, 인허가일자, 폐업일자, 영업상태, 위생업종명, 위생업태명, 급수시설구분, 종업원 수, 다중이용업소 여부, 소재지 정보(도로명주소, 지번주소, 위도·경도), 총시설규모 등으로 구성됩니다. 해당 데이터는 지역 내 수산물 기반 외식업 동향 파악, 식품위생 관리 정책 수립, 해산물 전문 상권 개발, 안전 관리체계 구축 등에 활용될 수 있습니다. 데이터는 경기도 31개 시군 전체를 포괄하며 Open API를 통해 실시간 정보 연계가 가능합니다.

제공기관: 경기도
분류: 식품건강
키워드: 생선회음식점, 일반음식점, 위생업종, 인허가정보, 다중이용업소, 소재지정보, 종업원수, 급수시설구분
형식: api
선정 기준: 운영 자동승인 OpenAPI
수정일: 2025-09-08
이용허락: 이용허락범위 제한 없음

# 국민건강보험공단_감염성질환(인플루엔자) 의료이용정보

1. 배경 : 감염성 질환을 평가하기 위해 지속적인 감시가 필요함. 2. 목적 : 건강보험 빅데이터를 이용한 질병 발생자료를 구축하여 일자별, 인구사회학적 특성(성/연령/시도) 및 의료이용행태 특성(입원/외래)의 자료를 제공함으로써 감시체계 자료원으로 활용하고자 함. 3. 사례정의 : 상병코드 ○ J09 확인된 동물매개 또는 범유행 인플루엔자바이러스에 의한 인플루엔자 ○ J10 확인된 계절성 인플루엔자바이러스에 의한 인플루엔자 ○ J11 바이러스가 확인되지 않은 인플루엔자 4. 구축방법 ○ 전체 청구상병 테이블(주상병(=1상병) 및 주상병 이외의 모든 부상병 포함)에서 해당 상병코드가 포함된 모든 청구건 추출 ○ 해당 상병코드로 진단 받은 모든 청구건을 중복제거 후 진료에피소드로 묶고, 건수를 산출함. - 각 청구건의 날짜 간격이 28일 이내인 경우 하나의 진료에피소드로 구축함. - 방법론 참조 : 국립환경과학원 '국민건강보험공단 빅데이터를 이용한 가습기살균제 건강피해 규명 연구(II)'(2020), '가습기살균제 호흡기계 건강피해 통합 판정체계 구축 연구'(2021) ○ 2006년 1월~2025년 12월까지 주·부상병 조건의 진료에피소드 건수 - 하나의 진료에피소드에 포함된 여러 청구건들 중에서 해당 상병코드가 주상병 또는 제2상병으로 1회 이상 청구된 경우임. ○ 2006년 1월~2025년 12월까지 "외래 및 입원"과 "입원"의 진료에피소드 건수 - "입원" 진료에피소드는 하나의 진료에피소드에 포함된 여러 청구건들 중 하나 이상의 입원 청구건이 포함된 경우임. ○ 시도, 요양개시일, 입원/외래, 성별, 연령군별 진료에피소드 건수를 산출함. - 외래 및 입원 주·부상병 조건의 진료에피소드 건수(파일명: 외래입원주부상병) - 입원 주·부상병 조건의 진료에피소드 건수(파일명: 입원주부상병)

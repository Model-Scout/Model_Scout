# 법무부_수용정보 관련 통계

교정시설의 및 수용자에 대한 처우시 중요한 자료로 활용되고 있는 자료로 수용기본사항 통계를 제공 ( 입출소, 재판 년단위, 수용현황 등) 1. 외국인 수용자 : 성별, 형명, 형기별 인원 현황 2. 소년 수용자 : 형명, 형기별, 죄명별 인원 현황 3. 여성 수용자 : 형명, 형기별, 인원 현황 4. 수용자 입소사유 : 직입소, 형확정, 기타

제공기관: 법무부
분류: 법률
키워드: 수용인원통계, 수용통계, 보안통계, 외국인_수용자, 1일평균_수용자, 성별_수용자
형식: csv
선정 기준: 중앙·광역 기관 파일데이터

# 음양력 정보제공 서비스

(천문우주정보)음력일정보, 양력일정보, 특정음력일정보, 율리우스적일정보를 조회하는 서비스 입니다. 사용자는 연(음력), 월(음력), 일(음력), 일, 윤년구분, 윤달구분, 요일, 간지(월), 월일수(음력), 연(양력), 월(양력) 간지(세차), 간지(일진), 율리우스적일에 대해 확인할 수 있습니다.

제공기관: 한국천문연구원
분류: 과학기술
키워드: 음력 변환, 양력 변환, 율리우스 적일
형식: api
선정 기준: 운영 자동승인 OpenAPI

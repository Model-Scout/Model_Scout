# 택배신청 저장 서비스

우편소포에 대한 신청과 접수완료, 취소 처리 기능을 제공하는 OPEN API 서비스 입니다. ㅇ 출력하는 항목(사용자가 응답 받게 되는 데이터) : 신청자이름, 우편번호, 전화번호, 휴대전화, 수령자이름, 중량, 부피, 내용물, 내용품코드, 배송특이사항, 이메일, 방문접수 우체국, 요금부담여부, 접수결과수신, 방문접수일자, 기표지, 신청번호, 물품명, 받는분, 요금부담자, 지불방법, 할인, 예상요금, 부가서비스, 세금계산서

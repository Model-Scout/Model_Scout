# 고속도로구간별 도로위험도지수정보 조회 서비스

- 고속도로 구간별 도로위험도지수 정보 * 고속도로명, 고속도로구간명과 차종(승용, 버스, 택시, 화물차로 구분)을 이용하여 해당 구간의 실시간(10분단위) 도로위험도지수 및 도로위험등급 정보를 제공 - 해당 데이터는 교통사고정보개방시스템( https://opendata.koroad.or.kr/api/sample.do) 에서 <API대분류: 교통안전정보>, <API소분류 : 고속도로구간별 도로위험지수API>를 선택 후 검색 시 WMS 및 REST 형태의 샘플 결과 데이터를 확인하실 수 있습니다.

제공기관: 한국도로교통공단
분류: 재난안전
키워드: 고속도로구간별, 도로위험도지수정보, 교통사고, 도로위험등급, 실시간
형식: api
선정 기준: 국가중점데이터 OpenAPI

# 한국고용정보원_워크넷 강소기업 청년친화강소기업_20210520

[강소기업 API - 청년친화강소기업] 고용노동부에서 선정한 청년에게 추천하는 작지만 강한기업 '청년친화강소기업' 입니다. <API 사용법> 기본값 1, 출력건수 등을 파라미터로 받아 총건수, 출력건수, 기업명, 사업자등록번호, 대표자, 업종코드(상), 업종명(상), 업종코드(중), 업종명(중), 지역코드, 지역명, 상시근로자 수 등의 결과를 제공합니다. * 유의사항: 문자열로 입력되는 항목의 경우 공백이나 오탈자가 포함되면 검색 결과가 제대로 나오지 않을 수 있으므로 주의해야 합니다. 대부분의 파라미터는 선택적으로 입력할 수 있으며, 필요한 조건만 입력해도 조회는 가능합니다.

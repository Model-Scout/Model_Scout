# 외교부_국가(지역)별 주요협정정보

외교부 홈페이지에 공개 중인 각 국가별 약황 정보 중 주요협정 정보를 CSV 형식으로 제공합니다. (데이터 업데이트 주기: 12개월, 실시간 정보는 동명의 API 참고) 제공되는 정보의 항목은 국가, 국가코드(ISO 2자리), 협정명, 협정년도, 협정월, 협정내용 제공되는 데이터의 예시는 1.투르크메니스탄 2.TM 3.이중과세방지협정 개정 4.2020 5.대한민국과 투르크메니스탄 간 2020년 2월 개정한 것으로, 양국 국민과 기업의 소득에 대한 이중과세를 방지하고 조세 탈세를 예방하기 위하여 과세권 배분과 조세 감면 등에 관한 사항을 규정하는 협정이다. 의 내용으로 제공되며, 이외에도 1,324건의 정보가 제공됩니다.

제공기관: 외교부
분류: 통일외교안보
키워드: 협정_조약, 해외, 외교, 체결국가명, 협정_년도, 협정_월, 협정_내용
형식: csv

# PlayStation 2 Games

Data about all PlayStation 2 games

PlayStation 2 was released by Sony Computer Entertainment in 2000 and is one of the most popular game console.
In this datasets, data about all PlayStation2 games contain.

I changed the name of some games to solve "UnicodeDecodeError".
(Chanter♯: Kimi no Uta ga Todoitara -&gt; Chanter Sharp: Kimi no Uta ga Todoitara, etc.)

If you have any problem, please make a discussion thread about it.

##Columns
Both 2 csv files have 7 columns.
| Column name | Description |
| --- | --- |
| Title |  Game Title (In English)|
| Developer | Developer name which developed the game|
| Publisher | Publisher name which released the game|
| First released | Date when the game was released firstly|
| JP | Released = the game was released in Japan (or Korea), Unreleased = the game was not released |
| EU/PAL | Released = the game was released in EU (or Australia), Unreleased = the game was not released |
| NA | Released = the game was released in North America, Unreleased = the game was not released |

# Bluesky Social: December 2025

101,040 posts from the Bluesky social network from December 2-25, 2025

## Dataset Overview

[Live Collection View](https://dr.eamer.dev/bluesky/firehose/)

- Collection Period: December 2-25, 2025
- Source: Bluesky social media posts via the AT Protocol firehose
- Anonymization: All author identifiers anonymized using SHA-256 hashing

## Data Included

Live view while collecting: dr.eamer.dev/bluesky/firehose/

- Post Text
- Sentiment Scores: VADER
- Detected Languages: 90 languages
- Thread Structure: Reply chains preserved via hashes
- Media Flags
- Embed Types
- Hashtags
- Mentions
- External Links

## Data Excluded

- Engagement Metrics: Likes, reposts, reply counts (stored separately in user repositories)

### Use Cases

- Sentiment Analysis
- Multilingual NLP
- Temporal Patterns
- Content Analysis
- Language Modeling
- Thread Structure Analysis

### Not Suitable For

- Virality Prediction
- Influence Analysis
- Popularity Modeling
- Anything Requiring Engagement Counts

# Power BI Project

Data analysis of a bakery store data

This project focuses on analyzing a bakery sales dataset extracted from a Korean bakery store. The dataset includes information on various products, their prices, sales quantities, and timestamps. The goal of this project is to gain insights into the bakery's sales performance, understand customer preferences, and identify patterns and trends.

# UN speeches. Keyword: "Korea"



This dataset is a result of a WebScrap of the [UN Digital Library](https://digitallibrary.un.org/search?ln=en&cc=Speeches&p=korea&f=&rm=&sf=latest%20first&so=d&rg=50&c=Speeches&c=&of=hb&fti=0&fct__3=2024&fti=0). The search was made by the key term "Korea". 

Each downloaded record contains speeches from various countries, so the text of each PDF was partitioned into the individual speeches it includes.

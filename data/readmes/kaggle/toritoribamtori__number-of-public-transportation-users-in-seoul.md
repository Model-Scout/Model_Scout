# Number of public transportation users in Seoul

Number of public transportation users stored by user and pattern

The above dataset contains information on public transportation usage patterns in Seoul, South Korea.
We have information on public transport ridership numbers and patterns from November 30, 2021 to December 4, 2023.
Public transportation users are stored by type (general, children, seniors, disabled, etc.), and you can check public transportation usage patterns (bus-subway, bus-bus-subway, etc.).
The original dataset can be found at the Seoul Open Data Plaza(https://data.seoul.go.kr), and this dataset was downloaded as of December 12, 2023.

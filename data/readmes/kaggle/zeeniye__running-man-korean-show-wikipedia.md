# Running Man Korean Show Wikipedia (런닝맨)

Yoo Jae-suk,Haha,Jee Seok-jin,Kim Jong-kook,Song Ji-hyo,Jeon Somin,Yang Se-Chan

Running Man was originally classified as an "urban action variety"; a genre of variety shows in an urban environment. The MCs and guests were to complete missions at a landmark to win the race. The show has since shifted to a more familiar reality-variety show concept focused on games. It first aired on July 11, 2010. [[1](https://en.wikipedia.org/wiki/Running_Man_(South_Korean_TV_series))]

Scrape from Wikipedia, this dataset listed the detail of the Korean Show from the first time till now. Notes that this dataset is still not very clean as there are still areas that need to be processed.

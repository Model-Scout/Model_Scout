# Introduction
- challenger, grandmaster, master 100,800 game data(korea, 2020)
- There are three large categories
       - team object data
       - participants data
       - gameDuration
- File extension is .pickle
       - because of many column is json data type
       - The csv extension does not preserve the json data type.
       - The pickle extension does preserve the json data type.
       - Click the following link to read this file.
               - [Click!](https://www.kaggle.com/gyejr95/match-data-information-participants-team-object)

# Data summary
### match_data_version1
- 108,000 row
- gameId : game id
- gameDuration : game time
- participants : In-game information of 10 summoners who participated in the game

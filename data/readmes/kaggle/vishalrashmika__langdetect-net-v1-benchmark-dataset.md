# Multilingual Script & Romanized Text Dataset
A multilingual phrase corpus supporting native Unicode scripts and romanized text.

## Overview
This dataset is designed for training and benchmarking robust text-based language detection engines. Unlike standard corpora that only focus on native scripts, this dataset includes text variations to handle romanized detection—capturing how global languages are frequently written using the Latin alphabet in casual digital communication (e.g., text messages, social media).

It provides a solid baseline for handling mixed Unicode ranges, tokenization challenges, and phonetic transliterations in natural language processing (NLP) pipelines.

## Supported Languages:
- English (Native Latin script)
- Arabic (Includes Arabizi romanization)
- Hindi (Includes Hinglish romanization)
- Mandarin (Includes Pinyin romanization)
- Japanese (Includes Romaji romanization)
- Korean (Includes Revised Romanization)
- Sinhala (Includes Singlish romanization)
- Tamil (Includes Tanglish romanization)

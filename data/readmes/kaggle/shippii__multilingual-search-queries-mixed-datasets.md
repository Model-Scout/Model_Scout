# Multilingual Search Queries + Mixed Datasets

Utilised for training models to identify the language of short query-style text.

Search query data set is composed of originally 2 million English search queries obtained from the Open Resource for Click Analysis in Search (ORCAS) data set. These 2 million samples have been run through machine translation to generate search query data for 20 other different languages. In total, there are approximately 42 million samples.

Mixed data set is composed of 1.6 million search queries for each language from what was previously mentioned, as well as 400,000 samples obtained from the W2C Web Corpus for each language. It total, there is also approximately 42 million samples. However, the file size is much larger due to the W2C Web Corpus samples being much longer on average than the search queries.

Languages used:
English (en), Chinese (zh), Russian (ru), Portuguese (pt), Spanish (es), French (fr), German (de), Italian (it), Dutch (nl), Japanese (ja), Korean (ko), Arabic (ar), Thai (th), Hindi (hi), Hebrew (he), Vietnamese (vi), Turkish (tr), Polish (pl), Indonesian (id), Malay (ms), and Ukrainian (uk).

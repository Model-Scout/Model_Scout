# Cosmetics with Color Code

Dataset of Korean, Global Cosmetics (Lip, Eye, Eyebrow) by Category

## Overview

This dataset contains structured information on Korean cosmetic products, including their **brand**, **category**, **series**, **type**, **color name**, and **hex color code**. It is curated to support applications in **color-based recommendation systems**, **e-commerce filtering**, and **computer vision** tasks such as facial region-based product matching.

## Columns

- `section`: Product usage area (e.g., lip, eye, eyebrow)
- `category`: Cosmetic category (e.g., tint, shadow, pencil)
- `brand`: Brand name
- `product_series`: Product line or collection
- `product_name`: Specific product name
- `color_name`: Commercial shade name
- `hex_color`: HEX code representing the product’s color
- `price`: Price in KRW (if available)

## Use Cases

- Color recommendation based on facial image analysis
- Filtering cosmetics by section, brand, or color
- UI/UX mockups for virtual makeup try-on tools
- Color clustering and shade similarity computation using HEX or LAB values

# Movies Rating Dataset

source : themoviedb.org

| Column Name           | Description                                                                                     |
|-----------------------|-------------------------------------------------------------------------------------------------|
| genre_ids             | List of genre IDs associated with the movie (e.g., [28, 35, 878] corresponds to Action, Comedy, and Science Fiction). |
| original_language     | Language in which the movie was originally produced (e.g., 'en' for English).                  |
| original_title        | The title of the movie as it was originally released.                                          |
| popularity            | A measure of how popular the movie is, usually based on user ratings or views (higher values indicate more popularity). |
| release_date          | The date when the movie was released (in YYYY-MM-DD format).                                  |
| title                 | The title of the movie, which may differ from the original title.                              |
| vote_average          | The average rating given to the movie, typically on a scale from 1 to 10.                     |
| vote_count            | The total number of votes or ratings received for the movie.                                   |

# korean_voice

male korean voice actor audio in youtube

### Context

That is a dataset that a Korean male voice actor(Lee Jaebeom) audio, text, and data file from youtube channel(https://www.youtube.com/channel/UC25eCV-Q1NZkexOZ0XoCajw/featured). Therefore, this channel has its license.


### Content

There are short audio files segmented by subtitle. and a refined text file that corresponds to an audio file. Also, data file(numpy)  obtained by embedding audio and text files are there. The data can be used to train artificial intelligence models such as voice synthesis and voice recognition. 
And if you want to know how to use this data, see https://github.com/zldzmfoq12/voice-synthesizer. This github shows how to synthesize people voice.

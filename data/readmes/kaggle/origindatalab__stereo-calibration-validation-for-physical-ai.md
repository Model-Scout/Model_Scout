# Stereo Calibration Validation for Physical AI

## Overview

Origin Data Lab presents a technical evaluation package for stereo calibration consistency using real-world egocentric capture data.

This release accompanies **Technical Field Note #04** and provides evaluation artifacts, quantitative measurements, technical documentation, and visual analysis.

## Key Evaluation Results

| Metric | Reported Result |
|---|---|
| Capture resolution | 1600 × 1200, 30 fps |
| Stereo pairs analyzed | 29 |
| Feature matches | 19,386 |
| Mode-matched median epipolar error | 0.41 px |
| Mode-mismatched median epipolar error | 1.83 px |

The reported values are specific to the evaluated configurations and should not be interpreted as universal calibration accuracy.

## What Is Included

- Epipolar error distribution and visualization
- Capture-mode consistency comparison
- Rotation sensitivity analysis
- Field-angle evaluation
- Fisheye inverse-model evaluation
- Technical report and supporting evaluation artifacts

## Research Applications

Relevant to stereo vision, robotic perception, physical AI, egocentric sensing, camera calibration evaluation, and multimodal data quality assessment.

## Important Limitations

This release does not establish verified metric depth accuracy, a fully validated stereo baseline, camera-to-IMU extrinsic calibration, or production-ready calibration across all capture modes.

It is an **evaluation artifact collection**, not a full raw-video dataset or certified calibration product.

# Subway Boarding and Station information in Seoul

Subway Station Boarding data in Seoul(Korea)

# Data introduction

- This data is Subway station boarding data in seoul
- Boarding information include daily timely log, daily log, monthly timely log

### daily timely log
- 2015 ~ 2018 data
- Not exist 2019 data

### monthly timely log
- 2015 ~ 2019 data

### daily log
- 2015 ~ 2019

### subway station information
- name, line, coordinate ...etc

# Data source
- monthly timely log : [https://data.seoul.go.kr/dataList/OA-12252/S/1/datasetView.do](https://data.seoul.go.kr/dataList/OA-12252/S/1/datasetView.do)
- daily timely log : [https://data.seoul.go.kr/dataList/OA-12921/F/1/datasetView.do](https://data.seoul.go.kr/dataList/OA-12921/F/1/datasetView.do)
- daily log [https://data.seoul.go.kr/dataList/OA-12914/S/1/datasetView.do](https://data.seoul.go.kr/dataList/OA-12914/S/1/datasetView.do)
- subway station information : https://data.seoul.go.kr/dataList/OA-12753/A/1/datasetView.do

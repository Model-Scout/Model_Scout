# Currencies

Different Types of currencies all over the world.

The dataset represents different currencies and their related information. Here's an explanation of the columns:

**Name:** The name of the currency.
**Symbol:**The symbol or sign used to represent the currency.
**Code:**The three-letter currency code according to the ISO 4217 standard.
**Countries:**The countries or territories where the currency is used. This is represented as a list of country names.
**Digits:**The number of digits used to represent the currency value after the decimal p**oint.
Number:** The numeric code assigned to the currency according to the ISO 4217 standard.
Each row in the dataset corresponds to a specific currency and its details. Some columns may have the value "undefined" or "null" if the information is not available.

The dataset provides information on various currencies such as the UK Pound, Czech Koruna, Swiss Franc, Croatian Kruna, Danish Krone, Korean Won, Swedish Krona, Turkish Lira, Hungarian Forint, Brazilian Real, Bulgarian Lev, Polish Zloty, US Dollar, Russian Ruble, Japanese Yen, Romanian New Leu, Norwegian Krone, Australian Dollar, Israeli Shekel, New Zealand Dollar, Indonesian Rupiah, Philippine Peso, Euro, Canadian Dollar, Chinese Yuan, Hong Kong Dollar, Indian Rupee, Mexican Peso, Malaysian Ringgit, South African Rand, Thai Baht, and Singaporean Dollar.

# Medical Translation

Simple Translation of Medical instructions to non-English languages

### Context

This dataset was built in response to the amazing work by [Sudesna](https://sudesnaroychowdhury.wixsite.com/covid?fbclid=IwAR2-_6yIWIljep5zomYz3KUTOcYJ-SL4a6lbBe-c4C2KQtZkKa-rCoVNwxE), who built a medical translation website for medical staff to communicate with migrant workers in Singapore. This tool was initially built only for Tamil and Bengali translation but I thought that it would be a great idea to expand its usage to other foreign languages. With the help of so many kind people from around the world, the dataset has expanded to include other languages. It is still expanding and improving. If you would like to contribute to the dataset, click [here](https://docs.google.com/spreadsheets/d/1T96tsR2y0bZYUAnrjLv6ZX0j9gPMNQpI1F8AuRedRk0/edit#gid=948564083).

We are currently building a website to host the dataset but a preliminary template would feature an interactive table like [this](https://bit.ly/2xuvMAb)

### Content

Simple Translation of Medical terms, instructions and greetings to non-English languages.

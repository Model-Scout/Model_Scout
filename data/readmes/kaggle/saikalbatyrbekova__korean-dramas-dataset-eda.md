# Korean Dramas Dataset 

This CSV file contains data of 350 Korean Dramas from year 2003 to 2025

🎬 This dataset contains information on **350 Korean Dramas**, sourced primarily from MyDramaList and Kaggle. It is structured in a **CSV file** format, making it suitable for various Data Science and Machine Learning projects.

**📌  Dataset Overview**
- Total Rows: 351 
- Total Columns: 9
- Data Type: Textual and Numerical

**📌  Data Collection Sources**
- 70% of the dataset was sourced from Kaggle ([https://www.kaggle.com/datasets/ahbab911/top-250-korean-dramas-kdrama-dataset](url))
- 30% of the dataset was manually collected from MyDramaList ([https://mydramalist.com](url))

**📌  Columns Description**
The dataset includes both textual and numerical attributes for each drama:
- Rank (Numeric)
- Drama Title (Text)
- Year of release (Numeric)
- Number of episodes (Numeric)
- Description (Text)
- Genre (Text)
- Tags (Text)
- Actors (Text)
- Rating (Numeric)

This dataset is perfect for anyone interested in analyzing trends in K-Dramas, developing recommendation systems, or exploring audience preferences.

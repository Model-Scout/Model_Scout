# kbo baseball for kaggle

next year's AB or OPS prediction

### Message
If you download and this data is useful,
please upvote this dataset

### Context

This data is korean baseball Batter's Hitting Dataset, for 1991 ~ 2018

### Content

This data was crawled by " https://statiz.co.kr "
The name list of the Batter was collected directly using the stadium site. (korean's ten baseball's site) (ex -samsung lions etc)

### Acknowledgements

You can study baseball terminology and data, and use that data to predict next season's record.

### Inspiration

The reason for this data was created by writing a bachelor's thesis.
Also, he was very interested in baseball, so he decided to write a thesis with the data and collected and processed it.

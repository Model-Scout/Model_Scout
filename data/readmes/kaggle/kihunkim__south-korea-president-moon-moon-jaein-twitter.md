# South Korea President Moon (Moon Jae-in) twitter

Learning Korean with Moon's twitter

### Introduction 

This dataset  is metadata of South Korea President **Moon's twittter**. from `2012.01.01` to `2020.06.16`. As a south korean I was really sad that there are not so many 
datasets about korean language. So I made it !! 

If you are interested in **Korean Natural language processing(NLP)**. This dataset will be helpful. 

**Notice** 
In the original dataset you can find not only korean but also **different langugage** (like english, because he tweets sometime english for all tweets user from worldwide). So you need to pay attention to handle it !!. But that are a few cases 😄. 

### Data structure 

`username` :  twitter account name 
`tweet_date` : Date of tweets
`tweet_time`  : Time of tweets 
`text` : content of tweets
`favorites` : number of like button 
'retweets` : number of retweets 
`link` : address for corresponded tweet posts

# Seoul Apartment location and renting Data

Show detail location with lattitude, longitude of over 19,000 apartment in Seoul

### Context

The data for studying area around each apartment in Seoul


### Content

Original data is downloaded from : https://www.juso.go.kr/addrlink/addressBuildDevNew.do?menu=match
Only apartment is extracted from the original data.

You can find city, district, road, name of building as well as Longitude & Latitude of each apartment.
These info can be used to explore the neighborhood around each one.

# Historical Currencies Convertions From Euro

1 Euro converted to every currency registered by the Frankfurter API from 1999

Dataset created to explore the convertions from 1 Euro to every currency registered by the Frankfurter API and make time series forecasting.

This dataset will be updated in the future with new values.

- Initial currency = EUR: Euro
- Amount = 1
- Initial date = 1999-01-04
- Final date = 2023-10-18

# Top 250 Webtoons & Manhwa Analytics Dataset

Ratings, popularity, genres, chapters, and synopses from top Korean comics.

### Overview
This dataset provides comprehensive metadata for the top-rated 250 Webtoons and Manhwa (Korean digital comics), extracted directly from the AniList API. It includes average user scores, global rankings, popularity counts, chapter counts, status, genres, and cleaned plot synopses.

### Data Description
- **Source:** AniList GraphQL API
- **Format:** Clean CSV (`top_webtoons_dataset.csv`)
- **Rows:** 250 entries sorted by average score

### Suggested ML & Data Analytics Use Cases
1. **Exploratory Data Analysis (EDA):** Identify top-performing genres and score distributions.
2. **Correlation Analysis:** Compare popularity rank versus average score to see if hyped webtoons match user ratings.
3. **Natural Language Processing (NLP):** Perform TF-IDF, sentiment analysis, or topic modeling on plot synopses.

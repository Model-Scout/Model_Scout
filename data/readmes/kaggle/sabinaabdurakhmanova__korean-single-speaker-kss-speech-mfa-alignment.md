# Korean Single Speaker (KSS) MFA

Text Alignment (MFA) for the Korean Single Speaker (KSS) Speech Dataset

An aligned result was generated using Montreal Forced Aligner (MFA) on the [KSS dataset](https://www.kaggle.com/datasets/bryanpark/korean-single-speaker-speech-dataset), as repeated alignment extraction is time-consuming, and MFA setup can be challenging

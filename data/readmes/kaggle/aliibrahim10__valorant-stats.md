# Valorant Leaderboard Statistics

80,000+ player data from the leaderboards

### Notes
- All data is from Epidode 4: Act 3 of the Valorant ranked leaderboards.
- 80,000+ rows and 38 columns of leaderboard data from tracker.gg.
- Since there are 38 columns, some that I think need explanation will be listed below with additional information.
- Leaderboard consists of radiant/immortal[1-3] players so that will populate the ratings column except for a few profiles that were demoted as the data was collected.


# Additional Column Information
### Gun columns:
gun columns are [name, head, body, legs, kills]
[head,body,legs] -&gt; The percentage of bullets aimed at each section with that gun

### Region:
Abbreviations of the server the players are on

AP: Asia Pacific
KR: Korea

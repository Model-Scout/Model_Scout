# Is Tourism in Seoul Disabled-Friendly?

Data of Facilities for Disabled Tourists in Seoul

# Source

This data is from "Seoul Open Data Repository" (https://data.seoul.go.kr/).
Original dataset is written in Korean. I collected the files and translated it into English using Google Spreadsheet API.

# Content

Dataset is composed of 4 csv files.  

1) Accomodation : Data of Accomodations for disabled tourists.
2) Convinence : Data of Convinence facilities for disabled tourists.
3) Restaurant : Data of Restaurants for disabled tourists.
4) Tour : Data of Tour site for diabled tourists.

Each csv file is composed of 19 columns.  

1) ID : # of ID for the facility
2) Name : Name of the facility
3) District : Name of District. If you are not familiar with district names of Seoul, check this [wikipedia page](https://en.wikipedia.org/wiki/List_of_districts_of_Seoul).
4) Address : Address of the facility
5) Contact : Phone number of the facility
6) Homepage : Website of the facility
7) Upvote : Count of recommendation provided by Seoul Open Data Repository
8) Main Entrance Access Road : Whether there is an access road to main entrance for wheelchairs. (Y/N)
9) Handicap Parking : Whether there is a disabled-only parking lot (Y/N)
10) Main Entrance Slope Way : Whether there is a slope way in main entrance (Y/N)
11) Disabled Escalator : Whether there is an escalator for disabled (Y/N)
12) Disabled Toilet : Whether there is a toilet for disabled (Y/N)
13) Disabled Lodging Facility : Whether there is a lodging facility for disabled (Y/N)
14) Disabled Seat : Whether there is a seat for disabled (e.g. in stadium, in subway, etc) (Y/N)
15) Disabled Ticket Office : Whether there is a ticket office for disabled (Y/N)
16) Service for visually-impaired : Whether there is a aiding service for visually-impaired (Y/N)
17) Service for the hearing-impaired :  Whether there is a aiding service for hearing-impaired (Y/N)
18) Information Service : Whether there is a information service center for disabled (Y/N)
19) Wheelchair Rental : Whether there is a wheelchair rental service for disabled (Y/N)

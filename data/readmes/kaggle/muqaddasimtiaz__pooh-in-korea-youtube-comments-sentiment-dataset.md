# Pooh in Korea YouTube Comments Sentiment Dataset

20 manually labeled comments for sentiment analysis

This dataset contains 20 manually labeled YouTube comments from "Pooh in Korea" channel.

**Dataset Statistics:**
- Total comments: 20
- Positive: 14 comments
- Neutral: 5 comments  
- Negative: 1 comment
- Languages: Mixed (Hindi + Urdu + English)

**Columns:**
- Comment Text: Original YouTube comment
- Sentiment: Positive/Neutral/Negative
- Reason: Why this label was assigned
- Comment Length: Number of characters
- Has Emoji?: Yes/No
- Language: Hindi/English/Mixed

**Use Case:** Sentiment analysis for code-switched social media text.

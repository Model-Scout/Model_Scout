# Korean Guidelines for Primary Physicians & ICU 

Open PDF files for primary physicians to treat commonly-seen diseases

- This is open-source guidelines for primary physicians in Korea. Inspired by this article : ["Textbooks Are All You Need"](https://arxiv.org/abs/2306.11644)
- This dataset could be used to make an QA bot or solve VQA tasks. Fine-tuning the open-sourced LLMs can be done.
- Reference : [Korean Medical Guidelines Information Center](https://www.guideline.or.kr/).
- Extracting Korean texts from PDF files : [Use PyPDF2](https://wooiljeong.github.io/python/pdf-to-text/#pypdf2)

# Model Scout 프론트엔드

Next.js 15 · React 19 · Tailwind CSS 4. 백엔드 V2 공개 API 5개만 사용한다([API 명세](../backend/docs/02-api-v2.md)).
화면 기준은 Figma v2 시안 A(홈), A-1(대화 기록), B(추천 결과 3단)다.

## 실행

```powershell
pnpm install
pnpm dev
```

`NEXT_PUBLIC_API_URL`이 API 주소다. 화면 코드는 그대로 두고 이 값만 바꿔 전환한다.

| 값 | 대상 |
| --- | --- |
| `/api/mock` | 내장 mock API (AI 없이 화면 작업·시연). 화면 오른쪽 아래에 "시연 데이터" 표시 |
| `https://49-247-194-63.sslip.io` | VPS 백엔드 (요청마다 실제 LLM 호출) |

값이 없으면 `http://localhost:8000`으로 요청하므로 Vercel에서는 반드시 설정한다. 브라우저에 노출되는 환경변수는 이것 하나다.

| 경로 | 화면 |
| --- | --- |
| `/` | 홈. 첫 요청 후 그룹 ID가 오면 주소만 `/result/{group_id}`로 바뀐다 |
| `/result/{group_id}` | 저장된 대화·결과 복원. 공유 링크 |

## Mock API

`src/app/api/mock/[...path]/`에 공개 API 5개를 계약(`backend/app/result.py`) 형식 그대로 구현했다.
클라이언트가 `${NEXT_PUBLIC_API_URL}/api/chat`을 부르므로 실제 경로는 `/api/mock/api/chat`이다.

- 켜는 조건: `next dev`이거나 서버 환경변수 `MOCK_API=1`. 그 외에는 모든 경로가 404다.
- Vercel 시연: `MOCK_API=1`, `NEXT_PUBLIC_API_URL=/api/mock` 두 값을 함께 설정한다.
- 단계 지연: `MOCK_DELAY_MS` (기본 700ms).
- 저장소는 서버 메모리다. Vercel에서는 인스턴스가 바뀌면 기록이 사라져 새로고침 복원이 404가 될 수 있다.

고정 입력으로 각 흐름을 재현한다. 추천 결과는 입력과 관계없이 따릉이 시연 데이터(모델 4, 데이터 3, ok·check·unknown 혼합)다.

| 입력 | 결과 |
| --- | --- |
| "따릉이"가 들어간 첫 요청 | 되묻기 → 같은 대화에서 답하면 추천 결과 |
| 그 밖의 첫 요청, 또는 "따릉이 [바로] …" | 바로 추천 결과 |
| 결과 화면에서 "결과에 질문" | 선택 후보의 저장된 판정을 설명. 결과 카드는 유지 |
| 결과 화면에서 "조건 바꿔 다시 추천" | 같은 대화에서 재추천 |
| "날씨" 포함 | reject 안내 |
| `[오류]` | 부분 token 뒤 SSE error |
| `[끊김]` | done/error 없이 연결 종료 |
| `[한도]` | 429, Retry-After 30 |
| `[빈결과]` | 후보 0개 결과 |
| `[저장실패]` | history_saved=false |
| 전국 자전거도로 표준데이터의 README | 404 (원문 없음 화면) |

같은 대화가 처리 중일 때 다시 요청하면 409, 다른 브라우저(세션)에서 이어서 요청하면 403이다.

## 백엔드 계약에 없는 프론트 동작

계약이 정하지 않아 프론트가 정한 것들이다. 계약이 바뀌면 이 목록부터 확인한다.

| 항목 | 프론트 동작 | 한계 · 백엔드에 필요한 것 |
| --- | --- | --- |
| 공유 링크 소유권 | `GET /api/groups` 목록에 있으면 소유자, 없으면 읽기 전용. 질문 중 403이 오면 읽기 전용으로 전환 | 목록은 최대 100개라 오래된 내 대화가 읽기 전용으로 보일 수 있다. `GroupDetail`에 소유 여부가 있으면 정확해진다 |
| 후보 지표 키 | `gpu_fit.verdict/label/needed_gib/precision`, `benchmarks[].benchmark/dataset/metric/score`를 읽는다 | 계약상 두 필드는 형식 없는 object다. 키가 없거나 다르면 미확인으로 표시한다 |
| 홈 조건 | 선택한 조건을 `조건: 언어 한국어, 실행 환경 로컬 GPU 8GB, 상업적 이용 가능.` 문장으로 query 끝에 붙이고 전송 전에 보여 준다 | 실행 환경 선택지(8/16/24GB, CPU만)는 프론트가 정했다. 시안은 "GPU 1장" |
| 대화 목록 | 제목과 수정 시각만 표시 | 시안의 "모델 4 · 데이터 3"은 `GroupSummary`에 없다. 대화 검색 API도 없어 검색창을 뺐다 |
| 저장 버튼 | 뺐다 | 저장함 API 없음 |
| 분석 취소 | 응답 수신만 끊고 "다시 요청하면 잠시 기다리거나 거절될 수 있어요"라고 안내 | 취소 API 없음. 백엔드가 진행 중 단계를 마칠 때까지 409 가능 |
| 연결 중단 | 자동 재전송하지 않고 "저장된 기록 확인" 버튼으로 그룹을 다시 조회 | 요청 멱등·재개 기능 없음 |
| 질문 대상 | 기본값은 선택한 후보(`target_id`). 칩을 눌러 추천 전체로 바꾼다 | |
| 인용 하이라이트 | README에서 quote와 정확히 같은 문장만 하이라이트. 못 찾으면 저장된 인용문을 따로 표시 | `location`은 항상 null |
| 결과 복원 | `result`가 null이 아닌 마지막 메시지의 결과·출처를 함께 쓴다. 후보 0개여도 최신 결과로 본다. 그런 메시지가 없을 때만 최상위 `result` | 백엔드 `get_group`·mock과 같은 기준이다. API 명세(02-api-v2.md)의 "비어 있지 않은 스냅샷" 문구는 구현에 맞춰 갱신이 필요하다 |
| 결과 출처 | 결과를 만든 메시지의 `sources` 중 선택 후보의 `source_id`·`kind`가 같은 것만 보여 준다 | 결과 스냅샷에 sources가 없어 메시지에서 찾는다 |
| 공유 | 링크 복사 전에 "링크를 가진 사람은 대화 전체와 결과를 볼 수 있다"고 확인 | 만료·철회 없음 |
| CORS | 브라우저가 VPS를 직접 호출 | 고정 주소(운영·고정 Preview)는 백엔드 `CORS_ORIGINS`에, PR마다 바뀌는 Preview 주소 패턴은 `CORS_ORIGIN_REGEX`로 허용한다 |
